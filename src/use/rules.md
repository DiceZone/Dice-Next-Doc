# 规则速查

跑团时随手查规则，无需翻书。Dice!Next 使用本地可扩展的规则库，离线可用、可自行增补。

## 指令

| 指令 | 说明 |
|------|------|
| `.rules 词条` / `.rule 词条` | 查询规则词条（`.rule` 为原版别名） |
| `.rules 规则书:词条` | 在指定规则书中查询 |
| `.ruleset 规则书` | 设置本群默认规则书（群管理） |
| `.rule set 规则书` | 原版设置写法，等同 `.ruleset 规则书` |

## 用法

```
.rules 大失败           → 查询（先本群默认书，再全部）
.rules coc:困难成功     → 在 COC7 规则书中查询
.rules dnd:借机攻击     → 在 DND 规则书中查询
.ruleset dnd            → 把本群默认规则书设为 dnd
.rule set dnd           → 同上（原版 Dice! 写法）
.ruleset show / clr     → 查看 / 清除默认规则书（清除也需要群管理）
```

支持词条的精确匹配与模糊（子串）匹配。

## 内置规则书

| 规则书 | 别名 | 内容 |
|--------|------|------|
| `coc7` | coc、克苏鲁 | 大成功/大失败、困难/极难成功、理智与疯狂、伤害加值、体格等 |
| `dnd` | dnd5e、5e、龙与地下城 | 优势/劣势、先攻、借机攻击、豁免、熟练加值、长短休、死亡豁免等 |

## 自定义规则书

规则书是放在 `data/rules/` 目录下的 JSON 文件（包根目录的 `rules/` 也兼容），每个文件一本：

```json
{
  "name": "coc7",
  "aliases": ["coc", "克苏鲁"],
  "entries": {
    "大失败": "技能值<50 时骰出 96-100 为大失败……",
    "困难成功": "骰值 ≤ 技能值的一半即为困难成功。"
  }
}
```

放入新文件即可扩充规则库，骰主可按自己跑的规则系统自由增补。也可在 Web 管理面板的规则页面直接编辑。

::: tip 规则包
同一个规则书 JSON 还能声明**技能同义词**（`alias`）、默认骰等「规则包」能力，词条与同义词写在一个文件里即可一起生效；成套的玩法（帮助速查、卡模板、插件等）则可打包成规则包分发、导入即用。详见[规则包编写](/develop/rulepack)。
:::
