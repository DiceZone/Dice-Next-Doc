# 娱乐与互动

轻松的日常互动指令，活跃群聊气氛。

## 指令总览

| 指令 | 说明 |
|------|------|
| `.jrrp` | 今日人品 |
| `.mrrp` | 明日人品 |
| `.zrrp` | 昨日人品 |
| `.name` | 随机姓名（别名 `.gn`） |
| `.nnn` | 随机改名 |
| `.me` | 原文代述 |
| `.ak` | 抉择分歧 |
| `.sleep` | 休息 |
| `.text` | 文本模板求值 |
| `.rpmode` | 骰娘人格切换 |
| 好感度 | 好感系统（见下） |

## 人品 `.jrrp` / `.mrrp` / `.zrrp`

```
.jrrp              → 今日人品（每人每天固定）
.jrrp on / off     → 群管理开启 / 关闭本群今日人品（持久保存）
.mrrp              → 明日人品（提前看明天）
.zrrp              → 昨日人品（回顾昨天）
```

人品值按「使用者 + 日期」确定性生成，同一天多次查询结果一致。

## 随机姓名 `.name` / `.nnn`

```
.name              → 随机一个名字（每个名字随机中/英/日）
.name en 3         → 生成 3 个英文名（cn / en / jp 可选，一次最多 10 个）
.nnn               → 随机起个名字并直接设为你的昵称
.nnn jp            → 指定日文名改名（cn / en / jp 可选）
```

不指定国家时，每个名字都随机从中文 / 英文 / 日文中选（与原版「随机姓名」混合牌堆一致）。`.nnn` 与 `.nn` 一样会同步更名当前绑定的人物卡。

## 动作代述 `.me`

让骰娘转述你输入的正文（跑团常用的「旁白」），不会自动添加发言人名称：

```
.me 推开了古宅的大门       → 推开了古宅的大门
.me on / off               → 群管理开启 / 关闭本群 .me
```

- 普通用户与 Master 都按正文代述，不自动拼接人物卡名或昵称；需要名称时请自行写入正文。
- 私聊可远程代述到指定群：`.me <群号> <动作>`。
- `.me` 可被全局或本群禁用（`.group +禁用me`）。

## 抉择分歧 `.ak`

把几个候选方案列出来，让命运替你选（按窗口保存）：

```
.ak#走哪条路               → 新建抉择「走哪条路」
.ak+左边的隧道|右边的楼梯   → 添加分支（| 分隔可一次多个）
.ak-2                      → 删除第 2 个分支
.ak show                   → 查看当前分支
.ak=                       → 随机抽取一个（抽完自动清空，同原版）
.ak clr                    → 手动清空
```

新建时也可以一句话写完：`.ak#标题+选项1|选项2`。

## 休息 `.sleep`

```
.sleep             → 骰子去休息，返回一句休息语
```

## 好感度系统

骰子会记住与你的好感度，并给出称号（厌恶 / 陌生 / 友好 / 亲密 / 挚友 / 恋人）。

```
好感               → 查看你的好感与称号（无需前缀）
好感排行           → 全局好感排行
群内好感排行       → 本群好感排行
```

骰主 / 高信任用户（信任等级 ≥ 4，见[群管与系统](/use/admin)）可以调控好感，可带 `@某人` 指定对象：

```
.好感增加 10       → 增加好感（也可写 .favor add 10）
.好感成长          → 按原版 DiceFavor 规则掷一次成长
.好感覆写 50       → 直接覆写好感值（.favor set）
.好感擦除          → 清除全部好感记录（.favor clr）
```

好感越高，自然成长越难（复刻原版 DiceFavor 的成长判定）。

## 文本模板 `.text`

`.text` 会把文本里 `{大括号}` 内的表达式与变量求值后输出，兼容海豹 SealDice 的 `.text`。

开发中的旧版随机分项兼容也支持 `.text {sample:效果拔群|干得漂亮}`，候选项可包含 `.text` 支持的变量或骰式；build 909 及之前尚不支持。

```
.text 看看手气 {1d16}      → 看看手气 7
.text {$t玩家} 掷出 {2d6}   → 变量与掷骰混排
```

## 骰娘人格切换 `.rpmode`

一套「人格」是对骰娘回复文案的一组覆盖。切换人格后，骰子的各种回复会换成该人格的口吻。人格在后台[指令列表页](/manage/commands)创建与编辑。

```
.rpmode                    → 查看当前人格与可用人格列表
.rpmode set 傲娇           → 切换到「傲娇」人格
.rpmode off                → 当前窗口明确关闭人格，使用基础/全局自定义文案
.rpmode default            → 清除当前选择，重新继承适配器或全局默认人格
.rpmode inherit            → 同上，继承适配器或全局默认人格
.rpmode copy 傲娇 温柔      → 从「傲娇」复制出「温柔」人格（Master）
.rpmode del 温柔           → 删除人格（Master，内置人格不可删）
```

群或频道可以分别选择人格；切换需要群管理员、邀请人或骰主权限。QQ 官方机器人不再因暂时读不到群角色而把所有成员视为管理员；未来平台提供可信群角色后会沿用同一权限入口。邀请人可以调整人格、骰子开关等非破坏性群设置，但不能仅凭邀请人身份执行踢人、禁言等平台管理操作。

普通用户在私聊中选择人格时，只影响自己与当前适配器的私聊，不会修改骰子的全局人格。可选项由骰主在该适配器的「人格与用户选择」中决定；未开放的人格不会出现在列表中，也不能用名称绕过限制。`off` 是当前窗口明确不用任何人格，`default` / `inherit` 则删除当前覆盖并继承适配器或全局默认。`copy` / `del` 等管理操作仍仅 Master 可用。
