# 角色卡管理

Dice!Next 内置完整的人物卡系统，支持多角色卡、随机生成、卡片锁定、群名片同步与检定统计。

## 指令总览

| 指令 | 说明 |
|------|------|
| `.st` | 录入 / 修改 / 查看属性 |
| `.pc` | 多角色卡管理（新建/绑定/生成/锁定/删除） |
| `.en` | 技能成长（详见[掷骰与检定](/use/dice)） |
| `.nn` | 设置在骰子中的昵称 |
| `.nnn` | 随机改名（抽随机姓名并设为昵称） |
| `.sn` | 按模板设置自己的群名片 |
| `.setsn` | 设置本群名片显示哪些属性 |
| `.hiy` | 检定统计 |

## `.st` 录入属性

```
.st 力量50 敏捷60 hp12/12     → 录入属性，hp/san/mp 可写「当前/上限」
.st hp-2                       → 增减（支持骰子表达式，如 san+1d3）
.st show                       → 查看当前角色卡
.st show 60                    → 只看 ≥60 的属性
.st show 力量 敏捷             → 只看指定的几项
.st del 力量                   → 删除某属性
.st clr                        → 清空角色卡（含关联属性/公式/武器/上限）
.st export                     → 导出为可直接 .st 重新导入的一行文本
.st fmt                        → 按同义词表归一属性名（转卡）
```

支持中英文与常见别名自动归一（如「计算机 / 电脑 / 计算机使用」识别为同一技能）。

### 武器与伤害加值

```
.st &手枪=1d10+2   → 绑定武器「手枪」，之后 .r 手枪 直接掷伤害
.st db=1d4         → 手动录入伤害加值（存公式原文，不会摇成数字）
```

`db`（伤害加值）是**公式属性**：录入的是投掷公式，掷骰时才展开（`.r 1d3+db`）。未手动录入时，录卡后会按 COC7 规则由「力量+体型」查表**自动计算**并在回执中提示；手动录入的值优先保留。

### 关联属性（表达式联动）

```
.st 物防=敏捷+1     → 物防始终等于「敏捷+1」，敏捷变了它跟着变
.st pd='dex+1'     → 英文属性引用需加引号
```

关联属性存的是表达式，读取（检定、`.st show`）时按当前引用属性求值，显示为「物防=敏捷+1(=61)」。

### 自动卡面重算

开启自动卡面（默认开，仅 COC 模式）后，修改 体质 / 体型 / 意志 / 克苏鲁神话 等基础属性时，HP / SAN / MP 会**按上限变化的差值**同步当前值（例如 4/13 → 体质提升后 6/15，而非重置为满），并附带一行「（自动卡面）因 … 变化，已自动重新计算」的提示。

## `.pc` 多角色卡

```
.pc new 张三       → 新建角色卡「张三」
.pc tag 张三       → 在本群绑定使用「张三」
.pc rename 李四    → 给当前卡更名
.pc untag          → 解除当前绑定（卡片仍保留）
.pc list           → 列出我的角色卡
.pc del 张三       → 删除
.pc @某人          → 查看对方的角色卡
```

绑定角色卡后，掷骰昵称会自动显示为该卡名。

### `.pc build` 随机生成

```
.pc build          → 按 COC7 模板随机生成人物卡（已有值的属性跳过）
.pc build pc:bg    → 冒号分隔连用多个模板（pc=COC7 属性，bg=背景）
.pc redo           → 先清空当前卡再重新生成
```

模板可自定义：把 JSON 模板放进 `card-templates/`（或 `data/card-templates/`）目录并重启骰娘，即可追加新的生成参数，支持骰点公式、牌堆抽取文本与 JS 表达式（暂不支持随[规则包](/develop/rulepack)分发，需手动放置）。

### `.pc lock` 卡片锁定

```
.pc lock w         → 锁定写入（.st 等修改一律拒绝）
.pc lock r         → 锁定查看
.pc unlock w       → 解锁
```

适合守秘人要求「锁卡」的场合，防止跑团中途改卡。

## `.npc` NPC 群共享角色卡

`.pc` 管理的是「你个人」的角色卡；`.npc` 管理的是**整个群共享**的 NPC 角色卡，供守秘人给 NPC 建卡、代掷。仅能在群聊中使用。

```
.npc new 老猎人           → 新建 NPC「老猎人」
.npc list                → 列出本群所有 NPC
.npc 老猎人 st 力量50 敏捷60 → 给 NPC 录属性（语法同 .st）
.npc 老猎人 ra 侦查        → 以「老猎人」的身份代掷侦查检定
.npc show 老猎人          → 查看该 NPC 的角色卡
.npc del 老猎人           → 删除 NPC 及其角色卡
.npc clr 老猎人           → 清空该 NPC 的属性（保留 NPC）
```

`.npc <名> <子指令>` 会以该 NPC 的身份执行子指令（如 `st` 录卡、`ra`/`rc` 代骰），回复前会标注 `【NPC：老猎人】`。代骰过程中不能再嵌套调用 `.npc`。

## `.nn` / `.nnn` 昵称

```
.nn 阿强           → 设置骰子内昵称为「阿强」
.nn                → 清除昵称
.nnn               → 随机起名并设为昵称（随机中/英/日姓名）
.nnn jp            → 指定日文姓名（可选 cn / en / jp）
```

已绑定角色卡时，`.nn` / `.nnn` 会同时把绑定卡更名，保持两处名字一致。

## 群名片 `.sn` / `.setsn`

```
.setsn hp san dex  → 设置本群名片显示这几项（需群管理）
.sn                → 按群模板更新自己的群名片
.sn auto           → 开启自动同步：属性变化时即时更新群名片
.sn auto off       → 关闭自动同步
.sn off            → 清除
```

`hp` / `san` / `mp` 会自动按 COC 规则推导上限并显示为「当前/上限」。

## 检定统计 `.hiy`

```
.hiy               → 查看总体检定统计
.hiy 侦查          → 查看某技能的出目次数 / 成功率 / 等级分布
```

::: tip 数据可视化
角色卡也可在 [Web 管理面板 → 玩家管理](/manage/dashboard) 中查看与编辑。
:::
