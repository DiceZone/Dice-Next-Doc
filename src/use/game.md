# 团务管理（.game）

`.game` 是移植自原版 Dice! 的团务系统：在群里「开团」建立游戏领域，管理 GM 与玩家名单、团变量，以及防刷点的轮盘骰。所有团务指令仅在**群聊**中可用。

## 指令总览

| 指令 | 说明 |
|------|------|
| `.game new [团名]` | 开团（需群管理，开团者自动成为 GM） |
| `.game join` / `.game exit` | 玩家上桌 / 退出 |
| `.game master` | 自任 GM，或（已是 GM 时）列出 GM 名单 |
| `.game state` | 查看团状态（GM / 玩家名单 / 团变量） |
| `.game set <变量> <值>` | 设置团变量（GM） |
| `.game call` | @ 全体玩家点名（GM） |
| `.game kick <QQ>` | 把玩家踢下桌（GM） |
| `.game close` / `.game open` | 暂时关闭 / 重新展开游戏领域 |
| `.game over` | 结团（清空全部团数据） |
| `.game rou 面数[*份数]` | 启用轮盘骰（GM），另有 `rou hist/reset/clr` |

不带参数的 `.game` 会显示帮助。

## 开团与名单

```
.game new 迷雾之城     → 开团（不填团名会自动生成一个）
.game join             → 玩家报名上桌
.game master           → 申请成为 GM / 查看 GM 名单
.game state            → 团状态一览
.game kick 10001       → GM 踢人下桌
.game exit             → 自己退出（GM 退出也用这条）
```

- 开团需要**群管理权限**；开新团会清掉本群旧团的数据。
- 首个 GM 之外再添 GM 需要群主 / 群管理 / 骰主确认（复刻原版权限规则）。

## 团变量

GM 可以给这一团记录任意键值（如章节、天气、时间线）：

```
.game set 章节 第三章   → 设置团变量（也可写 .game set 章节=第三章）
.game set 章节          → 查看单个变量
.game state             → 团状态会列出全部变量
```

团变量与 Lua 模组的 `msg.game` / GameTable 数据互通，模组可以直接读写同一份团数据。

## 暂关与结团

```
.game close            → 暂时关闭游戏领域（保留名单与变量）
.game open             → 重新展开
.game over             → 结团，清空全部团数据
```

若本群还有进行中的[跑团日志](/use/log)，`.game over` 会提醒你用 `.log end` 结束记录。

## 轮盘骰 `.game rou`

轮盘骰用于防止「重骰刷点」：GM 为某个面数启用后，本群的 `1dN` / `dN` 单骰掷骰改为**袋中不放回抽取**——把 1..N 各放一份（或多份）进袋子，抽一个少一个，抽空自动重填。

```
.game rou 20           → 为 d20 启用轮盘骰（袋中 1~20 各 1 份）
.game rou 6*3          → 为 d6 启用，1~6 各 3 份（面数×份数最多 100）
.game rou hist         → 查看本轮已抽出的点数记录
.game rou reset        → 复原袋子（清空抽取记录，重新装满）
.game rou clr          → 清除轮盘骰，恢复普通掷骰
```

启用 / 复原 / 清除均需 GM；轮盘只拦截**单骰单轮**的 `1dN` 掷骰，其它表达式不受影响。游戏领域关闭（`.game close`）期间轮盘也随之停用。
