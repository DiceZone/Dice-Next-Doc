# 掷骰与检定

所有指令以 `.`（英文句号）开头，也支持 `。`、`!`、`！`。指令中的参数请使用**英文半角**符号。

> 本页覆盖「通用掷骰」「COC 检定」「BRP 检定」「DND」四大类。角色卡相关见[角色卡管理](/use/card)，娱乐指令见[娱乐与互动](/use/fun)。

## 通用掷骰

| 指令 | 说明 |
|------|------|
| `.r` / `.rs` | 完整掷骰 / 仅显示最终值，默认骰面可用 `.set` 修改 |
| `.rd` | 掷默认骰（`.rd6` 等带面数写法则掷指定骰） |
| `.rh` / `.h` / `.H` | 暗骰，结果私聊发送给你（`.h` / `.H` 为原版短别名） |
| `.rah` / `.rch` | 暗检定（COC），结果私聊发送 |
| `.rx` | 心理学暗骰（守秘人用） |
| `.ww` | WOD 骰池（成功数统计，出 10 加骰） |
| `.dx` | 双十字（Double Cross）连锁掷骰 |
| `.set` | 设置 / 重置个人默认骰面，或切换本群规则系统 |

### `.r` 掷骰

```
.r 3d6+2 攻击      → 掷 3d6 加 2，原因「攻击」
.r3d6+2 攻击       → 同上，指令与表达式之间的空格可省略
.r 2#d20           → 连掷 2 次 d20
.rs 3d6+2          → 只显示最终值，不展开每颗骰子
.rd                → 掷默认骰（未设置时为 d100）
.rd6               → 掷 d6
.r 1d3+db          → db 自动展开为人物卡的伤害加值公式
```

`db`（伤害加值）在表达式中会自动替换成人物卡里录入的公式；未手动录入时按 COC7 规则由「力量+体型」现算。详见[角色卡管理](/use/card)。

### `.rh` / `.h` 暗骰与暗检定

```
.rh 1d100          → 暗骰，结果私聊发给你
.h 1d100           → 同上；大写 .H 也可用，且不会占用 .help
.rah 侦查           → 暗检定（读卡），结果私聊
.rch 侦查 60        → 暗检定（指定成功率），结果私聊
```

群里只会提示「某人进行了暗骰」，他人看不到点数；房规（`.setcoc`）、奖惩骰等照常生效。

### `.rx` 心理学暗骰

```
.rx @某人          → 对被 @ 的调查员掷一次心理学检定
.rx @某人 40       → 指定成功率
```

守秘人专用：含成功等级的详细结果**私聊发给你**，群里只出一句不剧透的回执。省略成功率时读对方人物卡的「心理学」，默认 10。

### `.ww` WOD 骰池

```
.ww 8              → 掷 8 个 d10，≥8 计一个成功，10 额外加骰
.ww 8 7            → 成功线改为 7
```

与 `.r` 不同，`.ww` 统计的是**成功数**而非点数总和。

### `.dx` 双十字

```
.dx 3c8            → 3 个骰，临界值 8（达到即爆发加骰）
.dx 5 10           → 等价写法（空格分隔）
.dx 5a7            → a 写法：无限加骰骰池（数成功个数，WOD 风格）
```

### `.rs` 简短结果 / Fate（NdF）

```
.rs 3d6+2          → 仅显示最终值，不展示完整计算过程
.rsh d100          → 简短结果与暗骰标记可组合
.r 4dF             → 掷 4 个命运骰（Fate / FUDGE）
```

`.rs` 复刻原版 Dice! 的短结果语义；Fate 骰仍由 `NdF` 表达式提供。命运骰每颗结果为 `+`、`0`、`-`（即 +1 / 0 / −1），完整结果形如 `4dF=[+ − 0 +]=1`。

### `.set` 默认骰与规则系统

```
.set 20            → 把个人默认骰设为 d20（1-9999）
.set               → 重置为 d100
.set list          → 列出可切换的规则系统（★ 标记本群当前）
.set coc7          → 切换本群规则系统并联动默认骰面（需群管理）
```

设置默认骰后，`.r` 不带表达式与 `.rd` 都会掷默认骰。规则系统由[规则包](/develop/rulepack)提供，切换后包内的指令、同义词等按群生效。

## COC（克苏鲁的呼唤）

| 指令 | 说明 |
|------|------|
| `.coc` | 生成 COC7 调查员属性 |
| `.ra` / `.rc` | 技能 / 属性检定（自动读取角色卡） |
| `.rb` / `.rp` | 奖励骰 / 惩罚骰 |
| `.rad` | 先掷 d100 再用同一骰值做检定 |
| `.rav` | 对抗检定 |
| `.sc` | 理智检定（自动扣 SAN 并存卡） |
| `.en` | 技能成长 |
| `.ti` / `.li` | 临时 / 不定疯狂症状 |
| `.setcoc` | 设置本群房规（大成功/大失败规则） |
| `.hiy` | 检定统计 |

### COC 制卡 `.coc`

```
.coc / .coc7       → 生成一组 COC7 调查员属性
.coc6              → 生成一组 COC6 调查员属性
.cocd / .coc7d     → COC7 详细制卡结果
.coc6d             → COC6 详细制卡结果
.coc7d 3           → 一次生成 3 组（最多 10 组）
```

原版用于列宽排版的尾随 `s` 标记也可接受，例如 `.coc7ds 3`；它不改变数值规则。

### 检定 `.ra` / `.rc`

```
.ra 侦查           → 读取角色卡侦查值检定
.ra 力量60         → 临时指定数值检定
.ra 困难侦查        → 困难难度
.ra 侦查 @某人      → 代某人检定（读他的卡）
.ra 2#侦查         → 连续检定 2 次
```

检定自动判定成功等级：大成功 / 极难 / 困难 / 成功 / 失败 / 大失败，并受本群 `.setcoc` 房规影响。

### 奖励 / 惩罚骰 `.rb` / `.rp`

```
.rb 侦查           → 1 个奖励骰
.rp2 60            → 2 个惩罚骰，对 60 检定
.rapass23          → 黏着写法：按「最长指令优先」解析为 .rap ass 23
```

### `.rad` 同骰值检定

```
.rad               → 掷一个 d100，直接以它作为「d」检定
.rad 侦查          → 第一行按 .r 展示掷骰过程，第二行用同一个骰值对侦查判定
```

适合「先亮骰再对技能」的玩法：两行用的是**同一个骰值**。

### 对抗检定 `.rav`

```
.rav 侦查 @某人     → 双方各掷 d100，先比成功等级，再比点数
.rav 斗殴 60       → 己方读卡，对方直接给数值
```

### 理智检定 `.sc`

```
.sc 1/1d6          → 成功扣 1，失败扣 1d6；自动从角色卡扣 SAN
.sc 1d3/1d10 50    → 指定当前 SAN 为 50
.sc b 1/1d6        → 带 1 个奖励骰的理智检定（.scb 亦可）
.sc p2 1/1d6       → 带 2 个惩罚骰
```

### 技能成长 `.en`

```
.en 侦查            → 对侦查掷 d100，大于当前值（或 >95）则成长 1d10 并存卡
.en 侦查 60         → 临时指定技能值
.en 侦查 +1d6       → 自定成功成长值（以 +/- 开头）
.en 侦查 -1/+1d10   → 「失败成长/成功成长」两段式
.en 侦查 聆听        → 批量成长（也可写 .en 侦查|聆听）
```

### 疯狂症状 `.ti` / `.li`

```
.ti                → 抽取一个临时性疯狂症状
.li                → 抽取一个不定性疯狂症状
```

### 房规 `.setcoc`

```
.setcoc 2          → 设置本群 COC 房规为规则 2（可选 0-7）
.setcoc show       → 查看当前房规
.setcoc clr        → 清除（恢复规则 0）
```

规则 0-7 的大成功/大失败判定方式各不相同，`.ra`/`.rc`/`.rb`/`.rp`/`.sc`/`.rav` 都会按当前房规判定。可用 `.rules coc:大失败` 速查各房规的判定细则（见[规则速查](/use/rules)）。

### 检定统计 `.hiy`

```
.hiy               → 查看总体检定统计
.hiy 侦查          → 查看某技能的出目次数 / 成功率 / 等级分布
```

## BRP（基础角色扮演系统）

| 指令 | 说明 |
|------|------|
| `.ba` | BRP 检定（d100 低骰） |
| `.bav` | 抵抗表对抗 |

### `.ba` BRP 检定

```
.ba 侦查           → 读卡检定
.ba 斗殴60         → 指定成功率
.ba 侦查 @某人      → 代骰
.ba 2#侦查         → 连掷
```

成功等级：大成功 ≤ 技能/20、特殊成功 ≤ 技能/5、成功 ≤ 技能、失败 > 技能、大失败（骰出 100，或失败且骰出 99）。

### `.bav` 抵抗表对抗

```
.bav 力量 体型      → 主动方力量 vs 被动方体型（属性名读卡，也可直接填数值）
```

目标% = 50 +（主动 − 被动）× 5，掷 1d100 ≤ 目标则主动方胜。

## DND（龙与地下城）

| 指令 | 说明 |
|------|------|
| `.dnd` | 生成 DND 属性（4d6 取高 3） |
| `.setdnd` | 开关本群 DND5e 模式 |
| `.rc` | DND 模式下的 d20 检定（优势/劣势） |
| `.buff` | 临时属性加值 |
| `.ri` / `.init` | 先攻列表 |
| `.ss` | 法术位管理 |
| `.cast` | 消耗法术位施法 |
| `.longrest` | 长休（回血 + 法术位全恢复） |
| `.ds` | 死亡豁免 |

### DND 模式 `.setdnd`

```
.setdnd on         → 开启本群 DND5e 模式（.rc 改为 d20 检定）
.setdnd off        → 关闭（.rc 恢复 COC d100）
.setdnd            → 切换
```

### d20 检定 `.rc`

DND 模式下 `.rc` 变为 d20 检定，属性值（含 `.buff` 加值）作为调整值：

```
.rc 力量           → 1d20 + 力量调整
.rc 优势 力量+2     → 优势（两个 d20 取高），额外 +2
.rc 劣势 敏捷       → 劣势（取低）
.rc 5 攻击         → 直接给调整值 5
```

### 调整值检定 `.rdc`

`.rdc` 直接对「属性调整值」做检定：属性按 `(属性值−10)/2` 向下取整，技能读取独立检定加值。

```
.rdc 力量+2 破门 15       → 1d20 + 力量调整 +2，理由「破门」，阈值 15（≥ 视为成功）
.rdc 3# B 力量+2 破门 15  → 3 轮，B 取高（P 取低）
```

轮数最多 9，用 `N#` 前缀。`.rdc` 仅在已开启 DND5e 模式的群可用（`.setdnd on`）。

### 临时加值 `.buff`

```
.buff 力量:2       → 设置力量 +2 的 Buff
.buff 力量+1       → 增减
.buff              → 查看当前 Buff
.buff del 力量     → 删除某项
.buff clr          → 全部清除
```

Buff 会计入 DND 模式的 `.rc` 检定与属性读取。

### 先攻 `.ri` / `.init`

```
.ri +2             → 投 d20+2 加入先攻
.ri +2 哥布林       → 指定名字加入
.init              → 按先攻值排序查看
.init clr          → 清空先攻列表
.init del 哥布林    → 删除某条
```

### 法术位 `.ss` / `.cast`

```
.ss init 4 3 2     → 设置 1/2/3 环法术位上限
.ss set 3环 5      → 单独设置某一环
.ss 3环 -1         → 增减
.ss                → 查看当前法术位
.ss rest           → 全部恢复
.ss clr            → 清除设置
.cast 3            → 消耗 1 个 3 环法术位
.cast 3 2          → 消耗 2 个
```

### 长休 `.longrest` / 死亡豁免 `.ds`

```
.longrest          → HP 恢复至上限，法术位全部恢复（也可写 .长休）
.ds                → 死亡豁免检定（也可写 .死亡豁免），需 HP 为 0
```

死亡豁免按 DND5e 规则：累计 3 次成功稳定、3 次失败死亡；骰出 20 直接回复 1 HP，骰出 1 记 2 次失败。长休需要先用 `.st hpmax:<值>` 设置生命上限。

## 指令约定

- 标点用英文半角；`[必填]`、`(可选)`。
- 多轮检定用 `N#` 前缀，避免刷屏。
- **指令与参数之间的空格可以省略**（与原版 Dice! 一致）：`.help指令`、`.ri+2`、`.rd6` 均合法。交叉时按「最长指令优先」解析（如 `.rapass23` = `.rap ass 23`）；想让短指令吃字母参数时请用空格隔开。
- 触发频率限制后会有冷却，请耐心等待。
