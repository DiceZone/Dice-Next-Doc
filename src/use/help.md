# 帮助与语言

Dice!Next 内置一套统一的帮助注册表：内置指令说明、规则包词条、插件注册的帮助、以及可自定义的帮助文档都汇入同一个 `.help`，还可以按群锁定搜索域、切换回复语言。

## 查帮助 `.help`

```
.help              → 指令总览菜单
.help ra           → 查看某条指令 / 某个词条的帮助（.help .ra 也行）
.help 克苏鲁       → 词条不限于指令，规则速查、牌堆说明等都能查
```

- 词条支持**模糊匹配**：唯一命中直接显示；多个候选会列出让你挑；找不到会提示。
- 帮助来源（按统一注册表汇总，重名自动去重）：
  1. **内置**指令说明；
  2. **规则包**自带的帮助词条（本群激活的规则包，其同名词条优先生效）；
  3. **插件**（JS / Lua）注册的帮助；
  4. **帮助文档**（`data/helpdoc/` 与各规则包 `helpdoc/` 目录下的 JSON）。
- 超长的帮助内容会自动分段发送。

### 溯洄引用

帮助词条内容支持溯洄格式函数：`{词条}` 展开另一个词条的内容（可递归），`[{%_1D3}*10]` 这类含 `{}` 的方括号块会当算式求值；不含 `{}` 的 `[示例]` 保持原样。牌堆卡面也支持同一套引用语义（见[牌堆](/use/deck)）。

## 自定义帮助 `.helpdoc`

`.helpdoc <词条>` 与 `.help <词条>` 等价；不带词条时给出使用提示（完整条目请到网页后台「帮助文档」页浏览 / 搜索）。

自定义帮助文档放在 `data/helpdoc/` 目录（`*.json`，兼容海豹 SealDice 帮助文档格式）：

```json
{
  "mod": "我的速查",
  "brief": "一句话简介",
  "helpdoc": {
    "词条名": "词条内容",
    "别名": "&词条名"
  }
}
```

值以 `&` 开头表示别名（指向另一词条）。规则包也可以在包内 `helpdoc/` 目录随包分发帮助，词条来源会标成 `<包名>/<mod>`。

### 默认来源 `.helpdoc default`

多个来源有同名词条时（例如 dnd3r 与 dnd5r 都有「猫头鹰熊」），可指定优先来源：

```
.helpdoc default           → 查看当前默认来源与可选来源
.helpdoc default dnd5r     → 同名词条优先用 dnd5r
.helpdoc default clear     → 取消（恢复按加载顺序）
```

### 搜索域 `.helpdoc scope`

比默认来源更强：把本群的帮助搜索**锁定**在某个来源内，其余来源的词条一律过滤（内置指令说明仍保留）。适合跑某个特定规则时防止查到别家内容：

```
.helpdoc scope coc7包      → 本群 .help 只查该来源
.helpdoc scope clear       → 解除锁定
.helpdoc scope             → 查看当前搜索域
```

## Web 管理

在 Web 管理面板的「帮助文档」页可以浏览、搜索全部帮助词条，并可视化编辑自定义帮助文档。

## 语言切换 `.lang`

骰子回复支持四种内置语言：简体中文 / 繁体中文 / English / 日本语。群管理可切换本群语言，私聊里则切换你自己的：

```
.lang                  → 查看当前语言与用法
.lang 繁體             → 切换（简体 / 繁體 / en / 日本語 及各种常见别名都能识别）
.lang clr              → 清除覆盖，恢复默认
```

### 自定义语言包

把翻译文件 `<语言码>.json` 放进 `i18n/` 目录即可自动加载为新语言；包内的 `_meta.keywords` 声明这门语言的切换关键词（之后 `.lang <关键词>` 就能切过去）。目录里附带 `_custom_language_example.json` 模板可供参考，改内置语言的个别文案同理。

### AI 翻译语言

如果 `.lang` 的参数既不是内置语言也没有对应翻译文件，还会查骰主在 AI 设置中登记的 **AI 翻译语言**：命中后该窗口的回复会在发送前由大模型实时翻译成目标语言（回复会稍有延迟，且骰点数字保证不被改动）。详见 [AI 功能](/use/ai)。
