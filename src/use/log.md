# 跑团记录（Log）

Dice!Next 可记录群内跑团过程，结束时整理上传到日志站并发送群文件，方便回顾与归档。

## 指令总览

| 指令 | 说明 |
|------|------|
| `.log new [名称]` | 新建并开始记录 |
| `.log on` / `.log off` | 继续 / 暂停记录 |
| `.log end` | 结束记录，上传取链接并发群文件 |
| `.log halt` | 强行结束本次记录（不上传） |
| `.log list [页码]` | 本群日志列表（分页） |
| `.log get [名称]` | 重新上传某份日志并取回放链接 |
| `.log del <名称>` | 删除日志 |
| `.log stat [名称]` | 统计（条数 / 参与者 / 时段 / 发言最多） |
| `.log export [名称]` | 只把日志发到群文件（不上传日志站） |
| `.log type txt/html` | 设置群文件格式（群管以上） |
| `.log time` / `.log timer` | 跑团计时 |
| `.log masterget <群号> [名称]` | 骰主跨群取某群日志的链接 |
| `.log` | 查看当前记录状态 |

省略名称的子指令默认操作本群最近一份日志。

## 使用流程

```
.log new 第一章     → 开始记录
…正常跑团…
.log off            → 中途暂停（休息）
.log on             → 回来继续（回复会引用暂停处的消息，方便定位）
.log end            → 结束，上传并发群文件
```

同一群同时只能有一份进行中的日志；跑崩了不想留档可用 `.log halt` 直接掐掉。

## 记录内容

记录是否进行由**群总开关、日志功能开关和日志会话状态**共同决定。`.bot off` 或 `.bot log off` 会停止记录与计时并保留会话；重新开启后，原本进行中的日志继续记录，手动 `.log off` 暂停的日志不会自动恢复。关闭期间的消息不会事后补录，彻底禁用和黑名单等限制仍有效。

- 完整保留发言、掷骰结果与图片（图片默认在本地缓存一份，导出 HTML 时内嵌）。
- 结束时自动上传日志站，返回可分享的回放链接；同时把日志作为**群文件**发送。
- 群文件格式由 `.log type` 决定：`txt` 纯文本（默认）或 `html` 自包含网页（含内嵌图片，可直接离线打开）。

## 只记日志

由群管理员配置功能开关，再按原有日志权限启动记录：

```text
.bot on
.bot log on
.bot roll off
.bot reply off
.bot plugin off
.log new 第一章
```

之后用 `.log off/on` 暂停或继续，`.log end` 结束。恢复正常使用时，按需要重新开启 `roll`、`reply`、`plugin`。AI、欢迎语、转发及自动化有各自开关，如不需要也请关闭；上述配置不会禁用全部管理或娱乐指令。

## 跑团计时

```
.log timer on/off   → 开关本群跑团计时
.log time           → 查看当前记录的累计时长
```

开启后，`.log new/on/off/end` 会自动开始 / 暂停 / 累计本次跑团时长。

## 日志站上传

- 默认上传到官方日志站 `log-api.dice.zone`，默认使用 **DiceNext 专属 zstd JSON 协议**；已有安装保留此前保存的协议选择。
- 地址与协议在[系统设置 → 云服务 → 日志站](/manage/cloud-services#日志站)修改。`dice/logsite_format` 可选 `dicenext`（默认）、`seal`（SealDice V1）、`seal_v105`（Parquet）或 `legacy`（旧版多段 txt POST）；连接自建站时须选择该站支持的协议。
- 上传目标**不是官方站**时，回复链接会附加提示「当前配置的日志站并非官方站点，链接安全性请自行确认」。

## Web 管理

### 平台文件发送差异

`.log export` 只导出文件，不上传日志站。OneBot / Milky 的群文件能力取决于所连接的协议端；QQ 官方机器人已接入富媒体文件通道，但文件发送仍受账号权限、平台限制及上传结果影响，不能把本地导出成功等同于平台已收到文件。

遇到平台拒绝或收不到文件，可用 `.log get` 上传并取回放链接，或从下方 Web 管理下载。QQ 官方的接口接入与真实凭据下端到端验收是两回事，详见[适配器配置](/config/adapter#qq-官方机器人能力边界)。

### 面板下载与管理

在 Web 管理面板的 **数据管理 → 跑团记录 → 日志管理** 中可以：

- 查看全部群的历史记录（名称 / 创建人 / 起止时间 / 条数 / 占用空间），并按任一列排序
- 占用空间包含日志数据库中实际保存的内容与 `data/logs/images` 中该日志的本地图片；图片容量会单独标出
- 导出 TXT 或 Excel（CSV），下载 HTML 网页版
- 手动上传到日志站取链接，或在样式化二次确认后删除记录；删除会一并清理日志消息与本地缓存图片

面板的群组管理还提供**群文件查看与下载**，跑团发出的日志群文件也能在这里直接取回。
