# 跑团记录（Log）

Dice!Next 可记录群内跑团过程，结束时整理上传到日志站并发送群文件，方便回顾与归档。

## 指令总览

| 指令 | 说明 |
|------|------|
| `.log new [名称]` | 新建并开始记录 |
| `.log on` / `.log off` | 继续 / 暂停记录 |
| `.log end` | 结束记录，上传取链接并发群文件 |
| `.log halt` | 强行结束本次记录（不上传） |
| `.log list [页码]` | 本群日志列表（分页） |
| `.log get [名称]` | 重新上传某份日志并取回放链接 |
| `.log del <名称>` | 删除日志 |
| `.log stat [名称]` | 统计（条数 / 参与者 / 时段 / 发言最多） |
| `.log export [名称]` | 只把日志发到群文件（不上传日志站） |
| `.log type txt/html` | 设置群文件格式（群管以上） |
| `.log time` / `.log timer` | 跑团计时 |
| `.log masterget <群号> [名称]` | 骰主跨群取某群日志的链接 |
| `.log` | 查看当前记录状态 |

省略名称的子指令默认操作本群最近一份日志。

## 使用流程

```
.log new 第一章     → 开始记录
…正常跑团…
.log off            → 中途暂停（休息）
.log on             → 回来继续（回复会引用暂停处的消息，方便定位）
.log end            → 结束，上传并发群文件
```

同一群同时只能有一份进行中的日志；跑崩了不想留档可用 `.log halt` 直接掐掉。

## 记录内容

- 完整保留发言、掷骰结果与图片（图片默认在本地缓存一份，导出 HTML 时内嵌）。
- 结束时自动上传日志站，返回可分享的回放链接；同时把日志作为**群文件**发送。
- 群文件格式由 `.log type` 决定：`txt` 纯文本（默认）或 `html` 自包含网页（含内嵌图片，可直接离线打开）。

## 跑团计时

```
.log timer on/off   → 开关本群跑团计时
.log time           → 查看当前记录的累计时长
```

开启后，`.log new/on/off/end` 会自动开始 / 暂停 / 累计本次跑团时长。

## 日志站上传

- 默认上传到官方日志站 `log-api.dice.zone`，使用与 SealDice（海豹）日志站相同的 **SealDice V1 协议**（zlib 压缩 JSON、PUT 上传），因此也可以直接指向任何海豹兼容的自建日志站。
- 上传地址可在系统设置中修改（配置键 `dice/logsite_url`，留空恢复官方站）；上传协议可选（`dice/logsite_format`）：`seal`（默认，SealDice V1）、`legacy`（旧版多段 txt POST）、`dicenext`（DiceNext 专属 zstd JSON 格式）等。
- 上传目标**不是官方站**时，回复链接会附加提示「当前配置的日志站并非官方站点，链接安全性请自行确认」。

## Web 管理

在 Web 管理面板的 **数据管理 → 跑团记录 → 日志管理** 中可以：

- 查看全部群的历史记录（名称 / 创建人 / 起止时间 / 条数 / 占用空间），并按任一列排序
- 占用空间包含日志数据库中实际保存的内容与 `data/logs/images` 中该日志的本地图片；图片容量会单独标出
- 导出 TXT 或 Excel（CSV），下载 HTML 网页版
- 手动上传到日志站取链接，或在样式化二次确认后删除记录；删除会一并清理日志消息与本地缓存图片

面板的群组管理还提供**群文件查看与下载**，跑团发出的日志群文件也能在这里直接取回。
