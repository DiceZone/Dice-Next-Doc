# coc7r：Keeper Companion 选用规则

此功能对应 Chaosium 的 **Call of Cthulhu Keeper Companion（2026，CHA23197-H）**。这是第七版的补充书，含多个可选机制；`coc7r` 是 Dice!Next 的配置名，不代表官方发布了独立的新版本号。以下页码是书内印刷页码。

## 启用与返回

群管理员输入：

```
.set coc7r
.coc7r help
```

恢复原先的 CoC7：

```
.set coc7
```

切换只选择本群的规则，不会转换或覆盖已有卡片。原有 CoC7 的房规仍保留；`coc7r` 的技能检定房规单独保存，默认规则 0。`.coc7`、`.coc6` 仍显式生成原版人物属性。

WebUI V1、V2 的「规则管理」均可编辑此包的默认选项。更新内置资源不会覆盖保存到 `data/rules/` 的修改或停用状态。

## 默认机制与可选项

| 项目 | 实际行为 | 书内页码 |
| --- | --- | --- |
| 属性池 | 8 个 `(2D6+5)×5`，由玩家自由分配；不擅自写入卡片 | 9–10 |
| 购点／预设 | 480 点；上限 90，建议下限 30；10 组预设数组 | 9–10 |
| 兴趣／职业 | 兴趣 EDU+INT；自定义职业额外 300 点，6–12 技能含信用；职业选择由玩家与 KP 确认 | 11–15 |
| 技能 | 修订基础值；安抚 APP/5；社交技能输入按说服处理；保留旧卡原字段，不合并旧技能数值 | 15、17–24 |
| 移动 | `7+(STR>SIZ)+(DEX>SIZ)`，保留年龄修正；单次移动 ×2 米/码、整回合移动 ×4 | 10、62 |
| 成长 | 原成长判定保留；可选成功后固定 +5；实际技能从不足 90 达到 90 时恢复 2D6 SAN，受上限限制 | 49–51、94 |
| 理智 | 震惊、余震、Changed、现实检定与恢复辅助；按游戏章节记录累计损失 | 85–99 |

可选项默认关闭：

```
.coc7r options bases on
.coc7r options specialties on
.coc7r options take5 on
.coc7r options
```

分别为「按属性计算技能基础值」「格斗／射击专长最低值」「成长成功后取 5」。用 `off` 关闭。群聊内的选项优先于规则包默认值。已录入的技能总值不会随属性变化重算；专长下限仅影响有效值，不重写原数值。显式成长表达式（如 `.en 侦查0+3`）保留原意。

宗教、语言、科学等应指定专长，例如 `.st 宗教(道教)30`、`.ra 母语(汉语)`。不能仅凭「冲锋枪」判定技能：需根据实际武器选择手枪或步枪／霰弹枪。旧卡上的取悦、话术、恐吓不会自动变成同值的说服；由 KP 确认转换后再 `.st 说服数值`。

## 建卡与移动

```
.coc7r
.coc7r 3
.coc7r array 1
.coc7r points
.pc new 新调查员
.st STR60 CON60 SIZ50 DEX65 APP60 INT70 POW60 EDU65 年龄30
.coc7r init
.coc7r mov
.st show 兴趣点
```

生成器只给属性池，分配后须自行保存。年龄引起的属性调整、幸运、职业、兴趣技能点分配仍需按书和 KP 要求完成。`init` 仅在 SAN 尚未录入时以 POW 初始化并限制在最大 SAN 内。当前 SAN 和初始 POW 是独立数值。

## 理智与状态

```
.sc 0/1d6
.sc 0/1d6 mythos
.coc7r loss 1d4 mythos
.coc7r show
```

`mythos` 表示 KP 已确认该损失来自克苏鲁神话，程序不从描述猜测原因。书籍、法术等直接损失用 `loss`，不会额外掷一次 SAN。普通 `.sc` 禁用奖励／惩罚骰和孤注一掷，失败表达式的大失败取可计算的最大损失。支持非负整数、NdM 与加减组合；不支持的表达式会报用法，不会随机猜最大值。

- 指定数值如 `.sc 0/1d6 50` 只计算，不写卡，也不会猜测 POW、INT 或累计状态。
- 自动结算需卡上有 SAN、POW、INT。SAN 与状态一次性保存；锁卡、并发修改或保存失败会拒绝写入。
- 单次实际损失达到 5 时掷 INT；成功进入震惊，玩家选择表现，持续 1D10 回合。已处于 Changed 时阈值为 10。
- 震惊期间不再损失 SAN；不按现实钟表自动解除。实际结束后用 `.coc7r endshock confirm`。
- 余震到在安全地点睡过一夜才结束，用 `.coc7r sleep confirm`。
- 本章累计损失达到 POW 的五分之一时进入 Changed。五分之一按官方属性分数规则向下取整；例如 POW=51 时为 10。
- `.coc7r chapter confirm` 重置累计损失与本章安抚恢复次数，不解除 Changed。
- `.coc7r recover confirm` 仅在 KP 确认至少一周休养、并修订锁定背景后使用。不会自动写背景或选择恐惧症。
- SAN=0 是 Lost，恢复命令拒绝继续治疗。恢复 SAN 不减少累计损失。

状态随卡片保存，改名、重启后保留；各平台／适配器／会话的章节记录分开。人物卡本身仍沿用原有共享规则：若同一张卡绑定在多个群，卡上的 SAN 也仍是同一个数值。

`.st` 属于手动改卡，不自动推断损失来源或执行理智流程。需要记入章节的扣点请用 `.sc` / `loss`。POW 被手动调整后可用 `.coc7r loss 0` 按新阈值重新结算状态。没有自动推断旧卡历史累计值。

## 安抚、神话成长与现实检定

```
.ra 安抚
.coc7r reassure @对方
.coc7r reassure @对方 push
.coc7r reassure 对方用户ID
.coc7r mythos first
.coc7r mythos later
.coc7r reality
.coc7r reality assisted
```

`reassure` 可以 @ 对方，也可以直接写对方的用户 ID。它会写入他人的卡，只允许群管理员代为结算；普通玩家可先 `.ra 安抚` 后请 KP 处理。目标须已有卡和所需数值，不能安抚自己。成功可恢复 2 SAN（每章只受益一次、受最大 SAN 限制），并结束震惊、暂时抑制恐惧症；余震保留。用过本章 SAN 恢复后，仍可进行其他安抚效果。

**安抚的大失败／失败孤注一掷暂采用 1D4 SAN 损失。** 原书第 22 页写 1D4，第 94 页写 1D6；这是当前明确选择的处理方案，不声称已有官方勘误。`push` 仅能在之前一次安抚失败并获 KP 允许后使用，程序不会验证完整的叙事过程。

神话导致的震惊／Changed 会登记待结算事件。同一事件同时触发两者只计一次；不同事件分别排队。首次选择 `first` 加 5，之后 `later` 加 1。旧卡是否曾经历此事件由玩家确认，程序不根据已有神话技能值猜测；已确认过的卡不能再次领取首次奖励。

现实检定成功后记录幻觉抵抗，下一次 SAN 损失解除；失败损失 1 SAN。`assisted` 表示另一个调查员已经成功安抚协助，此时加 1 奖励骰。

## 恢复理智

在 KP 确认相应条件后：

```
.coc7r reward 1d6
.coc7r therapy 80
.coc7r therapy 80 phobia
.coc7r therapy 80 push
.coc7r selfhelp INT 30 5
```

- `reward` 结算章节末的 KP 奖励。
- `therapy` 每游戏月一次，使用治疗者技能或机构评级。成功恢复 1D3，或选择 `phobia` 移除一项恐惧症；失败不恢复；大失败／失败孤注一掷损失 1D6 并提示治疗关系结束。恐惧症和治疗关系由 KP 记在背景中。
- `selfhelp` 用于成长阶段。先掷 INT 或 POW，再输入**已掷出的 D100 结果**及可选幸运花费，程序结算这次结果，不重掷。例如 INT=50、骰值 30、花幸运 5 后达到困难成功，恢复 1D6。未达困难成功损失 1 SAN，并提示修订、锁定背景；不能花超过现有的幸运或修改大失败。
- 技能在实际游戏中经 `.en` 从不足 90 达到 90，自动结算 2D6 SAN 奖励；创建或手动修改技能不会自动领奖。
- 所有恢复遵守 `99−克苏鲁神话` 上限。Changed 时 `.en 幸运` 会拒绝恢复，但仍能按规则花费幸运。

治疗月份、成长阶段和 KP 奖励资格使用游戏内时间，由 KP 确认，不由服务器日期自动授权。自助输入已有结果不会校验外部聊天中那次骰值。

## 战斗与追逐计算辅助

```
.coc7r fire 20 8 2
.coc7r spray 50
.coc7r chase 7 fail 3
```

集中自动射击 20/50/100 发，伤害与护甲同时乘 5/10/20；扫射对应 5/10/20 米区域，对每个目标独立判定、难度提高一级，伤害不倍增。三连发只掷一次伤害，不乘 3。这些指令不替 KP 判定命中、射程、护甲类型或掩体。

追逐输入当前 MvP 与已经判定的成功／失败／失败孤注一掷。失败掷 1D6 消耗 MvP，仍有 MvP 才前进一步；归零则退出，失败孤注一掷直接退出。起始 MvP 通常等于 MOV，重伤减半。地点、障碍、检查难度、队友帮助和剧情后果仍由 KP 管理。

## 实现边界

本包提供可重复计算的机制和现有骰子指令适配，**不是整本书的自动主持系统**。圆桌先攻的座位方向、近战枪械反击的许可、群体敌人、爆炸场景、重伤／濒死治疗流程、可选快速治疗、非标准生物属性训练、职业列表和背景叙事仍由 KP 使用基础掷骰和书中规则处理；不会在开启 `coc7r` 后自动改写这些流程。
