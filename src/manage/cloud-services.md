# 云服务

**管理面板 → 系统设置 → 云服务**，管理骰娘的云服务连接、授权与同步。

## 骰娘密钥

1. 在 [账号中心](https://account.dice.zone/dashboard/bindings) 验证骰娘所有权并生成正式 API Key。
2. 在「骰娘密钥配置管理」中选择对应适配器，填写并保存密钥。
3. 按需要配置下方的心跳、云黑名单或云人物卡功能。

每个适配器分别保存密钥。平台连接页原有密钥入口仍可使用，两处修改同一份配置；已有配置无需重填。已有密钥仅显示末四位，输入框留空不修改，只有明确选择清除并保存才删除。

骰娘 API Key 与 WebUI 管理 API Key、平台连接 Access Token 不同，请勿混用。自动获取的未验证心跳 Key 不能代替云人物卡所需的正式 Key。

## 心跳上报

打开心跳服务开关，保存后点击「立即测试」，查看最近上报时间和结果。默认服务为 [heart.dice.zone](https://heart.dice.zone)，也可填写自建地址。

- **骰主信息**：昵称和 QQ 可选；两项均留空时沿用骰主列表与玩家档案的自动读取规则，填写后使用手工信息。
- **公开展示**：控制是否出现在心跳广场与搜索，不等同于停用心跳服务。
- **上报间隔**：180–480 秒，默认 240 秒；上线时立即上报，之后周期保活。
- **离线状态**：正常退出会补报离线；崩溃或断网由服务端超时判定。

## 云黑名单

配置同步开关、服务地址、独立 Token、本地拉黑自动上报、最低危险等级及同步周期；可查看最近结果并立即同步。

独立 Token 留空时兼容旧心跳 Token，再回退到已配置的适配器骰娘 Key，不要求为了云黑先开启公开心跳展示。

- 上报记录先等待云端核验，通过后才参与下发。
- 达到危险等级门槛的有效记录并入本地黑名单，并显示云黑标记。
- 云端注销只解除对应的云黑来源记录，不删除骰主独立添加的本地黑名单。

[权限设置](/manage/permissions#云黑名单)保留本地黑名单管理和云黑标记，云端连接与同步设置在本页管理。

## 云人物卡

骰主配置正式骰娘 Key 后，玩家在**私聊骰娘**中使用 `.cloud auth` 授权；默认只读，写入需使用 `.cloud auth write` 并在账号中心确认。

后台不代替玩家授权，不展示玩家令牌。拉取、上传、同步与退出授权均由玩家使用 `.cloud` 指令完成，详见[云服务与身份绑定](/use/cloud)。

目前为手动同步：本地卡仍是跑团时使用的数据，令牌过期或骰子重启后需重新授权；冲突不会强制覆盖双方内容。

## 日志站

配置 `.log end` / `.log get` 上传日志的目标地址与协议，并可恢复默认配置。

默认官方地址为 `log-api.dice.zone`，默认协议为 DiceNext 专属 zstd JSON（`dicenext`）。也可选择 SealDice V1（`seal`，zlib JSON）、SealDice V105（Parquet）或旧版多段 txt 协议（`legacy`）；请与目标站点支持的协议对应。已有安装保留已保存的协议选择。

非官方地址会显示第三方站点提示。配置前请确认服务可信，上传会将跑团记录发送到所选站点。具体用法见[跑团记录](/use/log)。

## 其他设置在哪里

- 图床、图片发送与日志图片保存仍在[基础设置](/manage/settings#图片相关)，支持原有配置作用域。
- 通知窗口及推送在[通知设置](/manage/notice)，人工智能与程序更新仍有各自入口。
- 旧的 `#/settings?tab=cloud` 等后台链接仍兼容跳转；也可在顶栏搜索「云服务」「心跳」「云人物卡」直接进入相关卡片。
