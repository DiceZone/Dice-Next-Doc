# 通知设置

**管理面板 → 系统设置 → 通知设置**，管理骰主通知的接收窗口、第三方推送与审计日志，分三个选项卡。

## 通知窗口

通知窗口是接收骰主通知的聊天（群或私聊）。点「添加窗口」后从群组 / 人员列表**搜索勾选**（支持按群名、昵称或 QQ 号搜索）；也可以直接在聊天里发 `.notice on`（仅骰主）把当前窗口设为通知窗口，详见[管理指令](/use/admin)。

每个窗口可**逐项勾选**要接收的通知事件；事件按四个区域分组，区域标题的勾选框 = 全选 / 全不选该区域：

| 区域 | 级别值 | 包含事件 |
|------|--------|----------|
| 例行通知 | 1 | 信任等级变更、账号别名绑定 |
| 重要通知 | 2 | 好友申请、新好友已添加、加群邀请、退群（定时/不活跃/网页）、指令退群 (.dismiss)、骰娘被移出群、黑名单自动退群、非好友邀请拒绝/退群、群名含关键词退群、定时任务触发、全局开关变更、敏感词规则命中（实际发送级别随规则等级变化）、发现新版本、更新结果 |
| 关键通知 | 4 | 管理权限增减、拉黑操作 |
| 错误通知 | 8 | 运行错误、更新失败 |

用指令 `.notice level <n>` 订阅时（1 例行 / 2 重要 / 4 关键 / 8 错误，可叠加，15 = 全部），默认勾选对应区域的全部事件。

更新检测属于系统事件，没有具体来源群。账号级通知窗口会优先使用该窗口绑定的适配器发送；自动安装结果会由 Windows 管理器在重启后回报，并核对实际运行版本。升级前已经创建且逐项筛选事件的窗口不会被擅自扩展订阅范围，请按需勾选“发现新版本”“更新结果”“更新失败”和“敏感词规则命中”。

## 第三方推送

不在 QQ 上也能收到通知：

### SMTP 邮件推送

填写 SMTP 服务器、端口、账号、密码 / 授权码、发件人与收件人即可。465 端口勾选 SSL；587 端口取消勾选（走 STARTTLS）。

### Webhook 推送

把通知以 JSON `POST` 到第三方地址（可对接钉钉 / 飞书 / 自建服务的中转），报文格式：

```json
{ "ts": "…", "level": 2, "op": "…", "msg": "…", "origin": "…" }
```

两种推送都按**区域**过滤（不区分具体事件），发送在后台进行，失败静默（可查服务器日志）。「发送测试通知」按钮会走全部渠道发一条测试消息并记入审计，方便验证配置。

## 审计日志

表格展示最近 200 条通知事件（时间 / 级别 / 事件 / 发生地 / 内容），级别用颜色标签区分。全部通知事件持久化在 `data/audit/notice_*.jsonl`，可随时回溯。

::: tip
无论有没有配置通知窗口，事件都会写入审计日志——窗口和推送只决定「有没有人被主动告知」。
:::
