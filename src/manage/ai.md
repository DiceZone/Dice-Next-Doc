# 人工智能

**管理面板 → 人工智能**，接入 OpenAI 兼容的大模型，为骰娘提供回复润色、翻译、对话、NPC 扮演、图像识别等能力。侧栏分为五个子页：**模型 / 对话 / NPC 扮演 / 回复润色 / 回复翻译**（编辑状态共享，任意子页点「保存」即保存全部）。

::: warning 费用与延迟
开启 AI 后，相关功能会按你配置的模型计费，且被 AI 处理的回复会有延迟（取决于网络与大模型响应速度）。请给每个模型设好 token / 费用限额。所有 AI 功能失败或超时都会回退：润色 / 翻译发原文，对话不回复。
:::

## 模型

### 总开关

「启用人工智能」是所有 AI 功能的总开关，关闭时润色、翻译、对话等全部不生效（其它子页会置灰并提示先到「模型」页打开）。

### 全局请求参数

所有 AI 调用共用的参数（润色 / 翻译会另用较低温度以求忠实）：温度 temperature、top_p、最大 token、频率惩罚、存在惩罚。

### 模型列表

可添加多个模型来源，每个模型卡片包含：

| 字段 | 说明 |
|------|------|
| 显示名 | 自定义名称，如「GPT-4o mini」「本地 Qwen」 |
| 接入地址 Base URL | OpenAI 兼容接口地址，默认 `https://api.openai.com/v1` |
| 模型名 model | 如 `gpt-4o-mini`、`qwen2.5` |
| API Key | 本地模型可留空 |
| 输入价 / 输出价 | 每百万 token 单价，用于费用统计 |
| token 上限 / 费用上限 | 0 = 不限；超限后该模型停止调用 |

每个模型显示已用 token 与累计费用，并有「测试」按钮：实测一次请求，返回延迟、token 数与估算费用。各功能（润色 / 翻译 / 对话 / 摘要 / 识图 / NPC）都可以分别指定模型，留空则用首个启用的模型。

## 对话

让骰娘在群里像真人一样聊天（仅群聊生效）。

### 触发方式（三态）

- **被 @骰娘**：必定回复，不受冷却限制。
- **命中关键词**（逗号分隔，如「骰娘, 在吗」）：必定回复，不受冷却限制。
- **待机概率**（0–100）：其余消息按概率随机搭话，受「每群冷却(秒)」限制，别设太高否则会频繁插话。

### 生成参数

上下文轮数（读取本群近期聊天记录作为上下文）、回复最大字数、每群冷却秒数、回复时是否 @ 发送者、是否禁止输出 emoji、自定义过滤词（喂给 AI 前从文本里删掉水印 / 签名 / 刷屏词），以及人设与系统提示词（留空用内置默认，可点「载入默认」在模板基础上修改）。

### 群历史记忆（滚动摘要）

对话超出近期窗口后，把更早的聊天按批压缩成一份群摘要注入背景，让骰娘记得更久之前的事。可配置摘要模型、保留轮数（折叠批大小）、摘要字数上限与摘要提示词；页面内可查看 / 清空已存的各群摘要。仅当滑出窗口的消息攒够一批才调用模型（天然限频、控成本）。

### 长期记忆（持久事实 · 向量检索）

从对话里抽取值得长期记住的事实（人物卡 / 剧情 / 约定），向量化存库；聊天时按当前话题相似度检索最相关的几条注入。可配置嵌入连接与嵌入模型名（如 `text-embedding-3-small`，需与对话模型分开填）、事实抽取模型、检索条数 Top-K、相似度阈值、每群事实上限与抽取提示词；同样可查看 / 清空已存事实。

### 工具调用

开启后骰娘用 function-calling 调用真实功能，而不是自己编数字（需模型支持 tools）：

| 工具 | 说明 |
|------|------|
| `roll_dice` | 掷骰，走真实骰子引擎 |
| `draw_deck` | 抽牌堆 |
| `get_attr` | 读发送者人物卡属性 |
| `set_attr` | 写发送者人物卡（有风险，默认关闭） |
| `run_command` | 执行任意指令 / 插件（权限同发送者） |
| `search_help` | 在帮助文档里查词条 |

「最大工具轮数」限制连环调用次数，最后一轮强制输出文本回复。仅在「对话」开启时生效。

### AI 白名单（访问控制）

开启后，只有白名单内的群 / 私聊能使用 AI 对话与 NPC；非白名单群即使群管发 `.ai on` 也会被拒绝，防止未授权群消耗 API 费用。名单从群组 / 玩家列表搜索勾选添加。白名单只控制对话 / NPC / 群记忆；回复润色与翻译是全局功能，不受影响。

### 图像识别（多模态）

消息带图片时，用多模态模型识别图片内容得到文字描述注入对话，让骰娘「看懂图」。仅在被 @ 或命中关键词等触发时才识别（控成本）。可配置识图模型（可与对话模型分开）、单条最多识别张数与识图提示词。

**图链直传**开关：开启时直接把 QQ 图片链接传给大模型（快，但链接可能过期）；关闭则下载后以 base64 上传（慢但可靠）。

## NPC 扮演

定义 NPC（名字 / 人设 / 背景知识 / 触发词）。群里消息提到 NPC 名字或命中触发词时，骰娘以该 NPC 的身份、口吻、知识回复（复用记忆与工具调用，优先于默认骰娘对话）。可用于扮演旅店老板、神秘线人等。

每个 NPC 可设置：触发词（除名字外）、专属模型（可选）、限定群（如 `onebot_v11:123456`，留空 = 全部群）、人设与背景知识（只有角色知道的信息）。**情绪记忆**开启后，NPC 对每个玩家维护好感度（-100~100）与情绪，语气随关系变化；每次互动后用模型评估好感增减（额外一次请求）。

## 回复润色

掷骰 / 检定类回复发送前，用大模型按人设与情境润色。两种方式：

- **仅润色措辞**：保留数字 / 结果，只改说法。
- **按情境增加 rp 描述**：在结果基础上加入角色扮演描写。

可设置人设 / 风格与系统提示词（可「载入默认」修改）。模型须严格保留原始数字与成功 / 失败结果——服务端会校验数字，被改坏时自动回退原文；失败或超时也发原文。

**覆盖范围**：润色与翻译都按类别勾选生效——掷骰/检定、牌堆抽取、娱乐指令（今日人品 / 疯狂 / 随机名等）、自定义回复、插件结果。

## 回复翻译

配合 `.lang` 实现自定义语言：先在页面定义语言（名称 + 切换关键词，如名称「德语」、关键词「de, german, 德语」），群里 / 私聊发 `.lang <关键词>` 即可切换。回复先按默认语言生成，发送前由大模型翻译成目标语言（带缓存，同文本不重复计费）。翻译提示词可用 `{lang}` 占位目标语言名。失败或超时自动发原文；切回内建语言或 `.lang clr` 即停用翻译。

## 聊天侧指令

`.ai on/off` 可分群开关本群 AI 功能（对话 / NPC），详见[管理指令](/use/admin)。白名单模式开启时，非白名单群 `.ai on` 也会被拒绝。

::: tip AI 不会拖慢指令
所有大模型调用都在独立的后台队列串行执行，不占用消息线程——即使 AI 接口卡住 30 秒，普通指令也照常秒回；堆积过多时直接丢弃新的 AI 任务（对话不回、润色回退原文）。
:::

::: tip 先在测试台预览
可在「指令测试」页发 `.r` 或聊天内容，直接预览润色 / 翻译 / 对话效果，无需进群。见[指令测试](/manage/playground)。
:::
