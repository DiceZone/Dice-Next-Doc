# 指令列表

**管理面板 → 指令列表**，一处查看全部指令并**自定义骰娘的回复文案**，同时管理骰娘的**人格**。

页面顶部有人格下拉与「人格管理」按钮，下方按分类分选项卡展示所有可编辑文本。

## 选项卡

| 选项卡 | 内容 |
|---|---|
| 全部文本 | 所有指令的回复文案（可逐条自定义） |
| 全部变量 | 文案里可用的变量说明 |
| 无效文本 | 引用了但已不存在的孤立文案键（便于清理） |
| 各分类 | 通用 / COC / DND / 娱乐 / 工具 / 管理等，按功能归组 |

顶部搜索框可按键名或文本过滤。每条文本右侧的 `编辑` 可改写；被改过的条目会标一个 `●`，可一键**还原**为默认文案。

## 自定义回复文案

骰子几乎所有回复（掷骰结果、检定成功 / 失败、各种提示）都以模板文本存储，可在此改写口吻，并使用变量：

- 指令专属变量以浅色 chip 展示在编辑器里；
- 通用变量（标 **全局变量**）用「插入全局变量」按钮插入，如 `{nick}`、`{user}` 等。

每条文案都明确保存一种输出格式：

- **纯文本**：默认选择，也是旧版自定义文案、插件回复和历史人格文案的兼容格式。用户输入的 `**`、`#`、`>`、下划线等字符会按原文发送，不会被猜测为 Markdown 后误删。
- **Markdown**：仅在明确选择后启用。QQ 官方机器人、Discord、KOOK 等支持 Markdown 的平台会按富文本发送；OneBot 等纯文本平台会在适配器出口自动降级，保留可见文字、CQ 码和骰子表达式。

编辑弹窗下方同时提供两种实时示例：

- **Markdown 平台**：预览支持富文本的平台预计看到的效果；
- **OneBot / 纯文本**：调用与实际发送相同的后端降级器，预览 OneBot 等平台预计收到的文字。

模板变量会用示例值代入预览；这只用于查看排版，不会执行真实骰点，也不会发送消息。

> 改写文案不会改变指令逻辑，只改变对外措辞。想给不同场景多套口吻，请用下面的「人格」。

## 骰娘人格

一套**人格**是对上述回复文案的一组覆盖。切到某个人格后编辑文案，改动只保存到该人格；群内用 [`.rpmode`](/use/fun) 切换人格即可整体换一套口吻。

- **人格下拉**：选「默认（全局）」编辑全局文案，或选某人格编辑其专属覆盖。选中人格时页面会提示「正在编辑人格『…』」。
- **人格管理**（按钮）：新建 / 复制 / 重命名 / 删除人格，或设为默认。内置人格不可删除。

聊天侧对应指令见[娱乐与互动 → 骰娘人格切换](/use/fun)。

## 导入 / 导出

右上角 `导出` / `导入` 可备份或迁移全部自定义文案与人格覆盖，便于在多台部署间同步。

::: tip 兼容性
指令习惯已全面兼容青果骰（OlivaDice）与海豹骰（SealDice），从这两者迁移的用户可直接沿用熟悉的指令。
:::
