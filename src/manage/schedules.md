# 定时任务

**管理面板 → 系统设置 → 定时任务**，设置每日定时向群 / 私聊推送消息（早安问候、跑团提醒、活动公告），也能加**触发条件**、**插件指令**与**退群动作**做「因果」式自动化（如定时调用 DailyNews，或「7 天没人用就退群」）。

## 新建任务

| 字段 | 说明 |
|------|------|
| 名称 | 任务备注名 |
| 时刻 | 每日触发时间（时:分） |
| 目标类型 | 群 / 私聊 |
| 目标号码 | 群号 / QQ 号 |
| 星期 | 多选周一~周日；不选 = 每天 |
| 动作 | **发送消息** / **执行插件指令** / **退群** |
| 触发条件 | 留空 = 无条件按时触发；填 `inactive>=7` 表示本群 ≥7 天无指令才触发。支持 `>=` `>` `<=` `<` `==` |
| 内容 / 插件指令 / 告别语 | 发送动作填推送文本；插件动作填完整触发指令；退群动作可填退群前的告别语 |

内容支持变量与函数渲染：`{self}`、`{group}`、`{date}`、`{roll:1d100}`（投骰）、`{draw:牌堆}`（抽牌堆）等。

::: tip 因果示例：不活跃自动退群
动作选「退群」、条件填 `inactive>=7`，即「到点检查，本群 7 天以上没人用指令就发告别语并退群」；群里有人用过指令则当天跳过。
:::

## 执行插件指令

动作选择「执行插件指令」后，内容填写插件平时在聊天中接收的完整指令，例如：

```text
.dailynews
.专长 星质形 ASTRAL_AQUAN
求签 月老
```

任务到点后会在所选帐号和群 / 私聊上下文中调用已启用的 **SealDice JS 插件或 Dice! Lua 插件**，并把插件返回内容发送到目标。也支持「立即执行」测试。

该动作使用专门的低权限虚拟消息，只进入 JS / Lua 插件指令层，不会执行 `.admin` 等 Dice!Next 内置管理指令。插件在目标群被单独停用时同样不会运行。

### 从聊天中添加本群任务

骰主也可以直接在目标群或私聊中创建插件指令定时任务：

```text
.admin clock + 本群早报 07:30 .dailynews
.admin clock + 本群求签 08:00 求签 月老
.admin clock list
.admin clock - 本群早报
```

命令创建的任务会记录当前骰娘帐号、平台和群 / 私聊目标，并立即出现在管理面板的定时任务列表中；它与网页新建的「执行插件指令」任务相同，可以编辑时间、星期、触发方式、目标和指令，也可以启停、立即执行或删除。同一窗口使用相同名称再次添加会更新原任务，不会重复创建。

也支持原版紧凑写法，例如 `.admin clock+本群早报=7:30 .dailynews`。只有骰主能通过 `.admin clock` 新增或删除任务；定时执行时仍使用低权限插件上下文。

## 行为

- 到达设定时刻、当天尚未触发、星期匹配、且触发条件满足时，自动执行一次。
- **单点推送，不群发**——只作用于你指定的目标，避免刷屏 / 封号风险。

## 管理

- 列表中可随时用开关**启用 / 停用**任务，或**删除**。
- 点编辑图标可**编辑**已有任务（表单回填，改完保存）。

## 旧 Dice! Lua 插件定时任务

单文件 Lua 插件通过 `task_call['任务名'] = '全局函数名'` 登记定时入口后，骰主可直接在聊天中配置：

```text
.admin clock + 任务名 07:30
.admin clock list
.admin clock - 任务名
```

这类任务也会显示在本页列表中，动作标记为「Lua 插件任务」；可停用、立即运行或删除。`7:30` 与 `07:30` 两种时间写法都可用。任务的发送目标由插件函数内部的 `sendMsg` 决定，因此不提供普通任务的目标与内容编辑表单。只有骰主可以执行 `.admin clock`。

DailyNews 等旧插件使用的 `.admin notice group/QQ … +8` 订阅与 `.send notice 8 …` 推送会自动接入本项目的统一通知窗口，不需要逐个修改插件源码。

::: tip 定时上下班
想要「上班问候 + 晚安」？建两条任务即可（例如 09:00 一条、23:00 一条）。
:::
