# 适配器管理

**管理面板 → 平台连接**，添加、启停与监控连接。连接状态每几秒自动刷新，无需手动刷新页面。

## 添加适配器

点击「添加连接」，表单为**渐进式引导**：先选连接方式，选定后才出现地址等后续字段。

| 字段 | 说明 |
|------|------|
| 适配器名称 | 识别用显示名 |
| 适配器类型 | OneBot v11 |
| 连接模式 | 正向 WebSocket / 反向 WebSocket |
| 连接地址 / 端口 | 正向填端点地址（如 `ws://127.0.0.1:3001`）；反向填本程序监听的端口 |
| Access Token | 认证令牌（可选），留空则不校验 |

- 连接模式旁有 **? 帮助图标**，悬停显示正向 / 反向的详细说明；选定后表单内也会显示对应提示。
- 正向地址会**自动纠正**协议头（漏写补 `ws://`，`http/https` 自动转 `ws/wss`），非法地址与端口有即时校验提示。

### 传输模式说明

| 模式 | 行为 | 框架处配置 |
|------|------|------|
| 正向 WebSocket（`forward_ws`） | 本骰作为 WS 客户端，**主动连接**登录框架的 OneBot v11 WS 服务端 | 选「WebSocket服务端 / 主动WebSocket / 正向WebSocket」，填框架监听端口 |
| 反向 WebSocket（`reverse_ws`） | 本骰作为 WS 服务端在本地端口监听，**等待框架连入** | 选「反向WebSocket / 被动WebSocket / WebSocket客户端」，填 `ws://本机IP:端口` |

::: tip 区分正向 / 反向
按「谁主动发起连接」区分：正向＝Dice!Next 去连框架；反向＝框架来连 Dice!Next。两端配置要一一对应。
:::

反向 WS 适配器可点「连接方式」查看**连接信息**：自动列出本机 / 内网 / 公网三种可填地址，并提示公网访问需在服务器防火墙 / 安全组开放端口。

## 编辑 / 测试 / 删除

- **编辑**：修改后保存，适配器会按新配置重连。**适配器平台类型创建后不可修改**（需换平台请删除重建）。
- **测试**：检查端点是否可达。
- **重连**：手动立即重连。
- **删除**：移除该适配器。

## 断线重连与退避

连接断开后自动重连，采用退避策略：前 10 次每 5 秒重试 → 第 11~20 次每 60 秒重试 → 超过 20 次暂停并显示「**连接超时**」状态（区别于「已禁用」），此时点「启用」可手动恢复重连。连接需保持 30 秒以上才重置重试计数，避免「短暂连上又断」导致无限快速重连。

连接异常时，可在[运行概览](/manage/dashboard)的最近日志里查看详细的连接 / 收发信息排查。
