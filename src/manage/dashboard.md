# 管理面板总览

Dice!Next 自带 Web 管理面板，浏览器打开服务地址（默认 `http://localhost:18088`）即可进入。绝大多数配置都能在面板里完成，无需改文件。

::: tip 登录与安全
- **登录密码**：在 [WebUI 设置](/manage/settings#webui-设置页) 中设置管理面板登录密码后，打开面板需先输入密码（Cookie 会话认证）；留空保存即关闭登录。
- **API Key**：后端接口的访问密钥，与配置文件中的 `server/api_key` 保持一致。
- 面板要暴露到公网时，务必两者都设置。
:::

## 全局设置搜索

管理面板顶栏提供全局设置搜索，桌面端也可按 `Ctrl+K`（macOS 为 `⌘K`）打开。搜索会同时匹配页面名、功能大类、具体设置、说明以及常用别名，例如 `Markdown`、`敏感词`、`SMTP`、`密码`、`定时任务`。结果会显示具体功能、所属页面和内容摘要；仅通过别名命中时还会标出命中的关键词。例如搜索“更新”或“升级”都会显示“检测与自动更新”，搜索“翻译”会直接显示“AI 翻译（.lang 自定义语言）”，并可定位到对应子页面和功能卡片。

选择结果后会直接打开对应页面；系统设置、通知设置和 WebUI 设置中的具体项目还会自动切换到正确选项卡、滚动到目标卡片并短暂高亮。搜索弹窗、结果列表和键盘选择均使用面板自身样式，不依赖浏览器原生下拉框。
## 菜单与页面

侧栏按功能分组，当前全部页面如下：

### 顶层页面

| 页面 | 作用 |
|------|------|
| 运行概览 | 状态卡片（在线适配器 / 运行时间 / 活跃记录 / 自定义回复数）与最近日志 |
| [指令测试](/manage/playground) | 不连 QQ 直接发指令试回复（可切场景、平台、回复语言、昵称） |
| [平台连接](/manage/adapter-manager) | 添加 / 管理 OneBot 适配器连接 |
| [高级回复](/manage/replies) | 自定义回复、因果规则与计数器 |
| 指令列表 | 全部指令、文案与变量（可自定义所有回复文本，含骰娘人格管理） |
| [帮助文档](/manage/help-docs) | `.help` / `.helpdoc` 帮助词条的可视化查看与编辑 |

### 扩展管理

| 页面 | 作用 |
|------|------|
| [插件](/manage/plugins) | Lua 模组与 JS 插件分选项卡管理（上传 / 启停 / 配置 / 重载） |
| [规则](/manage/rules) | 规则包管理与可视化规则编辑器 |
| 牌堆 | 牌堆文件上传 / 管理（用法见[牌堆与随机](/use/deck)） |

### 数据管理

| 页面 | 作用 |
|------|------|
| [群组管理](/manage/groups) | 按群管理（开关 / 成员 / 模拟聊天 / 日志 / 群文件 / 分群 AI 与插件） |
| [玩家管理](/manage/players) | 玩家档案、信任 / 好感与玩家详情页 |
| [权限设置](/manage/permissions) | 用户信任等级、白名单、骰娘识别与黑名单 |

### 人工智能

模型、对话、NPC 扮演、回复润色、回复翻译五个子页，详见 [AI 功能](/manage/ai)。

### 系统设置

| 页面 | 作用 |
|------|------|
| [系统设置](/manage/settings) | Master、指令前缀、审批策略、全局设置、数据迁移等 |
| [通知设置](/manage/notice) | 骰主通知窗口、SMTP / Webhook 推送与审计日志 |
| [WebUI 设置](/manage/settings#webui-设置页) | 登录密码、API Key、运行 IP / 端口、主题、控制台日志模式 |
| [定时任务](/manage/schedules) | 定时 / 条件触发的推送与自动退群任务 |
| 备份恢复 | 数据备份与恢复 |

另有「开发计划」（内置路线图）与「关于项目」（版本 / 协议信息）两个信息页。

## 运行概览

- **状态卡片**：在线适配器数、运行时间、活跃记录数、自定义回复数。
- **最近日志**：后台日志滚动显示，便于排查连接 / 收发问题（详细程度可在 [WebUI 设置](/manage/settings#webui-设置页) 切换）。

## 系统托盘（Windows）

- 程序启动后**默认隐藏控制台窗口，最小化到系统托盘**（首次会弹气泡提示）；配置 `dice/console_start_hidden` 设为 `false` 可恢复启动即显示控制台。
- 托盘图标悬停显示端口（如 `Dice!Next(18088)`，方便多开区分）；托盘菜单可打开管理面板、显示控制台或退出程序。
