# 权限设置

**管理面板 → 数据管理 → 权限设置**，管理用户信任等级、白名单群、骰娘识别与黑名单，分三个选项卡。

## 信任等级阶梯

DiceNext 移植了原版 Dice! 的 nTrust 信任体系，所有权限门控都基于它：

| 等级 | 含义 |
|------|------|
| 0 | 普通用户 |
| 1–3 | 信任层（受信任对象，可远程管理群设置） |
| 4 | 管理员（可用 `.trust` / `.admin` / 全局操作，不受全局指令停用限制） |
| 255 | 骰娘自身（内部保留值） |
| 256 | 骰主 Master（最高权限） |

聊天侧对应指令：`.trust <@某人/QQ号> [等级0-255]`（省略等级则查询；管理员≥4 可用，只能设低于自己的等级）、`.admin add/del <@某人/QQ号>` 与 `.admin list`（仅骰主），详见[管理指令](/use/admin)。

## 权限管理

### 用户信任等级

列表只显示有权限的用户（信任等级 > 0 或骰主），带 QQ 头像、支持搜索与分页（默认每页 20，可调）。每行的下拉框直接切换等级：普通 / 信任 1–3 级 / 管理员 / **骰主**——「骰主」也是可选等级之一，选中即加入骰主名单，切到其他等级即移出。

「添加权限」弹窗按**搜索添加**式操作：先选平台（QQ；Discord 暂不可选），输入 QQ 号或搜索已有用户，再选权限等级。用户使用过指令后会自动建档，即可被搜到。

### 白名单群

用户无需白名单——达到信任等级即视为受信任；只有**群**需要单独加白名单。填群号（可附原因）添加。

**仅白名单模式**开关：开启后，只有白名单内的群才会响应，其余群一律忽略。

## 骰娘名单

识别群内的其它骰子，避免互相触发：

- **自动识别**：通过各骰系 `.bot` 固定格式回执自动登记（支持 Dice! / Dice!Next / OlivaDice / SealDice），记录 QQ 号、骰系与识别时间。
- **手动登记**：填 QQ 号与骰系名称添加。
- **@静默**：用户「@其它骰娘 + 指令」时，本骰保持静默，不会当作代骰执行。

## 黑名单

黑名单内的用户 / 群不响应任何指令（黑名单群还会自动退群，见通知事件「黑名单自动退群」）。

- 「新增黑名单」弹窗：选平台、目标类型（用户 / 群）、输入 ID（可从已有玩家 / 群列表搜索联想）、备注原因。
- 列表带头像、目标类型标签、原因与添加时间，支持按 QQ / 群号 / 原因搜索和分页。

::: tip 旧版数据迁移
原版 Dice! 的 `BlackList.json` 可通过「系统设置 → 导入旧版数据」一键迁入，详见[数据迁移](/guide/migration)。
:::

## 云黑名单

跨骰共享的云端黑名单（[cloudban.dice.zone](https://cloudban.dice.zone)），语义传承自原版 Dice! 云黑：**上报的记录先进入待核验状态，管理员核验通过后才对全网骰娘生效**；记录注销走「墓碑」下发，各骰同步后自动解除。被拉黑的用户可在网站登录后提交申诉。

**前置条件**：需要先完成[心跳上报](/manage/settings#心跳上报)的绑定拿到 access_token（云黑上报用同一凭证，以此追责到骰娘与骰主）。

| 配置项 | 说明 |
|------|------|
| 启用云黑 | 总开关。开启后才会同步 / 上报 |
| 服务地址 | 默认官方 cloudban.dice.zone，可自建 |
| access_token | 留空自动复用心跳上报的 token，也可单独填写 |
| 本地拉黑自动上报 | 开启后，骰主拉黑（指令或面板）会自动上报云端待核验 |
| 最低危险等级 | 同步并入本地黑名单的门槛：1 仅记录警示 / 2 不良用户（默认）/ 3 严重（集骰、恶意破坏） |
| 同步周期 | 1 / 6 / 12 / 24 小时，另有「立即同步」按钮 |

**同步规则**：

- 云端核验生效（active）且危险等级达到门槛的记录，自动并入本地黑名单，原因带 `[云黑#编号]` 前缀，列表中显示「云黑」徽章；
- 云端注销的记录，只解除**带该前缀**的本地条目——骰主手动拉黑的条目绝不会被云端动到；
- 本地上报的记录仅来源骰可注销（在云黑网站操作），管理员核验拒绝的记录不会下发。
