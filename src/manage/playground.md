# 指令测试

**管理面板 → 指令测试**，一个聊天式测试台：不用打开 QQ / Discord，直接在网页里发消息试指令、看骰娘怎么回。

## 使用方法

顶部先选好环境，然后像聊天一样输入指令（也可点快捷按钮 `.r`、`.ra 侦查 60`、`.coc` 等）：

| 选项 | 说明 |
|------|------|
| 场景 | 群聊 / 私聊 |
| 平台 | QQ (OneBot v11) / Discord |
| 回复语言 | 默认(跟随平台) / 简体中文 / 繁體中文 / English / 日本語 |
| 昵称 | 模拟发送者的昵称（默认「测试员」） |

## 和真实消息完全同管线

测试台的消息走与真实群消息相同的处理链，所以看到什么就是群里会发什么：

1. 内置指令
2. JS 插件
3. Lua 模组
4. 自定义回复
5. AI 对话 / NPC（开启时；注入群摘要与长期记忆，便于预览）

最后同样经过 AI 润色与 AI 翻译（开启时），方便在配置 AI 后直接预览效果。指令没匹配到任何处理器时会显示「无回应」提示。

## 不影响真实数据

测试消息使用虚拟身份（用户 `10001`、群 `100001`），不会发到任何真实群，也不会消耗触发式广播（那只在真实群消息上生效）；`.st` 等指令写入的数据都记在这个虚拟身份名下。

::: tip
测试台是排查问题的第一站：改了自定义回复、装了新插件、调了 AI 配置，先来这里发一条试试，再到真实群验证。
:::
