# 高级回复

**管理面板 → 高级回复**，管理关键词触发的自动回复。页面分三个选项卡：**自定义回复**、**因果规则**、**计数器**。

## 自定义回复

### 回复列表

| 列 | 说明 |
|---|---|
| 匹配类型 | 关键词 / 前缀 / 正则 / 搜索匹配 |
| 匹配内容 | 触发文本 |
| 回复内容 | 命中后的回复 |
| 优先级 | 多条匹配时数字越大越优先（默认 100） |
| 状态 | 启用 / 禁用开关 |
| 操作 | 编辑 / 删除 |

顶部搜索框可按匹配内容或回复内容过滤。

### 添加 / 编辑回复

点「添加回复」打开编辑器：

- **触发条件**：可添加多个条件，选择「全部满足 (AND)」或「任一满足 (OR)」；每个条件的匹配类型可选关键词 / 前缀 / 正则 / 搜索（消息包含）。
- **回复内容**：可添加多条，命中后**随机选一条**发送。点「插入图片」上传图片，以平台中立码 `[img,file=<本地路径>]` 保存，发送时按[系统设置的「图片发送方式」](/manage/settings)自动转换；也支持 CQ 码 / 海豹码。
- **变量**：`{nick}` 昵称 · `{user}` QQ · `{group}` 群号 · `{roll:1d100}` 投骰 · `{draw:牌堆}` 抽牌堆 · `{a|b|c}` 随机选一 · 正则时 `{$1}` 为捕获组。更多变量见[关键词回复](/use/reply)。
- **优先级**：多条规则同时命中时的先后。

### 匹配测试

列表下方的「匹配测试」输入任意文本，即时显示会命中哪些规则，方便调试正则。

### 触发式广播

「新增广播」可设置一条**触发式广播**（如活动公告）：

- 广播**不会主动群发**（防止频繁发消息被封号），而是在每个群**下一次触发任意骰子指令**时附在该指令回复后自动发出，每个群仅发一次。
- 缓冲区只保留一条待推送广播；新增 / 替换会覆盖上一条并重新计数，也可随时撤销。上限 200 个汉字。
- 有待推送广播时页面顶部显示横幅，标注已推送到多少群。

## 因果规则

比自定义回复更强的「条件 → 动作」引擎，可视化编辑器支持**从模板开始**（早安问候、每日打卡、限频抽卡、点歌、专属回应），点一个套用后改文字即可。

- **当满足**（条件，可多条 AND/OR）：包含 / 完全等于 / 以…开头 / 正则匹配（捕获组可在回复里用 `{$1}` 取值）/ 发送者白名单 / 发送者黑名单 / 指定群 / 计数器满足。
- **就执行**（动作，可多条）：回复消息（多行随机选一）/ 计数器加减 / 计数器设为 / 计数器清零 / 调用接口（把返回内容存到变量，回复里 `{变量名}` 引用；需在系统设置开启外部请求）。
- **高级设置**：优先级、冷却秒数（按每人 / 每群 / 全局维度计算）。
- **试一试**：输入一条消息，实时看这条规则会不会触发、回复什么。

规则列表支持搜索、启停开关、编辑与删除。

## 计数器

查看、编辑、重置因果规则引擎的**持久化计数器**（如打卡次数）。计数器按「每用户 / 每群 / 全局」维度各自独立保存，回复里用 `{counter:名字}` 引用。
