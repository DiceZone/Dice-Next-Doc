# 群组管理

**管理面板 → 数据管理 → 群组管理**，以「列表 + 详情」方式管理骰子所在的每个群。

## 群列表

- **活跃群组 / 已退群** 两个选项卡；支持卡片 / 列表两种视图与搜索（群名 / 群号 / 备注）。
- 群记录在机器人加群或使用过 `.bot` / `.group` 后自动出现，也可手动输入群号添加。
- 显示群名、群号、备注标签、骰子在群内的权限（群主 / 管理员 / 成员）。
- **启用 / 关闭**：等同于远程 `.bot on/off`。
- **彻底禁用 / 解除禁用**：完全静默某群（比 `.bot off` 更强，群内任何人都无法再启用，只能从本页面恢复）。

## 详情选项卡

| 选项卡 | 功能 |
|--------|------|
| 功能管理 | 群名片 / 备注 / 邀请人 / 回复语言 / 欢迎词 / 发消息 / 退群 |
| 人工智能 | 本群 AI 开关与群记忆管理 |
| 插件 | 为本群单独启停插件 / 模组 |
| 人员管理 | 成员列表与禁言 / 踢出等群管操作 |
| 日志管理 | 跑团记录的导出 / 上传 / 删除 |
| 群文件 | 查看、下载、上传群文件 |
| 模拟聊天 | 实时查看群消息并直接发言 |

### 功能管理

- **骰娘群名片**：机器人在本群显示的群名片（未设置时使用 QQ 昵称）。
- **群备注**：仅后台可见的备注标签。
- **群邀请人**：记录邀请骰娘入群的人，权限视同群管理员。
- **本群回复语言**：设置后本群回复使用该语言（等同群内 `.lang`）。
- **入群欢迎设置**：本群的欢迎词（支持 `@提及` / QQ 号 / 昵称变量）、发送延迟与冷却（秒）。实际值不会低于[系统设置](/manage/settings)里的全局最低延迟 / 冷却，防止连续进群刷屏。
- **群操作**：发消息、退群（可选「退群并移除记录」或「仅退群，保留记录」）、移除记录（仅删后台记录，不退群）。

### 人工智能

- **本群 AI 功能**开关：关闭后本群不再触发骰娘 AI 对话 / NPC，也不建立群记忆（需先在「人工智能」页开启全局开关；群内也可用 `.ai on/off`，需群管）。
- **本群记忆**：查看 / 清空本群的 AI 记忆（摘要 + 事实）；记忆随对话滚动生成。

详见 [AI 功能](/manage/ai)。

### 插件

为本群单独启停插件（Lua 模组 / JS 插件）。关闭后该插件的指令在本群不响应，不影响其它群与全局设置。

### 人员管理

拉取成员列表与角色；管理员可禁言 / 解禁 / 踢出 / 改名片，群主可设专属头衔。支持按昵称 / 名片 / QQ 搜索。

::: tip 权限提示
执行禁言 / 踢人等操作需要骰子在该群拥有管理员权限；若骰子只是普通成员，面板会提示权限不足。
:::

::: tip 群自动化（指令配置）
骰子有群管理权限时，群管可在群内用 `.group auto pass 关键字`（加群验证消息含关键字自动通过，`all`＝全过）、`.group auto kick 关键字` / `.group auto mute 关键字 [分钟]`（发言含关键字自动踢出 / 禁言，豁免骰主、群管、信任用户与邀请人）配置本群自动化；`.group auto` 查看，关键字留空＝关闭。
:::

### 日志管理

查看该群的跑团记录（名称 / 创建人 / 开始时间 / 上次记录 / 条数）：

- **导出**：TXT / Excel / 网页（HTML，开启「保存日志图片」后图片内嵌显示）。
- **上传**：上传到日志站并自动复制分享链接。日志站地址与上传协议（SealDice 兼容 / DiceNext 专属等）在[系统设置 → 日志站](/manage/settings)配置。
- **删除**：删除日志（同时清理其本地缓存图片）。

### 群文件

- 浏览群文件与文件夹（名称 / 大小 / 上传者 / 上传时间）。
- **下载**：优先直连 QQ 直链下载，保留真实文件名。
- **上传**：上传文件到群（上限 30MB），QQ 处理后自动出现在列表。
- 需要已连接的 NapCat / go-cqhttp 适配器。

### 模拟聊天

实时查看该群消息并直接发送，无需切到 QQ：

- 消息带**头像**与发送者名称（有群名片显示群名片，骰娘显示自己设置的名称）。
- 支持发送**文字、图片、表情包**（上传图片保存为本地表情包，点击即发）与**戳一戳**。
- 撤回的消息标注「已撤回」；引用消息以气泡样式显示；文件消息可直接下载。
- 「拉取历史消息(NapCat)」可回填历史记录；向上翻阅时不会被新消息打断，一键「回到最新消息」。
- 聊天记录持久化保存在 `chat.db`，保留天数在[系统设置 → 聊天记录保留期](/manage/settings)配置。
