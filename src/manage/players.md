# 玩家管理

**管理面板 → 数据管理 → 玩家管理**，查看所有与骰子交互过的玩家档案。

## 档案来源

玩家档案在首次与骰子交互时**自动建立**，无需手动添加。

## 列表内容

| 列 | 说明 |
|----|------|
| 昵称 | 最近一次显示名（含 QQ 头像），点击进入详情页 |
| QQ 号 | 平台账号 |
| 信任等级 | 下拉直接调整（见下） |
| 好感度 | 当前好感值，行内直接编辑 |
| 指令数 | 累计触发指令次数 |
| 上次指令 | 最近一次使用时间 |

默认左侧玩家列表、右侧选中玩家详情，原表格页不再作为独立显示模式。工具栏可按昵称、账号、信任、好感、指令次数和上次指令时间排序，并切换升 / 降序；默认按信任等级排列。支持平台筛选、搜索及点选 / 输入页码跳转。

## 信任等级

下拉可选：普通（0）、信任 1~3 级、管理员（4）、**骰主**。

- 0＝普通；1~3＝信任层（可远程管理群设置）；4＝管理员（可用 `.trust` / `.admin` 与全局操作）；骰主＝最高权限。
- 选「骰主」即把该账号加入 Master 名单（与[系统设置](/manage/settings)的 Master 卡片同步）；从骰主切到其他等级则移出名单。
- 聊天里对应指令为 `.trust <QQ> <等级>` / `.admin add`；从旧版导入的 5 级以上信任值也会正常显示。
- 信任等级影响指令权限（如全局停用的指令对信任 4+ 无效）。

## 操作

- **搜索**：按昵称 / QQ 过滤。
- **编辑信任 / 好感**：在选中玩家的详情区域修改。
- **删除记录**：移除某玩家的档案。
- **删除好友**：经适配器解除好友关系（双方并非好友时不可用）。

## 玩家详情页

点击左侧玩家，在右侧按选项卡展示该玩家的数据；保存、删除及好友操作都针对当前选择，切换玩家、筛选条件或离开页面前会提示未保存的修改：

| 分区 | 内容 |
|------|------|
| 个人信息 | 昵称、信任、好感和该玩家出现过的群 |
| 人物卡 | 全部人物卡与属性；标注默认卡与各群绑定关系；可**复制 .st**（一键生成录卡指令）、逐项修改属性、删除人物卡 |
| 设置键值 | 该玩家的各项设置（全局 / 分群） |
| 插件数据 | Lua 模组存储的玩家变量与卡片数据 |
| 模拟聊天 | 查看该玩家的私聊记录并发送消息 |

支持集中保存的修改在页面编辑后点**「保存全部修改」**提交（会提示成功 / 失败条数）；个别即时操作按按钮提示执行。列表仍保留在左侧，无需返回上一级页面才能选择另一名玩家。
