# 文件管理与图片资源

入口：**数据管理 → 文件管理 → 图片资源**。

文件列表只显示名称、路径、大小、修改时间，不加载缩略图。需要看图时点击「预览」；「复制图片代码」可直接用于回复、掷骰文本、牌堆等位置。

## 图片放在哪里

统一保存在本实例的 `data/images/`：

| 目录 | 用途 |
| --- | --- |
| `reply/` | 自定义回复 |
| `text/` | 掷骰文本、人格文案 |
| `deck/<牌堆文件名>/` | 该牌堆的图片，完整文件名含 `.json`，保留内部子目录 |
| `plugin/<插件名>/`、`mod/<模组名>/` | 按所属插件或模组集中存放 |
| `chat/` | 主动上传的聊天图片、收藏表情 |
| `shared/` | 通用图片 |
| `cache/chat/`、`cache/log/` | 有独立清理规则的聊天 / 跑团日志缓存 |

可以新建自己的文件夹。目录只表示归属，不限制使用位置，不会为全局去重把一个牌堆或插件的图片拆散到其他目录。

## 常用操作

- 支持搜索、排序和服务端分页，默认每页 20 项。
- 批量选择后可以复制、剪切、删除或下载 ZIP；进入目标目录后粘贴，同名覆盖需要确认。
- 行内提供预览、复制图片代码；「更多」提供路径复制、下载、引用查询和重命名等操作。
- 图片 ZIP 可以批量导入并保留子目录，只接收图片，不执行包内脚本。
- 回复、掷骰文本、牌堆、插件模板设置和模拟聊天共用图片选择器，可上传新图片，也可直接引用已有资源。

移动或重命名会更新已识别引用，旧图片码和旧链接也保留兼容。仍被引用的图片不能删除；先替换引用，再移入回收站，需要时可恢复。永久删除不可撤销，请谨慎操作。

::: warning 动态路径不能完全静态识别
插件可能自行拼接路径、读取外部数据库或枚举私有目录。未发现引用不代表一定没有使用，建议先回收观察，不要直接永久删除。源码不会为了迁移图片被自动改写。
:::

## 迁移与备份

启动后会后台整理旧 Next 图片目录；发生问题时保留源文件并显示迁移提醒。旧 Dice! 导入对源骰子只读：在 Next 中复制牌堆图片并调整 Next 的引用，不修改旧文件。

私有插件 / 模组资源按名称归档。已登记图片的 Lua 文件读写可通过路径别名继续使用；不能证明可删除的旧私有路径保留兼容副本，避免破坏动态调用。

备份会保存所选图片和路径索引；局部恢复合并索引，不丢失未选择图片的链接。聊天缓存和日志缓存仍按原保留期 / 删除规则清理，不会清理回复、牌堆等永久资源。

管理和预览需要面板登录或 API Key。普通预览不会公开图片；配置 HTTP 发送后，永久资源可生成随机 token 链接，缓存不通过资源分享入口公开。

牌堆连同图片迁移到其他骰子，见 [`.deck` 牌堆包](/use/deck#deck-牌堆包)。
