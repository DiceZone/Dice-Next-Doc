# 规则管理

**管理面板 → 扩展管理 → 规则**，管理可导入的规则包（属性别名 / 衍生公式 / 速查手册 / 自定义指令），群内用 `.set <规则>` 切换激活。

## 规则包列表

每条规则包显示名称、版本、作者、`.set` 切换关键字、默认骰面，以及别名 / 衍生公式 / 速查词条 / 帮助数量统计；带自定义指令、指令别名或停用指令的还会列出对应指令徽章。

| 操作 | 说明 |
|------|------|
| 启用 / 停用 | 开关单个规则包 |
| 在线编辑 | 打开可视化规则编辑器（见下） |
| 导出 | 下载规则 JSON 文件 |
| 删除 | 移除规则包（内置规则不可删） |

列表支持分页（每页条数可选）。内置规则（如 COC7、DND 等）标「内置」，导入的标「已导入」。

## 导入

- **导入规则文件**：单个规则 JSON。
- **导入规则包(zip)**：一个 zip 打包规则 + 帮助文档 + Lua/JS 插件（`pack.json` 清单声明），群内 `.set` 激活后整套生效。规则包区会单独展示每个包的规则 / 指令 / 帮助 / 插件统计，可整包启停或删除（删除会移除整个包目录）。

规则包的编写与分发格式见[规则包编写](/develop/rulepack)与[实战：转化海豹规则插件](/develop/rulepack-example-fu)。

## 兼容规则

以插件形式提供的规则系统也会汇总显示在本页，可直接启停：

- **JS 兼容规则**：海豹 SealDice JS 插件（`seal.gameSystem` / `coc.registerRule`），列出其注册的指令。
- **Lua 兼容规则**：原版 Dice! Lua mod（含 `model/*.xml` 属性模板，如 COC7-TRPG / DND-5E）。

上传 / 删除 / 配置这类插件请到[插件管理](/manage/plugins)页。

## 可视化规则编辑器

点「新建规则」或某个规则包的「在线编辑」进入编辑器，支持**表单模式**与**源码模式**（直接编辑 JSON）随时切换：

| 区块 | 内容 |
|------|------|
| 基本信息 | 名称（英文，作文件名）、显示名称、版本、作者、默认骰面、`.set` 切换关键字 |
| 成功等级 | 检定成功等级判定（内置 / 自定义 / 不使用） |
| 属性别名 | 规范名 + 别名列表（`.st` 录卡时同义词归一） |
| 衍生公式 | 属性 + 公式（如闪避＝敏捷/2） |
| 默认值 | 属性默认数值 |
| 速查词条 | `.rules` 规则速查的词条与解释 |
| 指令别名 | 输入词 → 目标指令 |
| 自定义指令 | 指令名 + 输出模板（`{表达式}` 求值替换，支持掷骰 / 取卡值 / 条件三元等）+ 帮助文字 |
| 停用的指令 | 本规则激活时屏蔽的内置指令 |

编辑器底部有**实时测试**：以当前编辑内容直接试跑指令（可注入测试属性），不需保存。

## 相关功能（不在本页）

| 需求 | 去哪里 |
|------|--------|
| 指令前缀 | [系统设置](/manage/settings) |
| COC 房规（大成功 / 大失败判定） | 群内 `.setcoc 0-7`，`.rules coc:大失败` 速查，详见[掷骰与检定](/use/dice) |
| 规则包附带的帮助词条 | 自动进入 `.help` 统一帮助与[帮助文档](/manage/help-docs)页 |
| 自定义关键词回复 | [高级回复](/manage/replies) |
| 黑白名单 / 信任 | [权限设置](/manage/permissions) |

## 生效方式

面板中修改后即时保存生效，无需重启。
