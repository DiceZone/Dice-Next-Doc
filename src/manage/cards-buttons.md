# 卡片与按钮

**管理面板 → 高级回复 → 卡片与按钮**，按 QQ 官方机器人账号编辑菜单和指令面板。此页目前面向 QQ 官方平台，不是其他适配器的通用卡片编辑器。

- **全局菜单**：编辑消息入口、HTTPS 链接、二级菜单和开关，支持条目排序与布局预览；发布会覆盖该账号的完整单聊菜单。
- **指令面板**：按单聊、群聊、文字子频道与频道私信筛选，创建或编辑指令和链接条目，设置管理员限制、备注及关联对象。

账号选择、前端验证、发布确认与草稿保护均在此页完成。原自定义回复、因果规则和计数器仍位于同级的「自定义回复」页面，不会迁移或清空已有规则。

权限要求、平台上限和关联操作见 [QQ 官方 API v2 能力](/develop/qq-official-api#可视化编辑)。
