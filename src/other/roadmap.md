## 更新日志

### 2026-08-02 · build 770

- **历史配置升级保护**：检测到配置目录只剩历史遗留的 `default_config.json` 时，不再读取其内容或将其写回数据库。程序会删除该文件，并仅用数据库中的最近有效配置快照重建 `server.json`、`adapters.json` 等拆分文件；若快照不存在则安全停止，避免默认配置覆盖用户原有设置。

### 2026-08-01 · build 769

- **跨平台帮助文件随包发布**：Linux、macOS 与 Windows 打包流程均会携带 `help/`，`.help` 的跑团术语与规则说明不再只存在于 Windows 开发目录。
- **规则包重载稳定性**：修复修改、启停或删除规则包时的锁重入死锁；规则包热重载不再导致 WebUI 持续加载、配置无法保存及主程序失去响应。
- **前缀与插件兼容**：骰娘探测与多骰 @ 判断改为遵从当前配置的指令前缀，不会再让已移除的 `.bot` 以前缀形式参与触发。Lua / JS 规则包中以旧式 `.va` 等名称登记的命令，会自动映射到当前前缀，例如仅启用 `>` 时可用 `>va` 调用。
- **@ 消息与日志撤回**：各适配器传给 Lua / JS 的消息内容继续移除用于选择骰娘的 `@` 段，便于规则包做文本匹配；OneBot 群消息撤回会同时标记聊天记录，并从正在记录的跑团日志移除对应原消息（历史上未保存消息 ID 的旧日志无法追溯）。
- **官方 QQ 好友操作保护**：QQ 官方机器人 OpenID 没有删除好友接口，玩家页不会再为这类用户激活“删除好友”。只有该 OpenID 已绑定真实 QQ，且这个 QQ 确实是任一已连接 OneBot 的好友时，才会通过该 OneBot 显示并执行删除。

### 2026-07-29 · builds 753–763

- **可选备份与按天保留**：新增“立即备份到服务器”，不再强制浏览器下载；手动与自动备份统一保存在 `data/backups/`，并使用 `dicenext_bak_YYYYMMDD-HHMMSS.zip`。备份会排除该目录，避免把旧备份递归打进新包。可分别选择系统配置、人物卡与数据库、跑团/运行日志、牌堆规则帮助、JS/Lua 插件及本地媒体；局部恢复仅覆盖所选内容，未选数据不会被清空。自动备份沿用相同选择项，清理策略改为保留最近 N 天而非按份数。
- **已保存备份恢复**：备份列表新增“恢复”操作，可直接选取手动或自动保存的 ZIP 校验并暂存；重启主程序后应用恢复，恢复前的数据仍会保留为回滚副本。
- **富消息发送形式**：系统设置新增“传统文本 / 卡片消息”。Discord 使用 Embed，KOOK 使用 CardMessage，QQ 官方机器人优先使用 Markdown，未获 QQ Markdown 权限时自动降级为传统文本；OneBot 保持传统文本。

### 2026-07-28 · builds 727–752

- **完整备份与恢复**：旧版 Dice! 数据导入已集中到“备份恢复”页面；新增 ZIP 格式的本地完整备份下载与恢复上传。备份会包含当前配置和全部 `data/` 用户数据，并在导出前刷新 SQLite WAL；生成后会校验压缩包。备份现统一保存在 `data/backups/`；面板可保留、重新下载和删除，并支持按间隔/每日时刻自动备份及按数量滚动保留。恢复包会校验清单及文件路径后暂存，在下次启动前安全替换数据；恢复前的数据自动保留为回滚副本。
- **跨骰与自响应防误触发**：修复自响应账号 `@` 已登记骰娘执行 `.r/.ra/.pc` 等指令时，因代骰兼容分支而误按自身执行的问题。明确 @ 其他已登记骰娘时现在始终静默，覆盖内置指令与 JS 插件；正常 @ 玩家代骰不受影响。
- **DND `.rdc` 兼容修复**：支持原版紧凑写法 `.rdc3#+1d4力量 15`，附加骰会在每一轮独立重掷，并正确叠加属性调整值/技能检定加值。回执会展开为 `D20+1D4+5=18+3+5=26>15 成功` 格式；帮助已说明 `+2`、`+1d4` 与轮数写法。
- **Windows 发行管理器**：Windows 包改为顶层 `dice-next.exe` 管理器、`app/dice-next-core.exe` 服务核心和集中式 `lib/` 运行库。管理器不依赖包内 DLL，直接双击即可启动 core 并继承控制台日志；更新时会复制出临时维护器，待原进程退出后替换包括 `dice-next.exe` 自身在内的完整程序文件，生成回滚目录。设置 `DICENEXT_UPDATE_RESTART=NO` 后，更新完成只退出，不会自行重启 core，适配 MCSM 等进程托管面板。

### 2026-07-26 · builds 648–701

- 新增 QQ 官方机器人 2.0 WebSocket 适配器：支持 AppID + AppSecret、扫码绑定、官方群/私聊消息及多官方机器人并存。
- 新增 Discord 与 KOOK 原生 Gateway 适配器：可在面板分别配置 Bot Token，支持服务器频道、私聊与 `@机器人 指令`；Discord 需在开发者后台开启 Message Content Intent。
- 官方 OpenID 可与 OneBot 已验证的真实 QQ/群关联，统一人物卡、群设置与日志；`.info` 可查看当前窗口的 OpenID 和绑定信息。
- 默认仅允许在 OneBot 窗口反向绑定官方 OpenID；官方窗口直绑真实 QQ 改为默认关闭的高风险系统设置，并带二次确认与风险说明。
- QQ 官方 API 暂无可信群角色信息，基础群管级指令目前允许群内用户执行，以保证 `.bot on/off` 等日常操作可用；待官方开放角色鉴权后恢复真实校验。骰主/信任级权限不会由官方 OpenID 映射获得。
- 修复官方消息中的 `<@OpenID>` 导致指令前缀无法识别的问题；`@机器人 .r`、`@机器人 .bot` 等现在可正常执行，后台也会显示可读的官方入站消息记录。

### 2026-07-25 · builds 605–629

- `.dx` 临界骰改为 `<数值,临界值>` 显示，成功骰更清楚。
- `.ww` 支持 `a` 加骰阈值、`c` 成功阈值、`+X` 附加成功，并以 ⑦⑧⑨⑩ 标记成功骰。
- 补齐群共享 NPC 的帮助/多语言文案，以及 DND 临时生命值、批量先攻等体验。
- `.st pp/gp/ep/sp/cp` 支持 DND 钱币自动换算与找零。
- 玩家详情新增分栏与私聊模拟聊天。
- Roadmap 改为当前进度表与按日期更新日志，避免测试用户阅读冗长历史计划。
- Lua/JS 补齐群名片读取、私聊回复与日志状态兼容；`.log list` 可区分进行、暂停、结束。
- 模拟聊天支持上传群文件；规则包删除重载增加并发保护与异常隔离。
- `.game over` 现在会自动结束仍在进行的跑团日志，和旧版 Dice! 保持一致（暂停中的日志不受影响）。
- `.game` 支持多群接入同一团：开团时生成不可顺推的 16 位团号，GM 在其他群使用 `.game open 团号` 后共享团务状态；关闭仅影响当前群，结团会解除全部接入群并收尾进行中的日志。
- 数据管理新增“日志管理”：可按群、日志、团名和团号检索、导出、删除；显示团号、接入群与日志状态。跨团导出按时间合并各团群发言，以 `〔场景：群名〕` 标记场景，结团后仍可导出历史记录。
- 日志管理分为日志/团务两个选项卡：日志使用可排序表格，团务卡片显示 GM、玩家、创建时间和分状态日志统计。
