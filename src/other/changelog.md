# 更新日志

Dice!Next 的版本更新记录。完整功能进度见[开发计划](/other/roadmap)。

## 2026-08-27 · build 863

- 回复展示形式改为即时保存的全局 Markdown / 富消息主开关；关闭后 QQ 官方、Discord、KOOK 及显式 Markdown 模板全部降级为传统文本，平台/账号局部设置不能绕过全局关闭。
- 指令文本编辑器新增变量级 Markdown 样式，可逐项选择普通、粗体、斜体、行内代码或删除线，并同步 Markdown 与纯文本双预览。
- 修复 QQ 官方、Discord、KOOK 在传统文本模式下仍发送显式 Markdown 的优先级不一致问题。

## 2026-08-26 · build 860

- 原版 Dice! 指令兼容补齐：暗骰 / 简短骰、COC6/7 制卡、群开关、暗抽、角色卡、规则书、Mod、用户、文案与云服务兼容入口接入统一实现。
- 安全边界明确：不恢复 `.system cmd` 远程 Shell；玩家 / 卡片不可逆删除、插件文件更新与删除继续要求 Web 管理面板确认；聊天不触发外部云黑同步。
- SealDice JS 兼容按 `sealdice-core` 对齐加载、消息、指令、发送与平台事件钩子，补全端点、消息 ID、频道、时间、富媒体分段及 @ 状态字段。

## 2026-08-11 · build 828

- QQ 官方机器人 2.0 跟进 2026-08-10 能力更新：OpenAPI 域名统一为 `api.bot.qq.com`，Markdown 可选图片资源强校验；群组管理新增成员禁言、入群申请人工审批、自动审批策略与白名单管理；用户入群申请事件进入现有通知和自动审批管线。

## 2026-08-06 · build 796

- 多账号群管理：同一平台多个骰娘账号在同一群的开关、锁定、AI、群名片、欢迎语、插件与当前日志按账号独立，群列表不再互相覆盖；日志仍共享，群详情可切换账号。
- 备份稳定性：自动备份不再因文件被占用失败，跳过旧备份目录、瞬时占用自动重试、手动/自动备份互斥。
- 备份排除实例锁：跳过运行时单实例锁文件 `data/.instance.lock`，解决 Windows 备份“文件被占用”报错。
- 群管理权限：群管理员可使用 `.bot on/off`；OneBot 缺角色时自动从成员信息补查。
- 默认骰修正：`.rd-5` / `.r-5` 按“当前默认骰 − 修正”掷骰。
- 时区统一：系统设置新增“时区”，日志上传正文、网页导出、审计、备份名与定时任务统一按配置时区输出，存储保持 UTC。
- 消息分段：新增“消息分段”开关；QQ 官方机器人、Discord、KOOK 不分段；分段按顺序间隔发送。
- QQ 官方骰主：添加 Master 可选“QQ 官方机器人”，按骰主 OpenID 识别。
- QQ 官方群记录修复：群事件统一映射公共群号，不再产生 OpenID“已退群”幽灵记录；历史幽灵记录启动时自动清理；群内发言会清除删除/退群标记并重建记录。
- 适配器最后活跃：适配器详情显示最近一次收到消息/事件的时间。
- 骰主设置：添加 QQ 官方骰主时下拉选项显示为 OpenID，并提示可用 `.info` 指令查询。
- 定时任务按帐号执行：平台下拉改为帐号（适配器:ID），可指定具体骰娘帐号发送/退群。
- 消息发送形式按帐号：每个适配器可单独设置传统文本/卡片消息，或跟随全局默认。
- 通知按帐号来源：通知窗口支持全局或指定适配器帐号，通知由来源帐号发出。
- 通知发送回退顺序：系统级通知按内部适配器编号顺序发送直到成功；帐号来源通知优先来源帐号，失败后回退。

## 2026-07-26 · 多平台适配

- 新增 QQ 官方机器人 2.0：支持 AppID + AppSecret、扫码绑定、官方群与私聊消息，以及多官方机器人并存。
- 新增 Discord 原生 Gateway 适配器：支持服务器频道、私聊与 `@机器人 指令`。使用前请在 Discord Developer Portal 开启 Message Content Intent。

## v3.0.0（公测中）

首个重构版本，目前处于公测阶段。

### 核心
- 全新前后端分离架构：C++ 后端 + React 管理面板
- OneBot v11 适配（正向 / 反向 WebSocket、HTTP）
- 多语言支持（简体 / 繁體 / English）
- 旧版数据一键迁移

### 掷骰与规则
- 通用掷骰、暗骰、WOD 骰池、双十字
- COC 检定全套（奖励/惩罚骰、对抗、困难/极难、代骰、连掷、理智、成长、疯狂、房规）
- BRP 检定（`.ba`）与抵抗表对抗（`.bav`）
- DND：`.setdnd` 模式、d20 检定、先攻、法术位（`.ss/.cast/.longrest`）、临时加值（`.buff`）
- COC / DND 制卡、`.pc build` 按模板生成
- 规则速查（COC / DND，可扩充）
- 免空格黏着指令（`.ra侦查`、`.rapass23` 等）、`.rd` 默认骰挂钩

### 角色卡
- 属性录入与别名识别、多角色卡、群名片同步、检定统计
- 伤害加值（DB）公式录入：`.st db=1d4` 存投掷公式不摇，掷骰时 `.r 1d4+db` 自动展开；也可按力量+体型查表自动计算
- 关联属性：`.st 物防=敏捷+1` 存表达式联动求值
- 卡片锁定（`.pc lock`）、自定义卡模板（可随规则包分发）
- HP / SAN 上限变化时按差值同步当前值，自动重算有清晰提示

### 团务
- `.game` 团务系统（原版全子指令）：开团 / 重开 / GM / 团变量 / 点名 / 踢人 / 暂关 / 结团
- 轮盘骰 `.game rou`（不放回抽取防刷点，含历史 / 重置）
- 团数据与 Lua 模组 `msg.game` 同源互通

### 娱乐
- 今日 / 明日 / 昨日人品、随机姓名（默认每名随机中/英/日）、休息、好感度系统
- 第三人称动作 `.me`、抉择分歧 `.ak`、随机改名 `.nnn`

### 牌堆
- 兼容原版牌堆、内联随机、运行时临时牌堆、默认牌堆

### 扩展与插件
- 规则包系统：可导入规则包（属性模板 / 同义词 / 规则速查 / 帮助 / 脚本），群内切换
- Lua 模组子系统：兼容原版 Dice! mod（人物卡模板、规则书、因果回复、好感、背包）
- JS 插件子系统：兼容海豹 SealDice 插件
- 统一帮助系统：内置指令 / 规则 / 插件三源合并，可分页检索

### 跑团记录
- 记录开关及查询 / 统计 / 删除 / 导出全套子指令、TXT / Excel / HTML 导出
- 日志站上传兼容 SealDice V1 协议，站点地址可自选（非官方站有提示）
- 心理学暗骰 `.rx`（守秘人对调查员暗检定，私聊出结果 + 群内回执）
- 跨窗口消息转发 `.link`（双向 / 单向链接两个聊天窗口）

### 权限与通知
- 信任等级体系（0-255 阶梯，`.trust` / `.admin` 指令，语义与原版一致）
- 账号别名合并 `.alias`（别名账号权限按主号计算）
- 骰主通知系统：`.notice` 注册通知窗口，网页可逐项勾选 14 类事件（例行 / 重要 / 关键 / 错误）
- SMTP 邮件 / Webhook 第三方推送（带发送测试）
- 审计日志：权限变更 / 审批 / 运行报错全记录，网页可查

### AI（可选，默认关闭）
- AI 网关：多模型管理、全局请求参数，兼容 OpenAI 接口
- 掷骰回复润色：按骰娘人设改写文风，带数字保留校验（骰点绝不会被改错）
- AI 翻译：配合 `.lang` 自定义语言，发送前自动翻译
- 对话回复：@ / 关键词 / 待机概率触发，冷却与群上下文；分群开关 `.ai on/off` + 白名单模式
- 短期记忆（群聊滚动摘要）与长期记忆（向量检索人物卡 / 剧情事实）
- 工具调用：AI 掷骰走真实引擎、可抽牌 / 查卡 / 执行指令
- NPC 扮演：按剧本设定演出，限定群与触发词
- 图像识别（多模态）、禁 emoji 选项
- AI 调用并行化，慢响应不阻塞普通指令

### 群管理与系统
- 群开关、外置模式、单群 / 全局指令停用、权限分级
- 入群欢迎（延迟合并防刷屏）、退群、留言、旁观、黑白名单
- 好友 / 加群邀请审批策略（关键词 / 等级门槛）、强拉退群、群名关键词退群、黑名单自动退群
- 群自动化：按消息关键字自动审批 / 踢人 / 禁言（`.group auto`）
- 骰娘探测：识别群内其它骰子并 @ 静默，默认回复不以指令开头，防跨骰误触发与循环
- 聊天记录持久化（撤回标注、保留期可配），网页模拟聊天支持头像 / 图片 / 表情包 / 戳一戳 / 群名片
- 多语言新增日本語，支持用户自定义语言包（放入 i18n 目录自动加载）
- 名称变量细分：QQ 昵称 / 群名片 / 人物卡名独立变量，包裹符号可控
- 定时任务（每个任务独立开关 / 在线编辑）：可设触发条件做「因果」，如 `inactive>=7` 表示本群 7 天无指令；动作支持发送消息或退群（例「闲置 7 天自动退群」），内容支持 `{group}` `{date}` `{roll:..}` `{draw:..}` 等变量/函数
- 关键词自定义回复（多条件、随机结果、动态指令 `{roll}` `{draw}` `{api}` 等）
- 低代码「因果」规则：可视化「条件（匹配 / 过滤 / 冷却 / 计数器）→ 动作（回复 / 改计数 / 调 API）」，无需写脚本
- 骰娘人格：多套命名文案，在「指令列表」页选人格即可直接编辑该人格的回复文案；支持新建 / 复制 / 编辑 / 删除 / 设为默认
- 原版趣味文案「风味」层：可叠加原版 Dice! 的文案风格
- 长消息合并转发（`.coc 5` 多结果 / 过长帮助以聊天记录形式发送，可开关）

### 旧版数据迁移
- 人物卡、玩家档案（含好感）、黑名单、自定义回复、帮助文案、Master
- 模组（mod）、外置牌堆（PublicDeck）、群配置（停用 / 房规 / 欢迎词）

### 管理面板
- 仪表盘、适配器管理、规则管理、回复管理、牌堆管理
- 群组管理（含日志管理、群文件、分群插件 / AI 启停）、玩家管理（详情二级页可查改全部属性）、定时任务、系统设置
- 权限设置、通知设置、AI、扩展管理（Lua / JS 分选项卡）、帮助文档、测试台
- 面板登录密码（Cookie 认证）、运行 IP / 端口在线修改、系统托盘、开机自启、启动隐藏控制台
- 图片发送方式：网页插入的图片以平台中立码 `[img,file=…]` 保存，发送时按设置转 base64 内嵌（默认）或 HTTP 链接（可配主机），QQ 框架跑在其他设备也能正常收图
- 崩溃自诊断：异常自动落盘 `data/logs/crash_*.txt`，附启动阶段标记，方便报障
