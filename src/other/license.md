# 开源协议

Dice!Next 基于 **GNU Affero General Public License v3.0 (AGPLv3)** 开源发布。

## 为什么是 AGPLv3

Dice!Next 是 **Dice!** 的重构延续，而 Dice! 采用 AGPLv3 协议。作为其衍生作品，Dice!Next 同样遵循 AGPLv3 这一强著佐权（copyleft）协议继续开源。

## 简要说明

| 权限 / 义务 | 说明 |
|------|------|
| 商业使用 | ✅ 允许 |
| 修改 | ✅ 允许 |
| 分发 | ✅ 允许 |
| 私有使用 | ✅ 允许 |
| 开源义务 | ⚠️ 修改后分发、**或通过网络提供服务**，都必须以 AGPLv3 公开对应源代码 |
| 协议保留 | ⚠️ 必须保留版权声明与许可证 |
| 担保 | ❌ 无任何担保 |

::: warning 网络服务条款
AGPLv3 的核心区别在于：即使你只是把修改版**作为网络服务**对外提供（而非分发软件本体），也需要向使用者提供对应的源代码。
:::

完整条款见 [GNU AGPLv3 全文](https://www.gnu.org/licenses/agpl-3.0.html)。
