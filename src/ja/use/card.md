# キャラクターシート

Dice!Next には完全なキャラクターシートの仕組みが組み込まれており、複数のシート、ランダム生成、シートのロック、グループ内の名前の同期、判定の統計に対応しています。

::: tip 例に出てくる名前
能力値や技能の名前は、シートに記録されている名前を使います。例では内蔵の COC ルールの中国語名を使っています。たとえば 力量（STR）、敏捷（DEX）、体质（CON）、体型（SIZ）、意志（POW）、侦查（目星）です。张三 や 老猎人（年老いた猟師）などはキャラクター名の例です。
:::

## コマンド一覧

| コマンド | 説明 |
|------|------|
| `.st` | 能力値の記録 / 変更 / 表示 |
| `.pc` | 複数のシートの管理（新規作成 / 紐付け / コピー / 出力 / 生成 / ロック / 削除） |
| `.en` | 技能の成長（[ダイスと判定](/ja/use/dice)を参照） |
| `.nn` | ダイスボット内でのニックネームを設定 |
| `.nnn` | ランダムな名前に変更（ランダムな名前を引いてニックネームにする） |
| `.sn` | テンプレートに従ってグループ内の自分の名前を設定 |
| `.setsn` | このグループの名前にどの能力値を表示するかを設定 |
| `.hiy` | 判定の統計 |

## `.st` 能力値の記録

```
.st 力量50 敏捷60 hp12/12     → 能力値を記録。hp/san/mp は「現在/最大」で書ける
.st hp-2                       → 増減（san+1d3 のようなダイス式も可）
.st show                       → 現在のシートを表示
.st show 60                    → 60 以上の能力値だけを表示
.st show 力量 敏捷             → 指定した項目だけを表示
.st del 力量                   → 能力値を削除
.st clr                        → シートを空にする（関連能力値 / 式 / 武器 / 最大値を含む）
.st export                     → .st でそのまま取り込み直せる 1 行の文章として出力
.st fmt                        → 同義語表に従って能力値の名前を統一（シートの変換）
```

中国語・英語の名前やよく使われる別名は自動で統一されます（例：「计算机 / 电脑 / 计算机使用」は同じ「コンピューター」技能として扱います）。

### 武器とダメージボーナス

```
.st &手枪=1d10+2   → 武器「手枪」（拳銃）を登録。以後 .r 手枪 で直接ダメージを振れる
.st db=1d4         → ダメージボーナスを手動で記録（式の原文を保存し、数値には振らない）
```

`db`（ダメージボーナス）は **式の能力値** です。記録するのはダイスの式で、ダイスを振るときに展開されます（`.r 1d3+db`）。手動で記録していない場合は、シートの記録後に COC7 のルールに従って STR + SIZ から表で **自動計算** し、返信で知らせます。手動で記録した値が常に優先されます。

### 関連能力値（式による連動）

```
.st 物防=敏捷+1     → 物防（物理防御）は常に「DEX+1」になり、DEX が変わると追従する
.st pd='dex+1'     → 英語の能力値名を参照するときは引用符が必要
```

関連能力値には式が保存されます。読み取るとき（判定や `.st show`）に、参照している能力値の現在の値で計算し、「物防=敏捷+1(=61)」のように表示します。

### シートの自動再計算

シートの自動計算を有効にしている場合（既定で有効、COC モードのみ）、CON / SIZ / POW などの基本能力値を変更すると、HP / MP の現在値が **最大値の変化分だけ** 連動して変わります（例：CON が上がると 4/13 が 6/15 になり、全快にはリセットされません）。あわせて「（自動計算）… が変わったため再計算しました」という 1 行の案内が付きます。

SAN の初期値は POW と同じです（元祖 Dice! と同じ）。99 − クトゥルフ神話 は上限にすぎず、神話の技能が上がった場合、SAN は新しい上限を超えた分だけが上限まで下げられ、差分で減らされることはありません。シートにまだ SAN が記録されていない場合、`.sc` も POW で判定し、判定後にシートへ書き込みます。

## `.pc` 複数のキャラクターシート

### BDC クラウドのキャラクターシート

クラウドのキャラクターシートとアカウントの認可は、すべて `.cloud` にまとめられています。詳しくは[クラウドと本人確認](/ja/use/cloud)を参照してください。よく使うものは次のとおりです。

```text
.cloud auth [write] // アカウントセンターの認可を申請。既定は読み取りのみで、write を付けると書き込みも申請
.cloud confirm // Web ページで確認コードを入力して同意した後、個人チャットに戻って確認
.cloud list // クラウドのキャラクターシートを一覧表示
.cloud pull <クラウドのシート ID> [ローカルのシート名] // クラウドのシートをローカルに取得
.cloud push <ローカルのシート名> // ローカルのシートを初めてアップロード
.cloud sync <ローカルのシート名> // 前回同期した版に基づいて変更を送信
```

`.cloud` のコマンドはすべて個人チャットでのみ使えます。取得した後、セッションのグループで `.pc tag <ローカルのシート名>` を使って紐付けると、`.st`、`.ra`、`.sc` は引き続きローカルのシートを読み書きします。同期は手動で行い、通常のダイスロールでネットワークのリクエストは発生しません。

現在、BDC のデバイス認可は短期間のトークンしか返さないため、期限切れやボットの再起動後には認可し直す必要がありますが、ローカルのシートと同期の対応関係は保持されます。完全に取り消す場合は、アカウントセンターの「認可済みアプリ」で操作してください。初回のアップロードがタイムアウトした場合は、二重にアップロードしないよう、まず `list` で作成済みかどうかを確認することをおすすめします。

### ローカルのシートの操作

```
.pc new 张三       → キャラクターシート「张三」を新規作成
.pc tag 张三       → このグループで「张三」を使う
.pc rename 李四    → 現在のシートの名前を変更（元祖の別名：.pc nn 李四）
.pc untag          → 現在の紐付けを解除（シートは残る）
.pc list           → 自分のシートを一覧表示
.pc del 张三       → 削除
.pc @相手          → 相手のシートを表示
.pc stat 侦查      → 現在のシートの判定の統計を表示
.pc cpy 备份=张三  → 「张三」を「备份」（バックアップ）にコピー（.pc copy でも可）
.pc cpy 备份       → 現在紐付けているシートを「备份」にコピー
.pc grp            → 各グループで現在紐付けているシートを表示
.pc tojson [シート名] → 指定したシートまたは現在のシートを JSON で出力
.pc type [ルール]  → グループのルールシステムを表示 / 切り替え
.pc temp           → build に使えるシートのテンプレートを一覧表示
```

シートを紐付けると、ダイスロールで表示される名前がそのシートの名前に自動で変わります。`.pc type` は Dice!Next のグループのルールシステムをそのまま使い、ずれが生じやすい「シートの種類」を別に管理することはしません。コピーの書き方では、等号の両側の順序は `コピー先=コピー元` です。

### `.pc build` ランダム生成

```
.pc build          → COC7 のテンプレートでキャラクターシートをランダム生成（値がある能力値は飛ばす）
.pc build pc:bg    → コロンで区切って複数のテンプレートを続けて使う（pc = COC7 の能力値、bg = 背景）
.pc redo           → 現在のシートを空にしてから生成し直す
```

テンプレートは自分で作れます。JSON のテンプレートを `card-templates/`（または `data/card-templates/`）フォルダーに置いてボットを再起動すると、新しい生成のパラメーターを追加できます。ダイスの式、デッキから引いた文章、JS の式に対応しています（現時点では[ルールパック](/ja/develop/rulepack)で配布することはできず、手動で置く必要があります）。

### `.pc lock` シートのロック

```
.pc lock w         → 書き込みをロック（.st などの変更はすべて拒否）
.pc lock r         → 閲覧をロック
.pc unlock w       → ロックを解除
```

キーパーが「シートのロック」を求める場面で、セッションの途中でシートを書き換えられないようにするのに向いています。

## `.npc` グループで共有する NPC のシート

`.pc` は **自分の** キャラクターシートを管理し、`.npc` は **グループ全体で共有する** NPC のキャラクターシートを管理します。キーパーが NPC のシートを作って代わりにダイスを振るためのもので、グループチャットでのみ使えます。

```
.npc new 老猎人           → NPC「老猎人」を新規作成
.npc list                → このグループのすべての NPC を一覧表示
.npc 老猎人 st 力量50 敏捷60 → NPC に能力値を記録（.st と同じ書き方）
.npc 老猎人 ra 侦查        → 「老猎人」として目星の判定を代わりに振る
.npc show 老猎人          → その NPC のシートを表示
.npc del 老猎人           → NPC とそのシートを削除
.npc clr 老猎人           → その NPC の能力値を空にする（NPC は残す）
```

`.npc <名前> <サブコマンド>` はその NPC としてサブコマンドを実行し（`st` での記録、`ra`/`rc` での代理ロールなど）、返信の先頭に `【NPC：老猎人】` を付けます。代理ロールの途中で `.npc` を入れ子にして呼び出すことはできません。

## `.nn` / `.nnn` ニックネーム

```
.nn 阿强           → ダイスボット内のニックネームを「阿强」にする
.nn                → ニックネームを消す
.nnn               → ランダムな名前を付けてニックネームにする（中国語 / 英語 / 日本語の名前からランダム）
.nnn jp            → 日本語の名前を指定（cn / en / jp から選択）
```

シートを紐付けている場合、`.nn` / `.nnn` は紐付けているシートの名前も同時に変更し、2 つの名前を揃えます。

## グループ内の名前 `.sn` / `.setsn`

QQ 公式では実際のグループ内の名前を変更できないため、`.sn` または `/sn` を実行すると、その後の返信の先頭に現在のシートの状態が表示されます。`.sn off` で自分の状態行をオフにできます。ダイスマスターは **基本設定 → 返信と表示 → QQ 公式の SN 状態行** で、色付きの文字（既定は赤。カラーパレットやスポイトで色を変更可能）、引用、通常の文字、カスタム形式、非表示から選べます。非表示にしてもプレイヤーのテンプレートは削除されず、再び表示すると元に戻ります。グローバル、アダプターの種類ごと、アカウントごとに設定できます。ほかの対応プラットフォームでは、引き続き実際のグループ内の名前を変更します。HP や SAN などの値を返信の任意の位置に入れたい場合は、[ダイスの返信内の動的なステータスバー](/ja/manage/commands#ダイスの返信にキャラクターシートの状態を表示する)を使えます。

```
.setsn hp san dex  → このグループの名前に表示する項目を設定（グループ管理者が必要）
.sn                → グループのテンプレートに従って自分の名前を更新
.sn {nick} SAN{san} → 個人の状態の内容を設定
.sn auto           → 自動同期を有効化：能力値が変わるとすぐに名前を更新
.sn auto off       → 自動同期を無効化
.sn off            → 消去
```

`hp` / `san` / `mp` は COC のルールに従って最大値を自動で求め、「現在/最大」として表示します。

## 判定の統計 `.hiy`

```
.hiy               → 判定全体の統計を表示
.hiy 侦查          → ある技能の出目の回数 / 成功率 / 成功度の分布を表示
```

::: tip パネルでの確認
キャラクターシートは [Web 管理パネル → プレイヤー管理](/ja/manage/dashboard)でも表示・編集できます。
:::
