# coc7r：Keeper Companion の選択ルール

この機能は Chaosium の **Call of Cthulhu Keeper Companion（2026、CHA23197-H）** に対応しています。これは第 7 版のサプリメントです。`coc7r` は Dice!Next での設定名にすぎず、公式に独立した新しい版が出たという意味ではありません。以下のページ番号は本に印刷されたページ番号です。

本に載っている改訂ルールは、どれも 1 つずつ採用できる選択肢です（序文 5 ページ）。そのため、このルールパックの各部分は個別にオン・オフでき、オフにした部分は基本の CoC7 に戻ります。

## 有効化と元に戻す方法

グループの管理者が次のように入力します。

```
.set coc7r
.coc7r help
```

元の CoC7 に戻すには：

```
.set coc7
```

`.coc7r` のコマンドはすべて `.c7r` と短縮できます。切り替えはこのグループのルールを選ぶだけで、既存のシートを変換したり上書きしたりはしません。元の CoC7 のハウスルールは保持され、`coc7r` の技能判定のハウスルールは別に保存されます（既定はルール 0）。`.coc7`、`.coc6` は引き続き元の能力値を明示的に生成します。

WebUI の「ルール管理」で、このパックの各ルールの既定値を編集できます。内蔵リソースを更新しても、`data/rules/` に保存した変更や無効化の状態は上書きされません。

## 各ルール

例では内蔵ルールの中国語の技能名を使っています。たとえば 侦查（目星）、安抚（安心させる）、理智（SAN）、幸运（幸運）です。

| ルール名 | 内容 | 既定 | 本のページ |
| --- | --- | --- | --- |
| `creation` | `.coc`、`.pc build` が `(2D6+5)×5` の能力値を 8 つ示し、プレイヤーが自由に割り振る。シートには書き込まない | オン | 9–10 |
| `skills` | 改訂版の技能表：新しい基本値。安心させる は APP/5。魅惑・言いくるめ・威圧の入力は 説得 として扱い、伝承 は オカルト として扱う | オン | 15、17–24 |
| `movement` | MOV＝`7+(STR>SIZ)+(DEX>SIZ)`。年齢による修正は残す | オン | 10 |
| `sanity` | 正気度の改訂：ショック、余波、Changed、Lost、安心させる、現実の判定、神話による成長と回復 | オン | 85–99 |
| `bases` | 能力値から技能の基本値を計算（`skills` が必要） | オフ | 23–24 |
| `specialties` | 近接戦闘／射撃の専門分野を同じ系統の最高値の半分以上にする（`skills` が必要） | オフ | 19 |
| `take5` | 成長判定の成功時に 1D10 を振らず、常に +5 する | オフ | 51 |

```
.coc7r options
.coc7r options sanity off
.coc7r options take5 on
```

変更できるのはグループの管理者だけで、グループでの設定がルールパックの既定値より優先されます。記録済みの技能の合計値は、能力値が変わっても再計算しません。専門分野の下限は有効な値にだけ影響し、元の数値は書き換えません。明示的な成長の式（`.en 侦查0+3` など）は元の意味のままです。`take5` を有効にした状態で通常どおり 1D10 を振りたい場合は `.en 侦查 +1d10` と書きます。

宗教、言語、科学などは専門分野を指定してください。たとえば `.st 宗教(道教)30`（宗教（道教））、`.ra 母语(汉语)`（母国語（中国語））です。「サブマシンガン」だけでは技能を判定できません。実際の武器に合わせて 拳銃 か ライフル／ショットガン を選んでください。

## キャラクター作成と移動

```
.coc7r
.coc7r 3
.coc7r array 1
.pc new 新调查员
.st STR60 CON60 SIZ50 DEX65 APP60 INT70 POW60 EDU65 年龄30
.coc7r mov
.st show 兴趣点
```

生成されるのは能力値の候補だけなので、割り振った後は自分で保存してください。`.coc7r` と `array` はどのグループでも使えます。興味ポイント（兴趣点）は EDU+INT です。ポイント購入は合計 480 点で、各能力値は 30–90 です。独自の職業では、職業技能（信用を含む）を 6–12 個選び、300 点を割り振ります。年齢（年龄）による能力値の調整、幸運、職業と技能ポイントの割り振りは、引き続き本と KP の指示に従って行ってください。POW を記録すると、SAN が自動で POW の値になります（85 ページ）。

### 旧シートの技能の統合

```
.coc7r migrate
.coc7r migrate @相手
```

旧シートの 魅惑・言いくるめ・威圧 は 説得 に、伝承 は オカルト に、サバイバルの各専門分野は サバイバル にまとめ、いずれも最高値を取り、古い項目は削除します。ルールを切り替えても自動では統合せず、`migrate` を実行したときだけシートを変更します。他人のシートを変換するにはグループの管理者が必要です。サブマシンガンは自動では変換しないので、実際の武器に合わせて記録し直してください。

## 正気度と状態

```
.sc 0/1d6
.sc 0/1d6 mythos
.coc7r loss 1d4 mythos
.coc7r show
.coc7r show @相手
```

`mythos` は、その喪失がクトゥルフ神話によるものだと KP が確認したことを表し、プログラムが説明文から原因を推測することはありません。書物や呪文などによる直接の喪失には `loss` を使い、SAN をもう一度振ることはしません。通常の `.sc` ではボーナス／ペナルティダイスとプッシュは使えず、失敗側の式のファンブルでは計算できる最大の喪失を取ります。0 以上の整数、NdM、足し算・引き算の組み合わせに対応しています。対応していない式には使い方を表示し、最大値をランダムに推測することはありません。

- `.sc 0/1d6 50` のように値を指定した場合は計算だけを行い、シートに書き込まず、POW、INT、累積の状態も推測しません。
- 自動の処理にはシートに POW と INT が必要です。SAN がまだ記録されていない場合は POW で判定します。SAN と状態は一度にまとめて保存し、シートのロック、同時の変更、保存の失敗があれば書き込みを拒否します。
- 1 回の実際の喪失が 5 に達すると INT を振ります。成功するとショック状態になり、プレイヤーが表れ方を選び、1D10 ラウンド続きます。すでに Changed の場合、基準は 10 です。
- この章の累積の喪失が POW の 5 分の 1 に達すると Changed になります。5 分の 1 は公式の能力値の端数処理に従って切り捨てます。たとえば POW=51 なら 10 です。
- SAN=0 は Lost で、回復のコマンドはそれ以上の治療を拒否します。SAN を回復しても累積の喪失は減りません。

状態の終了は、いずれも KP がゲーム内で確認して行い、現実の時計で自動的に解除されることはありません。

```
.coc7r end shock
.coc7r end sleep
.coc7r end chapter
.coc7r end changed
```

| コマンド | 効果 |
| --- | --- |
| `end shock` | ショックのラウンドが終わり、以後は喪失を免れない |
| `end sleep` | 安全な場所で一晩眠り、余波を終わらせる |
| `end chapter` | 新しい章：累積の喪失と、この章での 安心させる による回復の回数をリセット。Changed は解除しない |
| `end changed` | 少なくとも 1 週間の休養と、背景の改訂・固定を KP が確認したうえで Changed を解除 |

状態はシートと一緒に保存され、名前の変更や再起動の後も残ります。章の記録はプラットフォーム／アダプター／会話ごとに分かれています。シート自体は従来の共有ルールのままなので、同じシートを複数のグループに紐付けている場合、シートの SAN は 1 つの値のままです。

`.st` は手動でのシートの変更で、喪失の原因を推測したり正気度の処理を実行したりはしません。章に記録すべき減少には `.sc` / `loss` を使ってください。`sanity` が有効なとき、`.st 理智` は 99−クトゥルフ神話 を超えません。POW を手動で調整した後は、`.coc7r loss 0` で新しい基準によって状態を再計算できます。

## 安心させる、神話による成長、現実の判定

```
.ra 安抚
.coc7r reassure @相手
.coc7r reassure @相手 push
.coc7r reassure 相手のユーザーID
.coc7r mythos first
.coc7r mythos later
.sc reality
.sc reality b
```

`reassure` は相手を @ するか、相手のユーザー ID を直接書いて使えます。他人のシートに書き込むため、代わりに処理できるのはグループの管理者だけです。一般のプレイヤーは先に `.ra 安抚` を振ってから KP に処理を依頼してください。対象にはすでにシートと必要な値があることが必要で、自分自身を安心させることはできません。成功すると SAN が 2 回復し（1 章につき 1 回だけ。最大 SAN の制限あり）、ショックを終わらせ、恐怖症を一時的に抑えます。余波は残ります。

**安心させる のファンブル／プッシュの失敗は、現在 1D4 の SAN 喪失としています。** 原書では 22 ページに 1D4、94 ページに 1D6 と書かれており、これは現時点で明確に選んだ扱いで、公式の正誤表があるとは主張していません。`push` は、直前の 安心させる が失敗し、KP が許可した場合にだけ使えます。

神話によるショック／Changed は処理待ちのイベントとして登録され、最初に `first` を選ぶと 5、以後の `later` では 1 が加わります（88 ページ。正気度の改訂の本文のルール）。1 つのイベントで両方が起きた場合は 1 回だけ数えます。すでに確認したシートは、初回の報酬を再び受け取れません。

現実の判定は正気度ロールの一種です。失敗すると SAN を 1 失い、成功すると次に SAN を失うまで幻覚に抵抗します。`b` は、別の探索者がすでに 安心させる に成功して手助けしていることを表し、ボーナスダイスが 1 つ加わります。

## 正気度の回復

KP が条件を確認した後に使います。

```
.st 理智+1d6
.coc7r therapy 80
.coc7r therapy 80 phobia
.coc7r therapy 80 push
.coc7r selfhelp INT 30 5
```

- 章の終わりの KP からの報酬は `.st 理智+式` で直接与え、99−クトゥルフ神話 を超えることはありません。
- `therapy` はゲーム内の 1 か月に 1 回で、治療する側の技能か施設の評価を使います。成功すると 1D3 回復するか、`phobia` を選んで恐怖症を 1 つ取り除きます。失敗すると回復せず、ファンブル／プッシュの失敗では 1D6 を失い、治療関係が終わることを知らせます。
- `selfhelp` は成長の段階で使います。先に INT か POW を振り、**すでに振った D100 の結果** と、任意で消費する幸運を入力すると、プログラムはその結果で処理し、振り直しはしません。ハード成功に達すると 1D6 回復し、届かなければ SAN を 1 失い、背景の改訂と固定を促します。持っている以上の幸運を使ったり、ファンブルを書き換えたりはできません。
- 実際のプレイ中に `.en` で技能が 90 未満から 90 に達すると、2D6 の SAN の報酬を自動で処理します。技能の作成や手動での変更では報酬は得られません。
- Changed のあいだは `.en 幸运` による回復を拒否しますが、ルールに従って幸運を消費することはできます。

治療の月、成長の段階、KP の報酬の資格はゲーム内の時間を使い、KP が確認します。サーバーの日付によって自動で認められることはありません。

## 戦闘と追跡

```
.coc7r ri
.coc7r chase 7 fail 3
```

`ri` は円卓式のイニシアチブ（59 ページ）です。攻撃を仕掛けた側が先に行動し、争いがある場合は DEX の高い方が先です。1D6 を 1 回振り、偶数なら左、奇数なら右へ順番を回し、その戦闘のあいだはこの方向を使います。席の順番は KP が管理します。

追跡では、現在の MvP と、判定済みの成功／失敗／プッシュの失敗を入力します。失敗すると 1D6 を振って MvP を消費し、MvP が残っていれば 1 歩進みます。0 になると脱落し、プッシュの失敗ではすぐに脱落します。開始時の MvP は通常 MOV と同じで、重傷を負うと半分になります。場所、障害、判定の難易度、仲間の手助け、物語上の結果は引き続き KP が管理します。

## 実装の範囲

このパックが提供するのは、繰り返し計算できる仕組みと既存のダイスコマンドへの対応であり、**本全体を自動で進行するシステムではありません**。自動射撃と掃射、近距離での銃器による反撃、集団の敵、爆発の場面、重傷／瀕死の治療の手順、職業の一覧、恐怖症の表、背景の物語は、引き続き KP が基本的なダイスと本のルールを使って扱います。

参考：[Chaosium 公式の製品ページ](https://www.chaosium.com/call-of-cthulhu-keeper-companion-hardcover/)、[公式の能力値の半分／5 分の 1 の端数処理の説明](https://cthulhuwiki.chaosium.com/investigators/step-one-investigator-characteristics.html)。
