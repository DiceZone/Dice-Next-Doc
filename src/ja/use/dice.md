# ダイスと判定

すべてのコマンドは `.`（半角ピリオド）で始まります。既定では `。`、`!`、`！`、`/` も使え、独自の接頭辞は基本設定に従います。コマンドの引数には **半角** の記号を使ってください。

> このページでは「汎用ダイス」「COC の判定」「BRP の判定」「DND」の 4 種類を扱います。キャラクターシートについては[キャラクターシート](/ja/use/card)を、娯楽コマンドについては[娯楽と交流](/ja/use/fun)を参照してください。

::: tip 例に出てくる能力値・技能の名前
判定はキャラクターシートに記録された名前を読み取ります。例では内蔵の COC ルールの中国語名を使っています。たとえば 侦查（目星）、聆听（聞き耳）、心理学（心理学）、斗殴（近接戦闘・格闘）、力量（STR）、敏捷（DEX）、体型（SIZ）、理智（SAN）です。お使いのシートで使っている名前に置き換えてください。式の後ろの文章（攻击 = 攻撃、测试 = テスト など）は返信に表示される理由になります。
:::

## 汎用ダイス

| コマンド | 説明 |
|------|------|
| `.r` / `.rs` | 通常のロール / 最終値だけを表示。既定のダイスは `.set` で変更できます |
| `.rd` | 既定のダイスを振る（`.rd6` のように面数を付けるとそのダイスを振ります） |
| `.rh` / `.h` / `.H` | シークレットダイス。結果は個人チャットで届きます（`.h` / `.H` は元祖の短い別名） |
| `.rah` / `.rch` | シークレット判定（COC）。結果は個人チャットで届きます |
| `.rx` | 心理学のシークレットロール（キーパー用） |
| `.ww` | WOD のダイスプール（成功数を数え、10 で追加ロール） |
| `.dx` | ダブルクロスの連鎖ロール |
| `.set` | 個人の既定のダイスを設定 / リセット、またはグループのルールシステムを切り替え |

### `.r` ロール

```
.r 3d6+2 攻击      → 3d6 に 2 を足して振る。理由は「攻击」
.r3d6+2 攻击       → 同上。コマンドと式のあいだの空白は省略可
.r 2#d20           → d20 を 2 回続けて振る
.rs 3d6+2          → 最終値だけを表示し、ダイスを 1 つずつ展開しない
.rd                → 既定のダイスを振る（未設定なら d100）
.rd6               → d6 を振る
.r 1d3+db          → db はキャラクターシートのダメージボーナスの式に自動で展開
.r 他带着西服去干洗店 → 式ではない文章は理由になり、既定のダイスを振る
.r 1次掷骰          → 数字の直後に文字が続く場合は全体が理由になり、既定のダイスを振る
.rd 1次掷骰         → 同上。d の直後が空白の場合、d は既定のダイスを表す
```

`.r` の後ろの文章がダイスの式でない場合は理由として扱い、既定のダイスを振ります。これは元祖 Dice! と同じ動作です。数字だけでダイスを含まない書き出し（「1次掷骰」「3次攻击」＝「1 回振る」「3 回攻撃」など）も全体を理由として扱います。固定の式を振りたい場合は、`.r 1d6 打了3次` のようにダイスを明示してください。ダイスマスターは[基本設定](/ja/manage/settings)で「ロールの理由を無効にする」を有効にでき、その場合は結果だけを表示して理由は表示しません。

式の中の `db`（ダメージボーナス）は、キャラクターシートに記録した式に自動で置き換わります。手動で記録していない場合は、COC7 のルールに従って STR + SIZ からその場で計算します。詳しくは[キャラクターシート](/ja/use/card)を参照してください。

### `.rh` / `.h` シークレットダイスとシークレット判定

```
.rh 1d100          → シークレットダイス。結果は個人チャットで届く
.h 1d100           → 同上。大文字の .H も使え、.help の邪魔をしない
.rah 侦查           → シークレット判定（シートを読む）。結果は個人チャットで届く
.rch 侦查 60        → 成功率を指定したシークレット判定。結果は個人チャットで届く
```

グループには「誰かがシークレットダイスを振った」とだけ表示され、ほかの人には出目が見えません。ハウスルール（`.setcoc`）やボーナス・ペナルティダイスなどは通常どおり適用されます。

### `.rx` 心理学のシークレットロール

```
.rx @相手          → @ した探索者に対して心理学の判定を 1 回行う
.rx @相手 40       → 成功率を指定
```

キーパー専用です。成功度を含む詳しい結果は **あなたの個人チャットに届き**、グループにはネタバレにならない通知が 1 行だけ出ます。成功率を省略した場合は相手のシートの「心理学」を読み、既定値は 10 です。

### `.ww` WOD のダイスプール

```
.ww 8              → d10 を 8 個振り、8 以上を成功と数え、10 は追加で振る
.ww 8 7            → 成功の基準を 7 に変更
.ww8测试           → ダイスの直後にそのまま理由「测试」を付けられる
.ww 8a10c7 攻击    → 追加ロールの基準 / 成功の基準を指定し、理由「攻击」を表示
```

`.r` とは異なり、`.ww` は出目の合計ではなく **成功数** を数えます。

### `.dx` ダブルクロス

```
.dx 3c8            → ダイス 3 個、クリティカル値 8（到達すると追加ロール）
.dx 5 10           → 同じ意味の書き方（空白で区切る）
.dx5c10测试        → 空白なしで理由を付けると、返信に「掷骰 测试」と表示
.dx 5c10 测试     → 空白ありの書き方。効果は同じ
.dx 5a7            → a の書き方：上限なしの追加ロールのダイスプール（成功数を数える WOD 方式）
```

### `.rs` 短い結果 / フェイト（NdF）

```
.rs 3d6+2          → 最終値だけを表示し、計算の過程を表示しない
.rsh d100          → 短い結果とシークレットの指定を組み合わせられる
.r 4dF             → フェイト（FUDGE）ダイスを 4 個振る
```

`.rs` は元祖 Dice! の短い結果の動作を再現したものです。フェイトダイスは引き続き `NdF` の式で振ります。フェイトダイスの各出目は `+`、`0`、`-`（+1 / 0 / −1）で、完全な結果は `4dF=[+ − 0 +]=1` のようになります。

### `.set` 既定のダイスとルールシステム

```
.set 20            → 個人の既定のダイスを d20 にする（1-9999）
.set               → d100 に戻す
.set list          → 切り替えられるルールシステムを一覧表示（★ がグループの現在のもの）
.set coc7          → グループのルールシステムを切り替え、既定のダイスも連動（グループ管理者が必要）
```

既定のダイスを設定すると、式なしの `.r` と `.rd` はどちらも既定のダイスを振ります。ルールシステムは[ルールパック](/ja/develop/rulepack)で提供され、切り替えるとパック内のコマンドや同義語などがグループごとに有効になります。

## COC（クトゥルフ神話 TRPG）

| コマンド | 説明 |
|------|------|
| `.coc` | COC7 の探索者の能力値を生成 |
| `.ra` / `.rc` | 技能 / 能力値の判定（キャラクターシートを自動で読む） |
| `.rb` / `.rp` | ボーナスダイス / ペナルティダイス |
| `.rad` | まず d100 を振り、同じ出目で判定する |
| `.rav` | 対抗判定 |
| `.sc` | 正気度ロール（SAN を自動で減らしてシートに保存） |
| `.en` | 技能の成長 |
| `.ti` / `.li` | 一時的狂気 / 不定の狂気の症状 |
| `.setcoc` | グループのハウスルール（クリティカル / ファンブルのルール）を設定 |
| `.hiy` | 判定の統計 |

### COC のキャラクター作成 `.coc`

```
.coc / .coc7       → COC7 の探索者の能力値を 1 組生成
.coc6              → COC6 の探索者の能力値を 1 組生成
.cocd / .coc7d     → COC7 の詳細なキャラクター作成の結果
.coc6d             → COC6 の詳細なキャラクター作成の結果
.coc7d 3           → 一度に 3 組生成（最大 10 組）
```

元祖で列の配置に使われていた末尾の `s` も受け付けます（例：`.coc7ds 3`）。数値のルールは変わりません。

### 判定 `.ra` / `.rc`

```
.ra 侦查           → キャラクターシートの目星の値で判定
.ra 力量60         → 値を一時的に指定して判定
.ra 困难侦查        → 難易度ハード（困难 = ハード）
.ra 侦查 @相手      → 相手の代わりに判定（相手のシートを読む）
.ra 2#侦查         → 2 回続けて判定
```

`.ra 侦查-20` / `.rc 侦查+20` のような一時的な修正は、現在紐付けているキャラクターシートの実際の値（記録済みの関連能力値を含む）に対して適用します。記録がない場合だけルールの基本値を使い、シートは書き換えません。たとえば目星が 50 なら、それぞれ 30 と 70 で判定します。

### 成功率の計算

成功率は式で書けます。判定、対抗判定、能力値の変更は同じ計算ルールを使います。

```
.ra 力量+20-30        → 複数の足し算・引き算（STR が 60 なら 50 で判定）
.ra 力量 +20 -30 攻击  → 修正は空白で区切って書け、その後ろの文章は理由のまま
.ra 力量*2 / .ra 力量/2 → 掛け算と割り算。結果は切り捨て
.ra (力量+敏捷)/2      → 括弧と複数の能力値
.ra 侦查+1d10         → ダイスを振り、返信に出目を表示
.ra 力量^0.5*10       → べき乗と sqrt、cbrt、exp、ln、log、sin、cos、max、min などの関数、定数 pi、e
.ra 力量70+10         → まずインラインの値をシートの値の代わりに使ってから計算
.rav 力量+10 敏捷-5    → 対抗判定の両側でも使える
.rc 力量+2-1          → DND モードでは修正値に適用
.st hp-1d6+2         → 記号の後ろ全体が 1 つの量：(1d6+2) を減らす。武器のダメージ式をそのまま写せる
```

`.st` の `+` / `-` の後ろ全体は 1 つの量として扱います（元祖 Dice! と同じ）。そのため、小さい出目が出てもダメージが回復に変わることはありません。部分ごとに計算したい場合は括弧を付けるか、複数のコマンドに分けてください。判定の修正（`.ra 力量+20-30` など）は技能値に対する一連の足し算・引き算です。

途中は実数で計算し、最終結果は切り捨てます。判定の成功率の最低値は 1 です。記録されていない能力値を参照すると、その名前を示して知らせます。構文エラー、0 による割り算、範囲外の値（`10^1000` など）は推測で結果を出さず、すぐにエラーになります。悪用を防ぐため、1 つの式は最大 512 バイト、括弧の入れ子と項の数には上限があり、式全体で振れるダイスは最大 1000 個です。

出目を固定するプレビューの書き方 `.ra(1)50` は影響を受けません。括弧の中が数字とダイスだけで、後ろに演算子が続かない場合だけプレビューの出目とみなし、`.ra (力量+敏捷)/2` は式として扱います。

既定の状態と、`coc7` / `coc7r` に切り替えた後は、`.ra` と `.rc` はどちらも d100 を使います。`.pc type coc7r`（`.set coc7r` と同じ）は古い DND モードも終了し、`.setcoc <0-7>` でも CoC の判定に戻ります。`.rc` が d20 を使うのは DND を明示的に有効にした場合だけで、`.ra` は常に CoC の判定です。ビジュアルな返信の「もう一度判定」は任意のショートカットで、元のコマンドの修正、難易度、理由、接頭辞を保持します。自動で振り直すことはありません。

以前の混在モードの問題の影響を受け、`.st` で技能を DND の独立した技能領域に誤って保存していた場合は、CoC に切り替えてから `.st 侦查50` などでもう一度記録してください。更新によって、DND の技能ボーナスがすべて CoC のパーセンテージとして自動でシートに移されることはありません。実際の DND のデータと混同しないためです。

判定では成功度を自動で判断します：クリティカル / イクストリーム / ハード / レギュラー / 失敗 / ファンブル。グループの `.setcoc` のハウスルールの影響を受けます。

### ボーナス / ペナルティダイス `.rb` / `.rp`

```
.rb 侦查           → ボーナスダイス 1 個
.rp2 60            → ペナルティダイス 2 個で、60 に対して判定
.rapass23          → 続けて書いた形：「長いコマンドを優先」して .rap ass 23 と解釈
```

### `.rad` 同じ出目での判定

```
.rad               → d100 を 1 つ振り、そのまま「d」として判定
.rad 侦查          → 1 行目は .r と同じくロールの過程を表示し、2 行目で同じ出目を使って目星を判定
.rad 侦查50 搜书房  → 同上。成功率を一時的に指定し、理由（搜书房 = 書斎を調べる）を付ける
.rad 打了3次怪      → 技能ではない：文全体が理由になり、.rad と同じ
```

「先にダイスを見せてから技能に当てはめる」遊び方に向いています。2 行とも **同じ出目** を使います。

### 対抗判定 `.rav`

```
.rav 侦查 @相手     → 双方が d100 を振り、まず成功度を、次に出目を比べる
.rav 斗殴 60       → 自分はシートを読み、相手は値を直接指定
```

### 正気度ロール `.sc`

```
.sc 1/1d6          → 成功で 1、失敗で 1d6 減少。シートの SAN から自動で減らす
.sc 1d3/1d10 50    → 現在の SAN を 50 と指定
.sc b 1/1d6        → ボーナスダイス 1 個付きの正気度ロール（.scb でも可）
.sc p2 1/1d6       → ペナルティダイス 2 個付き
```

### 技能の成長 `.en`

```
.en 侦查            → 目星について d100 を振り、現在値を超える（または >95）と 1d10 成長してシートに保存
.en 侦查 60         → 技能値を一時的に指定
.en侦查60           → 元祖の詰めた書き方。上と同じ
.en 侦查 +1d6       → 成功時の成長量を指定（+/- で始める）
.en 侦查 -1/+1d10   → 「失敗時の変化 / 成功時の変化」の 2 段階
.en 侦查 0 -1/1     → 失敗で 1 減り、成功で 1 増える。両側の符号はそれぞれ計算
.en 侦查 聆听        → 複数の技能をまとめて成長（.en 侦查|聆听 とも書ける）
```

### 狂気の症状 `.ti` / `.li`

```
.ti                → 一時的狂気の症状を 1 つ引く
.li                → 不定の狂気の症状を 1 つ引く
```

### ハウスルール `.setcoc`

変更にはグループ管理の権限が必要です。設定は現在のグループの現在のボットアカウントにだけ適用され、同じグループの複数のボットアカウントが互いに上書きすることはありません。coc7r のハウスルールは別に保存されます。

```text
.setcoc 2          → ハウスルール 2 を設定（0–7）
.setcoc show       → 現在のハウスルールを表示
.setcoc help       → 各番号の意味を表示（.help setcoc / .setcoc list でも可）
.setcoc clr        → ルール 0 に戻す
.setcoc dg         → ルール 6 を使う
```

下の表では、A は技能値、D は D100 の結果を表し、整数の割り算は 0 の方向へ丸めます。特別な成功・失敗は通常の成功度より先に判定します。

| ルール | クリティカル | ファンブル | その他の成功度 |
| --- | --- | --- | --- |
| 0（既定） | D=1 | A<50 のとき D≥96、それ以外は D=100 | 通常の区分 |
| 1 | A<50 のとき D=1、それ以外は D≤5 | ルール 0 と同じ | 通常の区分 |
| 2 | D≤5 かつ D≤A | D=100、または判定失敗かつ D≥96 | 通常の区分。例：A=99、D=99 は成功のまま |
| 3 | D≤5 | D≥96 | 通常の区分 |
| 4 | D≤5 かつ D≤A/10 | D=100、または A<50 で判定失敗かつ D≥96+A/10 | 通常の区分 |
| 5 | D≤2 かつ D<A/10（厳密に小さい点に注意） | A<50 のとき D≥96、それ以外は D≥99 | 通常の区分 |
| 6（DG） | 判定成功かつ D=1 またはゾロ目 11/22/…/99 | 判定失敗かつ D=100 またはゾロ目 | それ以外はレギュラーの成功 / 失敗のみで、ハード / イクストリームなし。A=100、D=100 はレギュラーの成功 |
| 7 | クリティカルなし | D=100、または D=96–99 かつ (90−A)/20+D≥100 | D<96 のとき、D=1 または D≤A/5 はイクストリーム、それ以外は A に従ってレギュラーの成功 / 失敗。96–99 でファンブルでなければ失敗。ハードの成功はなし |

ルール 0–5 の「通常の区分」：D≤A/5 はイクストリーム、D≤A/2 はハード、D≤A はレギュラーの成功、それ以外は失敗です。たとえばルール 5 で A=20、D=2 の場合はクリティカルではなくイクストリームです。ルール 7 で A=50 の場合、98–100 はファンブルです。

ハウスルールは COC の技能判定とボーナス・ペナルティダイスに影響し、通常の `.r` の出目やほかのルールシステムは変わりません。正気度ロールには正気度の喪失そのものの計算ルールがあるため、技能の成功度をそのまま正気度喪失の式として使うことはできません。

### 判定の統計 `.hiy`

```
.hiy               → 判定全体の統計を表示
.hiy 侦查          → ある技能の出目の回数 / 成功率 / 成功度の分布を表示
```

## BRP（ベーシック・ロールプレイング）

| コマンド | 説明 |
|------|------|
| `.ba` | BRP の判定（d100 の下方ロール） |
| `.bav` | 抵抗表による対抗 |

### `.ba` BRP の判定

```
.ba 侦查           → シートを読んで判定
.ba 斗殴60         → 成功率を指定
.ba 侦查 @相手      → 代わりに振る
.ba 2#侦查         → 連続で振る
```

成功度：クリティカル ≤ 技能/20、スペシャル ≤ 技能/5、成功 ≤ 技能、失敗 > 技能、ファンブル（100 が出た場合、または失敗して 99 が出た場合）。

### `.bav` 抵抗表による対抗

```
.bav 力量 体型      → 能動側の STR 対 受動側の SIZ（能力値の名前はシートから読み、数値を直接入れても可）
```

目標% = 50 +（能動 − 受動）× 5 で、1d100 が目標以下なら能動側の勝ちです。

## DND（ダンジョンズ＆ドラゴンズ）

| コマンド | 説明 |
|------|------|
| `.dnd` | DND の能力値を生成（4d6 の上位 3 つ） |
| `.setdnd` | グループの DND5e モードを切り替え |
| `.rc` | DND モードでの d20 判定（有利 / 不利） |
| `.buff` | 一時的な能力値ボーナス |
| `.ri` / `.init` | イニシアチブの一覧 |
| `.ss` | 呪文スロットの管理 |
| `.cast` | 呪文スロットを消費して呪文を使う |
| `.longrest` | 大休憩（HP 回復と呪文スロットの全回復） |
| `.ds` | 死亡セーヴィング・スロー |

### DND モード `.setdnd`

```
.setdnd on         → グループの DND5e モードを有効にする（.rc が d20 の判定になる）
.setdnd off        → 無効にする（.rc は COC の d100 に戻る）
.setdnd            → 切り替え
```

### d20 判定 `.rc`

DND モードでは `.rc` が d20 の判定になります。6 つの能力値は、まず能力値（`.buff` のボーナスを含む）を `切り捨て((能力値−10)/2)` の修正値に換算し、コマンドに書いた一時的な修正を加えます。技能は記録した判定ボーナスを使います。たとえば STR が 18 の場合、`.rc 力量-5` は `1d20 +4 -5` になります。

```
.rc 力量           → 1d20 + STR の修正値
.rc 优势 力量+2     → 有利（d20 を 2 つ振って高い方）に、さらに +2（优势 = 有利）
.rc 劣势 敏捷       → 不利（低い方）（劣势 = 不利）
.rc 5 攻击         → 修正値 5 を直接指定
```

### 修正値の判定 `.rdc`

`.rdc` は「能力値の修正値」で直接判定します。能力値は `(能力値−10)/2` を切り捨て、技能は独立した判定ボーナスを読み取ります。

```
.rdc 力量+2 破门 15       → 1d20 + STR の修正値 + 2、理由「破门」（扉を破る）、目標値 15（以上で成功）
.rdc 3# B 力量+2 破门 15  → 3 回。B は高い方（P は低い方）
```

回数は最大 9 回で、`N#` の接頭辞を使います。`.rdc` は DND5e モードを有効にしたグループ（`.setdnd on`）でのみ使えます。

### 一時的なボーナス `.buff`

```
.buff 力量:2       → STR +2 のバフを設定
.buff 力量+1       → 増減
.buff              → 現在のバフを表示
.buff del 力量     → 1 つを削除
.buff clr          → すべて削除
```

バフは DND モードの `.rc` の判定と能力値の読み取りに反映されます。

### イニシアチブ `.ri` / `.init`

```
.ri +2             → d20+2 を振ってイニシアチブに加わる
.ri +2 哥布林       → 名前を指定して加わる（哥布林 = ゴブリン）
.ri +1d4 哥布林     → d20+1d4 を振る。修正のダイス式を名前とはみなさない
.ri 1d6 哥布林      → 指定したイニシアチブの式を使う
.ri 1d6 3#哥布林    → 独立した 3 つのイニシアチブ。それぞれ d6 を振って番号を付ける
.init              → イニシアチブ値の順に表示
.init clr          → イニシアチブの一覧を空にする
.init del 哥布林    → 1 件削除
```

### 呪文スロット `.ss` / `.cast`

```
.ss init 4 3 2     → 1/2/3 レベルの呪文スロットの上限を設定
.ss set 3环 5      → 1 つのレベルだけ設定（3环 = 3 レベル）
.ss 3环 -1         → 増減
.ss                → 現在の呪文スロットを表示
.ss rest           → すべて回復
.ss clr            → 設定を消去
.cast 3            → 3 レベルの呪文スロットを 1 つ消費
.cast 3 2          → 2 つ消費
```

### 大休憩 `.longrest` / 死亡セーヴ `.ds`

```
.longrest          → HP を最大値まで回復し、呪文スロットをすべて回復（.长休 でも可）
.ds                → 死亡セーヴィング・スロー（.死亡豁免 でも可）。HP が 0 である必要がある
```

死亡セーヴは DND5e のルールに従います。成功が 3 回たまると安定し、失敗が 3 回で死亡します。20 が出ると HP が 1 回復し、1 が出ると失敗 2 回として数えます。大休憩の前に `.st hpmax:<値>` で最大 HP を設定しておく必要があります。

## コマンドの決まりごと

- 記号は半角を使います。`[必須]`、`(省略可)`。
- 複数回の判定には `N#` の接頭辞を使い、チャットを埋めないようにします。
- **コマンドと引数のあいだの空白は省略できます**（元祖 Dice! と同じ）。`.help指令`、`.ri+2`、`.rd6` はいずれも有効です。名前が重なる場合は「長いコマンドを優先」して解釈します（例：`.rapass23` = `.rap ass 23`）。短いコマンドにアルファベットの引数を渡したい場合は空白で区切ってください。
- 頻度制限に達するとクールダウンがあります。しばらくお待ちください。
