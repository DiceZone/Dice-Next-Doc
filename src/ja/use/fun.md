# 娯楽と交流

グループチャットを盛り上げる、気軽な日常のコマンドです。

## コマンド一覧

| コマンド | 説明 |
|------|------|
| `.jrrp` | 今日の運勢 |
| `.mrrp` | 明日の運勢 |
| `.zrrp` | 昨日の運勢 |
| `.name` | ランダムな名前（別名 `.gn`） |
| `.nnn` | ランダムに名前を変える |
| `.me` | 文章の代弁 |
| `.ak` | 選択肢から選ぶ |
| `.sleep` | 休む |
| `.text` | 文章テンプレートの評価 |
| `.alias` / `.&` / `.a` | グループと個人のショートカット |
| `.rpmode` | ボットのペルソナの切り替え |
| 好感度 | 好感度の仕組み（下記参照） |

## 運勢 `.jrrp` / `.mrrp` / `.zrrp`

```
.jrrp              → 今日の運勢（1 人 1 日ごとに固定）
.jrrp on / off     → グループ管理者がこのグループの今日の運勢をオン / オフ（永続的に保存）
.mrrp              → 明日の運勢（先に明日を見る）
.zrrp              → 昨日の運勢（昨日を振り返る）
```

運勢の値は「使った人 + 日付」から決まった方法で生成されるため、同じ日に何度調べても同じ結果になります。

## ランダムな名前 `.name` / `.nnn`

```
.name              → ランダムな名前を 1 つ（名前ごとに中国語 / 英語 / 日本語からランダム）
.name en 3         → 英語の名前を 3 つ生成（cn / en / jp から選択、一度に最大 10 個）
.nnn               → ランダムに名前を付けて、そのまま自分のニックネームにする
.nnn jp            → 日本語の名前を指定して変更（cn / en / jp から選択）
```

国を指定しない場合、名前ごとに中国語 / 英語 / 日本語からランダムに選びます（元祖の「ランダムな名前」の混合デッキと同じ）。`.nnn` は `.nn` と同じく、現在紐付けているキャラクターシートの名前も同時に変更します。

## 代弁 `.me`

入力した本文をボットに代わりに言わせます（セッションでよく使う「ナレーション」）。発言者の名前は自動では付きません。

```
.me 推开了古宅的大门       → 推开了古宅的大门（古い屋敷の扉を押し開けた）
.me on / off               → グループ管理者がこのグループの .me をオン / オフ
```

- 一般のユーザーも Master も本文のとおりに代弁し、シートの名前やニックネームを自動で付けません。名前が必要な場合は本文に自分で書いてください。
- 個人チャットから指定したグループへ代弁できます：`.me <グループ番号> <動作>`。
- `.me` は全体またはグループごとに無効にできます（`.group +禁用me`）。

## 選択肢から選ぶ `.ak`

いくつかの候補を並べて、運命に選んでもらいます（チャットごとに保存）。

```
.ak#走哪条路               → 選択「走哪条路」（どの道を行くか）を新規作成
.ak+左边的隧道|右边的楼梯   → 選択肢を追加（| で区切ると一度に複数追加）
.ak-2                      → 2 番目の選択肢を削除
.ak show                   → 現在の選択肢を表示
.ak=                       → ランダムに 1 つ引く（引いた後は自動で空になる。元祖と同じ）
.ak clr                    → 手動で空にする
```

新規作成のときに 1 行でまとめて書くこともできます：`.ak#タイトル+選択肢1|選択肢2`。

## 休む `.sleep`

```
.sleep             → ボットが休みに行き、休むときの一言を返す
```

## 好感度の仕組み

ボットはあなたとの好感度を覚えていて、称号を付けます（厌恶 嫌い / 陌生 初対面 / 友好 友好的 / 亲密 親密 / 挚友 親友 / 恋人 恋人）。

```
好感               → 自分の好感度と称号を表示（接頭辞は不要）
好感排行           → 全体の好感度ランキング
群内好感排行       → このグループの好感度ランキング
```

ダイスマスターと信頼の高いユーザー（信頼レベル 4 以上。[グループ管理とシステム](/ja/use/admin)を参照）は好感度を調整でき、`@相手` で対象を指定できます。

```
.好感增加 10       → 好感度を増やす（.favor add 10 でも可）
.好感成长          → 元祖 DiceFavor のルールで成長を 1 回振る
.好感覆写 50       → 好感度の値を直接上書き（.favor set）
.好感擦除          → 好感度の記録をすべて消去（.favor clr）
```

好感度が高いほど自然な成長は難しくなります（元祖 DiceFavor の成長判定を再現）。

## 文章テンプレート `.text`

`.text` は文章の `{波括弧}` 内の式と変数を評価して出力します。SealDice の `.text` と互換です。

開発中の旧来のランダムな選択との互換として、`.text {sample:效果拔群|干得漂亮}` にも対応しています。候補には `.text` が対応する変数やダイスの式を含められます。build 909 以前ではまだ対応していません。

```
.text 看看手气 {1d16}      → 看看手气 7（「運試し 7」）
.text {$t玩家} 掷出 {2d6}   → 変数とダイスを混ぜて書ける
```

## ショートカット `.alias`

よく使うコマンドを短い名前で保存します。SealDice の使い方と互換です。これは **コマンドを実行する** もので、入力した文章をそのまま返信するものでも、アカウントの紐付けでもありません。

```text
.alias 侦查 .ra 侦查        // 現在のグループにショートカットを保存
.&侦查 60                  // 実際には .ra 侦查 60 を実行
.a 侦查 60                 // 同上。呼び出すときに後ろへ引数を追加できる
.alias --my 攻击 .r d20+3   // 自分の個人用ショートカットを保存
.&攻击                     // 実際には .r d20+3 を実行
.alias 侦查 .ra 侦查 70     // 同じ名前で定義すると上書き
.alias show                // このグループと自分のショートカットを一覧表示（list も同じ）
.alias del 侦查             // グループのショートカットを削除（rm も同じ）
.alias del --my 攻击        // 個人用ショートカットを削除
```

- **スコープ**：グループチャットでは既定でそのグループのショートカットとして保存し、一般のメンバーも管理できます。`--my` を付けると個人用として保存し、個人チャットでは既定で個人用です。`--my` は名前の前後どちらにも置けますが、引用符で囲んだ `"--my"` は対象のコマンドの引数として残ります。
- **優先順位**：まず現在のボットアカウントのこのグループの項目を探し、次に呼び出した人の個人用の項目を探します。グループのショートカットはほかのグループやボットのアカウントには漏れず、個人用はグループや個人チャットをまたいで使えます。プラットフォームをまたいで共有するには、先に本人確認の紐付けが必要です。
- **権限とスイッチ**：内蔵、ルールパック、JS / Lua プラグインの対象は、いずれも **呼び出した人** の権限で実行され、作成者のダイスマスターの権限は引き継ぎません。bot off、完全な無効化、ブラックリスト、禁止語、機能や個別のコマンドの無効化は引き続き適用され、ショートカットでこれらを回避することはできません。
- **制限**：名前には空白を含めず、最大 80 UTF-8 バイトです。グループ / 個人のスコープごとに最大 100 件です。対象は現在有効な接頭辞が付いた単一のコマンドである必要があり、追加の引数を含めて最大 4096 UTF-8 バイトです。ほかの `.a` / `.&` は呼び出せず、`.bind` は確認情報を保護する専用の手順を使うため対象にできません。コマンドの接頭辞を変えた場合は、保存済みの対象も合わせて変更してください。
- **結果**：通常の返信の前に、実際に展開されたコマンドを表示します。対象が意図的に何も返さない場合はそのまま何も返さず、代わりにカスタム返信と照合することはありません。インストールされていない、または使えなくなったプラグインのコマンドには案内を出し、通常のチャットの返信は実行しません。QQ 公式の構造化カードは元のカード形式のままです。

定義と呼び出しの返信は[コマンド一覧 → ツール → ショートカット](/ja/manage/commands)で書き換えられ、ペルソナ、複数の候補、重みにも対応しています。旧来のメインアカウントとサブアカウントの権限の関連付けはデータを保持したまま、管理の入口が [`.admin account-alias`](/ja/use/admin#権限の仕組み-信頼レベル) に変わりました。`.alias add` でアカウントを管理するのはやめてください。

## ボットのペルソナの切り替え `.rpmode`

「ペルソナ」はボットの返信文を上書きする 1 組の設定です。ペルソナを切り替えると、ボットのさまざまな返信がそのペルソナの口調に変わります。ペルソナは管理パネルの[コマンド一覧ページ](/ja/manage/commands)で作成・編集します。

```
.rpmode                    → 現在のペルソナと使えるペルソナの一覧を表示
.rpmode set 傲娇           → 「傲娇」（ツンデレ）のペルソナに切り替え
.rpmode off                → 現在のチャットでペルソナを明示的にオフにし、基本 / グローバルのカスタム文面を使う
.rpmode default            → 現在の選択を消し、アダプターまたはグローバルの既定のペルソナを再び引き継ぐ
.rpmode inherit            → 同上。アダプターまたはグローバルの既定のペルソナを引き継ぐ
.rpmode copy 傲娇 温柔      → 「傲娇」から「温柔」（やさしい）のペルソナを複製（Master）
.rpmode del 温柔           → ペルソナを削除（Master。内蔵のペルソナは削除不可）
```

グループやチャンネルはそれぞれペルソナを選べます。切り替えにはグループの管理者、招待者、またはダイスマスターの権限が必要です。QQ 公式ボットでは、グループの役割を一時的に読み取れないことを理由に、全メンバーを管理者として扱うことはなくなりました。今後プラットフォームが信頼できるグループの役割を提供した場合も、同じ権限の入口を使います。招待者はペルソナやダイスのオン・オフなど、破壊的でないグループの設定を変更できますが、招待者であるというだけで、キックやミュートなどのプラットフォームの管理操作を行うことはできません。

一般のユーザーが個人チャットでペルソナを選んだ場合、影響するのは自分と現在のアダプターの個人チャットだけで、ボットのグローバルなペルソナは変わりません。選べるペルソナは、ダイスマスターが[コマンド一覧 → ペルソナの公開](/ja/manage/commands)でボットのアカウントごとに設定します。公開されていないペルソナは一覧に表示されず、名前を指定して制限を回避することもできません。`off` は現在のチャットでどのペルソナも使わないことを明示し、`default` / `inherit` は現在の上書きを削除してアダプターまたはグローバルの既定を引き継ぎます。`copy` / `del` などの管理操作は引き続き Master だけが使えます。
