# セッション管理（.game）

`.game` は元祖 Dice! から移植したセッション管理の仕組みです。グループで「セッションを開く」とゲーム領域が作られ、GM とプレイヤーの名簿、セッションの変数、出目の厳選を防ぐルーレットダイスを管理できます。セッション管理のコマンドはすべて **グループチャット** でのみ使えます。

## コマンド一覧

| コマンド | 説明 |
|------|------|
| `.game new [セッション名]` | セッションを開く（グループ管理者が必要。開いた人が自動で GM になる） |
| `.game join` / `.game exit` | プレイヤーの参加 / 退出 |
| `.game master` | 自分が GM になる。すでに GM の場合は GM の名簿を表示 |
| `.game state` | セッションの状態（GM / プレイヤーの名簿 / セッションの変数）を表示 |
| `.game set <変数> <値>` | セッションの変数を設定（GM） |
| `.game call` | プレイヤー全員を @ して点呼（GM） |
| `.game kick <QQ>` | プレイヤーを卓から外す（GM） |
| `.game close` / `.game open` | ゲーム領域を一時的に閉じる / 再び開く |
| `.game over` | セッションを終了する（セッションのデータをすべて消去） |
| `.game rou 面数[*個数]` | ルーレットダイスを有効にする（GM）。ほかに `rou hist/reset/clr` |

引数なしの `.game` ではヘルプを表示します。

## セッションの開始と名簿

```
.game new 迷雾之城     → セッションを開く（名前を省略すると自動で生成）
.game join             → プレイヤーとして卓に参加
.game master           → GM になることを申請 / GM の名簿を表示
.game state            → セッションの状態の一覧
.game kick 10001       → GM がプレイヤーを卓から外す
.game exit             → 自分で退出する（GM の退出もこれ）
```

- セッションを開くには **グループ管理の権限** が必要です。新しいセッションを開くと、このグループの古いセッションのデータは消えます。
- 最初の GM 以外に GM を追加するには、グループのオーナー / 管理者 / ダイスマスターの確認が必要です（元祖の権限のルールを再現）。

## セッションの変数

GM はこのセッションに任意のキーと値（章、天気、時系列など）を記録できます。

```
.game set 章节 第三章   → セッションの変数を設定（.game set 章节=第三章 でも可）（章节 = 章、第三章 = 第 3 章）
.game set 章节          → 1 つの変数を表示
.game state             → セッションの状態にすべての変数が表示される
```

セッションの変数は Lua mod の `msg.game` / GameTable のデータと共有されているため、mod から同じセッションのデータを直接読み書きできます。

## 一時的に閉じる・終了する

```
.game close            → ゲーム領域を一時的に閉じる（名簿と変数は残る）
.game open             → 再び開く
.game over             → セッションを終了し、セッションのデータをすべて消去
```

このグループでまだ[セッションログ](/ja/use/log)を記録中の場合、`.game over` は `.log end` で記録を終えるよう知らせます。

## ルーレットダイス `.game rou`

ルーレットダイスは「振り直しによる出目の厳選」を防ぐためのものです。GM がある面数に対して有効にすると、このグループの `1dN` / `dN` の単一ダイスのロールは **袋から戻さずに引く** 方式になります。1..N を 1 つ（または複数）ずつ袋に入れ、引くたびに 1 つ減り、空になると自動で補充されます。

```
.game rou 20           → d20 でルーレットダイスを有効にする（袋に 1～20 を 1 つずつ）
.game rou 6*3          → d6 で有効にし、1～6 を 3 つずつ（面数×個数は最大 100）
.game rou hist         → この回にすでに引いた出目の記録を表示
.game rou reset        → 袋を元に戻す（引いた記録を消して満杯にし直す）
.game rou clr          → ルーレットダイスを解除し、通常のロールに戻す
```

有効化 / 元に戻す / 解除はいずれも GM が必要です。ルーレットが横取りするのは **単一ダイス・1 回分** の `1dN` のロールだけで、ほかの式には影響しません。ゲーム領域を閉じている（`.game close`）あいだは、ルーレットも停止します。
