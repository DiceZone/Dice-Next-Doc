# ルール早見

セッション中に本を開かなくてもルールを調べられます。Dice!Next はローカルで拡張可能なルールライブラリを使い、オフラインでも使え、自分で項目を追加できます。

## コマンド

| コマンド | 説明 |
|------|------|
| `.rules 項目` / `.rule 項目` | ルールの項目を調べる（`.rule` は元祖の別名） |
| `.rules ルールブック:項目` | 指定したルールブックの中で調べる |
| `.ruleset ルールブック` | グループの既定のルールブックを設定（グループ管理者） |
| `.rule set ルールブック` | 元祖の設定の書き方。`.ruleset ルールブック` と同じ |

## 使い方

```
.rules 大失败           → 調べる（まずグループの既定のブック、次にすべてのブック）（大失败 = ファンブル）
.rules coc:困难成功     → COC7 のルールブックで調べる（困难成功 = ハード成功）
.rules dnd:借机攻击     → DND のルールブックで調べる（借机攻击 = 機会攻撃）
.ruleset dnd            → グループの既定のルールブックを dnd にする
.rule set dnd           → 同上（元祖 Dice! の書き方）
.ruleset show / clr     → 既定のルールブックを表示 / 解除（解除にもグループ管理者が必要）
```

項目は完全一致とあいまい（部分文字列）一致の両方で検索できます。

## 内蔵のルールブック

CoC7 の Keeper Companion の選択ルールは `.set coc7r` で切り替えられます。詳しくは [coc7r の使い方](./coc7r)を参照してください。これは独立した実行時のルール設定で、`.ruleset` で選ぶ検索用の参考書とは別のものです。

| ルールブック | 別名 | 内容 |
|--------|------|------|
| `coc7` | coc、克苏鲁 | クリティカル / ファンブル、ハード / イクストリームの成功、正気度と狂気、ダメージボーナス、ビルドなど |
| `dnd` | dnd5e、5e、龙与地下城 | 有利 / 不利、イニシアチブ、機会攻撃、セーヴィング・スロー、習熟ボーナス、小休憩と大休憩、死亡セーヴなど |

内蔵の項目は中国語で書かれています。

## カスタムのルールブック

ルールブックは `data/rules/` フォルダーに置く JSON ファイルです（パッケージのルートの `rules/` にも対応）。1 ファイルにつき 1 冊です。

```json
{
  "name": "coc7",
  "aliases": ["coc", "克苏鲁"],
  "entries": {
    "大失败": "技能值<50 时骰出 96-100 为大失败……",
    "困难成功": "骰值 ≤ 技能值的一半即为困难成功。"
  }
}
```

新しいファイルを置くだけでルールライブラリを拡張でき、ダイスマスターは自分が遊ぶルールシステムに合わせて自由に追加できます。Web 管理パネルのルールのページで直接編集することもできます。

::: tip ルールパック
同じルールブックの JSON で **技能の同義語**（`alias`）や既定のダイスなどの「ルールパック」の機能も宣言でき、項目と同義語を 1 つのファイルに書けば一緒に有効になります。まとまった遊び方（ヘルプの早見、シートのテンプレート、プラグインなど）はルールパックにまとめて配布でき、取り込めばすぐに使えます。詳しくは[ルールパックの作成](/ja/develop/rulepack)を参照してください。
:::
