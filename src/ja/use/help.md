# ヘルプと言語

Dice!Next には統一されたヘルプの登録の仕組みが組み込まれています。内蔵のコマンドの説明、ルールパックの項目、プラグインが登録したヘルプ、カスタマイズできるヘルプ文書がすべて同じ `.help` に集約されます。グループごとに検索範囲を固定したり、返信の言語を切り替えたりもできます。

## ヘルプを調べる `.help`

```
.help              → コマンドの一覧メニュー
.help ra           → あるコマンド / 項目のヘルプを表示（.help .ra でも可）
.help 克苏鲁       → 項目はコマンドに限らず、ルール早見やデッキの説明なども調べられる
.help on / off     → グループ管理者がこのグループのヘルプコマンドをオン / オフ（永続的に保存）
```

一覧メニューは用途ごとに分かれています：ダイス、判定、キャラクターシート、生成、デッキ、娯楽、管理、アカウント。

### ヘルプのレイアウト

最新の main の引数なしの `.help` では、既定で末尾に次の 2 行のフィードバックの案内が加わります（`75ec20d`。まだ beta.925 には含まれていません）。

```text
Dice!Next 测试群：933145116
如有故障或建议欢迎加群反馈
```

（「Dice!Next テストグループ：933145116 / 不具合や提案はグループでお知らせください」）変更したのは既定のメインのヘルプの文面だけで、`.help <コマンド>` での検索には影響しません。ダイスマスターがすでにカスタマイズしたヘルプは引き続き優先され、強制的に置き換えられることはありません。

内蔵のコマンドのヘルプは「タイトルの行 + 1 行に 1 コマンド + `//` の説明」に統一し、補足は末尾に別の行で置きます。引数は `<必須>`、`[省略可]` と書きます。空のコマンド（たとえば `.log` だけを送った場合）が返す使い方の案内も、同じレイアウトを使います。

```
录卡 .st
.st <属性><值> // 录入或修改属性，如 .st 力量50 敏捷60
.st <属性>±<值> // 增减属性，支持骰子，如 hp-2、理智+1d3
.st show // 查看当前人物卡
.st clr // 清空人物卡
.st del <属性> // 删除某项属性
DND 钱币支持 pp/gp/ep/sp/cp，扣款自动换开。
```

4 つの画面言語はそれぞれこの文面を管理しており、言語を切り替える（下の `.lang` を参照）とヘルプの言語も同時に切り替わります。

- 項目は **あいまい検索** に対応しています。一致が 1 つならそのまま表示し、候補が複数あれば一覧を出して選んでもらい、見つからなければ知らせます。
- ヘルプの出所（統一された登録の仕組みに集約し、同じ名前は自動で重複を除きます）：
  1. **内蔵** のコマンドの説明
  2. **カスタム項目**（旧版の `CustomHelp.json` から取り込んだヘルプを含む）
  3. **ルールパック** に付属するヘルプの項目（このグループで有効なルールパックの同名の項目が優先）
  4. **プラグイン**（JS / Lua）が登録したヘルプ
  5. **カスタム文書**（`data/help/*.md`）と **ヘルプ文書パック**（`data/helpdoc/` と各ルールパックのフォルダーにある JSON）
- 長すぎるヘルプの内容は自動で分割して送ります。

### 溯洄形式の参照

ヘルプの本文が `&トピック` で始まる場合、別のトピックの別名として扱えます（2026-10-19 にローカルで追加）。複数段階の転送に対応し、転送先は引き続き現在の出所の優先順位と検索範囲に従って選びます。存在しない、循環する、深すぎる別名がいつまでも展開されることはありません。旧版から取り込んだカスタムヘルプでも使え、転送先の本文を手動でコピーする必要はありません。

ヘルプの項目の内容は溯洄形式の関数に対応しています。`{項目}` は別の項目の内容を展開し（再帰的に）、`[{%_1D3}*10]` のように `{}` を含む角括弧のブロックは式として評価します。`{}` を含まない `[例]` はそのまま残ります。デッキのカードも同じ参照の意味に対応しています（[デッキ](/ja/use/deck)を参照）。

## カスタムヘルプ `.helpdoc`

`.helpdoc <項目>` は `.help <項目>` と同じです。項目を付けない場合は使い方の案内を出します（すべての項目は Web 管理パネルの「ヘルプ文書」ページで閲覧・検索してください）。

カスタムのヘルプ文書は `data/helpdoc/` フォルダーに置きます（`*.json`。SealDice のヘルプ文書の形式と互換）。

```json
{
  "mod": "我的速查",
  "brief": "一句话简介",
  "helpdoc": {
    "词条名": "词条内容",
    "别名": "&词条名"
  }
}
```

値が `&` で始まるものは別名（別の項目を指す）です。ルールパックもパック内の `helpdoc/` フォルダーでヘルプを一緒に配布でき、その項目の出所は `<パック名>/<mod>` と表示されます。

### 既定の出所 `.helpdoc default`

複数の出所に同じ名前の項目がある場合（たとえば dnd3r と dnd5r の両方に「猫头鹰熊」（オウルベア）がある）、優先する出所を指定できます。

```
.helpdoc default           → 現在の既定の出所と選べる出所を表示
.helpdoc default dnd5r     → 同じ名前の項目では dnd5r を優先
.helpdoc default clear     → 取り消す（読み込み順に戻す）
```

### 検索範囲 `.helpdoc scope`

既定の出所よりも強い設定です。このグループのヘルプの検索をある出所の中に **固定** し、ほかの出所の項目はすべて除外します（内蔵のコマンドの説明は残ります）。特定のルールでセッションを行うときに、ほかのシステムの内容が出てこないようにするのに向いています。

```
.helpdoc scope coc7包      → このグループの .help はその出所だけを検索
.helpdoc scope clear       → 固定を解除
.helpdoc scope             → 現在の検索範囲を表示
```

## Web での管理

Web 管理パネルの[ヘルプ文書](/ja/manage/help-docs)ページでは、出所の種類と具体的な出所で絞り込み、すべてのヘルプの項目を検索し、カスタムヘルプを編集できます。過去の `help.topic.*` の項目は自動でこのページに含まれるため、既存のデータを取り込み直す必要はありません。内蔵のヘルプを変更しても、内蔵の出所の目印は残ります。

## 言語の切り替え `.lang`

ボットの返信は 4 つの内蔵言語に対応しています：簡体字中国語 / 繁体字中国語 / English / 日本語。グループの管理者はグループの言語を切り替えられ、個人チャットでは自分の言語を切り替えます。

```
.lang                  → 現在の言語と使い方を表示
.lang 繁體             → 切り替え（简体 / 繁體 / en / 日本語 とよく使われるさまざまな別名を認識）
.lang clr              → 上書きを消して既定に戻す
```

### カスタム言語パック

翻訳ファイル `<言語コード>.json` を `i18n/` フォルダーに置くと、新しい言語として自動で読み込まれます。パック内の `_meta.keywords` でその言語に切り替えるキーワードを宣言します（以後は `.lang <キーワード>` で切り替えられます）。フォルダーには参考用のテンプレート `_custom_language_example.json` が付いています。内蔵の言語の一部の文面を変える場合も同じ方法です。

### AI 翻訳の言語

`.lang` の引数が内蔵の言語でもなく、対応する翻訳ファイルもない場合は、ダイスマスターが AI 設定で登録した **AI 翻訳の言語** も調べます。一致すると、そのチャットの返信は送信前に大規模言語モデルによって目的の言語へリアルタイムで翻訳されます（返信は少し遅れますが、ダイスの数字は変わらないことが保証されます）。詳しくは [AI](/ja/manage/ai) を参照してください。
