# クイックスタート

起動から最初のダイスを振るまで、5 分で Dice!Next 3.0 を使い始めましょう。

## 1. Dice!Next をダウンロードして起動する

お使いのプラットフォーム向けのベータ版パッケージをダウンロードします。Windows では展開後に `dice-next.exe` をダブルクリックします。

初回起動時に `config/` 設定フォルダーと SQLite データベース（`data/dice.db` など）が自動で作成されます。Windows 版は既定で **タスクトレイ** に最小化された状態で動作し、右下に通知が表示されます。

詳しくは[インストール](/ja/guide/install)を参照してください。

## 2. 管理パネルを開く

トレイアイコンを右クリックして「Web パネルを開く」を選ぶか、ブラウザで `http://localhost:18088` にアクセスします。

::: tip ログインパスワードの設定
管理パネルの **WebUI 設定** ページでログインパスワードを設定することをおすすめします。設定すると、すべての管理ページと API にログインが必要になります。通常のログインセッションはブラウザまたは Dice!Next のセッションが終わると切れますが、「このデバイスを 30 日間信頼する」にチェックすると、ブラウザやプログラムを再起動してもログイン状態が保たれます。同じページで待ち受け IP / ポートも変更できます（変更後は再起動が必要で、ページにワンクリック再起動ボタンがあります）。
:::

## 3. OneBot アダプターを設定する

**管理パネル → アダプター管理** を開き、「アダプターを追加」をクリックします。

### 正方向 WebSocket（推奨）

Dice!Next から OneBot クライアント（NapCat、Lagrange、LLOneBot など）に接続します。

| パラメーター | 値 |
|------|-----|
| プロトコル | OneBot v11 |
| 通信方式 | 正方向 WebSocket（`forward_ws`） |
| エンドポイント | `ws://127.0.0.1:3001/` |
| Access Token | OneBot クライアントと同じ値（空欄可） |

OneBot クライアントで正方向 WS サーバーが有効になっていることを確認してください。接続が切れると Dice!Next は自動で再接続します（最初は 5 秒ごと、その後は 60 秒ごと。20 回連続で失敗すると一時停止し、パネルから手動で再接続できます）。

### 逆方向 WebSocket

OneBot クライアントから Dice!Next に接続します。

| パラメーター | 値 |
|------|-----|
| プロトコル | OneBot v11 |
| 通信方式 | 逆方向 WebSocket（`reverse_ws`） |
| エンドポイント | **ポート番号**（例：`6700`）を入力。Dice!Next はそのポートで待ち受けます |

次に、OneBot クライアントの逆方向 WS の接続先を `ws://<Dice!Next の IP>:<そのポート>/` に設定します。

## 4. ダイスを振ってみる

接続済みの QQ グループまたは個人チャットでコマンドを送ります。

```
.help                 # ヘルプ
.r                    # 既定の d100
.r 3d6+2              # 6 面ダイス 3 個 + 2
.coc                  # COC のキャラクター作成
.ra 侦查              # キャラクターシートを読んで COC の判定（侦查 = 目星）
.jrrp                 # 今日の運勢
.draw 塔罗            # 塔罗（タロット）デッキから引く
```

QQ に接続しなくても、管理パネルの **テスト台** でコマンドを送って返信を試せます。

## よくある質問

### OneBot クライアントに接続できない

ファイアウォールでポートが許可されているか、アドレスと Access Token の設定が正しいか、OneBot クライアント側の対応するサービスが有効かを確認してください。状態が「接続タイムアウト」の場合は自動再接続が一時停止しています。問題を直してから手動で再接続してください。詳しくは[トラブルシューティング](/ja/guide/troubleshooting)を参照してください。

### コマンドに反応しない

管理パネルのダッシュボードでログを確認し、アダプターの状態が「接続済み」になっているかを確認してください。次に、そのグループが `.bot off` で停止されていないかを確認します。

### 旧データを移行するには

[データ移行](/ja/guide/migration)を参照してください。管理パネル → システム設定 → 旧版データの取り込み で旧版のデータフォルダーを指定すると、一括で取り込めます。
