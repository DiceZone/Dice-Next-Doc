# プロジェクトについて

## Dice!Next

Dice!Next は定番の TRPG のダイスボット **Dice!** を全面的に作り直した新しい版で、モダンな技術の上で Dice! の使い心地を忠実に再現して引き継ぐことを目指しています。高性能な C++ のバックエンドとモダンな Web の管理パネルを持ち、フロントエンドとバックエンドを分け、すぐに使え、多言語に対応しています。

私たちの目標は、これまでの Dice! のユーザーが **苦労なく移行** できるようにしつつ、新しいユーザーにも始めやすくすることです。

## 敬意と参考

Dice!Next は先人の肩の上に立っています。次のプロジェクトとコミュニティに心からの敬意と感謝を捧げます。

### 原点：Dice!

- **[Dice!](https://github.com/Dice-Developer-Team/Dice)**：このプロジェクトが再現し、引き継いでいる元のプロジェクトです。Dice! は長年 TRPG のコミュニティに貢献してきており、そのルールの実装、文章、やり取りが Dice!Next の土台です。Dice!Next はその **AGPLv3** のライセンスに従ってオープンソースを続けています。

### 参考にしたプロジェクト

- **[SealDice（海豹核心）](https://github.com/sealdice/sealdice-core)**：優れたモダンなダイスのプロジェクトで、コマンドの互換と使い心地の設計で多くの参考になりました。
- **[OlivaDice（青果）](https://github.com/OlivOS-Team/OlivaDiceCore)**：Dice! との互換性が高いダイスの実装で、一部のコマンドの構文と機能の設計を照らし合わせました。
- **[OneDice](https://github.com/OlivOS-Team/lib-onedice)**：ダイスの式の統一の標準で、Dice!Next はその式の構文と互換です。
- **[OneBot の標準](https://github.com/botuniverse/onebot-11)**：オープンなチャットボットのプロトコルの標準で、Dice!Next のプラットフォームの対応は OneBot v11 をもとにしています。
- **[NapCat](https://github.com/NapNeko/NapCatQQ)**：NTQQ をもとにしたボットのプロトコルの実装です。
- **[LLOneBot](https://www.llonebot.com/)**：QQ のボットのフレームワークと OneBot のプロトコルの実装です。
- **[SnowLuma](https://snowluma.github.io/)**：NTQQ と OneBot の生態系向けのリモートのプロトコルのフレームワークです。

### 技術的な依存

drogon、nlohmann/json、SQLite / sqlite_orm、spdlog、React、Vite、shadcn/ui、VitePress など、多くのオープンソースのプロジェクト。
