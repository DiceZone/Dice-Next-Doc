## 2026-11-04 · 乱数の源の代替、アプリとしてのインストール、コマンドの全体の検索（未公開）

- **ダイスの乱数の源**：選んだ源が使えないときは別の安全な乱数の源を順に使い、すべて使えないときだけ緊急用の疑似乱数（xoshiro256**）を使います。プログラムのログで知らせ、回復した後は自動で戻すため、ロールが中断されることはもうありません。CPU のハードウェアのエントロピーの源を新しく加えました。x86-64 で RDSEED を読み、システムの乱数と XOR します。1 回あたり約 1 マイクロ秒で、追加のメモリは使いません。設定は[基本設定](/ja/manage/settings#ダイスの乱数の源)に移し、古い「ダイスのルール」のページは削除して転送するようにしました。
- **アプリとしてのインストール**：マニフェストは相対のアドレスを使うようにし、リバースプロキシのサブパスに対応しました。ページの移動だけを扱い何もキャッシュしない Service Worker を加え、ブラウザーがインストールの案内を出せるようにしました。WebUI の設定にインストールの入口を加え、HTTP の LAN のアドレスではインストールできない理由を説明します。[管理パネルをアプリとしてインストール](/ja/guide/install#管理パネルをアプリとしてインストール)を参照してください。これまでアドレスバーにずっとインストールのアイコンが出なかった根本の原因は、バックエンドの静的ファイルの許可リストに `.json` がなく、`manifest.json` が拒否されていたことでした。現在は `application/manifest+json` として個別に提供しています。ブラウザーがインストールを許すときは、上部のバーに「アプリをインストール」のボタンが表示されます。
- **コマンドの一覧**：すべての分類をまたぐ[全体の検索](/ja/manage/commands#全体の検索)を加え、分類のタブに一致の数を表示します。
- **QQ 公式**：スキャンのセッション番号に `/` を含むときに QR コードがときどき 404 になる問題を修正しました。内部の招待の API の「アプリに API へのアクセス権限がない」のログは DEBUG に下げました。[セッションのログ](/ja/use/log#qq-公式の-sn-状態行)には SN の状態行を記録しなくなりました。SN の「赤い小さな文字」は「色付きの文字」に変え、カラーパレットやスポイトで色を選べます。
- **判定の計算**：`.ra 力量+20-30` などの多段の補正で最初の項だけが計算される問題を修正しました。判定、対抗、DND の判定、`.st` は計算のルールを共有し、乗除、べき乗、括弧、ダイス、複数の能力値、よく使う関数に対応します。[成功率の計算](/ja/use/dice#成功率の計算)を参照してください。`.st hp-1d6+2` は 1d6+2 を引きます。
- **ホーム**：CPU とメモリのグラフはバックエンドが記録した直近 1 時間に変えました。状態のカードをクリックすると対応するページを開けます。[ダッシュボード](/ja/manage/dashboard)を参照してください。
- **画面**：コマンドのテストは既定で画面の言語で返信します。バックアップのページの項目と案内は 4 言語すべてそろいました。ダッシュボードにデータベースのパスを表示しなくなりました。macOS のシステムのアイコンを補いました。「について」のページのプロジェクトの紹介を書き直し、更新履歴の説明の文を削除しました。
