# 基本設定

Dice!Next は `config/` フォルダーに **JSON 形式** で設定を保存します。初回起動時に機能ごとのファイルが作成されます。

ほとんどの設定は [Web 管理パネル](/ja/manage/dashboard)で変更できるため、通常は手動でファイルを編集する必要はありません。初回に作成されるファイルには少数のキーしかなく、**多くのキーはパネルで設定して初めてファイルに現れます**（ないあいだは内蔵の既定値が使われます）。

## 設定ファイルの構成

機能ごとに別のファイルに保存されます。パネルで保存した変更や、ホットリロードの検証を通った手動の変更は、対応するファイルに書き戻されます。

| ファイル | 内容 |
| --- | --- |
| `server.json` | WebUI/API の待ち受け、データベースのパス、ログレベル |
| `webui.json` | WebUI のログイン設定 |
| `adapters.json` | アダプターの接続設定 |
| `dice.json` | ダイスの動作、ダイスマスター、ルール、AI の設定 |
| `events.json` | 友だち・グループ招待とイベントのポリシー |
| `i18n.json` | 既定の言語とプラットフォームごとの言語 |
| `backup.json` | 手動・自動バックアップの設定 |
| `hot_reload.json` | 設定とリソースのホットリロード |

以下はファイルごとの例です（実際には起動後に生成された内容が基準です）。

```json
// config/server.json
{
  "host": "0.0.0.0",
  "port": 18088,
  "api_key": "",
  "db_path": "./data/dice.db",
  "log_level": "info"
}
```

## 主な設定項目

### server

| 項目 | 説明 | 既定値 |
|------|------|--------|
| `host` | サービスの待ち受けアドレス | `0.0.0.0` |
| `port` | 管理パネル / API のポート。使用中の場合は起動時に次の空きポートへ移り、このキーに書き戻す | `18088` |
| `api_key` | バックエンド API のアクセスキー（初回に自動生成。パネルのリクエストは `X-API-Key` ヘッダーで送信） | 自動 |
| `db_path` | メインデータベースのパス（キャラクターシート / ログ / チャットなどは別の db ファイル） | `./data/dice.db` |
| `log_level` | 最低記録レベル trace/debug/info/success/warn/error。新しいログにすぐ反映され、旧来の warning/critical の値も使える | `info` |

::: tip WebUI のログインパスワードと api_key の関係
管理パネルへの **アクセス制御は「WebUI のログインパスワード」で行います**。パネルの WebUI 設定ページで設定すると、すべての `/api/*` リクエストにログインが必要になります（`webui.password` キー。空欄 = 認証なし）。ログイン時に「このデバイスを 30 日間信頼する」を選べ、信頼済みセッションはこのマシンの `config/webui_sessions.json` にのみ保存されます。`server.api_key` はパネルのリクエストに付く API キーで、外部連携のためのものです。ログインパスワードの代わりにはなりません。
:::

### dice

ダイスの動作に関する主なスイッチです。よく使うキー（多くはパネルのシステム設定で画面から変更できます）：

| 項目 | 説明 |
|------|------|
| `command_prefixes` | コマンドの接頭辞の配列。既定は `.` `。` `!` `！` |
| `masters` | ダイスマスターの一覧（`{platform, id}`、複数可） |
| `summon_word` | 呼び出しの言葉（空欄でオフ） |
| `whitelist_only` | ホワイトリストモード：ホワイトリストのグループだけに反応 |
| `silent_global` / `disabled_global` | 全体のサイレント / 全体で無効にするコマンドの一覧 |
| `disabled_jrrp` | `.jrrp` を全体で無効にする |
| `respond_self` | ボットのアカウント自身が送ったメッセージに反応するか（セルフコントロール。既定はオフ） |
| `console_start_hidden` | 起動時にコンソールを隠してトレイに最小化（既定は `true`） |
| `api_enabled` / `api_whitelist` / `api_timeout` | 返信内の `{api:URL}` による外部リクエストのスイッチ、ドメインの許可リスト、タイムアウト |
| `image_send` | 画像の送信方法（`base64` または `host` 経由の中継） |
| `message_format` | 送信時の表示方式：`traditional`（従来）、`standard`（標準）、`visual`（高度なビジュアル）。旧来の値 `card` は `standard` として扱います。詳しくは[アダプター設定](/ja/config/adapter#返信文とビジュアル方式)を参照 |
| `save_log_images` | セッションログでメッセージ内の画像を保存するか |
| `logsite_url` / `logsite_format` | ログサイトのアップロード先（空欄 = 公式サイト）とプロトコル形式 |
| `aliases` | 旧来のアカウント権限の関連付け（`{platform, alias, main}`。ダイスマスターが `.admin account-alias` で管理。`.alias` のショートカットとは別物） |
| `notice` | ダイスマスターの通知ウィンドウとイベントの購読（通知設定ページでの管理を推奨） |
| `ai` | AI サブシステムのすべての設定（モデル / 文章の調整 / 翻訳 / 会話 / 記憶 / ツール…。AI のページでの管理を推奨） |
| `rules.default_dice_sides` | `.r` を引数なしで使ったときの既定の面数 |
| `rules.coc_enabled` など | 各ルールシステムのスイッチと COC のクリティカル / ファンブルの範囲 |

### events

イベントと承認のポリシーです（パネルの権限設定 / システム設定で変更できます）。

| 項目 | 説明 |
|------|------|
| `friend_policy` / `auto_approve_friend` / `friend_keyword` | 友だち申請の承認ポリシー / 自動承認 / 認証キーワード |
| `friend_welcome` | 新しい友だちへの歓迎メッセージ（空欄 = 内蔵の文面） |
| `group_invite_policy` / `auto_approve_group` / `group_keyword` | グループ招待の承認ポリシー |
| `group_invite_reject_blacklist` / `group_invite_reject_nonfriend` | ブラックリストのグループ / 友だちではない人からの招待を拒否 |
| `poke_enabled` / `poke_command` | つつく機能への返信のスイッチ / つつく操作をコマンドに割り当て |

### i18n

| 項目 | 説明 |
|------|------|
| `default_locale` | 既定の返信言語（`zh-Hans` / `zh-Hant` / `en` / `ja`） |
| `platform_defaults` | プラットフォームごとの既定の言語 |
| `resource_dir` | 言語パックのフォルダー（既定は `i18n`。`<言語コード>.json` を置くとカスタム言語として自動で読み込む） |

### log

| 項目 | 説明 |
|------|------|
| `raw_events` | アダプターの生のイベントをログに記録するか（デバッグ用） |

### hot_reload

| 項目 | 説明 |
|------|------|
| `enabled` | 有効にすると、`config/` と `data/` 内のファイルの変更を検出して自動で反映 |
| `debounce_ms` / `watch_paths` | デバウンスの間隔と監視するフォルダー |

### adapters

アダプターの設定は `config/adapters.json` に保存されます。[アダプター管理](/ja/manage/adapter-manager)ページで保存した内容が基準です。手動で編集する場合も、ファイルを有効な JSON に保ってください。項目の説明は[アダプター設定](/ja/config/adapter)を参照してください。

## ホットリロードと再起動

`hot_reload.enabled` を有効にすると、設定ファイルの手動の変更が自動で検出され反映されます。管理パネルで変更した設定もすぐに保存され反映されます。

::: warning 再起動が必要な項目
`server.port` / `server.host` の変更は再起動後に反映されます。パネルの **WebUI 設定** ページで変更することをおすすめします。ページに案内が表示され、「今すぐ再起動」ボタンも用意されています。
:::

## アップグレード時の注意

アップグレードの際は、新しいパッケージを展開して丸ごと上書きするだけです。`config/` フォルダーはリリースパッケージに含まれていないため上書きされません。詳しくは[インストール](/ja/guide/install#アップグレード)を参照してください。
