# カスタム返信

**管理パネル → 高度な返信 → カスタム返信** で、キーワードで反応する自動返信を管理します。ページには **カスタム返信**、**因果ルール**、**カウンター** の 3 つのタブがあります。

## カスタム返信

### グローバル、プラットフォーム、アカウントの範囲

ページの見出しで **グローバル / アダプターのプラットフォーム / 特定のボットのアカウント** を選びます。カスタム返信の一覧、追加、編集、取り込み・出力、一致のテストは、すべて現在の選択を使います。その範囲自身のルールだけを表示し、ほかの範囲や引き継いだルールを編集できる一覧に混ぜることはありません。過去のルールは引き続き既定でグローバルで、選択を切り替えても自動で移されることはありません。

実行時には、メッセージが属する経路に当てはまるルールだけを照合します。アカウント、プラットフォーム、グローバルのルールはいずれも候補になり得るため、アカウントの範囲に切り替えたからといってグローバルのルールが全体的にオフになるわけではありません。優先度が同じ場合はアカウントがプラットフォームより、プラットフォームがグローバルより優先され、それ以外は従来どおりルールの優先度、条件、確率、制限に従って選びます。つつく機能も同じ見出しの範囲を使いますが、その設定はアカウント > プラットフォーム > グローバル の順に引き継ぎます。因果ルールとカウンターは、この選択によって経路ごとのデータになることはありません。

各返信の内容の下にある **ボタンとステータスバー** で、コンポーネントを追加・編集・削除できます。ボタンにはタイトルとコマンドを、ステータスバーには名前、現在値、最大値をそれぞれ入力します。これらは本文と一緒に `[[action:ダイスのコマンド|.r]]`、`[[bar:HP|{hp}|{hpmax}]]` などのソースとして保存され、本文を直接編集することもできます。コンポーネントはグローバル、プラットフォーム、アカウントの従来 / 標準 / 高度なビジュアルの方式に従い、リッチメッセージに対応していないプラットフォームでは自動で文章の形を使います。式の編集は現在[コマンドとペルソナの文面](/ja/manage/commands#文面の中の式)で使えます。

### 返信の一覧

| 列 | 説明 |
|---|---|
| 一致の種類 | キーワード / 前方一致 / 正規表現 / 部分一致 |
| 一致する内容 | 反応する文章 |
| 返信の内容 | 一致したときの返信 |
| 優先度 | 複数が一致したときは数字が大きいほど優先（既定は 100） |
| 状態 | 有効 / 無効のスイッチ |
| 操作 | 編集 / 削除 |

上部の検索欄で、一致する内容や返信の内容で絞り込めます。

### 返信の追加 / 編集

「返信を追加」をクリックするとエディターが開きます。

よく使う反応の条件と返信の内容はそのまま表示し、オン・オフ、確率、クールダウン、1 日の上限、グループ / ユーザーの制限、優先度などは「高度なオプション」にまとめています。狭い画面では既定で閉じ、広い画面では既定で開いてグリッド状に並べますが、手動で切り替えることもできます。開いたときは編集欄が独立してスクロールし、保存 / 破棄のボタンは文章を覆わずに下部に残ります。

- **反応の条件**：複数の条件を追加し、「すべて満たす（AND）」か「いずれかを満たす（OR）」を選べます。各条件の一致の種類は、キーワード / 前方一致 / 正規表現 / 部分一致（メッセージに含む）から選べます。
- **返信の内容**：複数追加でき、一致すると **重みに従ってランダムに 1 つ選んで** 送ります。それぞれに独立した重みの入力欄（0–999999、既定は 1）があり、実際に選ばれる確率も表示されます。重み 0 はしばらく選ばないことを表します。たとえば重み 3 と 1 は 75% と 25% になります。空でなく重みが 0 より大きい返信を少なくとも 1 つ残す必要があります。旧来の `::5::返信の文章` は、旧データを取り込むときや読み込むときに自動で重み 5 に変換されるため、目印を手で書く必要はなくなりました。正式なエディターでは返信の文章を書いたとおりに保存します。「画像を挿入」をクリックして画像をアップロードすると、プラットフォームに依存しないコード `[img,file=<ローカルのパス>]` として保存され、送信時に[システム設定の「画像の送信方法」](/ja/manage/settings)に従って自動で変換されます。CQ コード / SealDice のコードにも対応しています。
- **変数**：`{nick}` ニックネーム · `{user}` QQ · `{group}` グループ番号 · `{roll:1d100}` ダイス · `{draw:デッキ}` デッキから引く · `{a|b|c}` ランダムに 1 つ · 正規表現のとき `{$1}` は捕捉グループ。そのほかの変数は[キーワード返信](/ja/use/reply)を参照してください。
- **優先度**：複数のルールが同時に一致したときの順序です。
- **反応する確率**：ルール全体が反応するかどうかを決めるもので、上の「一致した後にどの返信を選ぶか」の重みとは別です。たとえば、ルールの反応する確率が 50%、ある返信が 25% を占める場合、その返信が送られる全体の確率は 12.5% です。

旧来の返信の参照は取り込み時に正規化され、あいまいな内容が自動で置き換えられることはありません。「システム設定 → バックアップと復元」で参照の移行レポートを確認・ダウンロードし、用途に合わせて `deck:` / `help:` / `text:` / `roll:` の接頭辞を付けてください。詳しくは[返信テンプレートの変数](/ja/use/reply#動的なコマンド)を参照してください。

### つつかれたときの返信

「一斉送信を追加」の左にある「つつかれたときの返信」ボタンをクリックします。これは唯一のイベントによる反応で、キーワードの入力は不要で、キーワードのルールの優先度の順位付けにも加わりません。

- 重み付きの複数の返信、変数、画像、反応する確率、クールダウン、1 日の上限、グループ / ユーザーの範囲の制限にも同様に対応しています。
- ページの見出しのグローバル、アダプターのプラットフォーム、特定のボットのアカウントの選択を使い、ダイアログで範囲を重ねて選ぶことはなくなりました。上書きの設定がない場合は上位の設定を引き継ぎ、部分的な設定は引き継ぎに戻せます。
- 旧来の単一の返信と「割り当てたコマンド」も残っています。割り当てたコマンドが空でない場合はコマンドを優先して実行し、空ならランダムな返信を送ります。
- つつかれたときの返信は、ボットの全体のスイッチとこのグループのカスタム返信のスイッチに従います。

### 一致のテスト

一覧の下にある「一致のテスト」に文章を入力すると、選んだプラットフォームまたはアカウントのコンテキストで、候補のルールと結果を表示します。アカウントの範囲ではそのアカウントが属するプラットフォームを使うため、ほかの経路の結果で現在のアカウントの設定が成功しているかを判断することはできません。テストで実際のグループにメッセージが送られることはありません。

### 反応型の一斉送信

「一斉送信を追加」で **反応型の一斉送信**（イベントのお知らせなど）を設定できます。

- 一斉送信は **自分から全グループへ送ることはありません**（頻繁な送信によるアカウント停止を防ぐため）。各グループで **次に何らかのダイスのコマンドが使われたとき**、そのコマンドの返信の後に自動で付けて送り、各グループに 1 回だけ送ります。
- 送信待ちの一斉送信は 1 件だけ保持します。追加 / 置き換えると前のものを上書きして数え直し、いつでも取り消せます。上限は漢字 200 文字です。
- 送信待ちの一斉送信があるときは、ページ上部にバナーを表示し、何グループに送ったかを示します。

## 因果ルール

カスタム返信より強力な「条件 → アクション」のエンジンです。視覚的なエディターでは **テンプレートから始める** ことができ（朝のあいさつ、毎日のチェックイン、回数制限付きのガチャ、曲のリクエスト、専用の反応）、1 つ選んで適用し、文章を変えるだけで使えます。

- **次を満たしたら**（条件。複数を AND/OR で組み合わせ可能）：含む / 完全に一致 / …で始まる / 正規表現に一致（捕捉グループは返信で `{$1}` として使える）/ 送信者のホワイトリスト / 送信者のブラックリスト / 指定したグループ / カウンターの条件。
- **次を実行**（アクション。複数可）：メッセージで返信（複数行からランダムに 1 つ）/ カウンターの加算・減算 / カウンターを値に設定 / カウンターを 0 に戻す / API の呼び出し（返ってきた内容を変数に保存し、返信で `{変数名}` として参照。システム設定で外部へのリクエストを有効にする必要あり）。
- **高度な設定**：優先度、クールダウンの秒数（ユーザーごと / グループごと / 全体で計算）。
- **試してみる**：メッセージを入力すると、このルールが反応するか、何を返すかをリアルタイムで確認できます。

ルールの一覧は、検索、オン・オフのスイッチ、編集、削除に対応しています。

## カウンター

因果ルールのエンジンの **永続化されたカウンター**（チェックインの回数など）を表示・編集・リセットします。カウンターは「ユーザーごと / グループごと / 全体」でそれぞれ独立して保存され、返信では `{counter:名前}` で参照します。
