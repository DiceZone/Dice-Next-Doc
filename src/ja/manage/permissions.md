# 権限設定

**管理パネル → データ管理 → 権限設定** で、ユーザーの信頼レベル、ホワイトリストのグループ、ボットの識別、ブラックリストを 3 つのタブで管理します。

## 信頼レベルの段階

DiceNext は元祖 Dice! の nTrust の信頼の仕組みを移植しており、すべての権限の判定はこれに基づいています。

| レベル | 意味 |
|------|------|
| 0 | 一般のユーザー |
| 1–3 | 信頼層（信頼された相手で、グループの設定をリモートで管理できる） |
| 4 | 管理者（`.trust` / `.admin` / 全体の操作が使え、全体でのコマンドの無効化の影響を受けない） |
| 255 | ボット自身（内部で予約された値） |
| 256 | ダイスマスター Master（最も高い権限） |

チャットでの対応するコマンドは、`.trust <@相手/QQ番号> [レベル 0-255]`（レベルを省略すると確認。管理者 4 以上が使え、自分より低いレベルしか設定できない）、`.admin add/del <@相手/QQ番号>` と `.admin list`（ダイスマスターのみ）です。詳しくは[管理コマンド](/ja/use/admin)を参照してください。

## 権限の管理

### ユーザーの信頼レベル

一覧には権限を持つユーザー（信頼レベル > 0 またはダイスマスター）だけを表示し、QQ のアイコン付きで、検索とページ分け（既定は 1 ページ 20 件、変更可）に対応しています。各行のプルダウンでレベルを直接切り替えます：一般 / 信頼 1–3 / 管理者 / **ダイスマスター**。「ダイスマスター」も選べるレベルの 1 つで、選ぶとダイスマスターの一覧に加わり、ほかのレベルに切り替えると外れます。

「権限を追加」ダイアログは **検索して追加する** 方式です。まずプラットフォームを選び（QQ。Discord はまだ選べません）、QQ 番号を入力するか既存のユーザーを検索してから、権限のレベルを選びます。ユーザーがコマンドを使ったことがあれば自動でプロフィールが作られるため、検索で見つけられます。

### ホワイトリストのグループ

ユーザーにはホワイトリストは不要で、信頼レベルに達していれば信頼済みとみなします。ホワイトリストに個別に追加する必要があるのは **グループ** だけです。グループ番号（理由も付けられます）を入力して追加します。

**ホワイトリストのみモード** のスイッチ：有効にすると、ホワイトリスト内のグループだけに反応し、ほかのグループはすべて無視します。

## ボットの一覧

グループ内のほかのダイスボットを識別し、互いに反応し合うのを防ぎます。

- **自動識別**：各ボットの系統の `.bot` の決まった形式の返信から自動で登録します（Dice! / Dice!Next / OlivaDice / SealDice に対応）。QQ 番号、ボットの系統、識別した時刻を記録します。
- **手動登録**：QQ 番号とボットの系統の名前を入力して追加します。
- **@ のときは黙る**：ユーザーが「@ほかのボット + コマンド」と送った場合、このボットは何も返さず、代理のロールとして実行しません。

## ブラックリスト

ブラックリストのユーザー / グループには、どのコマンドにも反応しません（ブラックリストのグループからは自動で退出もします。通知イベント「ブラックリストによる自動退出」を参照）。

- 「ブラックリストに追加」ダイアログ：プラットフォーム、対象の種類（ユーザー / グループ）を選び、ID を入力し（既存のプレイヤー / グループの一覧から候補を検索できます）、理由のメモを付けます。
- 一覧にはアイコン、対象の種類のラベル、理由、追加した時刻を表示し、QQ / グループ番号 / 理由での検索とページ分けに対応しています。

::: tip 旧版データの移行
元祖 Dice! の `BlackList.json` は「システム設定 → 旧版データの取り込み」で一括で移行できます。詳しくは[データ移行](/ja/guide/migration)を参照してください。
:::

## クラウドブラックリスト

クラウドブラックリストのスイッチ、サービスのアドレス、トークン、自動報告、危険度、同期の周期は、[システム設定 → クラウドサービス](/ja/manage/cloud-services#クラウドブラックリスト)にまとめました。このページには、ローカルのブラックリストの管理、クラウドの出所の目印、クラウドサービスへの入口を残しています。

クラウドの記録は、確認されて有効になり、危険度の基準に達するとローカルのブラックリストに統合されます。クラウドでの取り消しは、対応するクラウドの出所の記録を解除するだけで、ダイスマスターが独自に追加したローカルの項目は削除しません。ブラックリストに登録されたユーザーは、[クラウドブラックリストのサイト](https://cloudban.dice.zone)にログインして異議を申し立てられます。
