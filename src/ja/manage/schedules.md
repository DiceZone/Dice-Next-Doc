# 定期タスク

**管理パネル → システム設定 → 定期タスク** で、毎日決まった時刻にグループ / 個人チャットへメッセージを送るように設定します（朝のあいさつ、セッションの案内、イベントのお知らせ）。**実行の条件**、**プラグインのコマンド**、**退出のアクション** を加えて、「因果」式の自動化もできます（DailyNews を定期的に呼び出す、「7 日間誰も使わなければ退出する」など）。

## タスクの新規作成

メインのページには、既定で検索欄、「追加」ボタン、既存のタスクの一覧が表示されます。「追加」をクリックすると設定のダイアログが開き、タスクの編集もダイアログで行います。フォーム全体が一覧の上に常に表示されることはなくなりました。

| 項目 | 説明 |
|------|------|
| 名前 | タスクのメモ用の名前 |
| 時刻 | 毎日実行する時刻（時:分） |
| 宛先の種類 | グループ / 個人チャット |
| 宛先の番号 | グループ番号 / QQ 番号 |
| 曜日 | 月曜〜日曜を複数選択。選ばなければ毎日 |
| アクション | **メッセージを送る** / **プラグインのコマンドを実行** / **退出** |
| 実行の条件 | 空欄 = 条件なしで時刻どおりに実行。`inactive>=7` はこのグループで 7 日以上コマンドが使われていない場合だけ実行。`>=` `>` `<=` `<` `==` に対応 |
| 内容 / プラグインのコマンド / 別れのあいさつ | 送信のアクションでは送る文章、プラグインのアクションでは実行させる完全なコマンド、退出のアクションでは退出前の別れのあいさつ（任意） |

内容には変数と関数の描画が使えます：`{self}`、`{group}`、`{date}`、`{roll:1d100}`（ダイスを振る）、`{draw:デッキ}`（デッキから引く）など。

::: tip 因果の例：活動のないグループからの自動退出
アクションに「退出」を選び、条件に `inactive>=7` を入力します。これは「時刻になったら確認し、このグループで 7 日以上誰もコマンドを使っていなければ別れのあいさつを送って退出する」という意味です。グループで誰かがコマンドを使っていれば、その日は飛ばします。
:::

## プラグインのコマンドの実行

アクションで「プラグインのコマンドを実行」を選んだら、内容にはプラグインがふだんチャットで受け取る完全なコマンドを入力します。例：

```text
.dailynews
.专长 星质形 ASTRAL_AQUAN
求签 月老
```

時刻になると、選んだアカウントとグループ / 個人チャットのコンテキストで有効な **SealDice の JS プラグインまたは Dice! の Lua プラグイン** を呼び出し、プラグインが返した内容を宛先に送ります。「今すぐ実行」でのテストもできます。

このアクションは専用の権限の低い仮想メッセージを使い、JS / Lua プラグインのコマンドの層にだけ入るため、`.admin` などの Dice!Next 内蔵の管理コマンドは実行しません。宛先のグループでそのプラグインが個別に無効にされている場合も実行されません。

### チャットからこのグループのタスクを追加する

ダイスマスターは、対象のグループや個人チャットでプラグインのコマンドの定期タスクを直接作成することもできます。

```text
.admin clock + 本群早报 07:30 .dailynews
.admin clock + 本群求签 08:00 求签 月老
.admin clock list
.admin clock - 本群早报
```

コマンドで作成したタスクは、現在のボットのアカウント、プラットフォーム、グループ / 個人チャットの宛先を記録し、すぐに管理パネルの定期タスクの一覧に表示されます。Web ページで新規作成した「プラグインのコマンドを実行」のタスクと同じもので、時刻、曜日、実行の方法、宛先、コマンドを編集でき、有効化・無効化、今すぐ実行、削除もできます。同じチャットで同じ名前をもう一度追加すると、重複して作成せずに元のタスクを更新します。

元祖の詰めた書き方（例：`.admin clock+本群早报=7:30 .dailynews`）にも対応しています。`.admin clock` でタスクを追加・削除できるのはダイスマスターだけで、定期実行のときは引き続き権限の低いプラグインのコンテキストを使います。

## 動作

- 設定した時刻になり、その日にまだ実行しておらず、曜日が一致し、実行の条件を満たしたときに、自動で 1 回実行します。
- **宛先ごとに送り、一斉送信はしません**。指定した宛先にだけ作用するため、連投やアカウント停止の危険を避けられます。

## 管理

- 一覧のスイッチで、いつでもタスクを **有効化 / 無効化** したり、**削除** したりできます。
- 編集のアイコンをクリックすると既存のタスクを **編集** できます（フォームに値が入った状態で開き、変更後に保存）。
- 複数のタスクにチェックを入れると、**一括で有効化 / 無効化 / 削除** できます。一括削除には確認が必要です。操作は 1 件ずつ実行し、一部が失敗した場合は失敗した項目を残して再試行できるようにし、すべて成功したとは主張しません。旧 Lua プラグインのタスクで使える操作は、引き続きそのタスクの種類によって制限されます。

## 旧 Dice! の Lua プラグインの定期タスク

単一ファイルの Lua プラグインが `task_call['タスク名'] = 'グローバル関数名'` で定期実行の入口を登録していれば、ダイスマスターはチャットで直接設定できます。

```text
.admin clock + タスク名 07:30
.admin clock list
.admin clock - タスク名
```

このようなタスクもこのページの一覧に表示され、アクションは「Lua プラグインのタスク」と表示されます。無効化、今すぐ実行、削除ができます。`7:30` と `07:30` のどちらの書き方も使えます。タスクの送信先はプラグインの関数内の `sendMsg` で決まるため、通常のタスクの宛先と内容の編集フォームは用意していません。`.admin clock` を実行できるのはダイスマスターだけです。

DailyNews などの旧プラグインが使う `.admin notice group/QQ … +8` の購読と `.send notice 8 …` の送信は、このプロジェクトの統一された通知ウィンドウに自動で接続されるため、プラグインのソースを 1 つずつ修正する必要はありません。

::: tip 出勤と退勤
「出勤のあいさつ + おやすみ」が欲しい場合は、タスクを 2 つ作るだけです（たとえば 09:00 に 1 つ、23:00 に 1 つ）。
:::
