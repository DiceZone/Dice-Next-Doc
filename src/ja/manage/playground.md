# コマンドテスト

**管理パネル → コマンドテスト** はチャット形式のテスト台です。QQ / Discord を開かなくても、Web ページで直接メッセージを送ってコマンドを試し、ボットがどう返すかを確認できます。

## 使い方

上部で環境を選んでから、チャットのようにコマンドを入力します（`.r`、`.ra 侦查 60`、`.coc` などのショートカットボタンもクリックできます）。

| 項目 | 説明 |
|------|------|
| 場面 | グループチャット / 個人チャット |
| プラットフォーム | QQ（OneBot v11） / Discord |
| 返信の言語 | 画面の言語に従う（既定。パネルの言語を切り替えると連動）/ 既定（プラットフォームに従う）/ 简体中文 / 繁體中文 / English / 日本語 |
| ニックネーム | 送信者として模擬するニックネーム（既定は「测试员」＝テスター） |

## 実際のメッセージとまったく同じ処理の流れ

テスト台はコマンドと返信の処理の流れをそのまま使いますが、プラットフォームの実際のメッセージの配送や描画ではありません。Web ページで正常に表示されても、QQ 公式 / Discord / KOOK での実際のペイロード、権限、添付ファイルの送信が確認済みというわけではありません。主な処理の段階は次のとおりです。

1. 内蔵のコマンド
2. JS プラグイン
3. Lua mod
4. カスタム返信
5. AI の会話 / NPC（有効な場合。グループの要約と長期記憶を注入してプレビューできます）

最後に AI による文章の調整と AI 翻訳（有効な場合）も通るため、AI を設定した直後に効果をプレビューできます。コマンドがどの処理にも一致しない場合は「反応なし」と表示します。

## 実際のデータには影響しない

テストのメッセージは仮想の身元（ユーザー `10001`、グループ `100001`）を使い、実際のグループに送られることはなく、反応型の一斉送信も消費しません（これは実際のグループのメッセージでだけ働きます）。`.st` などのコマンドで書き込んだデータは、この仮想の身元に記録されます。

::: tip
テスト台は問題を調べるときの最初の場所です。カスタム返信を変えたとき、新しいプラグインを入れたとき、AI の設定を調整したときは、まずここで 1 回送って試してから、実際のグループで確認してください。
:::
