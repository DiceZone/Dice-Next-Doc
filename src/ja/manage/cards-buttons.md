# カードとボタン

**管理パネル → 高度な返信 → カードとボタン** で、QQ 公式ボットのアカウントごとにメニューとコマンドパネルを編集します。このページは現在 QQ 公式プラットフォーム向けで、ほかのアダプター向けの汎用カードエディターではありません。

- **グローバルメニュー**：メッセージの入口、HTTPS のリンク、サブメニュー、スイッチを編集し、項目の並べ替えとレイアウトのプレビューに対応します。公開すると、そのアカウントの 1 対 1 チャットのメニュー全体を置き換えます。
- **コマンドパネル**：1 対 1 チャット、グループチャット、テキストのサブチャンネル、チャンネルのダイレクトメッセージで絞り込み、コマンドとリンクの項目を作成・編集し、管理者の制限、メモ、関連付ける対象を設定します。

アカウントの選択、フロントエンドでの検証、公開の確認、下書きの保護はすべてこのページで行います。既存のカスタム返信、因果ルール、カウンターは同じ階層の「カスタム返信」ページに残っており、既存のルールが移動したり消えたりすることはありません。

権限の要件、プラットフォームの上限、関連する操作については [QQ 公式 API v2](/ja/develop/qq-official-api#視覚的な編集) を参照してください。
