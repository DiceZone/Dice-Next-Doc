# プレイヤー管理

**管理パネル → データ管理 → プレイヤー管理** で、ボットとやり取りしたことのあるすべてのプレイヤーのプロフィールを確認できます。

## プロフィールの作成

プレイヤーのプロフィールは、初めてボットとやり取りしたときに **自動で作成** されます。手動で追加する必要はありません。

## 一覧の内容

| 列 | 説明 |
|----|------|
| ニックネーム | 最新の表示名（QQ のアイコン付き）。クリックすると詳細ページに入る |
| QQ 番号 | プラットフォームのアカウント |
| 信頼レベル | プルダウンで直接調整（下記参照） |
| 好感度 | 現在の好感度。行内で直接編集できる |
| コマンド数 | 累計でコマンドを使った回数 |
| 最後のコマンド | 最後に使った時刻 |

既定では左にプレイヤーの一覧、右に選択したプレイヤーの詳細を表示し、旧来の表のページは独立した表示モードではなくなりました。ツールバーではニックネーム、アカウント、信頼、好感度、コマンド数、最後のコマンドの時刻で並べ替え、昇順・降順を切り替えられます。既定は信頼レベル順です。プラットフォームでの絞り込み、検索、ページ番号のクリックや入力による移動にも対応しています。

## 信頼レベル

プルダウンでは 一般（0）、信頼 1〜3、管理者（4）、**ダイスマスター** を選べます。

- 0＝一般、1〜3＝信頼層（グループの設定をリモートで管理できる）、4＝管理者（`.trust` / `.admin` と全体の操作が使える）、ダイスマスター＝最も高い権限です。
- 「ダイスマスター」を選ぶと、そのアカウントが Master の一覧に追加されます（[基本設定](/ja/manage/settings)の Master のカードと同期）。ダイスマスターからほかのレベルに変えると一覧から外れます。
- チャットでの対応するコマンドは `.trust <QQ> <レベル>` / `.admin add` です。旧版から取り込んだ 5 以上の信頼値も正しく表示されます。
- 信頼レベルはコマンドの権限に影響します（たとえば、全体で無効にしたコマンドも信頼 4 以上には効きません）。

## 操作

- **検索**：ニックネーム / QQ で絞り込みます。
- **信頼 / 好感度の編集**：選択したプレイヤーの詳細の欄で変更します。
- **記録の削除**：あるプレイヤーのプロフィールを削除します。
- **友だちの削除**：アダプターを通じて友だちの関係を解除します（友だちでない場合は使えません）。

## プレイヤーの詳細ページ

左のプレイヤーをクリックすると、右にそのプレイヤーのデータがタブごとに表示されます。保存、削除、友だちの操作はすべて現在選んでいるプレイヤーが対象で、プレイヤーや絞り込みの条件を切り替えるとき、ページを離れるときには、保存していない変更を知らせます。

| 区分 | 内容 |
|------|------|
| 個人情報 | ニックネーム、信頼、好感度、そのプレイヤーが現れたことのあるグループ |
| キャラクターシート | すべてのシートと能力値。既定のシートと各グループでの紐付けを表示。**.st をコピー**（シートを記録するコマンドをワンクリックで生成）、能力値の個別の変更、シートの削除ができる |
| 設定のキーと値 | そのプレイヤーの各設定（グローバル / グループごと） |
| プラグインのデータ | Lua mod が保存したプレイヤーの変数とシートのデータ |
| チャットのシミュレーター | そのプレイヤーの個人チャットの履歴を確認し、メッセージを送る |

まとめて保存できる変更は、ページで編集した後に **「すべての変更を保存」** で送信します（成功 / 失敗の件数を表示）。一部の即時の操作はボタンの案内に従って実行されます。一覧は左に残ったままなので、別のプレイヤーを選ぶために前のページへ戻る必要はありません。

## QQ 公式のユーザーのアイコン

一覧、カード、詳細では、プラットフォームから返されてキャッシュしたアイコンを統一して使います。アイコンの項目がない場合は、紐付けた AppID とユーザーの OpenID から QQ のアプリ用のアイコンのアドレスを生成します。AppID ごとにキャッシュは分かれ、再起動後も保持されます。アドレスが使えなくなった場合はユーザーのアイコンを表示し、OpenID を QQ 番号として扱ったり、アイコンでユーザーの身元を判断したりはしません。
