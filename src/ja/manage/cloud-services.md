# クラウドサービス

**管理パネル → システム設定 → クラウドサービス** で、ボットのクラウドサービスへの接続、認可、同期を管理します。

## ボットのキー

1. [アカウントセンター](https://account.dice.zone/dashboard/bindings)でボットの所有を確認し、正式な API キーを生成します。
2. 「ボットのキーの設定管理」で対応するアダプターを選び、キーを入力して保存します。
3. 必要に応じて、下のハートビート、クラウドブラックリスト、クラウドのキャラクターシートの機能を設定します。

キーはアダプターごとに保存されます。プラットフォームの接続ページにある従来のキーの入口も引き続き使え、どちらからも同じ設定を変更します。既存の設定を入力し直す必要はありません。既存のキーは末尾 4 文字だけを表示し、入力欄を空にしても変更されません。明示的に消去を選んで保存したときだけ削除されます。

ボットの API キーは、WebUI の管理用 API キーやプラットフォームの接続の Access Token とは別のものなので、混同しないでください。自動で取得した未確認のハートビート用のキーは、クラウドのキャラクターシートに必要な正式なキーの代わりにはなりません。

## ハートビートの報告

ハートビートのサービスのスイッチをオンにして保存し、「今すぐテスト」をクリックすると、最近の報告の時刻と結果を確認できます。既定のサービスは [heart.dice.zone](https://heart.dice.zone) で、自前のアドレスも入力できます。

- **ダイスマスターの情報**：ニックネームと QQ は任意です。両方とも空欄の場合は、ダイスマスターの一覧とプレイヤーのプロフィールから自動で読み取るルールを使い、入力すると手動の情報を使います。
- **公開表示**：ハートビートの広場や検索に表示するかどうかを制御します。ハートビートのサービスをオフにすることとは別です。
- **報告の間隔**：180–480 秒、既定は 240 秒です。オンラインになったときにすぐ報告し、その後は定期的に生存を知らせます。
- **オフラインの状態**：正常に終了したときはオフラインを報告します。クラッシュやネットワークの切断はサーバー側のタイムアウトで判定します。

## クラウドブラックリスト

同期のスイッチ、サービスのアドレス、独立したトークン、ローカルでのブラックリスト登録の自動報告、最低の危険度、同期の周期を設定し、最近の結果の確認とすぐの同期ができます。

独立したトークンが空欄の場合は、互換のために旧来のハートビートのトークンを使い、次に設定済みのアダプターのボットのキーを使います。クラウドブラックリストのために公開のハートビート表示を有効にする必要はありません。

- 報告した記録は、まずクラウドでの確認を待ち、通過してから配信の対象になります。
- 危険度の基準に達した有効な記録はローカルのブラックリストに統合され、クラウドブラックリストの目印が表示されます。
- クラウドでの取り消しは、対応するクラウドの出所の記録を解除するだけで、ダイスマスターが独自に追加したローカルのブラックリストは削除しません。

[権限設定](/ja/manage/permissions#クラウドブラックリスト)にはローカルのブラックリストの管理とクラウドの目印が残り、クラウドへの接続と同期の設定はこのページで管理します。

## クラウドのキャラクターシート

ダイスマスターが正式なボットのキーを設定した後、プレイヤーは **ボットとの個人チャット** で `.cloud auth` を使って認可します。既定は読み取りのみで、書き込みには `.cloud auth write` を使い、アカウントセンターで確認する必要があります。

管理画面がプレイヤーの代わりに認可したり、プレイヤーのトークンを表示したりすることはありません。取得、アップロード、同期、認可の解除は、すべてプレイヤーが `.cloud` のコマンドで行います。詳しくは[クラウドと本人確認](/ja/use/cloud)を参照してください。

現在は手動で同期します。セッションで使うのは引き続きローカルのシートで、トークンの期限切れやボットの再起動の後は認可し直す必要があります。競合があっても双方の内容を強制的に上書きすることはありません。

## ログサイト

`.log end` / `.log get` でログをアップロードする先のアドレスとプロトコルを設定し、既定の設定に戻すこともできます。

既定の公式のアドレスは `log-api.dice.zone`、既定のプロトコルは DiceNext 専用の zstd JSON（`dicenext`）です。SealDice V1（`seal`、zlib JSON）、SealDice V105（Parquet）、旧版の複数に分けた txt のプロトコル（`legacy`）も選べます。対象のサイトが対応するプロトコルに合わせてください。既存のインストールでは保存済みのプロトコルの選択を保持します。

公式ではないアドレスには、第三者のサイトである旨の注意が表示されます。アップロードするとセッションの記録が選んだサイトに送られるため、設定する前にそのサービスが信頼できるかを確認してください。使い方は[セッションログ](/ja/use/log)を参照してください。

## そのほかの設定の場所

- 画像のホスティング、画像の送信、ログの画像の保存は引き続き[基本設定](/ja/manage/settings#画像に関する設定)にあり、従来の設定のスコープにも対応しています。
- 通知ウィンドウと送信は[通知設定](/ja/manage/notice)にあり、AI とプログラムの更新にもそれぞれの入口があります。
- 旧来の `#/settings?tab=cloud` などの管理画面のリンクも引き続き転送されます。上部バーで「クラウドサービス」「ハートビート」「クラウドのキャラクターシート」を検索して、関連するカードに直接移動することもできます。
