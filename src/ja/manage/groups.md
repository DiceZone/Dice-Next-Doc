# グループ管理

**管理パネル → データ管理 → グループ管理** で、ボットが参加している各グループを「一覧 + 詳細」の形で管理します。

## グループの一覧

- **活動中のグループ / 退出済み** の 2 つのタブがあります。既定では左に一覧、右に詳細を表示し、表示方式のボタンでカード / 表にも切り替えられます。検索（グループ名 / グループ番号 / メモ）とアダプターのアカウントでの絞り込みに対応しています。
- 分割表示の一覧のページ分けでは、ページ番号のクリックや入力で移動できます。狭い画面では使える幅に合わせて並べ、右側の機能の内容を押しつぶして横並びのレイアウトを保つことはしません。
- グループの記録は、ボットがグループに参加したときや `.bot` / `.group` を使った後に自動で表示されます。グループ番号を手動で入力して追加することもできます。
- グループ名、グループ番号、メモのラベル、グループでのボットの権限（オーナー / 管理者 / メンバー）を表示します。
- **最後のコマンド**：一覧、カード、表、詳細のいずれにも、実際にコマンドを処理した最後の時刻を表示し、通常のチャットやカスタム返信は数えません。すべてのアダプターの表示ではグループ内のアカウントをまとめ、アカウントで絞り込むとそのアカウントの記録だけを表示します。最近使った順や長く使われていない順に並べ替えられます。
- 古い記録で日付しかないものには「日付のみ」と表示し、記録がないものには「コマンドの記録なし」と表示します。アップグレードやページを開いた時刻を過去のコマンドの時刻として扱うことはありません。正確な時刻はブラウザのローカルのタイムゾーンで表示します。
- **有効化 / 無効化**：リモートでの `.bot on/off` と同じです。
- **完全に無効化 / 無効化の解除**：グループを完全に黙らせます（`.bot off` より強く、グループ内の誰も再び有効にできず、このページからしか元に戻せません）。

分割表示では、これらの操作は選んだグループの右側の詳細の欄にあります。変更する前に「アダプターのアカウント」を確認してください。アカウントで絞り込んでいる場合は絞り込み中のアカウントを使い、同じグループの別のメインのアカウントを誤って変更することはありません。退出済み、完全に無効化などの状態は、対応する操作を制限します。

### 手動での一括退出

「一括退出」をクリックすると選択モードに入り、1 つずつチェックするか「このページを選択」を使います。ページをまたいで最大 100 グループまで選べます。検索、アカウントの絞り込み、「活動中のグループ / 退出済み」のタブを変えると選択は解除され、最後のコマンドの時刻に基づいて自動でチェックすることはありません。

複数のアカウントがいるグループでは、まず具体的なボットのアカウントで絞り込む必要があります。オフライン、退出済み、またはアダプターが退出に対応していないアカウントはチェックできません。現在は OneBot V11 と Milky に対応しており、QQ 公式など退出の機能を提供していないプラットフォームは操作の対象として表示されません。

確認のウィンドウには、グループ名、グループ番号、実際に操作するボットのアカウントを一覧表示します。既定ではグループの管理記録を残しますが、「グループの管理記録も消去する」にチェックすることもできます。退出と消去は同じバックエンドのリクエストで処理され、同じグループのほかのボットのアカウントを退出させたり消去したりすることはありません。キャラクターシートとセッションログは常に保持されます。一部が失敗した場合は別に一覧表示してチェックを残すため、確認してから再試行できます。リクエストが受け付けられても、プラットフォームで退出が完了したとは限りません。

### 退出済みの記録の一括消去

「退出済み」に切り替えて「記録を一括で消去」をクリックし、1 つずつチェックするか「このページを選択」を使い、グループ番号とボットのアカウントを確認してから確定します。ページをまたいで最大 100 件まで選べます。オフラインのアカウントも消去でき、アダプターが退出に対応している必要はありません。複数のアカウントがいるグループでは引き続き具体的なアカウントで絞り込む必要があり、どのボットを消去するかを推測することはありません。

この操作は選んだアカウントのグループの管理設定を消去するだけで、退出のリクエストを再び送ったり、キャラクターシート、セッションログ、同じグループのほかのアカウントのデータを削除したりはしません。バックエンドは消去のときに退出の状態を再確認し、すでにグループに再参加しているアカウントの消去は拒否します。失敗した項目はチェックを残すので、更新して確認してから再試行できます。

明示的に退出した後は、プラットフォームに残ったグループ一覧のキャッシュ、送信途中のメッセージ、遅れて届いた退出のイベントによって、消去した記録が作り直されることはありません。プログラムを再起動しても、10 分待っても、自動で再び表示されることはありません。本当にグループに再参加したときに初めて、そのアカウントの記録が復活します。まだグループにいる記録だけを削除しても退出にはならず、その後の実際のグループのメッセージで記録が作り直されることがあります。

## 詳細のタブ

| タブ | 機能 |
|--------|------|
| 機能の管理 | グループ内の名前 / メモ / 招待者 / 返信の言語 / 歓迎メッセージ / メッセージの送信 / 退出 |
| AI | このグループの AI のスイッチとグループの記憶の管理 |
| プラグイン | このグループだけでプラグイン / mod をオン・オフ |
| メンバー管理 | メンバーの一覧と、ミュート / キックなどのグループ管理の操作 |
| ログ管理 | セッションログの出力 / アップロード / 削除 |
| グループファイル | グループファイルの表示、ダウンロード、アップロード |
| チャットのシミュレーター | グループのメッセージをリアルタイムで確認し、直接発言 |

### 機能の管理

- **ログ / 返信 / ダイス / プラグイン**：4 つの独立したスイッチで、それぞれ `.bot log`、`.bot reply`、`.bot roll`、`.bot plugin` の `on/off` の操作に対応します。現在のボットのアカウントとグループごとに保存し、同じグループのほかのアカウントには影響しません。
- **スイッチの関係**：サブスイッチで全体スイッチや完全な無効化を回避することはできません。全体スイッチまたはログのスイッチをオフにすると記録とタイマーが止まり、記録中であれば一時停止を知らせますが、ログを削除したりセッションを終えたりはしません。再びオンにすると記録中だったログは再開しますが、`.log off` で手動で一時停止したログには引き続き `.log on` が必要です。
- **ログだけを記録する**：全体スイッチとログをオンのままにし、返信、ダイス、プラグインをオフにします。AI、歓迎メッセージ、自動化、転送を有効にしている場合は、用途に応じて個別にオフにしてください。詳しい手順は[セッションログ](/ja/use/log#ログだけを記録する)を参照してください。これはログ以外のすべての動作を一律に黙らせる専用のモードではありません。
- **ボットのグループ内の名前**：このグループでボットに表示される名前（未設定のときは QQ のニックネーム）。
- **グループのメモ**：管理画面でだけ見えるメモのラベル。
- **グループの招待者**：ボットをグループに招待した人を記録し、権限はグループの管理者と同等に扱います。
- **このグループの返信の言語**：設定すると、このグループの返信にその言語を使います（グループでの `.lang` と同じ）。
- **参加時の歓迎の設定**：このグループの歓迎メッセージ（`@メンション` / QQ 番号 / ニックネームの変数に対応）、送信の遅延とクールダウン（秒）。実際の値は[基本設定](/ja/manage/settings)のグローバルな最低の遅延 / クールダウンを下回らないため、続けて参加があったときにチャットが埋まるのを防ぎます。
- **グループの操作**：メッセージの送信、退出（「退出して記録を削除」または「退出のみで記録を残す」を選択）、記録の削除（管理画面の記録を削除するだけで退出はしない）。

### AI

- **このグループの AI 機能** のスイッチ：オフにすると、このグループではボットの AI の会話 / NPC が反応しなくなり、グループの記憶も作られません（先に「AI」ページでグローバルのスイッチを有効にする必要があります。グループ内でも `.ai on/off` を使え、グループ管理者が必要です）。
- **このグループの記憶**：このグループの AI の記憶（要約 + 事実）を確認 / 消去します。記憶は会話に合わせて順次生成されます。

詳しくは [AI](/ja/manage/ai) を参照してください。

### プラグイン

このグループだけでプラグイン（Lua mod / JS プラグイン）をオン・オフします。オフにすると、そのプラグインのコマンドはこのグループで反応しなくなりますが、ほかのグループやグローバルの設定には影響しません。

### メンバー管理

メンバーの一覧と役割を取得します。管理者はミュート / ミュートの解除 / キック / 名前の変更ができ、オーナーは専用の肩書きを設定できます。ニックネーム / グループ内の名前 / QQ での検索に対応しています。

::: tip 権限について
ミュートやキックなどの操作には、ボットがそのグループで管理者の権限を持っている必要があります。ボットが一般のメンバーにすぎない場合は、パネルに権限不足と表示されます。
:::

::: tip グループの自動化（コマンドでの設定）
ボットにグループ管理の権限がある場合、グループ管理者はグループ内で `.group auto pass キーワード`（参加の認証メッセージにキーワードが含まれていれば自動で承認、`all`＝すべて承認）、`.group auto kick キーワード` / `.group auto mute キーワード [分]`（発言にキーワードが含まれていれば自動でキック / ミュート。ダイスマスター、グループ管理者、信頼済みのユーザー、招待者は対象外）でこのグループの自動化を設定できます。`.group auto` で確認でき、キーワードを空欄にするとオフになります。
:::

### ログ管理

このグループのセッションログ（名前 / 作成者 / 開始時刻 / 最後の記録 / 件数）を確認します。

- **出力**：TXT / Excel / Web ページ（HTML。「ログの画像を保存」を有効にすると画像を埋め込んで表示）。
- **アップロード**：ログサイトにアップロードし、共有のリンクを自動でコピーします。ログサイトのアドレスとアップロードのプロトコルは[システム設定 → クラウドサービス → ログサイト](/ja/manage/cloud-services#ログサイト)で設定します。
- **削除**：ログを削除します（ローカルにキャッシュした画像もあわせて消去）。

### グループファイル

- グループファイルとフォルダー（名前 / サイズ / アップロードした人 / アップロード日時）を閲覧します。
- **ダウンロード**：QQ の直接リンクからのダウンロードを優先し、本当のファイル名を保持します。
- **アップロード**：ファイルをグループにアップロードします（上限 30MB）。QQ が処理した後に一覧に自動で表示されます。
- 接続済みの NapCat / go-cqhttp のアダプターが必要です。

### チャットのシミュレーター

QQ に切り替えなくても、このグループのメッセージをリアルタイムで確認し、直接送信できます。

- メッセージには **アイコン** と送信者の名前を表示します（グループ内の名前があればそれを表示し、ボットは自分に設定した名前を表示）。
- **文章、画像、スタンプ**（アップロードした画像はローカルのスタンプとして保存され、クリックで送信）と **つつく** の送信に対応しています。
- 取り消されたメッセージには「取り消し済み」と表示し、引用メッセージは吹き出しの形で表示し、ファイルのメッセージは直接ダウンロードできます。
- 「履歴メッセージを取得（NapCat）」で過去の記録を補えます。上にさかのぼっているあいだは新しいメッセージで中断されず、ワンクリックの「最新のメッセージに戻る」もあります。
- チャットの記録は `chat.db` に永続的に保存され、保存期間は[システム設定 → チャットの記録の保存期間](/ja/manage/settings)で設定します。
