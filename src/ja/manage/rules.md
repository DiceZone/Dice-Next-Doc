# ルール管理

**管理パネル → 拡張管理 → ルール** で、取り込めるルールパック（能力値の別名 / 派生する式 / 早見のマニュアル / カスタムコマンド）を管理します。グループでは `.set <ルール>` で有効なルールを切り替えます。

## ルールパックの一覧

各ルールパックには名前、バージョン、作者、`.set` で切り替えるキーワード、既定のダイス、別名 / 派生する式 / 早見の項目 / ヘルプの件数が表示されます。カスタムコマンド、コマンドの別名、無効にしたコマンドがあるものは、対応するコマンドのバッジも表示します。

| 操作 | 説明 |
|------|------|
| 有効化 / 無効化 | 個別のルールパックをオン・オフ |
| オンラインで編集 | 視覚的なルールエディターを開く（下記参照） |
| 出力 | ルールの JSON ファイルをダウンロード |
| 削除 | ルールパックを削除（内蔵のルールは削除不可） |

一覧はページ分けに対応しています（1 ページあたりの件数を選べます）。内蔵のルール（COC7、DND など）には「内蔵」、取り込んだものには「取り込み済み」と表示されます。

## 取り込み

- **ルールファイルを取り込む**：単一のルールの JSON。
- **ルールパック（zip）を取り込む**：ルール + ヘルプ文書 + Lua/JS プラグインを 1 つの zip にまとめたもの（`pack.json` のマニフェストで宣言）で、グループで `.set` で有効にするとまとめて有効になります。ルールパックの欄では各パックのルール / コマンド / ヘルプ / プラグインの件数を個別に表示し、パック全体の有効化・無効化や削除（削除するとパックのフォルダー全体を消去）ができます。

ルールパックの書き方と配布の形式は、[ルールパックの作成](/ja/develop/rulepack)と[実例：SealDice プラグインの変換](/ja/develop/rulepack-example-fu)を参照してください。

## 互換のルール

プラグインとして提供されているルールシステムもこのページにまとめて表示され、直接オン・オフできます。

- **JS 互換のルール**：SealDice の JS プラグイン（`seal.gameSystem` / `coc.registerRule`）。登録したコマンドを一覧表示します。
- **Lua 互換のルール**：元祖 Dice! の Lua mod（`model/*.xml` の能力値テンプレートを含む。COC7-TRPG / DND-5E など）。

このようなプラグインのアップロード / 削除 / 設定は[プラグイン管理](/ja/manage/plugins)ページで行ってください。

## 視覚的なルールエディター

「ルールを新規作成」または各ルールパックの「オンラインで編集」をクリックするとエディターが開きます。**フォームモード** と **ソースモード**（JSON を直接編集）はいつでも切り替えられます。

| 区画 | 内容 |
|------|------|
| 基本情報 | 名前（英字でファイル名に使う）、表示名、バージョン、作者、既定のダイス、`.set` で切り替えるキーワード |
| 成功度 | 判定の成功度の決め方（内蔵 / カスタム / 使わない） |
| 能力値の別名 | 正式な名前 + 別名の一覧（`.st` での記録時に同義語を統一） |
| 派生する式 | 能力値 + 式（例：回避＝DEX/2） |
| 既定値 | 能力値の既定の数値 |
| 早見の項目 | `.rules` のルール早見の項目と説明 |
| コマンドの別名 | 入力する言葉 → 対象のコマンド |
| カスタムコマンド | コマンド名 + 出力テンプレート（`{式}` を評価して置き換え。ダイス、シートの値の取得、三項条件などに対応）+ ヘルプの文章 |
| 無効にするコマンド | このルールが有効なときに遮断する内蔵のコマンド |

エディターの下部には **リアルタイムのテスト** があり、現在編集中の内容でそのままコマンドを試せます（テスト用の能力値を注入できます）。保存する必要はありません。

テストではエディターの現在の未保存の JSON の下書きを使い、ルールのカスタムコマンド、別名、遮断を対象にします。インストール済みのルールには書き込まず、実際のグループで有効なルールも切り替えず、実際のグループにメッセージを送ることもありません。構文や描画に失敗した場合はそのままエラーを表示し、下書きを無視して保存済みの版だけをテストすることはなくなりました。

## 関連する機能（このページ以外）

| やりたいこと | 場所 |
|------|--------|
| コマンドの接頭辞 | [基本設定](/ja/manage/settings) |
| COC のハウスルール（クリティカル / ファンブルの判定） | グループで `.setcoc 0-7`。`.setcoc help` で各番号の定義を確認。詳しくは[ダイスと判定](/ja/use/dice) |
| ルールパックに付属するヘルプの項目 | 自動で統一の `.help` と[ヘルプ文書](/ja/manage/help-docs)ページに入る |
| キーワードのカスタム返信 | [高度な返信](/ja/manage/replies) |
| ブラックリスト・ホワイトリスト / 信頼 | [権限設定](/ja/manage/permissions) |

## 反映のされ方

パネルで変更するとすぐに保存されて反映され、再起動は不要です。
