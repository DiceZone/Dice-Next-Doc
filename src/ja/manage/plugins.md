# プラグイン管理

Lua mod の詳細には互換性の注意を表示します。スキップした条件、旧 Dice! の JS のアクション、対応していないイベント / 数値の式、ファイルの読み込みエラーを一覧にし、「フォルダーが見つかった」ことを「すべての機能が実行できる」こととして扱いません。JS は SealDice の体系を使い、旧 Dice! の JS を互換で実行することはできません。Python は今のところ予定に入っていません。

**管理パネル → 拡張管理 → プラグイン** で、2 種類の拡張を 2 つのタブでまとめて管理します。

- **JS プラグイン**：SealDice と互換の JavaScript プラグイン（`seal.*` API）。
- **Lua mod**：元祖 Dice! と互換の Lua mod（フォルダー型の msg_reply モジュールと単一ファイルの msg_order プラグイン）。

## アップロードと読み込み

「プラグインをアップロード」をクリックしてファイルを選ぶと、拡張子に応じて自動で振り分けます。

| ファイル | 行き先 |
|------|------|
| `.js` | JS プラグイン |
| `.lua` | Lua の単一ファイルのプラグイン |
| `.json` | Lua mod の説明ファイル（技能や呪文の検索など、検索だけの mod） |
| `.zip` | Lua mod のパッケージ。元祖の「`<名前>.json` + フォルダー」の組、1 つのパッケージに複数の mod を入れたライブラリ全体の圧縮ファイル、`model/`/`rulebook/` だけを含むルール系のパッケージに対応 |

ファイルをデータフォルダーに直接置いてから（Lua mod は `data/mod`、単一ファイルのプラグインは `data/plugin`）「再読み込み」をクリックすることもできます。再読み込みでは JS と Lua の両方を更新し、再起動は不要です。無効化と削除のボタンは、mod の説明ファイルとリソースのフォルダーを **組にして** 処理するため、残骸が残りません。

::: tip 自分でプラグインを書きたい場合
[プラグイン開発入門](/ja/develop/plugin-quickstart)から始めてください。API の全体は [JS プラグイン API](/ja/develop/js-plugin-api) と [Lua mod リファレンス](/ja/develop/lua-mod)を参照してください。
:::

## プラグインのカード

各プラグインには名前、バージョン、作者、説明、登録したコマンドの一覧が表示され、右側に操作があります。

- **オン・オフのスイッチ**：個別のプラグインをすぐに有効 / 無効にします。
- **設定**：JS プラグインが設定項目を登録している場合に表示され、ダイアログで種類ごとにフォームを描画します（スイッチ / プルダウン / 複数行のテンプレート / 数値 / 文章）。保存するとすぐに反映されます。
- **詳細を表示**：バージョン、言語、ライセンス、ファイル名、ホームページ、説明の全文、登録したコマンド。Lua mod ではさらにコマンドの反応の種類（コマンド / キーワード / その言葉を含むと反応）とヘルプの項目（`.help <項目>` で調べる）を区別します。「保存されたデータ」を開くと、プラグインが永続化したキーと値を確認でき、JSON での出力と全消去にも対応しています。
- **削除**：ファイルごとディスクから削除します（確認のダイアログあり）。

特別な目印：

- **JS 互換のルール**：`seal.gameSystem` / `coc.registerRule` の形でルールシステムを提供する JS プラグインは、自動で `data/mod` に分類され、ネイティブの JSON のルールパックと区別されます。
- **旧版（置き換え済み）**：同じ名前のプラグインの新しいバージョンをアップロードすると、旧版は自動で灰色になり無効になります。

## 更新の確認

更新先のアドレスを宣言している JS プラグインは、個別に「更新を確認」するか、ページの見出しの「更新を確認」でまとめて確認できます。新しいバージョンが見つかったら、ワンクリックの「更新」で置き換えます。

## グループごとのオン・オフ

プラグインは既定で全体に適用されます。グループでは次のコマンドでグループごとに制御できます（グループのオーナー / 管理者のみ）。

```
.plugin list            プラグインとこのグループでの状態を一覧表示
.plugin on|off <名前>   プラグインをオン / オフ
.plugin all on|off      まとめてオン / オフ
```

元祖 Dice! の `.mod` は **全体の mod の管理** として復活しており、`.plugin` のグループごとのオン・オフとは別のものです。ダイスマスターまたは信頼レベル 4 以上が必要で、一般のグループ管理者 / 招待者は全体の mod を変更できません。

```
.mod / .mod list        全体の mod と状態を一覧表示
.mod on|off <名前>      mod を全体でオン / オフ
.mod <名前> on|off      元祖の引数の順序
.mod info <名前>        mod の情報を表示
.mod detail <名前>      リソースの統計を表示
.mod reload <名前>      指定した mod を再読み込み
.mod del <名前>         指定した mod のファイルを削除
```

`.mod get/update/reinstall` は WebUI へ案内するだけで、旧来のリモートのダウンローダーは復活させていません。有効化、無効化、再読み込み、削除、取り込みでは XML のテンプレートも更新し、無効にした Mod はテンプレートを提供しなくなります。削除するとファイルが消えるので、先にバックアップしてください。

## 互換性

Lua 側は元祖 Dice! の mod の生態系と互換です。JS 側の互換の目標は **SealDice のプラグイン API** で、旧 Dice! の JS の体系ではありません（`seal.vars` によるキャラクターシートとの橋渡し、`commands.disable` による内蔵コマンドの上書きなどを含む）。SealDice のルール系のプラグインは、ルールパックに変換してまとめて配布することもできます。実例は[実例：SealDice プラグインの変換](/ja/develop/rulepack-example-fu)と[ルールパックの作成](/ja/develop/rulepack)を参照してください。

2026-10-15 のローカルの実装では、完全な TOML の解析、確率 / 名簿 / 共有の回数制限 / ロック、clock と安全なイベント、入れ子の mod、ルールブック / tape、XML の安全な数値の式に対応を広げましたが、まだ今回のインストールパッケージでは公開していません。入れ子の項目は親の無効化を引き継ぎます。同じ名前のフォルダーと単一ファイルのプラグインは別々の管理 ID を使うため、削除の前に対象を確認してください。旧来の JS / Python、任意の XML のスクリプト、セキュリティポリシーの上書きは実行しないため、任意の旧パッケージがそのまま動く保証はありません。詳しくは [Lua の互換の範囲](/ja/develop/lua-mod#原版との互換についての説明)を参照してください。

### グループ内の名前と表示名

グループチャットでは、受け取ったメッセージに付いているグループ内の名前を優先し、ない場合だけ QQ のニックネームを使います。個人チャットにはグループ内の名前はありません。

| 項目 | 値 |
| --- | --- |
| `ctx.player.name` | 統一された表示名：グループ内の名前を優先し、なければ QQ のニックネーム |
| `ctx.player.card` / `msg.sender.card` | 現在のグループ内の名前。未設定の場合や個人チャットでは空文字列 |
| `msg.sender.nickname` | QQ のニックネーム（グループ内の名前の影響を受けない） |

```js
cmd.solve = (ctx, msg) => {
  const displayName = ctx.player.name;
  const groupCard = ctx.player.card; // グループ内の名前を厳密に読み取りたい場合に使う
  seal.replyToSender(ctx, msg, `${displayName} / ${groupCard || 'グループ内の名前は未設定'}`);
  return seal.ext.newCmdExecuteResult(true);
};
```

Lua mod のテンプレートでは、`{nick}` は QQ のニックネーム、`{card}` は現在のグループ内の名前（未設定のときは空）です。
