# 快速开始

5 分钟上手 Dice!Next 3.0，从启动到掷出第一个骰子。

## 1. 下载并启动 Dice!Next

下载对应平台的公测包；Windows 解压后双击 `dice-next.exe`。

首次启动会自动生成 `config/` 配置目录与 SQLite 数据库（`data/dice.db` 等）。Windows 程序默认最小化到**系统托盘**运行，右下角有气泡提示。

详细说明请参考[安装部署](/guide/install)。

## 2. 打开管理面板

托盘图标右键 →「打开网页面板」，或浏览器访问 `http://localhost:18088`。

::: tip 设置登录密码
建议在管理面板的 **WebUI 设置**页设置登录密码：设置后所有后台页面与 API 都需要先登录（Cookie 会话，7 天有效），避免后台被随意访问。同一页还可以修改运行 IP / 端口（改后需重启，页面提供一键重启按钮）。
:::

## 3. 配置 OneBot 适配器

进入 **管理面板 → 适配器管理**，点击「添加适配器」。

### 正向 WebSocket（推荐）

Dice!Next 主动连接 OneBot 客户端（NapCat、Lagrange、LLOneBot 等）：

| 参数 | 值 |
|------|-----|
| 协议 | OneBot v11 |
| 传输模式 | 正向 WebSocket（`forward_ws`） |
| 端点地址 | `ws://127.0.0.1:3001/` |
| Access Token | 与 OneBot 客户端一致（可留空） |

确保 OneBot 客户端已开启正向 WS 服务端。断线后 Dice!Next 会自动重连（先每 5 秒、后每 60 秒，连续 20 次失败后暂停，可在面板手动重连）。

### 反向 WebSocket

OneBot 客户端反向连接 Dice!Next：

| 参数 | 值 |
|------|-----|
| 协议 | OneBot v11 |
| 传输模式 | 反向 WebSocket（`reverse_ws`） |
| 端点地址 | 填一个**端口号**（如 `6700`），Dice!Next 在该端口监听 |

然后在 OneBot 客户端把反向 WS 上报地址指向 `ws://<Dice!Next 所在 IP>:<该端口>/` 即可。

## 4. 测试掷骰

在已连接的 QQ 群聊或私聊中发送指令：

```
.help                 # 帮助
.r                    # 默认 d100
.r 3d6+2              # 3 个 6 面骰 + 2
.coc                  # COC 规则车卡
.ra 侦查              # COC 检定（读人物卡）
.jrrp                 # 今日人品
.draw 塔罗            # 抽牌
```

不想连 QQ 也可以先在管理面板的**测试台**里直接发指令试回复。

## 常见问题

### 连接不上 OneBot 客户端？

检查防火墙是否放行了对应端口，确认地址与 Access Token 配置正确、OneBot 客户端对应服务已开启。状态显示「连接超时」说明自动重连已暂停，修好后手动重连。详见[故障排查](/guide/troubleshooting)。

### 指令无响应？

进入管理面板的 Dashboard 查看日志，确认适配器状态为「已连接」；再检查群是否被 `.bot off` 停用。

### 如何迁移旧数据？

参考[数据迁移](/guide/migration)：管理面板 → 系统设置 → 旧版数据导入，填旧版数据目录一键导入。
