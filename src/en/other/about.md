# About

## Dice!Next

Dice!Next is a complete rewrite of the classic TRPG dice bot **Dice!**, dedicated to faithfully reproducing and continuing the Dice! experience on a modern stack: a high-performance C++ backend plus a modern web admin panel, with separate frontend and backend, ready to use out of the box, and multilingual.

Our goal is to let existing Dice! users **migrate painlessly** while making it easier for new users to get started.

## Tribute and References

Dice!Next stands on the shoulders of those who came before. Our sincere respect and thanks go to the following projects and communities:

### The Origin: Dice!

- **[Dice!](https://github.com/Dice-Developer-Team/Dice)**: the original project that Dice!Next reproduces and continues. Dice! has served the TRPG community for years, and its rule implementations, texts and interactions are the foundation of Dice!Next. Dice!Next continues as open source under its **AGPLv3** license.

### Reference Projects

- **[SealDice](https://github.com/sealdice/sealdice-core)**: an excellent modern dice project that gave us many references in command compatibility and experience design.
- **[OlivaDice](https://github.com/OlivOS-Team/OlivaDiceCore)**: a dice implementation highly compatible with Dice!, whose command syntax and feature design we compared against.
- **[OneDice](https://github.com/OlivOS-Team/lib-onedice)**: a unified dice expression standard; Dice!Next is compatible with its expression syntax.
- **[OneBot standard](https://github.com/botuniverse/onebot-11)**: an open chatbot protocol standard; Dice!Next's platform adaptation is based on OneBot v11.
- **[NapCat](https://github.com/NapNeko/NapCatQQ)**: a bot protocol implementation based on NTQQ.
- **[LLOneBot](https://www.llonebot.com/)**: a QQ bot framework and OneBot protocol implementation.
- **[SnowLuma](https://snowluma.github.io/)**: a remote protocol framework for the NTQQ and OneBot ecosystem.

### Technical Dependencies

drogon, nlohmann/json, SQLite / sqlite_orm, spdlog, React, Vite, shadcn/ui, VitePress and many other open source projects.
