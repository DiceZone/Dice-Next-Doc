# Cards & Buttons

**Web panel → Advanced replies → Cards & buttons** edits menus and command panels per QQ Official Bot account. This page currently targets the QQ official platform; it is not a general card editor for other adapters.

- **Global menu**: edit message entries, HTTPS links, submenus and switches, with item ordering and a layout preview; publishing replaces the account's complete one-to-one chat menu.
- **Command panel**: filter by one-to-one chat, group chat, text sub-channel and channel direct message; create or edit command and link entries, and set admin restrictions, notes and linked objects.

Account selection, frontend validation, publish confirmation and draft protection are all handled on this page. The existing custom replies, causal rules and counters remain on the sibling "Custom replies" page; existing rules are not moved or cleared.

For permission requirements, platform limits and related operations, see [QQ Official API v2](/en/develop/qq-official-api#visual-editing).
