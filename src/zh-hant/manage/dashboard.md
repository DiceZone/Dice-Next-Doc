# 管理面板總覽

Dice!Next 自帶 Web 管理面板，瀏覽器開啟服務地址（預設 `http://localhost:18088`）即可進入。絕大多數配置都能在面板裡完成，無需改檔案。

首頁伺服器資訊展示最近 **10 分鐘**的 CPU 與記憶體使用率，每 **5 秒**更新，保留每次取樣的原始數值。後臺仍保留最近 1 小時的歷史，首頁只取其中最近 10 分鐘繪圖；後端重啟後重新累計。歷史不足 10 分鐘時按實際取樣顯示。首次讀取顯示載入佔位，重新整理失敗時保留最近快照並提示。舊版後端沒有歷史時，使用本瀏覽器的近期取樣。

::: tip 登入與安全
- **登入密碼**：在 [WebUI 設定](/zh-hant/manage/settings#webui-設定頁) 中設定管理面板登入密碼後，打開面板需先輸入密碼（Cookie 會話認證）；留空儲存即關閉登入。
- **API Key**：後端介面的訪問金鑰，與配置檔案中的 `server/api_key` 保持一致。
- 面板要暴露到公網時，務必兩者都設定。
:::

## 全域性設定搜尋

管理面板頂欄提供全域性設定搜尋，桌面端也可按 `Ctrl+K`（macOS 為 `⌘K`）開啟。搜尋會同時匹配頁面名、功能大類、具體設定、說明以及常用別名，例如 `Markdown`、`敏感词`、`SMTP`、`密码`、`定时任务`。結果會顯示具體功能、所屬頁面和內容摘要；僅通過別名命中時還會標出命中的關鍵詞。例如搜尋“更新”或“升級”都會顯示“檢測與自動更新”，搜尋“翻譯”會直接顯示“AI 翻譯（.lang 自訂語言）”，並可定位到對應子頁面和功能卡片。

選擇結果後會直接開啟對應頁面；系統設定、通知設定和 WebUI 設定中的具體專案還會自動切換到正確選項卡、滾動到目標卡片並短暫高亮。搜尋彈窗、結果列表和鍵盤選擇均使用面板自身樣式，不依賴瀏覽器原生下拉框。

## 新手教程

新手教程會在真實頁面中高亮相關功能，並使用只讀演示資料幫助瞭解介面。演示不是實際執行資料，不會儲存為骰娘配置或執行真實操作；退出教程後恢復正常頁面。

## 執行概覽

- **狀態卡片**：線上適配器、使用者、群組、跑團記錄、累計響應指令與執行時間。每張卡片都可點選，分別開啟平臺連線、玩家管理、群組管理、跑團記錄、指令列表和資料統計（含線上歷史）。
- **最近日誌**：按時間、級別、模組、內容顯示，預設最低 INFO；支援搜尋、診斷展開和訊息關聯。實際記錄閾值在 [WebUI 設定](/zh-hant/manage/settings#webui-設定頁) 修改。

## 程式日誌

六級順序為 **TRACE → DEBUG → INFO → SUCCESS → WARN → ERROR**。預設 INFO 顯示 INFO、SUCCESS、WARN、ERROR；正常協議心跳屬於 TRACE，列表重新整理、快取和成功的文案預覽請求屬於 DEBUG。文案儲存、匯入等管理操作繼續記錄，預覽失敗與耗時異常也保留相應日誌。SUCCESS 只表示重要操作已經確認完成，玩家檢定成功或失敗仍是正常 INFO。

`[处理]` 顯示內建指令、JS/Lua 插件、高階回覆等處理者、觸發方式、處理結果及擬傳送內容，並分配內部 msgID。`[消息]` 保留平臺格式化後的實際提交內容和同一個 msgID，不重複來源；分段、Markdown 回退重試、平臺確認和失敗都可對應。平臺操作使用 `[事件]`。msgID 不是平臺訊息 ID，提交或平臺接受都不等於使用者已經收到、閱讀。

插件 `log/print/console` 的主動日誌顯示具體來源；插件執行中請求傳送不提前記為整個執行成功，未完成的非同步任務會說明等待狀態。混合來源保留各處理者，定時、Lua sleepTime 及跨插件非同步續跑不依賴“最近執行的插件”猜來源。

首頁選擇最低展示級別、搜尋內容／模組／插件／msgID，或點選“檢視關聯記錄”。關聯視窗不受列表級別篩選影響；錯誤本身也帶來源詳情，原 INFO 記錄不在近期視窗時仍可排查。C++ 檔案、行號、函式及執行緒號在“診斷詳情”中檢視，不佔每條正常日誌的字首。

時間保留毫秒，按伺服器時區顯示，不按瀏覽器時區重算。首頁保留當前程序有界的近期記錄，最多讀取最近 500 條，不掃描整日檔案；完整歷史及詳情儲存到 `data/logs/app/` 的 `.log` 與 `.jsonl`。兩種檔案都脫敏，分享前仍應檢查未知個人資訊。

## 系統托盤（Windows）

- 程式啟動後**預設隱藏控制台視窗，最小化到系統托盤**（首次會彈氣泡提示）；配置 `dice/console_start_hidden` 設為 `false` 可恢復啟動即顯示控制台。
- 托盤圖示懸停顯示埠（如 `Dice!Next(18088)`，方便多開區分）；托盤選單可開啟管理面板、顯示控制台或退出程式。
- 從 build 926 起，在**系統設定 → 基礎設定 → 網路與系統 → Windows 托盤提示文字**中可以自訂名稱，最多 10 個 Unicode 字元，留空恢復 `Dice!Next`，儲存後立即生效。埠由程式按實際監聽埠自動追加，如 `希亚骰(18089)`，無需手動填寫。此項為整個程式的設定，不隨適配器切換；僅 Windows 可修改。
