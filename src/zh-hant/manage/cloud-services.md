# 雲服務

**管理面板 → 系統設定 → 雲服務**，管理骰孃的雲服務連線、授權與同步。

## 骰娘金鑰

1. 在 [賬號中心](https://account.dice.zone/dashboard/bindings) 驗證骰娘所有權並生成正式 API Key。
2. 在「骰娘金鑰配置管理」中選擇對應適配器，填寫並儲存金鑰。
3. 按需要配置下方的心跳、雲黑名單或雲人物卡功能。

每個適配器分別儲存金鑰。平臺連線頁原有金鑰入口仍可使用，兩處修改同一份配置；已有配置無需重填。已有金鑰僅顯示末四位，輸入框留空不修改，只有明確選擇清除並儲存才刪除。

骰娘 API Key 與 WebUI 管理 API Key、平臺連線 Access Token 不同，請勿混用。自動獲取的未驗證心跳 Key 不能代替雲人物卡所需的正式 Key。

## 心跳上報

開啟心跳服務開關，儲存後點擊「立即測試」，檢視最近上報時間和結果。預設服務為 [heart.dice.zone](https://heart.dice.zone)，也可填寫自建地址。

- **骰主資訊**：暱稱和 QQ 可選；兩項均留空時沿用骰主列表與玩家檔案的自動讀取規則，填寫後使用手工資訊。
- **公開展示**：控制是否出現在心跳廣場與搜尋，不等同於停用心跳服務。
- **上報間隔**：180–480 秒，預設 240 秒；上線時立即上報，之後週期保活。
- **離線狀態**：正常退出會補報離線；崩潰或斷網由服務端超時判定。

## 雲黑名單

配置同步開關、服務地址、獨立 Token、本地拉黑自動上報、最低危險等級及同步週期；可檢視最近結果並立即同步。

獨立 Token 留空時相容舊心跳 Token，再回退到已配置的適配器骰娘 Key，不要求為了雲黑先開啟公開心跳展示。

- 上報記錄先等待雲端核驗，通過後才參與下發。
- 達到危險等級門檻的有效記錄併入本地黑名單，並顯示雲黑標記。
- 雲端登出只解除對應的雲黑來源記錄，不刪除骰主獨立新增的本地黑名單。

[許可權設定](/zh-hant/manage/permissions#雲黑名單)保留本地黑名單管理和雲黑標記，雲端連線與同步設定在本頁管理。

## 雲人物卡

骰主配置正式骰娘 Key 後，玩家在**私聊骰娘**中使用 `.cloud auth` 授權；預設只讀，寫入需使用 `.cloud auth write` 並在賬號中心確認。

後臺不代替玩家授權，不展示玩家令牌。拉取、上傳、同步與退出授權均由玩家使用 `.cloud` 指令完成，詳見[雲服務與身份繫結](/zh-hant/use/cloud)。

目前為手動同步：本地卡仍是跑團時使用的資料，令牌過期或骰子重啟後需重新授權；衝突不會強制覆蓋雙方內容。

## 日誌站

配置 `.log end` / `.log get` 上傳日誌的目標地址與協議，並可恢復預設配置。

預設官方地址為 `log-api.dice.zone`，預設協議為 DiceNext 專屬 zstd JSON（`dicenext`）。也可選擇 SealDice V1（`seal`，zlib JSON）、SealDice V105（Parquet）或舊版多段 txt 協議（`legacy`）；請與目標站點支援的協議對應。已有安裝保留已儲存的協議選擇。

非官方地址會顯示第三方站點提示。配置前請確認服務可信，上傳會將跑團記錄傳送到所選站點。具體用法見[跑團記錄](/zh-hant/use/log)。

## 其他設定在哪裡

- 圖床、圖片傳送與日誌圖片儲存仍在[基礎設定](/zh-hant/manage/settings#圖片相關)，支援原有配置作用域。
- 通知視窗及推送在[通知設定](/zh-hant/manage/notice)，人工智能與程式更新仍有各自入口。
- 舊的 `#/settings?tab=cloud` 等後臺連結仍相容跳轉；也可在頂欄搜尋「雲服務」「心跳」「雲人物卡」直接進入相關卡片。
