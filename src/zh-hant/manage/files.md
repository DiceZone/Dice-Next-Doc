# 檔案管理與圖片資源

入口：**資料管理 → 檔案管理 → 圖片資源**。

檔案列表只顯示名稱、路徑、大小、修改時間，不載入縮圖。需要看圖時點選「預覽」；「複製圖片程式碼」可直接用於回覆、擲骰文本、牌堆等位置。

## 圖片放在哪裡

統一儲存在本實例的 `data/images/`：

| 目錄 | 用途 |
| --- | --- |
| `reply/` | 自訂回覆 |
| `text/` | 擲骰文本、人格文案 |
| `deck/<牌堆文件名>/` | 該牌堆的圖片，完整檔名含 `.json`，保留內部子目錄 |
| `plugin/<插件名>/`、`mod/<模组名>/` | 按所屬插件或模組集中存放 |
| `chat/` | 主動上傳的聊天圖片、收藏表情 |
| `shared/` | 通用圖片 |
| `cache/chat/`、`cache/log/` | 有獨立清理規則的聊天 / 跑團日誌快取 |

可以新建自己的資料夾。目錄只表示歸屬，不限制使用位置，不會為全域性去重把一個牌堆或插件的圖片拆散到其他目錄。

## 常用操作

- 支援搜尋、排序和服務端分頁，預設每頁 20 項。
- 批次選擇後可以複製、剪下、刪除或下載 ZIP；進入目標目錄後貼上，同名覆蓋需要確認。
- 行內提供預覽、複製圖片程式碼；「更多」提供路徑複製、下載、引用查詢和重新命名等操作。
- 圖片 ZIP 可以批次匯入並保留子目錄，只接收圖片，不執行包內指令碼。
- 回覆、擲骰文本、牌堆、插件模板設定和模擬聊天共用圖片選擇器，可上傳新圖片，也可直接引用已有資源。

移動或重新命名會更新已識別引用，舊圖片碼和舊連結也保留相容。仍被引用的圖片不能刪除；先替換引用，再移入回收站，需要時可恢復。永久刪除不可撤銷，請謹慎操作。

::: warning 動態路徑不能完全靜態識別
插件可能自行拼接路徑、讀取外部資料庫或列舉私有目錄。未發現引用不代表一定沒有使用，建議先回收觀察，不要直接永久刪除。原始碼不會為了遷移圖片被自動改寫。
:::

## 遷移與備份

啟動後會後臺整理舊 Next 圖片目錄；發生問題時保留原始檔並顯示遷移提醒。舊 Dice! 匯入對源骰子只讀：在 Next 中複製牌堆圖片並調整 Next 的引用，不修改舊檔案。

私有插件 / 模組資源按名稱歸檔。已登記圖片的 Lua 檔案讀寫可通過路徑別名繼續使用；不能證明可刪除的舊私有路徑保留相容副本，避免破壞動態呼叫。

備份會儲存所選圖片和路徑索引；區域性恢復合併索引，不丟失未選擇圖片的連結。聊天快取和日誌快取仍按原保留期 / 刪除規則清理，不會清理回覆、牌堆等永久資源。

管理和預覽需要面板登入或 API Key。普通預覽不會公開圖片；配置 HTTP 傳送後，永久資源可生成隨機 token 連結，快取不通過資源分享入口公開。

牌堆連同圖片遷移到其他骰子，見 [`.deck` 牌堆包](/zh-hant/use/deck#deck-牌堆包)。
