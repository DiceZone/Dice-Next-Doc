# 規則管理

**管理面板 → 擴展管理 → 規則**，管理可匯入的規則包（屬性別名 / 衍生公式 / 速查手冊 / 自訂指令），群內用 `.set <规则>` 切換啟用。

## 規則包列表

每條規則包顯示名稱、版本、作者、`.set` 切換關鍵字、預設骰面，以及別名 / 衍生公式 / 速查詞條 / 幫助數量統計；帶自訂指令、指令別名或停用指令的還會列出對應指令徽章。

| 操作 | 說明 |
|------|------|
| 啟用 / 停用 | 開關單個規則包 |
| 線上編輯 | 開啟視覺化規則編輯器（見下） |
| 匯出 | 下載規則 JSON 檔案 |
| 刪除 | 移除規則包（內建規則不可刪） |

列表支援分頁（每頁條數可選）。內建規則（如 COC7、DND 等）標「內建」，匯入的標「已匯入」。

## 匯入

- **匯入規則檔案**：單個規則 JSON。
- **匯入規則包(zip)**：一個 zip 打包規則 + 幫助文件 + Lua/JS 插件（`pack.json` 清單宣告），群內 `.set` 啟用後整套生效。規則包區會單獨展示每個包的規則 / 指令 / 幫助 / 插件統計，可整包啟停或刪除（刪除會移除整個包目錄）。

規則包的編寫與分發格式見[規則包編寫](/zh-hant/develop/rulepack)與[實戰：轉化海豹規則插件](/zh-hant/develop/rulepack-example-fu)。

## 相容規則

以插件形式提供的規則系統也會彙總顯示在本頁，可直接啟停：

- **JS 相容規則**：海豹 SealDice JS 插件（`seal.gameSystem` / `coc.registerRule`），列出其註冊的指令。
- **Lua 相容規則**：原版 Dice! Lua mod（含 `model/*.xml` 屬性模板，如 COC7-TRPG / DND-5E）。

上傳 / 刪除 / 配置這類插件請到[插件管理](/zh-hant/manage/plugins)頁。

## 視覺化規則編輯器

點「新建規則」或某個規則包的「線上編輯」進入編輯器，支援**表單模式**與**原始碼模式**（直接編輯 JSON）隨時切換：

| 區塊 | 內容 |
|------|------|
| 基本資訊 | 名稱（英文，作檔名）、顯示名稱、版本、作者、預設骰面、`.set` 切換關鍵字 |
| 成功等級 | 檢定成功等級判定（內建 / 自訂 / 不使用） |
| 屬性別名 | 規範名 + 別名列表（`.st` 錄卡時同義詞歸一） |
| 衍生公式 | 屬性 + 公式（如閃避＝敏捷/2） |
| 預設值 | 屬性預設數值 |
| 速查詞條 | `.rules` 規則速查的詞條與解釋 |
| 指令別名 | 輸入詞 → 目標指令 |
| 自訂指令 | 指令名 + 輸出模板（`{表达式}` 求值替換，支援擲骰 / 取卡值 / 條件三元等）+ 幫助文字 |
| 停用的指令 | 本規則啟用時遮蔽的內建指令 |

編輯器底部有**即時測試**：以當前編輯內容直接試跑指令（可注入測試屬性），不需儲存。

測試使用編輯器當前的未儲存 JSON 草稿，覆蓋規則自訂指令、別名與遮蔽；不寫入已安裝規則、不切換真實群的啟用規則，也不是向真實群傳送訊息。語法或渲染失敗會直接展示錯誤，不再只測試已儲存版本而忽略草稿。
