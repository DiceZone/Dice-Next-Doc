# 指令測試

**管理面板 → 指令測試**，一個聊天式測試臺：不用開啟 QQ / Discord，直接在網頁裡發訊息試指令、看骰娘怎麼回。

## 使用方法

頂部先選好環境，然後像聊天一樣輸入指令（也可點快捷按鈕 `.r`、`.ra 侦查 60`、`.coc` 等）：

| 選項 | 說明 |
|------|------|
| 場景 | 群聊 / 私聊 |
| 平臺 | QQ (OneBot v11) / Discord |
| 回覆語言 | 跟隨介面語言（預設，切換面板語言後同步）/ 預設(跟隨平臺) / 簡體中文 / 繁體中文 / English / 日本語 |
| 暱稱 | 模擬傳送者的暱稱（預設「測試員」） |

## 和真實訊息完全同管線

測試臺複用指令與回覆處理鏈，但不是平臺真實訊息投遞和渲染器；網頁顯示正常不代表 QQ 官方 / Discord / KOOK 的實際載荷、許可權與附件傳送已驗收。主要處理環節包括：

1. 內建指令
2. JS 插件
3. Lua 模組
4. 自訂回覆
5. AI 對話 / NPC（開啟時；注入群摘要與長期記憶，便於預覽）

最後同樣經過 AI 潤色與 AI 翻譯（開啟時），方便在配置 AI 後直接預覽效果。指令沒匹配到任何處理器時會顯示「無回應」提示。

## 不影響真實資料

測試訊息使用虛擬身份（使用者 `10001`、群 `100001`），不會發到任何真實群，也不會消耗觸發式廣播（那隻在真實群訊息上生效）；`.st` 等指令寫入的資料都記在這個虛擬身份名下。

::: tip
測試臺是排查問題的第一站：改了自訂回覆、裝了新插件、調了 AI 配置，先來這裡發一條試試，再到真實群驗證。
:::
