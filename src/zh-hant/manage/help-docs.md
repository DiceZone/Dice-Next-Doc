# 幫助文件

**管理面板 → 幫助文件**，彙總所有 `.help` 幫助條目，可搜尋、編輯與管理。

## 幫助來源

幫助系統是統一登錄檔，條目來自多個來源，頁面用標籤區分：

| 來源 | 說明 | 可否編輯 |
|------|------|----------|
| 內建 | 隨程式內建的指令幫助（i18n 文案） | 可編輯，可一鍵「還原為預設」 |
| 自訂幫助詞條 | 歷史指令新增或從舊版 `CustomHelp.json` 匯入的 `help.topic.*` 詞條 | 可編輯、可刪除 |
| 規則包 · 名稱 | 隨規則包分發的幫助 | 只讀（要改請編輯規則包） |
| 插件 · 名稱 / Lua模組 · 名稱 | 隨 JS 插件 / Lua 模組分發的幫助詞條 | 只讀（要改請編輯插件） |
| 文件包 · 名稱 | `data/helpdoc/` 等目錄裡的結構化幫助包，可能隨程式分發，也可能由骰主新增 | 只讀 |
| 自訂文件 | 骰主自建的幫助（存於 `data/help/*.md`） | 可編輯、可刪除 |

修改過的內建幫助仍屬於「內建」，額外標註「已自訂」，不會被誤認為使用者新建文件。規則包與插件的幫助**隨包分發**——裝包即得幫助，解除安裝即消失。

歷史自訂詞條不需要重新匯入，也不會被強制轉成檔案：原始內容、語言與純文本 / Markdown 格式繼續儲存在原來的文本覆蓋層。舊資料沒有可靠記錄“由指令建立還是由遷移匯入”，頁面統一歸為使用者自訂，不猜測來源。

## 瀏覽與搜尋

- 預設左側幫助檔案庫、右側當前條目；可先按「使用者自訂 / 內建幫助 / 插件 / 規則包 / 幫助文件包 / 其他來源」篩選，再選擇具體插件、包或檔案，並搜尋主題名或內容。
- 篩選、計數和分頁在服務端對完整目錄執行，不限於當前頁。插件類同時包含 JS 和 Lua；規則包附帶的幫助文件仍歸入規則包，保留原來的文件來源名。
- 分欄分頁提供頁碼按鈕及直接輸入跳頁，固定為兩行，避免偶爾多出不規則換行。
- 自建空文件、被同名條目遮蔽的檔案仍出現在管理列表，並顯示相應提示；這不改變聊天側同名詞條優先順序。

## 視覺化編輯

選中左側條目後，在右側點「編輯」開啟彈窗；「新增文件」建立自訂幫助檔案（填名稱 + 內容），儲存後群裡立刻可用 `.help <名称>` 查詢。歷史幫助詞條也可直接編輯、刪除；內建幫助可修改並恢復預設。

文本詞條顯示實際內容語言，編輯與刪除針對該語言，保留其他語言內容；某語言沒有詞條時會按骰子配置回退。格式選擇保留純文本 / Markdown 的顯式語義，不在瀏覽時抽取 `{sample:甲|乙}`。未儲存時離開會提示確認。

獨立自訂幫助不再顯示為「指令列表 → 全部文本」中的未歸類文案；該處提供幫助文件入口。與指令關聯的用法文本以及人格層的文本編輯仍保留。

## 匯入 / 匯出

- **匯出**：下載帶 `kind: "dicenext.help"`、`version: 1` 的 JSON，分別儲存自訂檔案與全部語言的幫助文本覆蓋（包括歷史詞條、內建幫助修改、格式和機率候選）。同名檔案與文本詞條分開儲存，不相互覆蓋；不包含插件、規則包或人格內容，後者請用對應的備份入口。
- **匯入**：支援上述新版備份，繼續相容舊 `.json`（`{名称: 内容}` 物件或含 `name` / `content` 的陣列）與單個 `.md` / `.txt`（檔名即條目名）。先校驗整份輸入，拒絕非法名稱和同一語言的重複詞條；覆蓋現有內容需確認，網路錯誤造成部分成功時會報告結果而不是假裝全部成功。

## 聊天側指令

2026-10-19 補齊舊幫助別名：把條目正文寫為 `&目标主题`，查詢時轉向目標；支援多級、忽略 ASCII 大小寫。指令新增或舊版匯入的文本詞條、自訂檔案和文件包使用同一解析規則；保留當前語言、規則優先來源及搜尋域，不靠別名越過範圍限制。迴圈超過 16 層或目標缺失會提示，列表與匯出仍儲存原始別名，不提前固化為正文。

群裡用 `.help <条目>` 查詢幫助；`.helpdoc scope <来源>` 可把本群搜尋域鎖定到某來源（如只查某規則包），`.helpdoc default <来源>` 設定同名詞條的優先來源（例如讓 dnd5r 壓過 dnd3r），詳見[管理指令](/zh-hant/use/admin)。

::: tip
幫助條目很多時，聊天裡 `.help` 只做精確 / 模糊查詢；想通覽全部條目請用本頁瀏覽與搜尋。
:::
