# 玩家管理

**管理面板 → 資料管理 → 玩家管理**，檢視所有與骰子互動過的玩家檔案。

## 檔案來源

玩家檔案在首次與骰子互動時**自動建立**，無需手動新增。

## 列表內容

| 列 | 說明 |
|----|------|
| 暱稱 | 最近一次顯示名（含 QQ 頭像），點選進入詳情頁 |
| QQ 號 | 平臺賬號 |
| 信任等級 | 下拉直接調整（見下） |
| 好感度 | 當前好感值，行內直接編輯 |
| 指令數 | 累計觸發指令次數 |
| 上次指令 | 最近一次使用時間 |

預設左側玩家列表、右側選中玩家詳情，原表格頁不再作為獨立顯示模式。工具欄可按暱稱、賬號、信任、好感、指令次數和上次指令時間排序，並切換升 / 降序；預設按信任等級排列。支援平臺篩選、搜尋及點選 / 輸入頁碼跳轉。

## 信任等級

下拉可選：普通（0）、信任 1~3 級、管理員（4）、**骰主**。

- 0＝普通；1~3＝信任層（可遠端管理群設定）；4＝管理員（可用 `.trust` / `.admin` 與全域性操作）；骰主＝最高許可權。
- 選「骰主」即把該賬號加入 Master 名單（與[系統設定](/zh-hant/manage/settings)的 Master 卡片同步）；從骰主切到其他等級則移出名單。
- 聊天裡對應指令為 `.trust <QQ> <等级>` / `.admin add`；從舊版匯入的 5 級以上信任值也會正常顯示。
- 信任等級影響指令許可權（如全域性停用的指令對信任 4+ 無效）。

## 操作

- **搜尋**：按暱稱 / QQ 過濾。
- **編輯信任 / 好感**：在選中玩家的詳情區域修改。
- **刪除記錄**：移除某玩家的檔案。
- **刪除好友**：經適配器解除好友關係（雙方並非好友時不可用）。

## 玩家詳情頁

點選左側玩家，在右側按選項卡展示該玩家的資料；儲存、刪除及好友操作都針對當前選擇，切換玩家、篩選條件或離開頁面前會提示未儲存的修改：

| 分割槽 | 內容 |
|------|------|
| 個人資訊 | 暱稱、信任、好感和該玩家出現過的群 |
| 人物卡 | 全部人物卡與屬性；標註預設卡與各群繫結關係；可**複製 .st**（一鍵生成錄卡指令）、逐項修改屬性、刪除人物卡 |
| 設定鍵值 | 該玩家的各項設定（全域性 / 分群） |
| 插件資料 | Lua 模組儲存的玩家變數與卡片資料 |
| 模擬聊天 | 檢視該玩家的私聊記錄併發送訊息 |

支援集中儲存的修改在頁面編輯後點**「儲存全部修改」**提交（會提示成功 / 失敗條數）；個別即時操作按按鈕提示執行。列表仍保留在左側，無需返回上一級頁面才能選擇另一名玩家。

## QQ 官方使用者頭像

列表、卡片與詳情統一使用平臺返回並快取的頭像；沒有頭像欄位時，根據繫結的 AppID 和使用者 OpenID 生成 QQ 應用頭像地址。不同 AppID 的快取隔離，重啟後保留。地址失效時顯示使用者圖示，不把 OpenID 當作 QQ 號，也不通過頭像判斷使用者身份。
