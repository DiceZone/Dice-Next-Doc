# 群組管理

**管理面板 → 資料管理 → 群組管理**，以「列表 + 詳情」方式管理骰子所在的每個群。

## 群列表

- **活躍群組 / 已退群** 兩個選項卡；預設左側列表、右側詳情，顯示方式按鈕仍可切換卡片 / 表格。支援搜尋（群名 / 群號 / 備註）和按適配器賬號篩選。
- 分欄列表的分頁可點選頁碼或輸入頁碼跳轉；窄屏按可用空間排列，不通過擠壓右側功能內容來保留完整橫向佈局。
- 群記錄在機器人加群或使用過 `.bot` / `.group` 後自動出現，也可手動輸入群號新增。
- 顯示群名、群號、備註標籤、骰子在群內的許可權（群主 / 管理員 / 成員）。
- **最後指令**：列表、卡片、表格及詳情均顯示最近一次實際處理指令的時間，不把普通聊天或自訂回覆計入。全部適配器檢視彙總群內賬號，篩選賬號後只顯示該賬號的記錄；支援按最近使用或較久未使用排序。
- 舊記錄只有日期時會標明「僅保留日期」，沒有記錄顯示「暫無指令記錄」，不會把升級或開啟頁面的時間當作歷史指令時間。精確時間按瀏覽器本地時區顯示。
- **啟用 / 關閉**：等同於遠端 `.bot on/off`。
- **徹底停用 / 解除停用**：完全靜默某群（比 `.bot off` 更強，群內任何人都無法再啟用，只能從本頁面恢復）。

在分欄檢視中，這些操作放在選中群的右側詳情區；先核對「適配器賬號」再修改。按賬號篩選時使用篩選中的賬號，而不是誤改同群另一個主賬號；已退群、徹底停用等狀態會限制相應操作。

### 手動批次退群

點選「批次退群」進入選擇模式，逐個勾選或「選擇本頁」，可跨頁最多選擇 100 個群。修改搜尋、賬號篩選或「活躍群組 / 已退群」選項卡會清空選擇，不會根據最後指令時間自動勾選。

多賬號群須先篩選具體骰娘賬號；離線、已退群或適配器不支援退群的賬號不可勾選。目前支援 OneBot V11、Milky，QQ 官方等未提供退群能力的平臺不會顯示為可操作物件。

確認視窗會列出群名、群號和實際操作的骰娘賬號。預設保留群管理記錄，也可勾選「同時清理群管理記錄」；退群與清理通過同一後臺請求處理，不會退出或清理同群其他骰娘賬號。人物卡及跑團日誌始終保留。部分失敗會單獨列出並保留勾選，便於核對後重試；請求受理不代表平臺已完成退群。

### 批次清理已退群記錄

切換到「已退群」，點選「批次清理記錄」，逐項勾選或「選擇本頁」，核對群號和骰娘賬號後確認。可跨頁最多選擇 100 項；離線賬號也能清理，不要求適配器支援退群。多賬號群仍須先篩選具體賬號，不能猜測要清理哪一隻骰娘。

此操作只清理所選賬號的群管理設定，不會再次傳送退群請求，不刪除人物卡、跑團日誌或同群其他賬號的資料。後臺會在清理時再次檢查退群狀態，已經重新入群的賬號會拒絕清理；失敗項保留勾選，可重新整理核對後重試。

明確退群后，平臺殘留的群列表快取、在途訊息及延遲退群事件不會重建已清理記錄；重啟程式或等待十分鐘也不會使其自動出現。真正重新入群后，記錄才會按該賬號恢復。單獨移除仍在群內的記錄不等於退群，後續真實群訊息仍可重新建立記錄。

## 詳情選項卡

| 選項卡 | 功能 |
|--------|------|
| 功能管理 | 群名片 / 備註 / 邀請人 / 回覆語言 / 歡迎詞 / 發訊息 / 退群 |
| 人工智能 | 本群 AI 開關與群記憶管理 |
| 插件 | 為本群單獨啟停插件 / 模組 |
| 人員管理 | 成員列表與禁言 / 踢出等群管操作 |
| 日誌管理 | 跑團記錄的匯出 / 上傳 / 刪除 |
| 群檔案 | 檢視、下載、上傳群檔案 |
| 模擬聊天 | 即時檢視群訊息並直接發言 |

### 功能管理

- **日誌 / 回覆 / 投擲 / 插件**：四類獨立開關，分別對應 `.bot log`、`.bot reply`、`.bot roll`、`.bot plugin` 的 `on/off` 操作。按當前骰娘賬號與群儲存，不影響同群其他賬號。
- **開關關係**：子開關不能繞過總開關或徹底停用。關閉總開關或日誌開關會停止記錄與計時，正在記錄時會提示暫停，但不刪除日誌、不結束會話；重新開啟後，原本進行中的日誌恢復，手動 `.log off` 暫停的日誌仍需 `.log on`。
- **只記日誌**：保持總開關和日誌開啟，關閉回覆、投擲、插件；如啟用了 AI、歡迎語、自動化或轉發，也需按用途單獨關閉。完整操作見[跑團記錄](/zh-hant/use/log#只記日誌)。這不是將所有非日誌行為一律靜默的專用模式。
- **骰娘群名片**：機器人在本群顯示的群名片（未設定時使用 QQ 暱稱）。
- **群備註**：僅後臺可見的備註標籤。
- **群邀請人**：記錄邀請骰娘入群的人，許可權視同群管理員。
- **本群回覆語言**：設定後本群回覆使用該語言（等同群內 `.lang`）。
- **入群歡迎設定**：本群的歡迎詞（支援 `@提及` / QQ 號 / 暱稱變數）、傳送延遲與冷卻（秒）。實際值不會低於[系統設定](/zh-hant/manage/settings)裡的全域性最低延遲 / 冷卻，防止連續進群刷屏。
- **群操作**：發訊息、退群（可選「退群並移除記錄」或「僅退群，保留記錄」）、移除記錄（僅刪後臺記錄，不退群）。

### 人工智能

- **本群 AI 功能**開關：關閉後本群不再觸發骰娘 AI 對話 / NPC，也不建立群記憶（需先在「人工智能」頁開啟全域性開關；群內也可用 `.ai on/off`，需群管）。
- **本群記憶**：檢視 / 清空本群的 AI 記憶（摘要 + 事實）；記憶隨對話滾動生成。

詳見 [AI 功能](/zh-hant/manage/ai)。

### 插件

為本群單獨啟停插件（Lua 模組 / JS 插件）。關閉後該插件的指令在本群不響應，不影響其它群與全域性設定。

### 人員管理

拉取成員列表與角色；管理員可禁言 / 解禁 / 踢出 / 改名片，群主可設專屬頭銜。支援按暱稱 / 名片 / QQ 搜尋。

::: tip 許可權提示
執行禁言 / 踢人等操作需要骰子在該群擁有管理員許可權；若骰子只是普通成員，面板會提示許可權不足。
:::

::: tip 群自動化（指令配置）
骰子有群管理許可權時，群管可在群內用 `.group auto pass 关键字`（加群驗證訊息含關鍵字自動通過，`all`＝全過）、`.group auto kick 关键字` / `.group auto mute 关键字 [分钟]`（發言含關鍵字自動踢出 / 禁言，豁免骰主、群管、信任使用者與邀請人）配置本群自動化；`.group auto` 檢視，關鍵字留空＝關閉。
:::

### 日誌管理

檢視該群的跑團記錄（名稱 / 建立人 / 開始時間 / 上次記錄 / 條數）：

- **匯出**：TXT / Excel / 網頁（HTML，開啟「儲存日誌圖片」後圖片內嵌顯示）。
- **上傳**：上傳到日誌站並自動複製分享連結。日誌站地址與上傳協議在[系統設定 → 雲服務 → 日誌站](/zh-hant/manage/cloud-services#日誌站)配置。
- **刪除**：刪除日誌（同時清理其本地快取圖片）。

### 群檔案

- 瀏覽群檔案與資料夾（名稱 / 大小 / 上傳者 / 上傳時間）。
- **下載**：優先直連 QQ 直鏈下載，保留真實檔名。
- **上傳**：上傳檔案到群（上限 30MB），QQ 處理後自動出現在列表。
- 需要已連線的 NapCat / go-cqhttp 適配器。

### 模擬聊天

即時檢視該群訊息並直接傳送，無需切到 QQ：

- 訊息帶**頭像**與傳送者名稱（有群名片顯示群名片，骰娘顯示自己設定的名稱）。
- 支援傳送**文字、圖片、表情包**（上傳圖片儲存為本地表情包，點選即發）與**戳一戳**。
- 撤回的訊息標註「已撤回」；引用訊息以氣泡樣式顯示；檔案訊息可直接下載。
- 「拉取歷史訊息(NapCat)」可回填歷史記錄；向上翻閱時不會被新訊息打斷，一鍵「回到最新訊息」。
- 聊天記錄持久化儲存在 `chat.db`，保留天數在[系統設定 → 聊天記錄保留期](/zh-hant/manage/settings)配置。
