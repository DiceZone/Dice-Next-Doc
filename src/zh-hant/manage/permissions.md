# 許可權設定

**管理面板 → 資料管理 → 許可權設定**，管理使用者信任等級、白名單群、骰娘識別與黑名單，分三個選項卡。

## 信任等級階梯

DiceNext 移植了原版 Dice! 的 nTrust 信任體系，所有許可權門控都基於它：

| 等級 | 含義 |
|------|------|
| 0 | 普通使用者 |
| 1–3 | 信任層（受信任物件，可遠端管理群設定） |
| 4 | 管理員（可用 `.trust` / `.admin` / 全域性操作，不受全域性指令停用限制） |
| 255 | 骰娘自身（內部保留值） |
| 256 | 骰主 Master（最高許可權） |

聊天側對應指令：`.trust <@某人/QQ号> [等级0-255]`（省略等級則查詢；管理員≥4 可用，只能設低於自己的等級）、`.admin add/del <@某人/QQ号>` 與 `.admin list`（僅骰主），詳見[管理指令](/zh-hant/use/admin)。

## 許可權管理

### 使用者信任等級

列表只顯示有許可權的使用者（信任等級 > 0 或骰主），帶 QQ 頭像、支援搜尋與分頁（預設每頁 20，可調）。每行的下拉框直接切換等級：普通 / 信任 1–3 級 / 管理員 / **骰主**——「骰主」也是可選等級之一，選中即加入骰主名單，切到其他等級即移出。

「新增許可權」彈窗按**搜尋新增**式操作：先選平臺（QQ；Discord 暫不可選），輸入 QQ 號或搜尋已有使用者，再選許可權等級。使用者使用過指令後會自動建檔，即可被搜到。

### 白名單群

使用者無需白名單——達到信任等級即視為受信任；只有**群**需要單獨加白名單。填群號（可附原因）新增。

**僅白名單模式**開關：開啟後，只有白名單內的群才會響應，其餘群一律忽略。

## 骰娘名單

識別群內的其它骰子，避免互相觸發：

- **自動識別**：通過各骰系 `.bot` 固定格式回執自動登記（支援 Dice! / Dice!Next / OlivaDice / SealDice），記錄 QQ 號、骰系與識別時間。
- **手動登記**：填 QQ 號與骰系名稱新增。
- **@靜默**：使用者「@其它骰娘 + 指令」時，本骰保持靜默，不會當作代骰執行。

## 黑名單

黑名單內的使用者 / 群不響應任何指令（黑名單群還會自動退群，見通知事件「黑名單自動退群」）。

- 「新增黑名單」彈窗：選平臺、目標型別（使用者 / 群）、輸入 ID（可從已有玩家 / 群列表搜尋聯想）、備註原因。
- 列表帶頭像、目標型別標籤、原因與新增時間，支援按 QQ / 群號 / 原因搜尋和分頁。

::: tip 舊版資料遷移
原版 Dice! 的 `BlackList.json` 可通過「系統設定 → 匯入舊版資料」一鍵遷入，詳見[資料遷移](/zh-hant/guide/migration)。
:::

## 雲黑名單

雲黑名單的開關、服務地址、Token、自動上報、危險等級與同步週期已集中到[系統設定 → 雲服務](/zh-hant/manage/cloud-services#雲黑名單)。本頁保留本地黑名單管理、雲黑來源標記和前往雲服務的入口。

雲端記錄經核驗生效且達到危險等級門檻後併入本地黑名單；雲端登出只解除對應的雲黑來源記錄，不刪除骰主獨立新增的本地條目。被拉黑的使用者可到 [雲黑名單站](https://cloudban.dice.zone) 登入後提交申訴。
