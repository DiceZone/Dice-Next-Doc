# 卡片與按鈕

**管理面板 → 高階回覆 → 卡片與按鈕**，按 QQ 官方機器人賬號編輯選單和指令面板。此頁目前面向 QQ 官方平臺，不是其他適配器的通用卡片編輯器。

- **全域性選單**：編輯訊息入口、HTTPS 連結、二級選單和開關，支援條目排序與佈局預覽；釋出會覆蓋該賬號的完整單聊選單。
- **指令面板**：按單聊、群聊、文字子頻道與頻道私信篩選，建立或編輯指令和連結條目，設定管理員限制、備註及關聯物件。

賬號選擇、前端驗證、釋出確認與草稿保護均在此頁完成。原自訂回覆、因果規則和計數器仍位於同級的「自訂回覆」頁面，不會遷移或清空已有規則。

許可權要求、平臺上限和關聯操作見 [QQ 官方 API v2 能力](/zh-hant/develop/qq-official-api#視覺化編輯)。
