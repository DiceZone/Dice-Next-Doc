# 定時任務

**管理面板 → 系統設定 → 定時任務**，設定每日定時向群 / 私聊推送訊息（早安問候、跑團提醒、活動公告），也能加**觸發條件**、**插件指令**與**退群動作**做「因果」式自動化（如定時呼叫 DailyNews，或「7 天沒人用就退群」）。

## 新建任務

主頁面預設顯示搜尋框、「新增」按鈕及已有任務列表。點選「新增」開啟配置彈窗，編輯任務也在彈窗中完成，不再把整套表單長期佔在列表上方。

| 欄位 | 說明 |
|------|------|
| 名稱 | 任務備註名 |
| 時刻 | 每日觸發時間（時:分） |
| 目標型別 | 群 / 私聊 |
| 目標號碼 | 群號 / QQ 號 |
| 星期 | 多選週一~週日；不選 = 每天 |
| 動作 | **傳送訊息** / **執行插件指令** / **退群** |
| 觸發條件 | 留空 = 無條件按時觸發；填 `inactive>=7` 表示本群 ≥7 天無指令才觸發。支援 `>=` `>` `<=` `<` `==` |
| 內容 / 插件指令 / 告別語 | 傳送動作填推送文本；插件動作填完整觸發指令；退群動作可填退群前的告別語 |

內容支援變數與函式渲染：`{self}`、`{group}`、`{date}`、`{roll:1d100}`（投骰）、`{draw:牌堆}`（抽牌堆）等。

::: tip 因果示例：不活躍自動退群
動作選「退群」、條件填 `inactive>=7`，即「到點檢查，本群 7 天以上沒人用指令就發告別語並退群」；群裡有人用過指令則當天跳過。
:::

## 執行插件指令

動作選擇「執行插件指令」後，內容填寫插件平時在聊天中接收的完整指令，例如：

```text
.dailynews
.专长 星质形 ASTRAL_AQUAN
求签 月老
```

任務到點後會在所選帳號和群 / 私聊上下文中呼叫已啟用的 **SealDice JS 插件或 Dice! Lua 插件**，並把插件返回內容傳送到目標。也支援「立即執行」測試。

該動作使用專門的低許可權虛擬訊息，只進入 JS / Lua 插件指令層，不會執行 `.admin` 等 Dice!Next 內建管理指令。插件在目標群被單獨停用時同樣不會執行。

### 從聊天中新增本群任務

骰主也可以直接在目標群或私聊中建立插件指令定時任務：

```text
.admin clock + 本群早报 07:30 .dailynews
.admin clock + 本群求签 08:00 求签 月老
.admin clock list
.admin clock - 本群早报
```

命令建立的任務會記錄當前骰娘帳號、平臺和群 / 私聊目標，並立即出現在管理面板的定時任務列表中；它與網頁新建的「執行插件指令」任務相同，可以編輯時間、星期、觸發方式、目標和指令，也可以啟停、立即執行或刪除。同一視窗使用相同名稱再次新增會更新原任務，不會重複建立。

也支援原版緊湊寫法，例如 `.admin clock+本群早报=7:30 .dailynews`。只有骰主能通過 `.admin clock` 新增或刪除任務；定時執行時仍使用低許可權插件上下文。

## 行為

- 到達設定時刻、當天尚未觸發、星期匹配、且觸發條件滿足時，自動執行一次。
- **單點推送，不群發**——只作用於你指定的目標，避免刷屏 / 封號風險。

## 管理

- 列表中可隨時用開關**啟用 / 停用**任務，或**刪除**。
- 點編輯圖示可**編輯**已有任務（表單回填，改完儲存）。
- 勾選多條任務後可**批次啟用 / 停用 / 刪除**。批次刪除需確認；操作逐條執行，部分失敗時保留失敗項供重試，不宣稱全部成功。舊 Lua 插件任務可用的操作仍受其任務型別限制。

## 舊 Dice! Lua 插件定時任務

單檔案 Lua 插件通過 `task_call['任务名'] = '全局函数名'` 登記定時入口後，骰主可直接在聊天中配置：

```text
.admin clock + 任务名 07:30
.admin clock list
.admin clock - 任务名
```

這類任務也會顯示在本頁列表中，動作標記為「Lua 插件任務」；可停用、立即執行或刪除。`7:30` 與 `07:30` 兩種時間寫法都可用。任務的傳送目標由插件函式內部的 `sendMsg` 決定，因此不提供普通任務的目標與內容編輯表單。只有骰主可以執行 `.admin clock`。

DailyNews 等舊插件使用的 `.admin notice group/QQ … +8` 訂閱與 `.send notice 8 …` 推送會自動接入本專案的統一通知視窗，不需要逐個修改插件原始碼。

::: tip 定時上下班
想要「上班問候 + 晚安」？建兩條任務即可（例如 09:00 一條、23:00 一條）。
:::
