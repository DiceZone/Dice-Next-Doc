# 規則包編寫指南

規則包（Rule Pack）是 Dice!Next 把**規則、幫助文件、插件**打包成一個**可整體安裝 / 啟停 / 刪除**的單元。骰主在後臺上傳一個 zip，玩家在群裡用 `.set` 啟用，整套規則就在這個群生效。

> 一句話：**一個 zip = 一個資料夾 + 一份 `pack.json` 清單 + 按目錄擺放的資源**。約定優於配置——你只要把檔案放進對應子目錄，系統自動發現，不用手寫檔案清單。

---

## 一、目錄結構

```
我的规则包/
├── pack.json          ← 必需：包的元数据（名字 / 版本 / 作者 / 激活键）
├── rules/             ← 规则文件（属性别名 / 默认骰 / 自定义指令 / 帮助）
│   └── xxx.json
├── helpdoc/           ← 帮助速查（词条→内容，可被 .help 查询）
│   └── xxx.json
├── lua/               ← Lua 插件（原版 Dice! mod，目录或单文件）
│   ├── 某模块/
│   └── 某单文件.lua
└── js/                ← JS 插件（兼容海豹 SealDice）
    └── 某插件.js
```

所有子目錄都是**可選**的——你可以只放 `rules/`（純宣告式規則），也可以只放 `lua/`（純插件規則），或任意組合。把整個資料夾打成 **zip** 即可分發。

::: tip 整體裝卸
刪除/停用一個包 = 刪除/改名這個資料夾（後臺一鍵完成）。包內所有資源隨之註冊或登出，不會有殘留。
:::

## 二、`pack.json`（清單）

只放後設資料，**不用**逐個列出檔案：

```json
{
  "name": "我的克苏鲁扩展",
  "id": "my-coc-extension",
  "version": "1.0.0",
  "author": "张三 (QQ:12345678)",
  "description": "一句话简介，会显示在规则页卡片上",
  "setKeys": ["mycoc"]
}
```

| 欄位 | 說明 |
| --- | --- |
| `name` | 包的顯示名稱 |
| `id` | 可選的穩定目錄標識，只能使用安全的檔名字元；省略時取 zip 檔名或唯一根目錄名 |
| `version` | 版本號，如 `1.0.0` |
| `author` | **作者**。轉化他人作品時**務必保留原作者** |
| `description` | 簡介 |
| `setKeys` | 啟用鍵陣列。玩家用 `.set <key>` 啟用。如 `["mycoc"]` → `.set mycoc` |

> 若包內 `rules/*.json` 自己聲明瞭 `set.keys`，`setKeys` 可省略（會自動採用規則的啟用鍵）。

::: warning 匯入與更新
匯入必須包含有效的 `pack.json`。系統會先檢查 ZIP 路徑、檔案數量和解壓大小，拒絕路徑穿越、符號連結及異常壓縮包。同一 `id`（或目錄標識）的規則包不會被靜默覆蓋；與現有規則重複的 `.set` 啟用鍵、JS 檔名或 Lua 模組名也會被明確拒絕。更新前請先刪除舊包。匯入、啟停或刪除若熱過載失敗，會自動回滾檔案操作。
:::

## 三、`rules/` —— 規則檔案

規則檔案是普通 JSON，定義這套規則系統的屬性、指令、預設骰等。啟用後**優先順序高於內建指令**，同名幫助詞條也覆蓋內建。

```json
{
  "name": "我的克苏鲁扩展",
  "id": "my-coc-extension",
  "set": {
    "keys": ["mycoc"],
    "diceSides": 100
  },
  "alias": {
    "侦查": ["侦察", "观察", "spot"],
    "力量": ["str", "STR"]
  },
  "computed": {
    "理智上限": "99 - 克苏鲁神话"
  },
  "commands": {
    "disable": ["jrrp"],
    "alias": { "检定": "ra" },
    "add": {
      "稳定": {
        "output": "{nick} 进行稳定判定：1d100={1d100}",
        "help": ".稳定 —— 进行一次稳定判定"
      }
    }
  },
  "help": {
    "本规则": "这是我的克苏鲁扩展，包含……"
  }
}
```

| 塊 | 作用 |
| --- | --- |
| `set.keys` | 啟用鍵；`set.diceSides` 啟用後本群預設骰面 |
| `alias` | **屬性同義詞**：`规范名 → [别名…]`。讓 `.st 侦察50`、`.ra 观察` 都識別為「偵查」 |
| `computed` | **衍生屬性**：用表示式從其它屬性算出（如理智上限） |
| `commands.disable` | 遮蔽內建指令（啟用的群裡這些指令靜默） |
| `commands.alias` | 指令別名：`输入词 → 目标指令`（`.检定` 走 `.ra`） |
| `commands.add` | **自訂指令**（DSL，見下）。值可為字串（輸出模板）或 `{output, help}` 物件 |
| `help` | 包級幫助：`主题 → 文本`，`.help <主题>` 可查 |

### 自訂指令的表示式（DSL）

`commands.add` 的 `output` 模板裡，`{…}` 會被求值：

| 寫法 | 含義 |
| --- | --- |
| `{nick}` `{user}` `{group}` `{self}` `{date}` `{time}` | 暱稱 / QQ號 / 群號 / 骰娘自稱 / 日期 / 時間 |
| `{1d100}` `{3d6+2}` | 擲骰（同一指令裡同一表示式只搖一次） |
| `{力量}` `{侦查}` | 取傳送者人物卡的屬性值 |
| `{arg}` | 指令後面跟的引數 |
| 四則 / 比較 / 三元 | `{力量 + 5}`、`{1d100 <= 侦查}`、`{1d100<=侦查 ? "成功" : "失败"}` |
| `min/max/abs` | `{max(力量, 敏捷)}`、`{abs(hp - 10)}` |

屬性缺失或函式未知時，這條指令返回失敗提示而不是錯誤。

::: warning 當前屬性對映的作用域限制
包內自訂指令、遮蔽項及 Lua/JS 插件按群啟用；但 `alias`、`computed`、`defaults`、`derived` 目前仍進入程序級相容登錄檔。多個規則包請避免宣告相互衝突的屬性別名或預設值。將這些屬性對映改為完整的群級作用域仍在後續重構計劃中。
:::

## 四、`helpdoc/` —— 幫助速查

結構化幫助文件，**相容海豹 SealDice** 的格式。一個檔案含多條詞條：

```json
{
  "mod": "克苏鲁术语表",
  "author": "张三",
  "brief": "常用术语速查",
  "helpdoc": {
    "百分骰": "投 1d100，用于大部分检定。",
    "理智": "调查员的精神稳定度，归零则永久疯狂。",
    "SAN": "&理智"
  }
}
```

- 鍵 = 詞條名，值 = 內容；玩家用 `.help <词条>` 查詢。
- 值以 `&` 開頭表示**別名**（`"SAN": "&理智"` 即 SAN 指向「理智」）。
- 海豹的 `.xlsx` 表格幫助文件，可用 `tools/convert_helpdoc.py` 轉成本格式（見下）。

激活了本包的群，包內同名詞條**優先**於內建/其它來源。

::: tip 三種「幫助/速查」入口怎麼選？
規則包裡有三個長得像的東西，作用不同：

| 入口 | 玩家怎麼查 | 適合放什麼 |
| --- | --- | --- |
| `helpdoc/` 目錄（本節） | `.help <词条>` | 術語、技能、法術等**大量速查詞條**——首選 |
| `rules/*.json` 裡的 `help` 塊 | `.help <词条>` | 跟某條自訂指令強相關的**少量說明** |
| `rules/*.json` 裡的 `entries` 塊 | `.rules <词条>` | 目前**僅對獨立放置的規則檔案生效**，規則包 bundle 內暫不接入——先別用它 |

拿不準就統一放 `helpdoc/`。
:::

::: warning 卡模板暫不能隨包分發
`.pc build` 用的人物卡模板（`card-templates/*.json`）目前只從骰娘本地的 `card-templates/` 與 `data/card-templates/` 目錄載入，**放進規則包 zip 不會生效**，且改動後需重啟骰娘。想分發卡模板，請提示使用者手動把檔案放進 `data/card-templates/`。
:::

## 五、`lua/` 與 `js/` —— 插件

複雜邏輯（需要聯網、狀態機、複雜判定）放插件：

- `lua/` —— 原版 Dice! 的 Lua mod：可以是**目錄**（含 `reply/` 因果回覆、`script/`、`speech/` 等），也可以是**單檔案 `.lua`**（用 `msg_order` 派發）。
- `js/` —— 相容海豹 SealDice 的 `.js` 插件。

::: warning 包內插件是「按群啟用」的
包內插件的指令**預設不生效**，只有在 `.set <key>` 激活了本包的群裡才響應（其它群、私聊都不受影響）。這正是「單群規則覆蓋」的關鍵。
:::

> 想讓插件**全域性生效**（所有群都能用，不隨規則啟用）？那它就不是規則包的一部分——直接在「擴展管理」裡單獨上傳即可。

## 六、啟用與優先順序

1. 骰主在後臺「規則」頁 **上傳 zip** → 校驗後安裝到 `data/rulepacks/<id>/`。頁面只顯示一個父規則包卡片，規則、幫助、Lua 與 JS 子項可在“檢視包內容”中集中檢視，不會散落成可獨立編輯的重複專案。
2. 群管理員在群裡發 `.set <激活键>`（如 `.set mycoc`）→ 本群規則系統切換。
3. `.set list` 列出所有可用規則系統，`★` 標記本群當前啟用的。
4. 啟用後，在這個群裡：
   - 包的**自訂指令 / 別名 / 預設骰 / 屬性對映**生效，**優先於內建指令**；
   - 包內**插件指令**生效；
   - 包的**同名幫助詞條**優先於內建。
5. 其它沒啟用的群不會執行本包的自訂指令和插件；屬性對映的當前限制見上方警告。

## 七、把現有 mod / 插件轉化成規則包

現有的原版 Dice! Lua mod、單檔案 Lua/JS 插件，都能包裝成規則包。**轉化時務必保留原作者資訊**（尊重作者、便於追溯）。

### 用指令碼（Lua mod / 單檔案）

```bash
python tools/convert_mod_to_pack.py <mod路径> [激活键] [输出目录]
# 例：把女仆RPG规则 mod 转成规则包，激活键 maid
python tools/convert_mod_to_pack.py server/data/mod/Maid-TRPG maid
```

指令碼會：
- 從 mod 的 `descriptor.json` / `<name>.json` 讀取 **name / author / version / brief**，寫進 `pack.json`（**作者原樣保留**）；
- 把 mod 目錄原樣放進 `lua/`；
- 若 descriptor 帶 `helpdoc`，抽成 `helpdoc/<name>.json`；
- 自動生成啟用鍵（或用你指定的）。

生成的 `pack.json` 會帶 `"convertedFrom"` 欄位註明來源。轉換完打成 zip 即可分發。

### 海豹 Excel 幫助文件轉換

```bash
python tools/convert_helpdoc.py <源目录> <输出目录>
```

把海豹的 `.xlsx`（列 `Key | Synonym | Content | Description`）和 `.json` 幫助文件統一轉成本格式，放進包的 `helpdoc/` 即可。

### 手動轉化

照「目錄結構」新建資料夾、寫 `pack.json`（**填上原作者**）、把插件檔案放進 `lua/` 或 `js/`、幫助放進 `helpdoc/`，打成 zip。

::: tip 關於屬性模板與規則手冊（舊版 mod 相容）
- `model/*.xml` 裡 `<any name='力量' alias='STR/str'>` 這類**屬性別名會自動併入** `.st`/`.ra`——`.st STR50`、`.ra DEX` 直接認得該規則系統的屬性名，無需手寫。
- `rulebook/*.yaml`（`{rule, manual:{术语:解释}}`，如 COC 法術/武器/神話、DND 法術/怪物/物品、女僕 RPG 手冊）的條目**自動併入** `.help`——`.help 弓箭`、`.help 深层魔法` 直接出速查。
- `speech/*.yaml` 模板詞條照常生效。
- `model/*.xml` 裡 `text='javascript'`/`text='dicexp'` 的**簡單算術衍生/預設值**（如 `闪避 = 敏捷/2`、`生命 = (体质+体型)/10`、`理智 = 意志`）**會自動計算並落地**——讀這些屬性時若沒顯式 `.st` 過，按公式算出；新建 COC 卡 `.st` 基礎屬性後自動填 HP/SAN/MP 並附卡面摘要（設定頁可關「自動卡面」）。
- **JS 插件規則**：`seal.gameSystem.newTemplate(ByYaml)` 裡的 `alias`（屬性別名）與 `defaultsComputed`（簡單算術衍生）也會自動併入 `.st`/`.ra`——海豹的 JS 自訂規則系統的屬性名直接可用。
- **僅**複雜表示式（帶條件/字串/`Math.max`/`$` 臨時變數）暫不翻譯，可在 `rules/*.json` 的 `computed` 塊自行宣告。
:::

## 八、一個最小完整例子

```
口袋规则/
├── pack.json
├── rules/pocket.json
└── helpdoc/pocket.json
```

`pack.json`
```json
{ "name": "口袋规则", "version": "1.0.0", "author": "你的名字", "setKeys": ["pocket"] }
```

`rules/pocket.json`
```json
{
  "name": "口袋规则",
  "set": { "keys": ["pocket"], "diceSides": 100 },
  "commands": { "add": { "运势": { "output": "{nick} 今日运势：{1d100}/100", "help": ".运势 —— 看今日运势" } } },
  "help": { "口袋规则": "一个最小示例规则包。" }
}
```

`helpdoc/pocket.json`
```json
{ "mod": "口袋速查", "author": "你的名字", "helpdoc": { "运势": "投 1d100 看今日运势。" } }
```

打包：把 `口袋规则/` 壓成 `口袋规则.zip` → 後臺「規則」頁上傳 → 群裡 `.set pocket` → `.运势` 即可用，`.help 运势` 出速查。

## 九、小結

| 你想做的 | 放哪 |
| --- | --- |
| 屬性同義詞 / 預設骰 / 衍生屬性 | `rules/*.json` 的 `alias` / `set` / `computed` |
| 簡單自訂指令（模板 + 骰點 + 屬性） | `rules/*.json` 的 `commands.add`（DSL） |
| 遮蔽 / 重新命名內建指令 | `rules/*.json` 的 `commands.disable` / `alias` |
| 速查詞條 | `helpdoc/*.json` |
| 複雜邏輯（聯網 / 狀態 / 複雜判定） | `lua/` 或 `js/` 插件 |
| 後設資料（名字 / 作者 / 啟用鍵） | `pack.json` |
