# 擲骰與檢定

所有指令以 `.`（英文句號）開頭，預設也支援 `。`、`!`、`！`、`/`；自訂字首以基礎設定為準。指令中的引數請使用**英文半形**符號。

> 本頁覆蓋「通用擲骰」「COC 檢定」「BRP 檢定」「DND」四大類。角色卡相關見[角色卡管理](/zh-hant/use/card)，娛樂指令見[娛樂與互動](/zh-hant/use/fun)。

## 通用擲骰

| 指令 | 說明 |
|------|------|
| `.r` / `.rs` | 完整擲骰 / 僅顯示最終值，預設骰面可用 `.set` 修改 |
| `.rd` | 擲預設骰（`.rd6` 等帶面數寫法則擲指定骰） |
| `.rh` / `.h` / `.H` | 暗骰，結果私聊傳送給你（`.h` / `.H` 為原版短別名） |
| `.rah` / `.rch` | 暗檢定（COC），結果私聊傳送 |
| `.rx` | 心理學暗骰（守秘人用） |
| `.ww` | WOD 骰池（成功數統計，出 10 加骰） |
| `.dx` | 雙十字（Double Cross）連鎖擲骰 |
| `.set` | 設定 / 重置個人預設骰面，或切換本群規則系統 |

### `.r` 擲骰

```
.r 3d6+2 攻击      → 掷 3d6 加 2，原因「攻击」
.r3d6+2 攻击       → 同上，指令与表达式之间的空格可省略
.r 2#d20           → 连掷 2 次 d20
.rs 3d6+2          → 只显示最终值，不展开每颗骰子
.rd                → 掷默认骰（未设置时为 d100）
.rd6               → 掷 d6
.r 1d3+db          → db 自动展开为人物卡的伤害加值公式
.r 他带着西服去干洗店 → 不是表达式的文字作为原因，掷默认骰
.r 1次掷骰          → 数字后紧跟文字时整段是原因，掷默认骰
.rd 1次掷骰         → 同上，d 后接空格时 d 是默认骰
```

`.r` 後面不是骰子表示式的文字會當作原因，擲預設骰，與原版 Dice! 一致。只有數字、沒有骰子的開頭（如「1次擲骰」「3次攻擊」）也整段算原因；要擲固定表示式請寫明骰子，如 `.r 1d6 打了3次`。骰主可在[基礎設定](/zh-hant/manage/settings)開啟「停用擲骰理由」，此時只顯示擲骰結果，不顯示任何原因。

`db`（傷害加值）在表示式中會自動替換成人物卡里錄入的公式；未手動錄入時按 COC7 規則由「力量+體型」現算。詳見[角色卡管理](/zh-hant/use/card)。

### `.rh` / `.h` 暗骰與暗檢定

```
.rh 1d100          → 暗骰，结果私聊发给你
.h 1d100           → 同上；大写 .H 也可用，且不会占用 .help
.rah 侦查           → 暗检定（读卡），结果私聊
.rch 侦查 60        → 暗检定（指定成功率），结果私聊
```

群裡只會提示「某人進行了暗骰」，他人看不到點數；房規（`.setcoc`）、獎懲骰等照常生效。

### `.rx` 心理學暗骰

```
.rx @某人          → 对被 @ 的调查员掷一次心理学检定
.rx @某人 40       → 指定成功率
```

守秘人專用：含成功等級的詳細結果**私聊發給你**，群裡只出一句不劇透的回執。省略成功率時讀對方人物卡的「心理學」，預設 10。

### `.ww` WOD 骰池

```
.ww 8              → 掷 8 个 d10，≥8 计一个成功，10 额外加骰
.ww 8 7            → 成功线改为 7
.ww8测试           → 骰式后可直接跟原因「测试」
.ww 8a10c7 攻击    → 自定义加骰线 / 成功线，并显示原因「攻击」
```

與 `.r` 不同，`.ww` 統計的是**成功數**而非點數總和。

### `.dx` 雙十字

```
.dx 3c8            → 3 个骰，临界值 8（达到即爆发加骰）
.dx 5 10           → 等价写法（空格分隔）
.dx5c10测试        → 无空格跟原因，回复显示「掷骰 测试」
.dx 5c10 测试     → 有空格写法，效果相同
.dx 5a7            → a 写法：无限加骰骰池（数成功个数，WOD 风格）
```

### `.rs` 簡短結果 / Fate（NdF）

```
.rs 3d6+2          → 仅显示最终值，不展示完整计算过程
.rsh d100          → 简短结果与暗骰标记可组合
.r 4dF             → 掷 4 个命运骰（Fate / FUDGE）
```

`.rs` 復刻原版 Dice! 的短結果語義；Fate 骰仍由 `NdF` 表示式提供。命運骰每顆結果為 `+`、`0`、`-`（即 +1 / 0 / −1），完整結果形如 `4dF=[+ − 0 +]=1`。

### `.set` 預設骰與規則系統

```
.set 20            → 把个人默认骰设为 d20（1-9999）
.set               → 重置为 d100
.set list          → 列出可切换的规则系统（★ 标记本群当前）
.set coc7          → 切换本群规则系统并联动默认骰面（需群管理）
```

設定預設骰後，`.r` 不帶表示式與 `.rd` 都會擲預設骰。規則系統由[規則包](/zh-hant/develop/rulepack)提供，切換後包內的指令、同義詞等按群生效。

### COC 制卡 `.coc`

```
.coc / .coc7       → 生成一组 COC7 调查员属性
.coc6              → 生成一组 COC6 调查员属性
.cocd / .coc7d     → COC7 详细制卡结果
.coc6d             → COC6 详细制卡结果
.coc7d 3           → 一次生成 3 组（最多 10 组）
```

原版用於列寬排版的尾隨 `s` 標記也可接受，例如 `.coc7ds 3`；它不改變數值規則。

### 檢定 `.ra` / `.rc`

```
.ra 侦查           → 读取角色卡侦查值检定
.ra 力量60         → 临时指定数值检定
.ra 困难侦查        → 困难难度
.ra 侦查 @某人      → 代某人检定（读他的卡）
.ra 2#侦查         → 连续检定 2 次
```

`.ra 侦查-20` / `.rc 侦查+20` 的臨時修正基於當前繫結人物卡的實際值，包含已錄入的關聯屬性；只有沒有錄入時才使用規則基礎值，不會改寫人物卡。例如偵查為 50 時，分別檢定 30 和 70。

### 成功率運算

成功率可以寫成算式，檢定、對抗與屬性修改共用同一套運算規則：

```
.ra 力量+20-30        → 多级加减（力量 60 时按 50 检定）
.ra 力量 +20 -30 攻击  → 修正可用空格分开写，后面的文字仍是原因
.ra 力量*2 / .ra 力量/2 → 乘除；结果向下取整
.ra (力量+敏捷)/2      → 括号与多个属性
.ra 侦查+1d10         → 掷骰，回复中标出掷出的点数
.ra 力量^0.5*10       → 乘方与 sqrt、cbrt、exp、ln、log、sin、cos、max、min 等函数，常量 pi、e
.ra 力量70+10         → 先用内联数值代替卡值，再运算
.rav 力量+10 敏捷-5    → 对抗双方同样可用
.rc 力量+2-1          → DND 模式下作用于调整值
.st hp-1d6+2         → 符号后的整段是一个数量：扣除 (1d6+2)，可直接抄武器伤害公式
```

`.st` 的 `+` / `-` 後面整段視為一個數量（與原版 Dice! 一致），因此擲出小點數時傷害也不會變成回血；要分別計算可加括號或拆成多條。檢定修正（如 `.ra 力量+20-30`）則是對技能值的一串加減。

中間按實數計算，最終結果向下取整；檢定成功率最低為 1。引用未錄入的屬性會提示具體名稱，語法錯誤、除以 0、超出範圍（如 `10^1000`）會直接報錯，不會猜測結果。為防止濫用，單個算式最長 512 位元組，括號巢狀與運算項數量有上限，整式最多擲 1000 顆骰子。

固定出目的預覽寫法 `.ra(1)50` 不受影響：括號內只有數字與骰子、且後面不是運算子時，才視為預覽出目；`.ra (力量+敏捷)/2` 會按算式處理。

預設以及切換到 `coc7` / `coc7r` 後，`.ra` 與 `.rc` 都使用 d100。`.pc type coc7r`（等價於 `.set coc7r`）會同步退出舊 DND 模式；`.setcoc <0-7>` 也會恢復 CoC 檢定。只有顯式開啟 DND 時 `.rc` 才使用 d20，`.ra` 仍是 CoC 檢定。視覺化回覆中的「再次檢定」是可選快捷操作，會保留原指令的修正、難度、原因與字首，不會自動重擲。

受舊版混合模式問題影響的使用者，如果此前 `.st` 把技能誤存進了 DND 獨立技能區，請切換到 CoC 後重新執行一次 `.st 侦查50` 等錄入。更新不會把所有 DND 技能加值自動當作 CoC 百分比搬入人物卡，以免混淆實際的 DND 資料。

檢定自動判定成功等級：大成功 / 極難 / 困難 / 成功 / 失敗 / 大失敗，並受本群 `.setcoc` 房規影響。

### 獎勵 / 懲罰骰 `.rb` / `.rp`

```
.rb 侦查           → 1 个奖励骰
.rp2 60            → 2 个惩罚骰，对 60 检定
.rapass23          → 黏着写法：按「最长指令优先」解析为 .rap ass 23
```

### `.rad` 同骰值檢定

```
.rad               → 掷一个 d100，直接以它作为「d」检定
.rad 侦查          → 第一行按 .r 展示掷骰过程，第二行用同一个骰值对侦查判定
.rad 侦查50 搜书房  → 同上，临时指定成功率并附原因
.rad 打了3次怪      → 不是技能：整句作为原因，与 .rad 相同
```

適合「先亮骰再對技能」的玩法：兩行用的是**同一個骰值**。

### 對抗檢定 `.rav`

```
.rav 侦查 @某人     → 双方各掷 d100，先比成功等级，再比点数
.rav 斗殴 60       → 己方读卡，对方直接给数值
```

```
.sc 1/1d6          → 成功扣 1，失败扣 1d6；自动从角色卡扣 SAN
.sc 1d3/1d10 50    → 指定当前 SAN 为 50
.sc b 1/1d6        → 带 1 个奖励骰的理智检定（.scb 亦可）

```

```
.en 侦查            → 对侦查掷 d100，大于当前值（或 >95）则成长 1d10 并存卡
.en 侦查 60         → 临时指定技能值
.en侦查60           → 原版紧凑写法，与上行等价
```

### 房規 `.setcoc`

修改需要群管理許可權，設定僅作用於當前群的當前骰娘賬號；同群多個骰娘賬號互不覆蓋。coc7r 的房規獨立儲存。

```text
.setcoc 2          → 设置房规 2（0–7）
.setcoc show       → 查看当前房规
.setcoc help       → 查看所有编号的含义（也可用 .help setcoc / .setcoc list）
.setcoc clr        → 恢复规则 0
.setcoc dg         → 使用规则 6
```

下表中 A 表示技能值、D 表示 D100 結果，整數除法向零取整。特殊成功或失敗先於普通等級判定。

| 規則 | 大成功 | 大失敗 | 其他等級 |
| --- | --- | --- | --- |
| 0（預設） | D=1 | A<50 時 D≥96；否則 D=100 | 通常分級 |
| 1 | A<50 時 D=1；否則 D≤5 | 同規則 0 | 通常分級 |
| 2 | D≤5 且 D≤A | D=100，或檢定失敗且 D≥96 | 通常分級；例如 A=99、D=99 仍成功 |
| 3 | D≤5 | D≥96 | 通常分級 |
| 4 | D≤5 且 D≤A/10 | D=100，或 A<50 且檢定失敗、D≥96+A/10 | 通常分級 |
| 5 | D≤2 且 D<A/10，注意是嚴格小於 | A<50 時 D≥96；否則 D≥99 | 通常分級 |
| 6（DG） | 檢定成功且 D=1 或雙數 11/22/…/99 | 檢定失敗且 D=100 或雙數 | 其餘僅普通成功/失敗，無困難/極難；A=100、D=100 為普通成功 |
| 7 | 不設大成功 | D=100；D=96–99 且 (90−A)/20+D≥100 | D<96 時，D=1 或 D≤A/5 為極難，否則按 A 判普通成功/失敗；96–99 未大失敗也為失敗，無困難成功 |

規則 0–5 的“通常分級”：D≤A/5 極難、D≤A/2 困難、D≤A 普通成功，否則失敗。例如規則 5 在 A=20、D=2 時是極難而非大成功；規則 7 在 A=50 時 98–100 為大失敗。

房規影響 COC 技能檢定及獎懲骰，不改變普通 `.r` 的點數或其他規則系統。理智檢定還有理智損失自身的結算規則，不能把技能等級直接當作理智損失公式。

## BRP（基礎角色扮演系統）

| 指令 | 說明 |
|------|------|
| `.ba` | BRP 檢定（d100 低骰） |
| `.bav` | 抵抗表對抗 |

### `.ba` BRP 檢定

```
.ba 侦查           → 读卡检定
.ba 斗殴60         → 指定成功率
.ba 侦查 @某人      → 代骰
.ba 2#侦查         → 连掷
```

成功等級：大成功 ≤ 技能/20、特殊成功 ≤ 技能/5、成功 ≤ 技能、失敗 > 技能、大失敗（骰出 100，或失敗且骰出 99）。

### `.bav` 抵抗表對抗

```
.bav 力量 体型      → 主动方力量 vs 被动方体型（属性名读卡，也可直接填数值）
```

目標% = 50 +（主動 − 被動）× 5，擲 1d100 ≤ 目標則主動方勝。

### DND 模式 `.setdnd`

```
.setdnd on         → 开启本群 DND5e 模式（.rc 改为 d20 检定）
.setdnd off        → 关闭（.rc 恢复 COC d100）
.setdnd            → 切换
```

### d20 檢定 `.rc`

DND 模式下 `.rc` 變為 d20 檢定。六項屬性先把屬性值（含 `.buff` 加值）換算為 `向下取整((属性值−10)/2)` 的調整值，再加指令中寫的臨時修正；技能則使用錄入的檢定加值。例如力量 18 時，`.rc 力量-5` 為 `1d20 +4 -5`：

```
.rc 力量           → 1d20 + 力量调整
.rc 优势 力量+2     → 优势（两个 d20 取高），额外 +2
.rc 劣势 敏捷       → 劣势（取低）
.rc 5 攻击         → 直接给调整值 5
```

### 調整值檢定 `.rdc`

`.rdc` 直接對「屬性調整值」做檢定：屬性按 `(属性值−10)/2` 向下取整，技能讀取獨立檢定加值。

```
.rdc 力量+2 破门 15       → 1d20 + 力量调整 +2，理由「破门」，阈值 15（≥ 视为成功）
.rdc 3# B 力量+2 破门 15  → 3 轮，B 取高（P 取低）
```

輪數最多 9，用 `N#` 字首。`.rdc` 僅在已開啟 DND5e 模式的群可用（`.setdnd on`）。

### 臨時加值 `.buff`

```
.buff 力量:2       → 设置力量 +2 的 Buff
.buff 力量+1       → 增减
.buff              → 查看当前 Buff
.buff del 力量     → 删除某项
.buff clr          → 全部清除
```

Buff 會計入 DND 模式的 `.rc` 檢定與屬性讀取。

### 先攻 `.ri` / `.init`

```
.ri +2             → 投 d20+2 加入先攻
.ri +2 哥布林       → 指定名字加入
.ri +1d4 哥布林     → 投 d20+1d4，不把修正骰式当成名字
.ri 1d6 哥布林      → 使用指定的先攻骰式
.ri 1d6 3#哥布林    → 三个独立先攻结果，逐个投 d6 并编号
.init              → 按先攻值排序查看
.init clr          → 清空先攻列表
.init del 哥布林    → 删除某条
```

### 法術位 `.ss` / `.cast`

```
.ss init 4 3 2     → 设置 1/2/3 环法术位上限
.ss set 3环 5      → 单独设置某一环
.ss 3环 -1         → 增减
.ss                → 查看当前法术位
.ss rest           → 全部恢复
.ss clr            → 清除设置
.cast 3            → 消耗 1 个 3 环法术位
.cast 3 2          → 消耗 2 个
```

### 長休 `.longrest` / 死亡豁免 `.ds`

```
.longrest          → HP 恢复至上限，法术位全部恢复（也可写 .长休）
.ds                → 死亡豁免检定（也可写 .死亡豁免），需 HP 为 0
```

死亡豁免按 DND5e 規則：累計 3 次成功穩定、3 次失敗死亡；骰出 20 直接回復 1 HP，骰出 1 記 2 次失敗。長休需要先用 `.st hpmax:<值>` 設定生命上限。

## 指令約定

- 標點用英文半形；`[必填]`、`(可选)`。
- 多輪檢定用 `N#` 字首，避免刷屏。
- **指令與引數之間的空格可以省略**（與原版 Dice! 一致）：`.help指令`、`.ri+2`、`.rd6` 均合法。交叉時按「最長指令優先」解析（如 `.rapass23` = `.rap ass 23`）；想讓短指令吃字母引數時請用空格隔開。
- 觸發頻率限制後會有冷卻，請耐心等待。
