# coc7r：Keeper Companion 選用規則

此功能對應 Chaosium 的 **Call of Cthulhu Keeper Companion（2026，CHA23197-H）**。這是第七版的補充書；`coc7r` 是 Dice!Next 的配置名，不代表官方釋出了獨立的新版本號。以下頁碼是書內印刷頁碼。

書中的修訂規則都是可以逐項採用的選項（序言第 5 頁），因此本規則包的每個部分都能單獨開關，關閉的部分改回核心 CoC7。

## 啟用與返回

群管理員輸入：

```
.set coc7r
.coc7r help
```

恢復原先的 CoC7：

```
.set coc7
```

所有 `.coc7r` 指令都可以簡寫為 `.c7r`。切換隻選擇本群的規則，不會轉換或覆蓋已有卡片。原有 CoC7 的房規仍保留；`coc7r` 的技能檢定房規單獨儲存，預設規則 0。`.coc7`、`.coc6` 仍顯式生成原版人物屬性。

WebUI 的「規則管理」可編輯此包各項規則的預設值。更新內建資源不會覆蓋儲存到 `data/rules/` 的修改或停用狀態。

## 各項規則

| 規則名 | 內容 | 預設 | 書內頁碼 |
| --- | --- | --- | --- |
| `creation` | `.coc`、`.pc build` 改為給出 8 個 `(2D6+5)×5` 屬性池，由玩家自由分配，不寫入卡片 | 開 | 9–10 |
| `skills` | 修訂技能表：新基礎值；安撫 APP/5；取悅、話術、恐嚇輸入按說服處理；學識按神秘學處理 | 開 | 15、17–24 |
| `movement` | MOV＝`7+(STR>SIZ)+(DEX>SIZ)`，保留年齡修正 | 開 | 10 |
| `sanity` | 理智修訂：震驚、餘震、Changed、Lost、安撫、現實檢定、神話成長與恢復 | 開 | 85–99 |
| `bases` | 按屬性計算技能基礎值（需 `skills` 開啟） | 關 | 23–24 |
| `specialties` | 格鬥／射擊專長不低於同類最高值的一半（需 `skills` 開啟） | 關 | 19 |
| `take5` | 成長檢定成功時固定 +5，不擲 1D10 | 關 | 51 |

```
.coc7r options
.coc7r options sanity off
.coc7r options take5 on
```

只有群管理員能修改，群聊內的設定優先於規則包預設值。已錄入的技能總值不會隨屬性變化重算；專長下限僅影響有效值，不重寫原數值。顯式成長表示式（如 `.en 侦查0+3`）保留原意，開啟 `take5` 後想照常擲 1D10 時寫 `.en 侦查 +1d10`。

宗教、語言、科學等應指定專長，例如 `.st 宗教(道教)30`、`.ra 母语(汉语)`。不能僅憑「衝鋒槍」判定技能：需根據實際武器選擇手槍或步槍／霰彈槍。

## 建卡與移動

```
.coc7r
.coc7r 3
.coc7r array 1
.pc new 新调查员
.st STR60 CON60 SIZ50 DEX65 APP60 INT70 POW60 EDU65 年龄30
.coc7r mov
.st show 兴趣点
```

生成器只給屬性池，分配後須自行儲存；`.coc7r` 與 `array` 在任何群都可使用。興趣點為 EDU+INT；購點共 480 點、單項 30–90；自訂職業選 6–12 項職業技能（含信用評級）分配 300 點。年齡引起的屬性調整、幸運、職業與技能點分配仍需按書和 KP 要求完成。錄入意志時，SAN 自動設為意志的值（第 85 頁）。

### 舊卡合併技能

```
.coc7r migrate
.coc7r migrate @对方
```

舊卡上的取悅、話術、恐嚇會併入說服，學識併入神秘學，生存的各專精併入生存，都取最高值，並刪除舊欄位。切換規則時不會自動合併，只有執行 `migrate` 才會改卡。轉換他人的卡需群管理員。衝鋒槍不會自動轉換，請按實際武器改錄。

## 理智與狀態

```
.sc 0/1d6
.sc 0/1d6 mythos
.coc7r loss 1d4 mythos
.coc7r show
.coc7r show @对方
```

`mythos` 表示 KP 已確認該損失來自克蘇魯神話，程式不從描述猜測原因。書籍、法術等直接損失用 `loss`，不會額外擲一次 SAN。普通 `.sc` 停用獎勵／懲罰骰和孤注一擲，失敗表示式的大失敗取可計算的最大損失。支援非負整數、NdM 與加減組合；不支援的表示式會報用法，不會隨機猜最大值。

- 指定數值如 `.sc 0/1d6 50` 只計算，不寫卡，也不會猜測 POW、INT 或累計狀態。
- 自動結算需卡上有 POW、INT；還沒錄入 SAN 時按意志檢定。SAN 與狀態一次性儲存；鎖卡、併發修改或儲存失敗會拒絕寫入。
- 單次實際損失達到 5 時擲 INT；成功進入震驚，玩家選擇表現，持續 1D10 回合。已處於 Changed 時閾值為 10。
- 本章累計損失達到 POW 的五分之一時進入 Changed。五分之一按官方屬性分數規則向下取整；例如 POW=51 時為 10。
- SAN=0 是 Lost，恢復命令拒絕繼續治療。恢復 SAN 不減少累計損失。

狀態的結束都由 KP 在遊戲中確認，不按現實鐘錶自動解除：

```
.coc7r end shock
.coc7r end sleep
.coc7r end chapter
.coc7r end changed
```

| 指令 | 效果 |
| --- | --- |
| `end shock` | 震驚回合結束；之後不再免於損失 |
| `end sleep` | 在安全地點睡過一夜，結束餘震 |
| `end chapter` | 新章節：重置累計損失與本章安撫恢復次數，不解除 Changed |
| `end changed` | KP 確認至少一週休養並修訂鎖定背景後解除 Changed |

狀態隨卡片儲存，改名、重啟後保留；各平臺／適配器／會話的章節記錄分開。人物卡本身仍沿用原有共享規則：若同一張卡繫結在多個群，卡上的 SAN 也仍是同一個數值。

`.st` 屬於手動改卡，不自動推斷損失來源或執行理智流程。需要記入章節的扣點請用 `.sc` / `loss`。開啟 `sanity` 時，`.st 理智` 不會超過 99−克蘇魯神話。POW 被手動調整後可用 `.coc7r loss 0` 按新閾值重新結算狀態。

## 安撫、神話成長與現實檢定

```
.ra 安抚
.coc7r reassure @对方
.coc7r reassure @对方 push
.coc7r reassure 对方用户ID
.coc7r mythos first
.coc7r mythos later
.sc reality
.sc reality b
```

`reassure` 可以 @ 對方，也可以直接寫對方的使用者 ID。它會寫入他人的卡，只允許群管理員代為結算；普通玩家可先 `.ra 安抚` 後請 KP 處理。目標須已有卡和所需數值，不能安撫自己。成功可恢復 2 SAN（每章只受益一次、受最大 SAN 限制），並結束震驚、暫時抑制恐懼症；餘震保留。

**安撫的大失敗／失敗孤注一擲暫採用 1D4 SAN 損失。** 原書第 22 頁寫 1D4，第 94 頁寫 1D6；這是當前明確選擇的處理方案，不聲稱已有官方勘誤。`push` 僅能在之前一次安撫失敗並獲 KP 允許後使用。

神話導致的震驚／Changed 會登記待結算事件，首次選擇 `first` 加 5，之後 `later` 加 1（第 88 頁，屬於理智修訂的正文規則）。同一事件同時觸發兩者只計一次。已確認過的卡不能再次領取首次獎勵。

現實檢定就是一次理智檢定：失敗損失 1 SAN；成功後在下一次 SAN 損失前抵抗幻覺。`b` 表示另一個調查員已經成功安撫協助，此時加 1 獎勵骰。

## 恢復理智

在 KP 確認相應條件後：

```
.st 理智+1d6
.coc7r therapy 80
.coc7r therapy 80 phobia
.coc7r therapy 80 push
.coc7r selfhelp INT 30 5
```

- 章節末的 KP 獎勵直接用 `.st 理智+表达式`，不會超過 99−克蘇魯神話。
- `therapy` 每遊戲月一次，使用治療者技能或機構評級。成功恢復 1D3，或選擇 `phobia` 移除一項恐懼症；失敗不恢復；大失敗／失敗孤注一擲損失 1D6 並提示治療關係結束。
- `selfhelp` 用於成長階段。先擲 INT 或 POW，再輸入**已擲出的 D100 結果**及可選幸運花費，程式結算這次結果，不重擲。達到困難成功恢復 1D6；未達到損失 1 SAN，並提示修訂、鎖定背景；不能花超過現有的幸運或修改大失敗。
- 技能在實際遊戲中經 `.en` 從不足 90 達到 90，自動結算 2D6 SAN 獎勵；建立或手動修改技能不會自動領獎。
- Changed 時 `.en 幸运` 會拒絕恢復，但仍能按規則花費幸運。

治療月份、成長階段和 KP 獎勵資格使用遊戲內時間，由 KP 確認，不由伺服器日期自動授權。

## 戰鬥與追逐

```
.coc7r ri
.coc7r chase 7 fail 3
```

`ri` 是圓桌先攻（第 59 頁）：發起攻擊者先行動，有爭議時 DEX 高者先；擲一次 1D6，偶數向左、奇數向右傳遞，整場戰鬥沿用此方向。座位順序由 KP 管理。

追逐輸入當前 MvP 與已經判定的成功／失敗／失敗孤注一擲。失敗擲 1D6 消耗 MvP，仍有 MvP 才前進一步；歸零則退出，失敗孤注一擲直接退出。起始 MvP 通常等於 MOV，重傷減半。地點、障礙、檢查難度、隊友幫助和劇情後果仍由 KP 管理。

## 實現邊界

本包提供可重複計算的機制和現有骰子指令適配，**不是整本書的自動主持系統**。自動射擊與掃射、近戰槍械反擊、群體敵人、爆炸場景、重傷／瀕死治療流程、職業列表、恐懼症表和背景敘事仍由 KP 使用基礎擲骰和書中規則處理。
