# 規則速查

跑團時隨手查規則，無需翻書。Dice!Next 使用本地可擴展的規則庫，離線可用、可自行增補。

## 指令

| 指令 | 說明 |
|------|------|
| `.rules 词条` / `.rule 词条` | 查詢規則詞條（`.rule` 為原版別名） |
| `.rules 规则书:词条` | 在指定規則書中查詢 |
| `.ruleset 规则书` | 設定本群預設規則書（群管理） |
| `.rule set 规则书` | 原版設定寫法，等同 `.ruleset 规则书` |

## 用法

```
.rules 大失败           → 查询（先本群默认书，再全部）
.rules coc:困难成功     → 在 COC7 规则书中查询
.rules dnd:借机攻击     → 在 DND 规则书中查询
.ruleset dnd            → 把本群默认规则书设为 dnd
.rule set dnd           → 同上（原版 Dice! 写法）
.ruleset show / clr     → 查看 / 清除默认规则书（清除也需要群管理）
```

支援詞條的精確匹配與模糊（子串）匹配。

## 內建規則書

CoC7 的 Keeper Companion 選用機制可用 `.set coc7r` 切換，詳見 [coc7r 使用說明](./coc7r)。這是獨立的執行規則配置，和 `.ruleset` 選擇查詢用的參考書不同。

| 規則書 | 別名 | 內容 |
|--------|------|------|
| `coc7` | coc、克蘇魯 | 大成功/大失敗、困難/極難成功、理智與瘋狂、傷害加值、體格等 |
| `dnd` | dnd5e、5e、龍與地下城 | 優勢/劣勢、先攻、藉機攻擊、豁免、熟練加值、長短休、死亡豁免等 |

## 自訂規則書

規則書是放在 `data/rules/` 目錄下的 JSON 檔案（包根目錄的 `rules/` 也相容），每個檔案一本：

```json
{
  "name": "coc7",
  "aliases": ["coc", "克苏鲁"],
  "entries": {
    "大失败": "技能值<50 时骰出 96-100 为大失败……",
    "困难成功": "骰值 ≤ 技能值的一半即为困难成功。"
  }
}
```

放入新檔案即可擴充規則庫，骰主可按自己跑的規則系統自由增補。也可在 Web 管理面板的規則頁面直接編輯。

::: tip 規則包
同一個規則書 JSON 還能宣告**技能同義詞**（`alias`）、預設骰等「規則包」能力，詞條與同義詞寫在一個檔案裡即可一起生效；成套的玩法（幫助速查、卡模板、插件等）則可打包成規則包分發、匯入即用。詳見[規則包編寫](/zh-hant/develop/rulepack)。
:::
