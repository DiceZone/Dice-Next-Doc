# 幫助與語言

Dice!Next 內建一套統一的幫助登錄檔：內建指令說明、規則包詞條、插件註冊的幫助、以及可自訂的幫助文件都匯入同一個 `.help`，還可以按群鎖定搜尋域、切換回復語言。

## 查幫助 `.help`

```
.help              → 指令总览菜单
.help ra           → 查看某条指令 / 某个词条的帮助（.help .ra 也行）
.help 克苏鲁       → 词条不限于指令，规则速查、牌堆说明等都能查
.help on / off     → 群管理开启 / 关闭本群帮助指令（持久保存）
```

總覽選單按用途分組：投骰、檢定、人物卡、生成、牌堆、娛樂、管理、賬號。

### 幫助的排版

最新 main 的無引數 `.help` 預設末尾增加以下兩行反饋入口（`75ec20d`，尚未進入 beta.925）：

```text
Dice!Next 测试群：933145116
如有故障或建议欢迎加群反馈
```

只調整預設主幫助文案，不影響 `.help <指令>` 查詢；骰主已有的幫助自訂覆蓋繼續優先，不會被強制替換。

內建指令幫助統一為「標題行 + 一行一個指令 + `//` 說明」，補充說明另起一行放在末尾。引數寫法為 `<必填>`、`[可选]`。空指令（例如只發 `.log`）給出的用法提示用同一套排版：

```
录卡 .st
.st <属性><值> // 录入或修改属性，如 .st 力量50 敏捷60
.st <属性>±<值> // 增减属性，支持骰子，如 hp-2、理智+1d3
.st show // 查看当前人物卡
.st clr // 清空人物卡
.st del <属性> // 删除某项属性
DND 钱币支持 pp/gp/ep/sp/cp，扣款自动换开。
```

四種介面語言各自維護這套文案，切換語言（見下文 `.lang`）會同時切換幫助的語言。

- 詞條支援**模糊匹配**：唯一命中直接顯示；多個候選會列出讓你挑；找不到會提示。
- 幫助來源（按統一登錄檔彙總，重名自動去重）：
  1. **內建**指令說明；
  2. **自訂詞條**（包括舊版 `CustomHelp.json` 匯入的幫助）；
  3. **規則包**自帶的幫助詞條（本群啟用的規則包，其同名詞條優先生效）；
  4. **插件**（JS / Lua）註冊的幫助；
  5. **自訂文件**（`data/help/*.md`）與**幫助文件包**（`data/helpdoc/` 及各規則包目錄下的 JSON）。
- 超長的幫助內容會自動分段傳送。

### 溯洄引用

幫助正文以 `&主题` 開頭時，可作為另一主題的別名（2026-10-19 本地補齊）。支援多級跳轉，目標仍按當前來源優先順序和搜尋域選擇；缺失、迴圈或過深別名不會無限展開。適用於舊版匯入的自訂幫助，不需手動複製目標正文。

幫助詞條內容支援溯洄格式函式：`{词条}` 展開另一個詞條的內容（可遞迴），`[{%_1D3}*10]` 這類含 `{}` 的方括號塊會當算式求值；不含 `{}` 的 `[示例]` 保持原樣。牌堆卡面也支援同一套引用語義（見[牌堆](/zh-hant/use/deck)）。

## 自訂幫助 `.helpdoc`

`.helpdoc <词条>` 與 `.help <词条>` 等價；不帶詞條時給出使用提示（完整條目請到網頁後臺「幫助文件」頁瀏覽 / 搜尋）。

自訂幫助文件放在 `data/helpdoc/` 目錄（`*.json`，相容海豹 SealDice 幫助文件格式）：

```json
{
  "mod": "我的速查",
  "brief": "一句话简介",
  "helpdoc": {
    "词条名": "词条内容",
    "别名": "&词条名"
  }
}
```

值以 `&` 開頭表示別名（指向另一詞條）。規則包也可以在包內 `helpdoc/` 目錄隨包分發幫助，詞條來源會標成 `<包名>/<mod>`。

### 預設來源 `.helpdoc default`

多個來源有同名詞條時（例如 dnd3r 與 dnd5r 都有「貓頭鷹熊」），可指定優先來源：

```
.helpdoc default           → 查看当前默认来源与可选来源
.helpdoc default dnd5r     → 同名词条优先用 dnd5r
.helpdoc default clear     → 取消（恢复按加载顺序）
```

### 搜尋域 `.helpdoc scope`

比預設來源更強：把本群的幫助搜尋**鎖定**在某個來源內，其餘來源的詞條一律過濾（內建指令說明仍保留）。適合跑某個特定規則時防止查到別家內容：

```
.helpdoc scope coc7包      → 本群 .help 只查该来源
.helpdoc scope clear       → 解除锁定
.helpdoc scope             → 查看当前搜索域
```

## Web 管理

在 Web 管理面板的[幫助文件](/zh-hant/manage/help-docs)頁可以按來源型別及具體來源篩選、搜尋全部幫助詞條，並編輯自訂幫助。歷史 `help.topic.*` 詞條自動納入該頁，既有資料無需重新匯入；內建幫助修改後仍保留內建來源標記。

## 語言切換 `.lang`

骰子回覆支援四種內建語言：簡體中文 / 繁體中文 / English / 日本語。群管理可切換本群語言，私聊裡則切換你自己的：

```
.lang                  → 查看当前语言与用法
.lang 繁體             → 切换（简体 / 繁體 / en / 日本語 及各种常见别名都能识别）
.lang clr              → 清除覆盖，恢复默认
```

### 自訂語言包

把翻譯檔案 `<语言码>.json` 放進 `i18n/` 目錄即可自動載入為新語言；包內的 `_meta.keywords` 宣告這門語言的切換關鍵詞（之後 `.lang <关键词>` 就能切過去）。目錄裡附帶 `_custom_language_example.json` 模板可供參考，改內建語言的個別文案同理。

### AI 翻譯語言

如果 `.lang` 的引數既不是內建語言也沒有對應翻譯檔案，還會查骰主在 AI 設定中登記的 **AI 翻譯語言**：命中後該視窗的回覆會在傳送前由大模型即時翻譯成目標語言（回覆會稍有延遲，且骰點數字保證不被改動）。詳見 [AI 功能](/zh-hant/manage/ai)。
