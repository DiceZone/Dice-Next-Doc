# 牌堆與隨機抽取

Dice!Next 相容原版 Dice! 牌堆格式，並提供給主持人（KP）的執行時臨時牌堆與內聯隨機工具。

## 指令總覽

| 指令 | 說明 |
|------|------|
| `.draw` / `.drawh` | 公開抽取 / 暗抽牌堆 |
| `.deck` | 檢視牌堆列表 / 管理臨時牌堆 / 設定預設牌堆 |
| `.gacha` | 抽卡（gacha 牌堆） |

## 抽牌 `.draw`

```
.draw 塔罗牌        → 从「塔罗牌」牌堆抽一张
.draw3 塔罗牌       → 连抽 3 张
.draw              → 抽本群默认牌堆（需先 .deck set）
.drawh 塔罗牌       → 结果私聊发给抽取者，群里只发暗抽回执
```

### 內聯隨機（跑團神器）

無需建堆，直接給候選項用 `/` 分隔即可隨機選一：

```
.draw 红/蓝/绿      → 在三项中随机选一个
.draw3 左/中/右     → 随机选 3 次
```

適合臨場讓骰子幫忙做隨機決定。

## 臨時牌堆 `.deck new`

任何人（含沒有管理許可權的 KP）都能為本群建立臨時牌堆，跑團時非常實用：

```
.deck new 出招 石头/剪刀/布   → 建立本群临时牌堆「出招」
.draw 出招                    → 从临时牌堆抽取
.deck del 出招                → 删除临时牌堆
```

## 團務私有牌堆 `.deck session`

先通過 `.game new` 建立團務，再由本團 GM、群管或骰主管理不放回牌堆。以下以當前 main 為準，所用安裝包是否包含新增入口請核對對應 Release 的原始碼版本：

```text
.deck session new 出场 甲/乙/丙       // 创建私有牌堆
.deck session from 敌人 公共敌人堆   // 复制公共牌堆，不修改来源
.deck session range 编号 1 20 2      // 从整数范围生成 1、3、5…19
.deck session members 抽签名单       // 从当前账号缓存的本群成员建立快照
.deck session rest 出场              // 查看剩余数量
.draw 出场                          // 抽走一张，不放回
.deck session reset 出场             // 恢复全部牌
.deck session del 出场               // 删除指定私有牌堆
.deck session clr                    // 清空本团私有牌堆
```

`::2::甲` 表示兩份甲；一個 Session 最多 10 個私有牌堆。接入同一團務的多個群共用牌池，不同團務互不影響；剩餘牌數持久儲存，舊版存檔的已抽狀態也會保留。抽空後必須顯式重置，不會自動補牌或改抽同名公共牌堆。儲存失敗時本次不扣牌。

抽取優先順序為：**團務私有牌堆 → 本群臨時牌堆 → 公共檔案牌堆**。本群臨時牌堆仍有放回，`.deck new/set/del/clr` 原有含義不變；團務管理使用上面的顯式 `session` 入口。Lua 三參 `drawDeck(gid, uid, name)` 共用團務牌池，一參 `drawDeck(name)` 仍只抽公共牌堆。

數字範圍可寫起點、終點和可選的正整數步長；起終點反寫會交換，僅寫一個數表示從 0 到該數，最多 10000 張。群成員生成要求當前適配器賬號線上且成員快取可用，不會改用另一個機器人補查。空快取會請求當前賬號重新整理並提示重試，不建立空牌堆；去重後每人一張，暱稱僅儲存快照，不跟隨更名。OneBot 直接使用已有成員快取和姓名索引，不逐人聯網取名。生成牌面按字面文本儲存，暱稱中的 `::份数::` 或 `{模板}` 不會被執行，偽造的 CQ 程式碼及分頁控制字元會中和。兩種生成方式仍遵守開團、GM / 群管 / 骰主許可權和原有儲存失敗保護。

## 預設牌堆 `.deck set`

```
.deck set 塔罗牌    → 设为本群默认牌堆（需群管理），之后直接 .draw 即可
.deck default       → 查看当前默认牌堆
.deck clr           → 清除默认牌堆
```

## 牌堆檔案

牌堆是 JSON 檔案（`{"牌堆名": ["卡面1", "卡面2", …]}`，一個檔案可含多個牌堆），從兩個目錄載入：

| 目錄 | 用途 |
|------|------|
| `decks/` | 隨安裝包分發的內建/示例牌堆（升級時會被替換） |
| `data/decks/` | 使用者自己的牌堆（上傳/手動放置都在這裡，升級不受影響） |

同名牌堆以 `data/decks/` 的為準。手動放入檔案後，在管理面板點「過載」或重啟即可生效。

### WebUI 上傳與編輯

在 [Web 管理面板](/zh-hant/manage/dashboard) 的「牌堆管理」頁可以：

- **上傳** `.json` 牌堆或海豹佈局 `.deck` 包，JSON 儲存到 `data/decks/`，圖片按檔名歸檔到 `data/images/deck/` 並重載；
- 左側選擇檔案、右側檢視該檔案的各牌堆條目；分頁支援點選頁碼與輸入跳頁。
- 使用者檔案可**線上編輯、下載或刪除**；內建檔案由面板與服務端共同限制為只讀，不能直接覆蓋或刪除。兩種來源即使檔名相同，也分別標識，不會讀寫錯檔案。
- 內建檔案可下載留存，也可把公開、非空的單個牌堆**複製為使用者牌堆檔案**後再編輯；保留該條目的卡面原文，但不復制整個合集、其他子牌堆或合集後設資料。引用仍依賴已載入的原牌堆；若需獨立分發，應另外核對依賴。
- 檢視牌堆的 `_title`、`_author` 等後設資料；
- 一鍵**過載**所有牌堆目錄（新增/修改/刪除的檔案都會反映）。

編輯條目時保留原始權重、引用、多行文本及未知擴展欄位，未儲存切換會提示。空物件讀取導致“無法讀取這個牌堆”的問題已修復；真正載入失敗時會顯示錯誤並允許重試，不把空內容當成已載入成功。

### `.deck` 牌堆包 {#deck-牌堆包}

「連同資源下載」會收集本地圖片，以及能靜態定位來源的已載入跨檔案牌堆依賴，生成 `.deck` ZIP。沒有本地依賴時仍下載 JSON。

包內 JSON 和 `assets/` 直接放在根目錄，**不要再套一層資料夾**，圖片引用為 `./assets/…`。權重、轉義和巢狀 `sample` 原樣保留，匯出時不抽牌、不執行模板或插件；Next 專有文本語法不保證在其他引擎中語義等價。

遠端圖片不自動下載；本地依賴缺失時會明確報錯，不匯出殘缺包。動態拼接的牌堆名或圖片路徑無法保證全部收集，請自行核對。

匯入時會先校驗包內容，再確認覆蓋；每個 JSON 牌堆的圖片集中放入 `data/images/deck/<该文件名>/`，保留子目錄。未被靜態引用的附帶圖片歸到首個牌堆並顯示提醒。不能包含指令碼、越界路徑、符號連結、加密內容或大小寫衝突的重名檔案。

上傳包不超過 128 MiB，單檔案不超過 128 MiB，解壓及歸檔後的圖片不超過 512 MiB / 10000 個，最多 100 個 JSON 牌堆；超過限制請拆分。

單獨整理或引用圖片，使用 [檔案管理](/zh-hant/manage/files)。

`.deck` 聊天列表預設隱藏 `_` 開頭的後設資料鍵（可在[系統設定](/zh-hant/manage/settings)關閉該隱藏）。

### 舊版牌堆相容

- 支援以下**原版 Dice! 牌堆格式**語法：子牌堆引用 `{牌堆}`（不放回）、`{%牌堆}`（放回）、骰子表示式 `[1d6]`、權重 `::N::卡面`、轉義 `\{` `\[`。
- 使用[資料遷移](/zh-hant/guide/migration)從原版 Dice! 升級時，`PublicDeck/` 目錄下的外接牌堆會自動校驗並匯入到 `data/decks/`。
- 牌堆檔案需為 **UTF-8 編碼**的 JSON；舊版遺留的 GBK 編碼檔案請先轉成 UTF-8 再放入。中文檔名沒有問題。

卡面可巢狀 `sample / case / grade / ran / len / expired / var / at / print / wait` 等[安全文本函式](/zh-hant/develop/lua-mod#安全文本函式)，支援 `[1d{ran:6~6}]` 這類顯式計算；變數以當前訊息上下文為準。只有選中的分支會抽牌、擲骰或登記等待，區域性變數與不放回子牌池在一次展開內複用；一輪渲染使用同一份牌堆目錄快照。

原有圖片 / CQ 碼、權重及 `\{` / `\[` 轉義繼續保留。暱稱、捕獲文本和其他執行時欄位不會再次解析，即使包含 `{牌堆}`、`[1d100]` 或 `{wait:1000}`。從成員生成的快照牌面仍完全按字面展示，不因為新增模板能力執行成員暱稱中的程式碼。

::: tip 牌堆裡引用幫助詞條
卡面中的 `{引用}` 若不是牌堆名，會嘗試查同名**幫助詞條**並展開其內容（溯洄 / OneDice 引用語義），可以和幫助文件配合做出複雜的抽取結構。參見[幫助系統](/zh-hant/use/help)。
:::
