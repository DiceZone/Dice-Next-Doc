# 角色卡管理

Dice!Next 內建完整的人物卡系統，支援多角色卡、隨機生成、卡片鎖定、群名片同步與檢定統計。

## 指令總覽

| 指令 | 說明 |
|------|------|
| `.st` | 錄入 / 修改 / 檢視屬性 |
| `.pc` | 多角色卡管理（新建/繫結/複製/匯出/生成/鎖定/刪除） |
| `.en` | 技能成長（詳見[擲骰與檢定](/zh-hant/use/dice)） |
| `.nn` | 設定在骰子中的暱稱 |
| `.nnn` | 隨機改名（抽隨機姓名並設為暱稱） |
| `.sn` | 按模板設定自己的群名片 |
| `.setsn` | 設定本群名片顯示哪些屬性 |
| `.hiy` | 檢定統計 |

## `.st` 錄入屬性

```
.st 力量50 敏捷60 hp12/12     → 录入属性，hp/san/mp 可写「当前/上限」
.st hp-2                       → 增减（支持骰子表达式，如 san+1d3）
.st show                       → 查看当前角色卡
.st show 60                    → 只看 ≥60 的属性
.st show 力量 敏捷             → 只看指定的几项
.st del 力量                   → 删除某属性
.st clr                        → 清空角色卡（含关联属性/公式/武器/上限）
.st export                     → 导出为可直接 .st 重新导入的一行文本
.st fmt                        → 按同义词表归一属性名（转卡）
```

支援中英文與常見別名自動歸一（如「計算機 / 電腦 / 計算機使用」識別為同一技能）。

### 武器與傷害加值

```
.st &手枪=1d10+2   → 绑定武器「手枪」，之后 .r 手枪 直接掷伤害
.st db=1d4         → 手动录入伤害加值（存公式原文，不会摇成数字）
```

`db`（傷害加值）是**公式屬性**：錄入的是投擲公式，擲骰時才展開（`.r 1d3+db`）。未手動錄入時，錄卡後會按 COC7 規則由「力量+體型」查表**自動計算**並在回執中提示；手動錄入的值優先保留。

### 關聯屬性（表示式聯動）

```
.st 物防=敏捷+1     → 物防始终等于「敏捷+1」，敏捷变了它跟着变
.st pd='dex+1'     → 英文属性引用需加引号
```

關聯屬性存的是表示式，讀取（檢定、`.st show`）時按當前引用屬性求值，顯示為「物防=敏捷+1(=61)」。

### 自動卡面重算

開啟自動卡面（預設開，僅 COC 模式）後，修改 體質 / 體型 / 意志 等基礎屬性時，HP / MP 會**按上限變化的差值**同步當前值（例如 4/13 → 體質提升後 6/15，而非重置為滿），並附帶一行「（自動卡面）因 … 變化，已自動重新計算」的提示。

SAN 的初始值等於意志（與原版 Dice! 一致）；99−克蘇魯神話只是上限，神話提升時 SAN 只有超出新上限的部分會被壓回上限，不會按差值扣減。卡上尚未錄入 SAN 時，`.sc` 也按意志進行檢定，檢定後寫入人物卡。

## `.pc` 多角色卡

### BDC 雲人物卡

雲端人物卡與賬號授權統一在 `.cloud` 下，完整說明見[雲服務與身份繫結](/zh-hant/use/cloud)。以下為常用幾條：

```text
.cloud auth [write] // 申请账号中心授权，默认只读，加 write 同时申请写入
.cloud confirm // 在网页输入验证码同意后，回到私聊确认
.cloud list // 查看云端人物卡
.cloud pull <云卡ID> [本地卡名] // 拉取云卡到本地
.cloud push <本地卡名> // 首次上传本地卡
.cloud sync <本地卡名> // 按上次同步的版本提交
```

所有 `.cloud` 指令都只能在私聊中使用。拉取後在跑團群用 `.pc tag <本地卡名>` 繫結，`.st`、`.ra`、`.sc` 繼續讀寫本地卡；同步是手動的，普通擲骰不髮網絡請求。

目前 BDC 裝置授權只返回短期令牌，因此過期或骰子重啟後需重新授權，但本地卡、
同步對應關係仍保留。完全撤銷請到賬號中心“已授權應用”操作。
首上傳超時後建議先 `list` 確認是否已建立，避免重複上傳。

### 本地多卡操作

```
.pc new 张三       → 新建角色卡「张三」
.pc tag 张三       → 在本群绑定使用「张三」
.pc rename 李四    → 给当前卡更名（原版别名：.pc nn 李四）
.pc untag          → 解除当前绑定（卡片仍保留）
.pc list           → 列出我的角色卡
.pc del 张三       → 删除
.pc @某人          → 查看对方的角色卡
.pc stat 侦查      → 查看当前卡的检定统计
.pc cpy 备份=张三  → 把「张三」复制成「备份」（也可写 .pc copy）
.pc cpy 备份       → 把当前绑定卡复制成「备份」
.pc grp            → 查看各群当前绑定的卡
.pc tojson [卡名]  → 导出指定卡或当前卡的 JSON
.pc type [规则]    → 查看 / 切换本群规则系统
.pc temp           → 列出可用于 build 的卡片模板
```

繫結角色卡後，擲骰暱稱會自動顯示為該卡名。`.pc type` 複用 Dice!Next 的本群規則系統，不另外維護一套容易漂移的“卡型別”；複製語法中的等號兩側順序為 `目标卡=来源卡`。

### `.pc build` 隨機生成

```
.pc build          → 按 COC7 模板随机生成人物卡（已有值的属性跳过）
.pc build pc:bg    → 冒号分隔连用多个模板（pc=COC7 属性，bg=背景）
.pc redo           → 先清空当前卡再重新生成
```

模板可自訂：把 JSON 模板放進 `card-templates/`（或 `data/card-templates/`）目錄並重啟骰娘，即可追加新的生成引數，支援骰點公式、牌堆抽取文本與 JS 表示式（暫不支援隨[規則包](/zh-hant/develop/rulepack)分發，需手動放置）。

### `.pc lock` 卡片鎖定

```
.pc lock w         → 锁定写入（.st 等修改一律拒绝）
.pc lock r         → 锁定查看
.pc unlock w       → 解锁
```

適合守秘人要求「鎖卡」的場合，防止跑團中途改卡。

## `.npc` NPC 群共享角色卡

`.pc` 管理的是「你個人」的角色卡；`.npc` 管理的是**整個群共享**的 NPC 角色卡，供守秘人給 NPC 建卡、代擲。僅能在群聊中使用。

```
.npc new 老猎人           → 新建 NPC「老猎人」
.npc list                → 列出本群所有 NPC
.npc 老猎人 st 力量50 敏捷60 → 给 NPC 录属性（语法同 .st）
.npc 老猎人 ra 侦查        → 以「老猎人」的身份代掷侦查检定
.npc show 老猎人          → 查看该 NPC 的角色卡
.npc del 老猎人           → 删除 NPC 及其角色卡
.npc clr 老猎人           → 清空该 NPC 的属性（保留 NPC）
```

`.npc <名> <子指令>` 會以該 NPC 的身份執行子指令（如 `st` 錄卡、`ra`/`rc` 代骰），回覆前會標註 `【NPC：老猎人】`。代骰過程中不能再巢狀呼叫 `.npc`。

## `.nn` / `.nnn` 暱稱

```
.nn 阿强           → 设置骰子内昵称为「阿强」
.nn                → 清除昵称
.nnn               → 随机起名并设为昵称（随机中/英/日姓名）
.nnn jp            → 指定日文姓名（可选 cn / en / jp）
```

已繫結角色卡時，`.nn` / `.nnn` 會同時把繫結卡更名，保持兩處名字一致。

## 群名片 `.sn` / `.setsn`

QQ 官方不能修改真實群名片，因此執行 `.sn` 或 `/sn` 後，當前人物卡狀態會顯示在之後回覆的頂部；`.sn off` 關閉自己的狀態行。骰主可在**基礎設定 → 回覆與顯示 → QQ 官方 SN 狀態行**選擇彩色文字（預設紅色，可用色盤或取色器改色）、引用、普通文字、自訂格式，或關閉顯示；關閉不刪除玩家的模板，重新開啟後恢復。支援全域性、分適配器型別和分賬號設定。其他支援的平臺仍修改真實群名片。若要把 HP、SAN 等數值插入指定文案位置，可使用[擲骰文本中的動態狀態條](/zh-hant/manage/commands#在擲骰回覆中顯示人物卡狀態)。

```
.setsn hp san dex  → 设置本群名片显示这几项（需群管理）
.sn                → 按群模板更新自己的群名片
.sn {nick} SAN{san} → 设置个人状态内容
.sn auto           → 开启自动同步：属性变化时即时更新群名片
.sn auto off       → 关闭自动同步
.sn off            → 清除
```

`hp` / `san` / `mp` 會自動按 COC 規則推導上限並顯示為「當前/上限」。

## 檢定統計 `.hiy`

```
.hiy               → 查看总体检定统计
.hiy 侦查          → 查看某技能的出目次数 / 成功率 / 等级分布
```
