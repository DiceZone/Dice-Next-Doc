# 團務管理（.game）

`.game` 是移植自原版 Dice! 的團務系統：在群裡「開團」建立遊戲領域，管理 GM 與玩家名單、團變數，以及防刷點的輪盤骰。所有團務指令僅在**群聊**中可用。

## 指令總覽

| 指令 | 說明 |
|------|------|
| `.game new [团名]` | 開團（需群管理，開團者自動成為 GM） |
| `.game join` / `.game exit` | 玩家上桌 / 退出 |
| `.game master` | 自任 GM，或（已是 GM 時）列出 GM 名單 |
| `.game state` | 檢視團狀態（GM / 玩家名單 / 團變數） |
| `.game set <变量> <值>` | 設定團變數（GM） |
| `.game call` | @ 全體玩家點名（GM） |
| `.game kick <QQ>` | 把玩家踢下桌（GM） |
| `.game close` / `.game open` | 暫時關閉 / 重新展開遊戲領域 |
| `.game over` | 結團（清空全部團資料） |
| `.game rou 面数[*份数]` | 啟用輪盤骰（GM），另有 `rou hist/reset/clr` |

不帶引數的 `.game` 會顯示幫助。

## 開團與名單

```
.game new 迷雾之城     → 开团（不填团名会自动生成一个）
.game join             → 玩家报名上桌
.game master           → 申请成为 GM / 查看 GM 名单
.game state            → 团状态一览
.game kick 10001       → GM 踢人下桌
.game exit             → 自己退出（GM 退出也用这条）
```

- 開團需要**群管理許可權**；開新團會清掉本群舊團的資料。
- 首個 GM 之外再添 GM 需要群主 / 群管理 / 骰主確認（復刻原版許可權規則）。

## 團變數

GM 可以給這一團記錄任意鍵值（如章節、天氣、時間線）：

```
.game set 章节 第三章   → 设置团变量（也可写 .game set 章节=第三章）
.game set 章节          → 查看单个变量
.game state             → 团状态会列出全部变量
```

團變數與 Lua 模組的 `msg.game` / GameTable 資料互通，模組可以直接讀寫同一份團資料。

## 暫關與結團

```
.game close            → 暂时关闭游戏领域（保留名单与变量）
.game open             → 重新展开
.game over             → 结团，清空全部团数据
```

若本群還有進行中的[跑團日誌](/zh-hant/use/log)，`.game over` 會提醒你用 `.log end` 結束記錄。

## 輪盤骰 `.game rou`

輪盤骰用於防止「重骰刷點」：GM 為某個面數啟用後，本群的 `1dN` / `dN` 單骰擲骰改為**袋中不放回抽取**——把 1..N 各放一份（或多份）進袋子，抽一個少一個，抽空自動重填。

```
.game rou 20           → 为 d20 启用轮盘骰（袋中 1~20 各 1 份）
.game rou 6*3          → 为 d6 启用，1~6 各 3 份（面数×份数最多 100）
.game rou hist         → 查看本轮已抽出的点数记录
.game rou reset        → 复原袋子（清空抽取记录，重新装满）
.game rou clr          → 清除轮盘骰，恢复普通掷骰
```

啟用 / 復原 / 清除均需 GM；輪盤只攔截**單骰單輪**的 `1dN` 擲骰，其它表示式不受影響。遊戲領域關閉（`.game close`）期間輪盤也隨之停用。
