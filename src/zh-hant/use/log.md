# 跑團記錄（Log）

Dice!Next 可記錄群內跑團過程，結束時整理上傳到日誌站併發送群檔案，方便回顧與歸檔。

## 指令總覽

| 指令 | 說明 |
|------|------|
| `.log new [名称]` | 新建並開始記錄 |
| `.log on` / `.log off` | 繼續 / 暫停記錄 |
| `.log end` | 結束記錄，上傳取連結併發群檔案 |
| `.log halt` | 強行結束本次記錄（不上傳） |
| `.log list [页码]` | 本群日誌列表（分頁） |
| `.log get [名称]` | 重新上傳某份日誌並取回放連結 |
| `.log del <名称>` | 刪除日誌 |
| `.log stat [名称]` | 統計（條數 / 參與者 / 時段 / 發言最多） |
| `.log export [名称]` | 只把日誌發到群檔案（不上傳日誌站） |
| `.log type txt/html` | 設定群檔案格式（群管以上） |
| `.log time` / `.log timer` | 跑團計時 |
| `.log masterget <群号> [名称]` | 骰主跨群取某群日誌的連結 |
| `.log` | 檢視當前記錄狀態 |

省略名稱的子指令預設操作本群最近一份日誌。

## 使用流程

```
.log new 第一章     → 开始记录
…正常跑团…
.log off            → 中途暂停（休息）
.log on             → 回来继续（回复会引用暂停处的消息，方便定位）
.log end            → 结束，上传并发群文件
```

同一群同時只能有一份進行中的日誌；跑崩了不想留檔可用 `.log halt` 直接掐掉。

## 記錄內容

記錄是否進行由**群總開關、日誌功能開關和日誌會話狀態**共同決定。`.bot off` 或 `.bot log off` 會停止記錄與計時並保留會話；重新開啟後，原本進行中的日誌繼續記錄，手動 `.log off` 暫停的日誌不會自動恢復。關閉期間的訊息不會事後補錄，徹底停用和黑名單等限制仍有效。

- 保留髮言、擲骰結果和圖片地址。開啟[日誌圖片儲存](/zh-hant/manage/settings#圖片相關)後，圖片可快取到本地，匯出 HTML 時內嵌。
- 結束時自動上傳日誌站，返回可分享的回放連結；同時把日誌作為**群檔案**傳送。
- 群檔案格式由 `.log type` 決定：`txt` 純文本（預設）或 `html` 自包含網頁（含內嵌圖片，可直接離線開啟）。

### QQ 官方 SN 狀態行

QQ 官方回覆頂部的 `.sn` 狀態行只是名片的替代展示，每條回覆都會重複，因此**不寫入跑團日誌**；日誌只記錄回覆正文。聊天窗與 `.link` 轉發仍顯示完整回覆。

### QQ 官方表情

- 自訂表情按圖片記錄官方附件地址，TXT、CSV 與日誌站上傳中的圖片引用使用標準 CQ 碼，如 `[CQ:image,file=https://…]`。
- QQ 自帶表情在文本記錄中顯示為 `[表情]`，暫不按表情 ID 推斷名稱。
- 舊記錄中的 `<faceType=…>` 標記會在匯出時相容轉換；自訂表情只有在記錄保留了圖片地址時才能恢復原圖，沒有地址的顯示為 `[图片]`。
- 日誌站開啟“表情圖片過濾”後，也會過濾舊版 `<faceType=…>` 標記及其 HTML 轉義形式，關閉過濾時保留原文。

## 只記日誌

由群管理員配置功能開關，再按原有日誌許可權啟動記錄：

```text
.bot on
.bot log on
.bot roll off
.bot reply off
.bot plugin off
.log new 第一章
```

之後用 `.log off/on` 暫停或繼續，`.log end` 結束。恢復正常使用時，按需要重新開啟 `roll`、`reply`、`plugin`。AI、歡迎語、轉發及自動化有各自開關，如不需要也請關閉；上述配置不會停用全部管理或娛樂指令。

## 跑團計時

```
.log timer on/off   → 开关本群跑团计时
.log time           → 查看当前记录的累计时长
```

開啟後，`.log new/on/off/end` 會自動開始 / 暫停 / 累計本次跑團時長。

## 日誌站上傳

- 預設上傳到官方日誌站 `log-api.dice.zone`，預設使用 **DiceNext 專屬 zstd JSON 協議**；已有安裝保留此前儲存的協議選擇。
- 地址與協議在[系統設定 → 雲服務 → 日誌站](/zh-hant/manage/cloud-services#日誌站)修改。`dice/logsite_format` 可選 `dicenext`（預設）、`seal`（SealDice V1）、`seal_v105`（Parquet）或 `legacy`（舊版多段 txt POST）；連線自建站時須選擇該站支援的協議。
- 上傳目標**不是官方站**時，回覆連結會附加提示「當前配置的日誌站並非官方站點，連結安全性請自行確認」。

## Web 管理

### 平臺檔案傳送差異

`.log export` 只匯出檔案，不上傳日誌站。OneBot / Milky 的群檔案能力取決於所連線的協議端；QQ 官方機器人已接入富媒體檔案通道，但檔案傳送仍受賬號許可權、平臺限制及上傳結果影響，不能把本地匯出成功等同於平臺已收到檔案。

遇到平臺拒絕或收不到檔案，可用 `.log get` 上傳並取回放連結，或從下方 Web 管理下載。QQ 官方的介面接入與真實憑據下端到端驗收是兩回事，詳見[適配器配置](/zh-hant/config/adapter#qq-官方機器人能力邊界)。

### 面板下載與管理

在 Web 管理面板的 **資料管理 → 跑團記錄 → 日誌管理** 中可以：

- 檢視全部群的歷史記錄（名稱 / 建立人 / 起止時間 / 條數 / 佔用空間），並按任一列排序
- 佔用空間包含日誌資料庫中實際儲存的內容與 `data/logs/images` 中該日誌的本地圖片；圖片容量會單獨標出
- 匯出 TXT 或 Excel（CSV），下載 HTML 網頁版
- 手動上傳到日誌站取連結，或在樣式化二次確認後刪除記錄；刪除會一併清理日誌訊息與本地快取圖片

面板的群組管理還提供**群檔案檢視與下載**，跑團發出的日誌群檔案也能在這裡直接取回。
