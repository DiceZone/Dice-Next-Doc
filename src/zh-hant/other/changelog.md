- BRP 檢定（`.ba`）與抵抗表對抗（`.bav`）
- DND：`.setdnd` 模式、d20 檢定、先攻、法術位（`.ss/.cast/.longrest`）、臨時加值（`.buff`）
- COC / DND 制卡、`.pc build` 按模板生成
- 規則速查（COC / DND，可擴充）
- 免空格黏著指令（`.ra侦查`、`.rapass23` 等）、`.rd` 預設骰掛鉤

### 角色卡
- 屬性錄入與別名識別、多角色卡、群名片同步、檢定統計
- 傷害加值（DB）公式錄入：`.st db=1d4` 存投擲公式不搖，擲骰時 `.r 1d4+db` 自動展開；也可按力量+體型查表自動計算
- 關聯屬性：`.st 物防=敏捷+1` 存表示式聯動求值
- 卡片鎖定（`.pc lock`）、自訂卡模板（可隨規則包分發）
- HP / SAN 上限變化時按差值同步當前值，自動重算有清晰提示

### 團務
- `.game` 團務系統（原版全子指令）：開團 / 重開 / GM / 團變數 / 點名 / 踢人 / 暫關 / 結團
- 輪盤骰 `.game rou`（不放回抽取防刷點，含歷史 / 重置）
- 團資料與 Lua 模組 `msg.game` 同源互通

### 娛樂
- 今日 / 明日 / 昨日人品、隨機姓名（預設每名隨機中/英/日）、休息、好感度系統
- 第三人稱動作 `.me`、抉擇分歧 `.ak`、隨機改名 `.nnn`

### 牌堆
- 相容原版牌堆、內聯隨機、執行時臨時牌堆、預設牌堆

### 擴展與插件
- 規則包系統：可匯入規則包（屬性模板 / 同義詞 / 規則速查 / 幫助 / 指令碼），群內切換
- Lua 模組子系統：相容原版 Dice! mod（人物卡模板、規則書、因果回覆、好感、背包）
- JS 插件子系統：相容海豹 SealDice 插件
- 統一幫助系統：內建指令 / 規則 / 插件三源合併，可分頁檢索

### 跑團記錄
- 記錄開關及查詢 / 統計 / 刪除 / 匯出全套子指令、TXT / Excel / HTML 匯出
- 日誌站上傳相容 SealDice V1 協議，站點地址可自選（非官方站有提示）
- 心理學暗骰 `.rx`（守秘人對調查員暗檢定，私聊出結果 + 群內回執）
- 跨視窗訊息轉發 `.link`（雙向 / 單向連結兩個聊天視窗）

### 許可權與通知
- 信任等級體系（0-255 階梯，`.trust` / `.admin` 指令，語義與原版一致）
- 賬號別名合併 `.alias`（別名賬號許可權按主號計算）
- 骰主通知系統：`.notice` 註冊通知視窗，網頁可逐項勾選 14 類事件（例行 / 重要 / 關鍵 / 錯誤）
- SMTP 郵件 / Webhook 第三方推送（帶傳送測試）
- 審計日誌：許可權變更 / 審批 / 執行報錯全記錄，網頁可查

### AI（可選，預設關閉）
- AI 閘道器：多模型管理、全域性請求引數，相容 OpenAI 介面
- 擲骰回覆潤色：按骰娘人設改寫文風，帶數字保留校驗（骰點絕不會被改錯）
- AI 翻譯：配合 `.lang` 自訂語言，傳送前自動翻譯
- 對話回覆：@ / 關鍵詞 / 待機機率觸發，冷卻與群上下文；分群開關 `.ai on/off` + 白名單模式
- 短期記憶（群聊滾動摘要）與長期記憶（向量檢索人物卡 / 劇情事實）
- 工具呼叫：AI 擲骰走真實引擎、可抽牌 / 查卡 / 執行指令
- NPC 扮演：按劇本設定演出，限定群與觸發詞
- 影像識別（多模態）、禁 emoji 選項
- AI 呼叫並行化，慢響應不阻塞普通指令

### 群管理與系統
- 群開關、外接模式、單群 / 全域性指令停用、許可權分級
- 入群歡迎（延遲合併防刷屏）、退群、留言、旁觀、黑白名單
- 好友 / 加群邀請審批策略（關鍵詞 / 等級門檻）、強拉退群、群名關鍵詞退群、黑名單自動退群
- 群自動化：按訊息關鍵字自動審批 / 踢人 / 禁言（`.group auto`）
- 骰娘探測：識別群內其它骰子並 @ 靜默，預設回覆不以指令開頭，防跨骰誤觸發與迴圈
- 聊天記錄持久化（撤回標註、保留期可配），網頁模擬聊天支援頭像 / 圖片 / 表情包 / 戳一戳 / 群名片
- 多語言新增日本語，支援使用者自訂語言包（放入 i18n 目錄自動載入）
- 名稱變數細分：QQ 暱稱 / 群名片 / 人物卡名獨立變數，包裹符號可控
- 定時任務（每個任務獨立開關 / 線上編輯）：可設觸發條件做「因果」，如 `inactive>=7` 表示本群 7 天無指令；動作支援傳送訊息或退群（例「閒置 7 天自動退群」），內容支援 `{group}` `{date}` `{roll:..}` `{draw:..}` 等變數/函式
- 關鍵詞自訂回覆（多條件、隨機結果、動態指令 `{roll}` `{draw}` `{api}` 等）
- 低程式碼「因果」規則：視覺化「條件（匹配 / 過濾 / 冷卻 / 計數器）→ 動作（回覆 / 改計數 / 調 API）」，無需寫指令碼
- 骰娘人格：多套命名文案，在「指令列表」頁選人格即可直接編輯該人格的回覆文案；支援新建 / 複製 / 編輯 / 刪除 / 設為預設
- 原版趣味文案「風味」層：可疊加原版 Dice! 的文案風格
- 長訊息合併轉發（`.coc 5` 多結果 / 過長幫助以聊天記錄形式傳送，可開關）

- 人物卡、玩家檔案（含好感）、黑名單、自訂回覆、幫助文案、Master

- 儀表盤、適配器管理、規則管理、回覆管理、牌堆管理

- 許可權設定、通知設定、AI、擴展管理（Lua / JS 分選項卡）、幫助文件、測試臺
- 面板登入密碼（Cookie 認證）、執行 IP / 埠線上修改、系統托盤、開機自啟、啟動隱藏控制台

- 崩潰自診斷：異常自動落盤 `data/logs/crash_*.txt`，附啟動階段標記，方便報障
