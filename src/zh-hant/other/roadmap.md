# 開發計劃

## 已實現 · 文案編輯器與 Markdown 遷移（2026-11-04，待發布）

- 文案編輯彈窗：
  - 編輯與預覽左右並排，各自滾動；窄屏用切換按鈕。
  - 新增 Markdown 格式工具欄，選中文字即可加粗、引用、加列表，支援 Ctrl/⌘+B、I。
  - 移除逐個變數的樣式設定。
  - 「載入預設」選單合併原來的預設選擇器與還原按鈕。
- 新文案預設 Markdown。純文本文案可逐條一鍵轉換，也可在指令列表按語言與人格批次轉換。轉換時模板語法原樣保留，只轉義會觸發格式的字元，顯示效果不變。
- 高階視覺預設與標準文案去掉全部 emoji，改用粗體標題與引用塊。只使用 QQ 官方文件列出的語法，並新增測試防止 emoji 再出現。
- 檢定等級、對抗結果、心理學回執、好感稱號等嵌入文案設為 Markdown 後保留樣式，編輯預覽同步顯示。
- `.r` 展開過程按原算式保留括號與負號，例如 `5-(-1)` 不再顯示為 `5--1`。

- 檢定與屬性修改共用運算模組：修復多級修正只算第一項，支援乘除、乘方、括號、擲骰、多個屬性與常用函式；`.st` 加減值整段計算。

## 釋出候選 · MCP 服務端首版

- 預設關閉、迴環直連優先，提供真實數學擲骰、幫助搜尋、非敏感執行狀態和按具體卡片授權的只讀查詢。
- 獨立 Bearer 憑據，明文僅建立／輪換時展示，支援許可權調整、顯式續期和立即撤銷；編輯許可權不延長有效期，不復用 BDC 金鑰或瀏覽器登入態。
- 面板提供連線指引、授權管理和按客戶端／結果篩選的服務端分頁記錄；保留 Host／Origin 校驗、鎖讀、請求限流、工作量與整數溢位保護，卡片失效不阻止停用授權。
- 管理寫入補充跨站防護與原子儲存；審計故障不丟失已生成憑據。超時可核對操作狀態，不自動重試；工具與管理佇列隔離，撤銷會丟棄在途查詢結果。
- 異常恢復須成功回讀當前配置後才解除操作鎖；補充單憑據併發上限、執行期限及退出協作取消。恢復配置／主資料庫後舊金鑰失效，保留授權範圍供核對，重新生成後才能啟用；資源單獨恢復不受影響。
- 加入官方 MCP SDK／Inspector 的舊版與新版協議聯調，經臨時證書驗證的 HTTPS 字首反代執行，納入 Windows／Linux CI 測試，不關閉 TLS 校驗。
- 增加不執行工具的本機連線自檢；授權頁面補齊已選卡片名稱、所屬使用者和失效狀態，按伺服器時鐘判斷到期，並展示保留審計中的最近成功呼叫。
- 增加隔離 Chromium 頁面互動迴歸；macOS 打包任務補充 HTTP 與官方客戶端 HTTPS 互通檢查，實際 macOS 結果待工作流執行驗證。
- 不開放發訊息、改設定、任意指令／插件或卡片公式執行，不增加使用者執行時依賴。詳見 [MCP 服務](/zh-hant/manage/mcp)。

## 釋出候選 · 內建登入（OpenOPQ，實驗性）

- 平臺連線新增內建登入，在面板填寫 QQ 號與有效 BDC 骰娘 API Key 後，下載並管理協議端、顯示二維碼與下載進度；V1 / V2 同步支援。
- 協議端不隨安裝包分發，執行前校驗清單簽名、檔案大小與 SHA-256；異常清單不執行。管理介面使用本機迴環，普通 OneBot 的配置和重連策略不變。
- 此功能需要中心提供對應系統的協議端與簽名服務，仍為實驗性功能。具體操作及邊界見[內建登入](/zh-hant/manage/adapter-manager#內建登入-openopq-實驗性)。

- **已儲存備份恢復**：備份列表新增“恢復”操作，可直接選取手動或自動儲存的 ZIP 校驗並暫存；重啟主程式後應用恢復，恢復前的資料仍會保留為回滾副本。

### 2026-07-28 · builds 727–752

- **Windows 發行管理器**：Windows 包改為頂層 `dice-next.exe` 管理器、`app/dice-next-core.exe` 服務核心和集中式 `lib/` 執行庫。管理器不依賴包內 DLL，直接雙擊即可啟動 core 並繼承控制台日誌；更新時會複製出臨時維護器，待原程序退出後替換包括 `dice-next.exe` 自身在內的完整程式檔案，生成回滾目錄。設定 `DICENEXT_UPDATE_RESTART=NO` 後，更新完成只退出，不會自行重啟 core，適配 MCSM 等程序託管面板。
