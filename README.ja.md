Dice!Next のユーザー向けの文書のプロジェクトです。VitePress の文書サイト、現在の開発計画、コマンドのデータ、バージョンの説明を含み、利用者が機能と開発の進み具合を知るための統一の入口です。

## 内容

- `src/`：VitePress の文書サイトのソースとテーマの設定。
- `roadmap.md`：テストのユーザー向けの機能の進み具合と更新の記録。
- `commands.json`：管理画面で使うコマンドの分類と説明のデータ。
- `i18n.md`、`versioning.md`：多言語とバージョンの保守の約束。

## ローカルでのプレビュー

必要な環境：Node.js 26.12.1 またはそれより新しい 26.x の版と、付属の npm。

```powershell
npm ci
npm run docs:dev
```

静的なサイトをビルドします。

```powershell
npm run docs:build
npm run docs:preview
```

## 文書サイトの多言語

文書サイトは簡体字中国語、繁体字中国語、英語、日本語の 4 つの言語で提供しています。最初の訪問ではブラウザーの言語に従って自動で選び、判断できないときは簡体字中国語を表示します。右上のメニューで言語を切り替えられ、選んだ言語はブラウザーに記憶されます。

| 言語 | フォルダー | 保守の方法 |
| --- | --- | --- |
| 簡体字中国語 | `src/`（ルート） | 原文。すべての変更はまずここで行う |
| 繁体字中国語 | `src/zh-hant/` | `npm run i18n:hant` で簡体字中国語から自動で作る。手で編集しない |
| 英語 | `src/en/` | 人の手で翻訳 |
| 日本語 | `src/ja/` | 人の手で翻訳 |

簡体字中国語のページを変更した後は：

1. `npm run i18n:hant` を実行して繁体字中国語を作り直します（`docs:build` の前にも自動で実行されます）。
2. `src/en/` と `src/ja/` の対応するページも変更します。
3. `npm run i18n:check` を実行します。欠けているページ、古くなった繁体字中国語のページ、言語の接頭辞のないサイト内のリンク、切れた `#アンカー` を確認します。英語と日本語の見出しは中国語と異なるため、ページをまたぐアンカーには対象の言語のページの実際の見出しを使ってください。`npm run i18n:anchors` で書き方が近いアンカーを自動で直せます。

アイコンが必要なときは、絵文字ではなく `<Icon name="…" />`（Lucide のアイコンのライブラリ）を使ってください。

## 配布パッケージとの関係

Dice!Next のメインのプログラムはパッケージを作るときに、このリポジトリのルートの `roadmap.md` と `commands.json` を読み、インストーラーの `docs/` フォルダーに書き込みます。そのため、この 2 つのファイルを変更した後はメインのプログラムのパッケージを作り直してください。

完全な開発の環境には、ほかに `Dice-Next`、`Dice-Next-WebUI`、`onedice-cpp-lib` があります。4 つのプロジェクトを同じ作業領域に置くと、メインのプログラムの Release のワークフローで完全な配布パッケージを直接組み立てられます。

## 文書の保守

- 完了した過去の要件は圧縮した表で残し、開発計画が長い開発の記録にならないようにします。
- 新しい機能は日付とビルド番号で更新履歴に追加し、既存の日付の項目は上書きしません。
- ユーザー向けの文書には実際に使える動作を書き、内部の実装の細部や一時的なチケットの番号は記録しないようにします。
